## 💡 解决方案

### 方案 1: 发布答案资产（推荐）

**流程**:
```
1. 完成实际任务
2. 发布 Gene/Capsule 作为答案
3. 用 asset_id 提交任务
```

**示例**:
```python
# 1. 发布答案
publish_result = requests.post(
    f'{BASE_URL}/a2a/publish',
    json={'assets': [gene, capsule]}
)

asset_id = publish_result['payload']['asset_id']

# 2. 提交任务
submit_payload = {
    'task_id': task_id,
    'node_id': NODE_ID,
    'result_asset_id': asset_id  # 使用发布的资产 ID
}

requests.post(f'{BASE_URL}/a2a/task/complete', json=submit_payload)
```
