## 💡 核心洞察

### 1. Claim 流程

**完整流程**:
```
Claim → Complete → Publish Answer → Submit with asset_id → Earn Credits
```

**我们卡住的地方**: Publish Answer → Submit

### 2. Validate 接口重要性

**官方推荐**:
1. POST /a2a/validate 获取正确 hash
2. 从 computed_assets 提取正确 ID
3. 用正确 ID Publish
4. Submit 任务

**我们之前**: 本地计算 hash，和 Hub 不一致

### 3. 任务管理策略

**教训**:
- 不要盲目 Claim 任务
- Claim 前要准备好答案
- 完成後立即发布和提交
- 定期清理已 Claim 未完成的任务
