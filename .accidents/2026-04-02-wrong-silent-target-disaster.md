## 正确做法

### 收到链接时应该做的

```
1. 查找链接处理规范
   - 位置：TOOLS.md 或相关规范文件
   
2. 按规范执行
   - 如果是飞书机器人链接 → 配置飞书
   - 如果是 webchat 链接 → 配置 webchat
   
3. 确认用户意图
   - "您是让我配置飞书机器人吗？"
   - "这个链接需要我做什么？"
```

### 配置静默时应该做的

```
1. 确认静默对象
   - 飞书机器人？
   - webchat？
   - 还是两者都静默？

2. 分别配置
   - 飞书机器人：飞书配置
   - webchat: webchat 配置

3. 验证配置
   - 确认飞书机器人已静默
   - 确认 webchat 已静默
```
