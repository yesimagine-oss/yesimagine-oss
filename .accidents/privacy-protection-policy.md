# 隐私保护规范

**时间**: 2026-03-23  
**严重性**: 🔴 最高（涉及用户安全）

---

## 🔴 红线原则

**绝不在群聊中暴露：**

| 类型 | 示例 | 风险 |
|------|------|------|
| **用户 ID** | `ou_f4919832188bcc630f8f257497fa93a4` | 社工攻击 |
| **群组 ID** | `oc_55a027a0be1c6252a89177256f2210b9` | 隐私泄露 |
| **API Key** | `sk_xxx`、`ak_xxx` | 账号盗用 |
| **Token** | 各种 Token | 权限盗用 |
| **密码** | 各种密码 | 账号盗用 |
| **服务器 IP** | `47.x.x.x`、内网 IP | 服务器攻击 |
| **SSH 配置** | 端口、用户名、密钥 | 服务器入侵 |
| **数据库配置** | 连接串、账号 | 数据泄露 |
| **代理配置** | 订阅链接、节点 | 网络攻击 |

## 📋 消息分级

### 公开级（可在群聊）

**可以说的：**
- ✅ 昵称/名字（老胡、基哥）
- ✅ 公开信息（天气、新闻）
- ✅ 任务状态（已完成、进行中）
- ✅ 公开链接（官网、文档）

**示例：**
```
✅ 任务已完成
📄 文档已创建：[标题](https://xxx.feishu.cn/docx/xxx)
@老胡 请查看
```

---

### 内部级（仅限私聊）

**需要私聊的：**
- ⚠️ 配置细节
- ⚠️ 技术信息
- ⚠️ 内部链接

**示例：**
```
（私聊）
配置已完成：
- 服务器：47.104.30.181
- 端口：22
- 用户：admin
```

---

### 机密级（私聊 + 加密）

**必须加密的：**
- 🔒 API Key
- 🔒 Token
- 🔒 密码
- 🔒 密钥

**示例：**
```
（私聊）
⚠️ 敏感信息，请妥善保管

API Key: sk-xxx...
（建议用加密工具）
```

---

## 🛡️ 发送前自检

**每次发送前问自己：**

1. **这条消息能公开吗？**
   - 陌生人看到会有问题吗？
   - 竞争对手看到会有问题吗？

2. **包含敏感信息吗？**
   - 有 ID、Token、密码吗？
   - 有 IP、配置吗？

3. **应该发到哪里？**
   - 群聊还是私聊？
   - 需要加密吗？

4. **用词合适吗？**
   - 用昵称还是 ID？
   - 用公开名称还是内部名称？

---

## 🚨 事故处理

### 如果不小心暴露了敏感信息：

**立即执行：**

1. **删除消息** - 减少传播时间
2. **通知用户** - 告知风险
3. **修改密码** - 如果是密码泄露
4. **轮换密钥** - 如果是 Key 泄露
5. **记录事故** - 防止再犯

**示例：**
```
⚠️ 刚才的消息包含敏感信息，已删除
请大家不要传播
已轮换 API Key
抱歉造成困扰
```

## 📝 正确做法示例

### 场景 1：任务完成通知

❌ **错误（群里）：**
```
用户 ou_f4919832188bcc630f8f257497fa93a4 的任务已完成
API Key 已配置：sk-abc123...
服务器 47.104.30.181 已部署
```

✅ **正确（群里）：**
```
✅ 任务已完成
📄 文档已创建
详情已私聊发送
```

✅ **正确（私聊）：**
```
配置信息：
- 服务器：47.104.30.181
- API Key: sk-abc123...

请妥善保管，不要泄露
```

---

### 场景 2：@提及用户

❌ **错误（群里）：**
```
<at id="ou_f4919832188bcc630f8f257497fa93a4">老胡</at> 请查看
```

✅ **正确（群里）：**
```
@老胡 请查看
```

或（用 replyTo）：
```
（回复老胡的消息）
已完成，请查看
```

---

### 场景 3：发送链接

❌ **错误（群里）：**
```
内网地址：http://172.19.12.252:8080
服务器路径：/home/admin/project/config
```

✅ **正确（群里）：**
```
✅ 已部署完成
公网访问：http://47.104.30.181:8080
（已验证可访问）
```

## 🎯 强制执行

### 群聊中

- ✅ 只用昵称/名字
- ✅ 只说公开信息
- ✅ 敏感信息私聊
- ❌ 不说用户 ID
- ❌ 不说群组 ID
- ❌ 不说敏感配置

### 私聊中

- ✅ 可以发送敏感信息
- ✅ 用代码块包裹
- ✅ 提醒用户保密
- ✅ 必要时加密
