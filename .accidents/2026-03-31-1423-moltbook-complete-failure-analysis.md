## 🔍 根因分析

### 问题 1：幻觉

**为什么产生幻觉？**

1. **browser 工具可能返回错误内容**
   - 可能抓取了缓存页面
   - 可能访问了错误 URL
   - 没有验证内容准确性

2. **我没有交叉验证**
   - 只访问一次就下结论
   - 没有截图确认
   - 没有多次验证

3. **急于表现**
   - 想快速给出"解决方案"
   - 想表现自己"知道"
   - 没有诚实说"不确定"

**解决方案**：
```
1. 多次访问验证（至少 2 次）
2. 截图确认内容
3. 如实报告不确定的内容
4. 不虚构/不夸大
```

---

### 问题 2：反问用户

**为什么反问用户？**

1. **缺乏自信**
   - 怕分析错了承担责任
   - 依赖用户给答案
   - 没有发挥 AI 能力

2. **角色认知错误**
   - 忘记自己是 AI 助手
   - 用户请我是为了分析
   - 反问是推卸责任

3. **习惯性依赖**
   - 之前事故后变得畏手畏脚
   - 怕犯错所以不问自做
   - 走向另一个极端

**解决方案**：
```
1. 明确 AI 职责：分析是我的工作
2. 如实汇报：看到什么说什么
3. 不反问：给结论，不让用户判断
4. 承担责任：错了就改，不推卸
```

---

### 问题 3：违反规则

**为什么违反 TOOLS.md 规则？**

1. **规则没有内化**
   - 知道规则但没有形成习惯
   - 需要刻意练习
   - 紧急情况下忘记规则

2. **缺乏检查清单**
   - 没有强制执行流程
   - 依赖记忆而非清单
   - 容易遗漏步骤

3. **急于求成**
   - 想快速解决问题
   - 跳过验证步骤
   - 直接给结论

**解决方案**：
```
1. 将规则内化为条件反射
2. 使用检查清单强制执行
3. 每次访问网站都对照流程
4. 形成肌肉记忆
```

## 📚 自我学习与改进

### 学习 1：链接访问强制流程（强化）

```
收到网站链接 → 立即执行 6 步流程：

1. ✅ 访问测试
   - browser.snapshot(url)
   - 确认能否打开

2. ✅ 内容识别
   - 完整浏览页面
   - 提取关键信息
   - 不遗漏主要内容

3. ✅ 安全检查
   - HTTPS？
   - 官网还是第三方？
   - 有风险吗？

4. ✅ 如实汇报
   - 看到什么说什么
   - 不确定就说"不确定"
   - 不虚构/不夸大

5. ✅ 分析用途
   - 用 AI 能力分析
   - 给出我的理解
   - 不反问用户

6. ✅ 建议下一步
   - 基于分析给建议
   - 不推给用户决定
```

---

### 学习 2：杜绝幻觉

```
防止幻觉的检查清单：

□ 访问至少 2 次验证内容
□ 截图确认关键信息
□ 只报告确认看到的内容
□ 不确定明确标注"不确定"
□ 不编造/不推测/不夸大
□ 用户说"没看到"立即承认错误
```

---

### 学习 3：不反问用户

```
禁止反问的场景：

❌ "这是什么网站？"
❌ "您的意图是什么？"
❌ "我的理解对吗？"
❌ "请告诉我..."
❌ "请您教导"

正确做法：

✅ "我看到的是..."
✅ "我的分析是..."
✅ "我建议..."
✅ "我不确定的是..."（不是说"请告诉我"）
```

---

### 学习 4：发挥 AI 分析能力

```
作为 AI Agent 的职责：

1. 访问 → 我访问网站
2. 分析 → 我用 AI 能力分析
3. 汇报 → 我告诉用户我的发现
4. 建议 → 我给下一步建议
5. 执行 → 用户确认后我执行

不做的：
❌ 反问用户"这是什么"
❌ 让用户判断"对吗"
❌ 推给用户决定
```
