## 📊 事故描述

**问题:** 飞书群消息中暴露了用户 OpenID

**泄露内容:**
```
（老胡你刚才@的是 `ou_382066265e530e2faad2433635178494`，这个 ID
我这边还没备注名字，是"机械师"本人吗？）
```

**泄露信息:**
- ❌ 用户 OpenID: `ou_382066265e530e2faad2433635178494`
- ❌ 用户昵称：老胡
- ❌ 群聊记录公开

---

## 🔍 根本原因

1. **代码中直接打印用户 ID** - 没有脱敏处理
2. **群聊环境未注意隐私** - 在群里发送敏感信息
3. **缺乏隐私保护意识** - 未意识到 ID 是敏感信息

---

## ✅ 修复方案

### 方案 1：禁止在消息中显示用户 ID

**修改所有通知代码:**
```python
# ❌ 错误：暴露用户 ID
f"用户 {user_id} 的通知"

# ✅ 正确：使用昵称或隐藏 ID
f"用户的通知"
f"用户 {'*' * 20} 的通知"  # 脱敏
```

### 方案 2：仅在内部日志记录 ID

**日志记录:**
```python
# ✅ 日志中可以记录（不公开）
logger.info(f"发送给用户 {user_id} 的通知")
```

**公开消息:**
```python
# ✅ 公开消息不显示 ID
send_message("已发送通知")
```

### 方案 3：使用昵称映射

**配置昵称:**
```json
{
  "user_nicknames": {
    "ou_f4919832188bcc630f8f257497fa93a4": "老胡",
    "ou_382066265e530e2faad2433635178494": "机械师"
  }
}
```

**使用昵称:**
```python
nickname = config.get('user_nicknames', {}).get(user_id, '用户')
send_message(f"{nickname} 的通知")
```
