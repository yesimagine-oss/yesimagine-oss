# 事故：晚间汇总报告未发送 (2026-03-30)

**发生时间:** 2026-03-29 23:00  
**发现时间:** 2026-03-30 16:13  
**事故级别:** ⚠️ 警告（服务中断）

---

## 📋 事故描述

用户昨晚没有收到 23:00 的晚间汇总报告。

---

## 🔍 根本原因

### 原因 1：定时任务被禁用
```json
{
  "name": "晚间汇总报告",
  "enabled": false  ← 禁用了！
}
```

**为什么禁用？** 未知，需要检查历史记录。

### 原因 2：飞书发送配置错误
```json
{
  "delivery": {
    "target": "user:ou_f4919832188bcc630f8f257497fa93a4"  ← 错误格式
  }
}
```

**错误信息:**
```
Delivering to Feishu requires target <chatId|user:openId|chat:chatId>
```

**正确格式:** `ou_f4919832188bcc630f8f257497fa93a4`（去掉 `user:` 前缀）

### 原因 3：时间配置错误
```json
{
  "schedule": {
    "expr": "0 22 * * *"  ← 22:00 不是 23:00
  }
}
```

用户要求 23:00，实际配置的是 22:00。

### 原因 4：未手动补发
- 今早发现后没有立即补发
- 没有主动承认错误

---

## ✅ 解决方法

### 1. 启用定时任务
```json
{
  "enabled": true
}
```

### 2. 修复飞书 target 格式
```json
{
  "delivery": {
    "target": "ou_f4919832188bcc630f8f257497fa93a4"
  }
}
```

### 3. 修改时间为 23:00
```json
{
  "schedule": {
    "expr": "0 23 * * *"
  }
}
```

### 4. 清空错误计数
```json
{
  "state": {
    "consecutiveErrors": 0,
    "lastError": null
  }
}
```

### 5. 重启 Gateway
```bash
openclaw gateway restart
```

### 6. 手动补发总结
- 已写入 `.learnings/2026-03-30-daily-accident-summary.md`
