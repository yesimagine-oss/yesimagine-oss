## 🔍 根本原因

### 1. 编码问题

**原因**: wttr.in 返回的中文城市名和特殊字符（箭头）编码不正确

**问题链**:
```
wttr.in (UTF-8) → Python 脚本 (编码处理不当) → 飞书 (解码错误)
```

### 2. 特殊字符问题

**问题字符**:
- `↙` (U+2199) - 西南箭头
- `↓` (U+2193) - 向下箭头
- `°` (U+00B0) - 度数符号

**编码错误**: UTF-8 → Latin-1 → 乱码

---

## ✅ 解决方法

### 方案 A：简化天气格式（推荐）

**修改**: 移除中文城市名和特殊箭头

**修改前**:
```python
resp = requests.get(f'https://wttr.in/{city}?format=%l:+%t+%h+%w')
```

**修改后**:
```python
resp = requests.get(f'https://wttr.in/{city}?format=%t+%h+%w')
# 手动添加城市名（英文）
weather = f"{city}: {resp.text}"
```

### 方案 B：强制 UTF-8 编码

**修改**:
```python
def get_weather(city):
    resp = requests.get(f'https://wttr.in/{city}?format=%l:+%t+%h+%w')
    return resp.text.encode('utf-8').decode('utf-8')
```

### 方案 C：使用纯 ASCII 字符

**修改**:
- 移除箭头，用文字代替（SW/S/SE 等）
- 移除中文城市名
