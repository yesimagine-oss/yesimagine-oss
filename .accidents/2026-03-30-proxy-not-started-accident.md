## 📋 事故描述

**现象**: 每日播报测试时，代理未自动启动，导致：
- 天气获取失败
- 飞书发送失败

**用户批评**: "代理就是按需启动的设置啊，如果没有启动就是事故"

---

## 🔍 根本原因

### 1. 代理自动管理机制缺失

**问题**:
- 代理管理器（proxy-manager.py）未运行
- 外网请求前未检查代理状态
- 未实现"按需启动"功能

**预期行为**:
```
检测到外网请求 → 检查代理状态 → 未运行则自动启动 → 执行请求
```

**实际行为**:
```
检测到外网请求 → 直接请求 → 代理未运行 → 失败
```

### 2. 监控机制缺失

**问题**:
- 代理管理器未添加到 crontab
- 无后台监控进程
- 失败后无告警

## ✅ 解决方法

### 1. 立即启动代理

```bash
python3 /home/admin/.openclaw/workspace/tools/proxy-manager.py start
```

### 2. 添加到 crontab（开机自启 + 监控）

```bash
* * * * * python3 /home/admin/.openclaw/workspace/tools/proxy-manager.py monitor
```

### 3. 修改 daily-brief.py（请求前检查代理）

```python
def check_and_start_proxy():
    """检查并启动代理"""
    try:
        requests.get('http://127.0.0.1:7890', timeout=2)
        return True
    except:
        subprocess.run(['python3', 'tools/proxy-manager.py', 'start'])
        time.sleep(3)
        return True
```
