## 🎯 @提及使用方法

### 正确的@提及格式

**飞书 API 支持的@提及格式：**

```json
{
  "msg_type": "text",
  "content": {
    "text": "@老胡 在的，需要什么帮助？"
  },
  "mentions": [
    {
      "id_type": "user_id",
      "user_id": "ou_f4919832188bcc630f8f257497fa93a4"
    }
  ]
}
```

**或者使用 open_id：**

```json
{
  "msg_type": "text",
  "content": {
    "text": "<at user_id='ou_f4919832188bcc630f8f257497fa93a4'>老胡</at> 在的，需要什么帮助？"
  }
}
```

## 🛡️ 隐私保护规则

### 允许的行为

| 场景 | 做法 |
|------|------|
| **@提及用户** | ✅ 使用飞书 API 的 mentions 参数 |
| **显示蓝色提及** | ✅ 飞书自动渲染 |
| **用户收到通知** | ✅ 飞书自动推送 |

### 禁止的行为

| 场景 | 做法 |
|------|------|
| **暴露用户 ID** | ❌ 不在消息文本中显示 `ou_xxx` |
| **手动写@代码** | ❌ 不发送`<at id="xxx">`纯文本 |
| **JSON 直接发送** | ❌ 不发送 JSON 代码给群聊 |

## 🔧 代码修改要点

### message 工具调用方式

```python
# 正确方式
feishu_api.send_message(
    chat_id="oc_xxx",
```
