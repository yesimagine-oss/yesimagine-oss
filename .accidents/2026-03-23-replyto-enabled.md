## ✅ 启用的方案

**使用 replyTo 代替@提及**

### 工作原理

```
用户发消息 → 机器人 replyTo 回复 → 飞书自动通知用户
```

### 优点

| 优点 | 说明 |
|------|------|
| ✅ **不需要权限** | 飞书原生支持，无需申请 |
| ✅ **立即能用** | 现在就可以用 |
| ✅ **用户收到通知** | 飞书自动推送通知 |
| ✅ **显示正确** | 显示"回复了 XXX" |
| ✅ **不暴露 ID** | 不手动写@代码 |

### 与@提及的对比

| 功能 | @提及 | replyTo |
|------|------|---------|
| **用户收到通知** | ✅ | ✅ |
| **显示蓝色提及** | ✅ | ❌ 显示"回复了 XXX" |
| **需要权限** | ❌ 需要申请 | ✅ 不需要 |
| **立即能用** | ❌ 等审批 | ✅ 现在就能用 |
| **暴露用户 ID** | ❌ 手动写会暴露 | ✅ 不暴露 |

---

## 📋 机器人行为规范（更新）

### 回复规则

1. **被@时**
   - ✅  replyTo 回复用户的消息
   - ✅ 简洁回答（1-3 行）
   - ❌ 不手动写@代码

2. **未被@时**
   - ✅ 根据上下文判断
   - ✅  replyTo 回复相关消息
   - ❌ 不重复已回答的问题

3. **私聊通知**
   - ✅ 任务开始/完成私聊通知
   - ✅ 使用 replyTo 或@提及
   - ❌ 不在群里说敏感信息
