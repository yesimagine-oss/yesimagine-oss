### 2. 添加數據驗證 ✅

```python

    data = fetch_api(code)
    if not data or data['current'] == 0:
        log("❌ 數據抓取失敗")
        return None
    return data
```

### 3. 添加內容質量檢查 ✅

```python
def validate_report(report: str) -> bool:
    if len(report.strip()) < 500:
        log("❌ 報告內容過短")
        return False
    if "收盘" not in report:
        log("❌ 報告缺少核心數據")
        return False
    return True
```
