| 原则 | 规范要求 | 我的行为 |

| **验证 > 假设** | 验证后再汇报 | ❌ 没有验证内容准确性 |

## 可能的原因

1. **访问了错误的页面** - 可能是缓存或旧版本
2. **网站有多个版本** - 不同用户看到不同内容
3. **browser 工具问题** - 可能抓取了错误的内容
4. **我理解错误** - 可能看错了页面

---

## 正确做法

**当用户说"我没看到你说的内容"时应该**：

```
1. ✅ 立即承认错误
   "我可能访问了错误的页面或版本"

2. ✅ 请用户描述他们看到的
   "请告诉我您看到的内容"

3. ✅ 重新访问验证
   再次访问网站确认

4. ✅ 如实汇报差异
   "我再次访问看到的是..."
```

**而不是**：
```
❌ 坚持自己看到的
❌ 反问用户"您确定吗"
❌ 假装知道
```

---

## 教训

1. **内容必须可验证** - 用户应该能看到我说的内容
2. **发现差异立即承认** - 不要坚持错误
3. **重新验证** - 再次访问确认
4. **诚实报告** - 不确定就说"可能访问了错误版本"
