## 🛠️ 解决方案

### 富文本格式（飞书 post 类型）

```json
{
  "msg_type": "post",
  "content": {
    "zh_cn": {
      "title": "晚间汇总报告",
      "content": [
        [{"tag": "text", "text": "📊 事故统计\n\n"}, {"tag": "text", "text": "总计：41 起", "style": {"bold": true}}],
        [{"tag": "hr"}],
        [{"tag": "text", "text": "🔴 P0 灾难性：19 起\n", "style": {"color": "red"}}],
        [{"tag": "text", "text": "🟠 P1 严重：18 起\n", "style": {"color": "orange"}}]
      ]
    }
  }
}
```

### 视觉效果

- 🎨 **颜色区分** - P0 红色、P1 橙色、P2 黄色
- 📏 **分隔线** - 清晰分组
- 🔗 **可点击链接** - 事故文件链接
- 📊 **结构化布局** - 标题、正文、列表
