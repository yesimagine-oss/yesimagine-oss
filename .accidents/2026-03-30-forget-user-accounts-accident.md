# 2026-03-30 忘记用户关注账号事故

**发生时间**: 2026-03-30 19:50  
**发现时间**: 2026-03-30 19:50  
**事故级别**: 🔴 严重（失忆）

---

## 📋 事故描述

**现象**: 用户说"我已经告诉过你我要关注的账号"，但 AI 不记得了

**问题**:
1. ❌ 忘记用户明确告知的信息
2. ❌ 需要用户重复告知
3. ❌ 显得不专业，不重视用户

**影响**:
- 用户体验差（需要重复说）
- 信任度下降（显得不用心）
- 效率降低（重复沟通）

---

## 🔍 根本原因

### 1. 未记录关键信息

**问题**: 用户告知关注账号后，没有记录到 TOOLS.md 或 MEMORY.md

**应该做的**:
```
用户告知关注账号 → 立即记录到 TOOLS.md → 后续直接使用
```

**实际做的**:
```
用户告知关注账号 → 未记录 → 忘记 → 问用户
```

### 2. 未查阅上下文

**问题**: 没有主动查看之前的对话记录

**应该做的**:
```
需要用户信息 → 查 sessions_history → 查 TOOLS.md → 查 MEMORY.md
```

**实际做的**:
```
需要用户信息 → 直接问用户
```

### 3. 失忆问题

**问题**: 跨 session 后信息丢失

**原因**:
- 重要信息未保存到永久存储
- 依赖 session 记忆（会重置）

---

## ✅ 解决方法

### 1. 立即记录

**位置**: `TOOLS.md` - 用户关注账号列表

**格式**:
```markdown
### 🐦 关注的 Twitter 账号

| 账号 | 说明 |
|------|------|
| @xxx | xxx |
```

### 2. 查阅上下文

**流程**:
```
需要用户信息 → 查 TOOLS.md → 查 MEMORY.md → 查 sessions_history → 再问用户
```

### 3. 主动确认

**话术**:
```
"您之前提到过关注 @xxx、@xxx 等账号，对吗？"
```
