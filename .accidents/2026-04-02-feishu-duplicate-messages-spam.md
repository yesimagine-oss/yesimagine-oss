## 正确做法

### 发送前检查

```
✅ 检查清单：
- [ ] 这条消息必须发送吗？
- [ ] 用户要求发送吗？
- [ ] 最近发送过相同内容吗？（5 分钟内）
- [ ] 可以合并到其他消息中吗？
```

### 防重机制

```python
# 伪代码
last_message_time = get_last_send_time(user_id, message_type)
if now - last_message_time < 300:  # 5 分钟
    skip_send()  # 跳过发送
```

### 合并发送

```
❌ 错误：
06:45 发送：心跳报告 #1
06:46 发送：心跳报告 #2
06:47 发送：心跳报告 #3

✅ 正确：
06:47 发送：心跳报告（汇总 3 次结果）
```

### 永久机制

| 机制 | 说明 | 实现方式 |
|------|------|---------|
| **消息去重** | 5 分钟内不发送相同内容 | 缓存 last_message |
| **频率限制** | 每种类型消息有发送上限 | 计数器 + 时间窗口 |
| **合并发送** | 相似内容合并为一条 | 消息队列 + 批处理 |
| **用户控制** | 用户可以关闭某类消息 | 配置开关 |

### 飞书发送规范
