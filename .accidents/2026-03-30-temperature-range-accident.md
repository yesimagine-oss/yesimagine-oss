## 📋 事故描述

**现象**: 飞书收到的每日播报中，温度显示为当前温度

**问题内容**:
```
🌤️ 济南 +13°C 🌤️ 威海 +7°C
```

**预期内容**:
```
🌤️ 济南 8°C~18°C 🌤️ 威海 5°C~12°C
```

**问题**:
1. ❌ 显示当前温度，不是最低~最高
2. ❌ 用户需要的是温度范围（方便穿衣）
3. ❌ 需求理解错误

---

## 🔍 根本原因

### 1. 需求理解错误

**问题**: 一直以为显示当前温度即可

**实际需求**:
- 最低温度（夜间/清晨）
- 最高温度（白天/午后）
- 格式：`最低~最高`

### 2. wttr.in 格式选择错误

**当前使用**:
```python
format=%t  # 当前温度
```

**应该使用**:
```python
format=%l:+%t+%h+%w  # 包含温度范围
# 或
format="%C+%t"  # 天气状况 + 温度范围
```

---

## ✅ 解决方法

### 修改 wttr.in 格式

**修改前**:
```python
resp = requests.get(f'https://wttr.in/{city_en}?format=%t')
```

**修改后**:
```python
# 获取温度范围（最低~最高）
resp = requests.get(f'https://wttr.in/{city_en}?format=%L+%H')
# %L = 最低温度，%H = 最高温度
```

### 格式化输出

**格式**:
```python
weather_text = f"{low_temp}~{high_temp}"
# 例如："8~18"
```
