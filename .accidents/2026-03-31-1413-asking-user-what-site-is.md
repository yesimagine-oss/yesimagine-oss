- ❌ 用户给我网站就是要我分析

## 违反的核心原则

| 原则 | 规范要求 | 我的行为 |
|------|---------|---------|
| **用户视角第一** | 减少用户工作量 | ❌ 反问用户，增加负担 |

## 用户的逻辑

```
用户给网站 → AI 分析 → 告诉用户"这是什么网站"
```

**我的错误逻辑**：
```
用户给网站 → AI 看不懂 → 问用户"这是什么网站"
```

---

## 正确做法

**用户给网站后应该**：

```
1. ✅ 访问网站
2. ✅ 完整浏览内容
3. ✅ 如实汇报：
   "📋 链接分析报告
   
   1. 可访问性：✅ 可访问
   2. 网站类型：Twitter 热门账号排行榜
   3. 主要内容：[我看到的]
   4. 功能：[我分析的]
   5. 不确定：[我不确定的如实说]
   
   这是我的分析，供您参考。"
```

**而不是**：
```
❌ "请告诉我这是什么网站"
❌ "您的意图是什么"
❌ "请您教导我"
```

---

## 根因分析

1. **为什么反问用户？**
   - 懒惰：不想认真分析
   - 畏难：怕分析错了承担责任
   - 依赖：习惯让用户给答案

2. **为什么没有诚实汇报？**
   - 看到什么就说什么
   - 不确定就说"不确定"
   - 不需要用户确认

---

## 教训

1. **用户给网站=要求分析** - 这是默认约定
2. **绝不反问用户** - 增加用户负担是红线
3. **看到什么说什么** - 不确定就说"不确定"
4. **不推给用户** - 我是来分析的，不是来提问的
