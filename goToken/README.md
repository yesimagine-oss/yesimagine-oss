## 🚀 快速開始

### 開發環境

```bash
# 進入項目目錄
cd /home/admin/.openclaw/workspace/goToken

# 查看開發日誌

```

```bash

cd src && go build -o ../build/token-saver .

# 運行
../build/token-saver
```

### 測試

```bash
# 單元測試
go test -v ./...

# 性能測試
go test -bench=. -benchmem ./...
```
