## 🎯 技能功能

goToken 自动优化你的 Token 使用，**无需手动调用**。

**自动行为**：
1. 拦截所有 LLM 请求
2. 检查缓存（精确匹配 + 语义匹配）
3. 缓存命中 → 直接返回（0 Token）
4. 缓存未命中 → 调用 API → 缓存答案

## 🔧 配置命令

### 查看缓存统计

```
/goToken stats
```

**输出示例**：
```
缓存统计:
- 总请求：100
- 缓存命中：75
- 命中率：75%
- Token 节省：60000
```

### 清理缓存

```
/goToken clear
```

### 查看配置

```
/goToken config
```

## ⚙️ 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `CACHE_TTL_HOURS` | 2 | 缓存有效期（小时） |
| `MAX_TOKENS` | 300 | 最大 Token 数 |
| `LLM_MODEL` | qwen-coding-lite | 使用的模型 |
| `DASHSCOPE_API_KEY` | - | DashScope API Key（必需） |

---

## ⚠️ 行为规范

### ✅ 应该做的

- 自动缓存重复问题
- 语义匹配相似问题
- 限流保护（最多 2 并发）
- 定期清理过期缓存
- 友好错误提示

### ❌ 不应该做的

- 不缓存实时数据（天气/股价）
- 不上传用户数据
- 不修改原始回答内容
- 不影响非 LLM 功能

---

## 🚨 错误处理

| 错误 | 提示 | 解决方案 |
|------|------|---------|
| API Key 缺失 | "DASHSCOPE_API_KEY 未设置" | 配置环境变量 |
| API 错误 | "AI 服务请求失败，请稍后重试" | 检查网络/API 额度 |
| 请求失败 | "本周额度已达上限，将在周一重置" | 等待额度重置 |
