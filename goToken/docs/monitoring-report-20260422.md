## 🎯 goToken 功能验证

### 缓存机制

**工作原理**:
```
1. 用户提问 → goToken 拦截
2. 检查缓存 → 命中？返回缓存答案
3. 未命中 → 调用 API → 缓存答案 → 返回
```

**缓存键**: 问题原文（精确匹配）  
**缓存 TTL**: 2 小时  
**限流**: 最多 2 个并发请求
