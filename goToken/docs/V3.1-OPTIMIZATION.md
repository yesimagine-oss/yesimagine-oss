## 🎯 優化內容

### 1. 閾值調整

### 2. 模板庫擴展

```go
// v1.0.1: 4 類模板
- install: (如何 | 怎麼 | 怎樣).*(安裝 |install|setup)
- usage: (如何 | 怎麼 | 怎樣).*(使用 |use|usage| 用)
- config: (如何 | 怎麼 | 怎樣).*(配置 |config|setup| 設置)
- error: (錯誤 |error|fail| 失敗 | 報錯)

// v1.0.2: 10 類模板 (新增 6 類)
- install: 安裝類
- usage: 使用類
- config: 配置類
- error: 錯誤類
- performance: 性能優化類
- compare: 比較類
- troubleshooting: 排查類
- best_practice: 最佳實踐類
- integration: 集成類
- deployment: 部署類
```

**影響:**
- 覆蓋更多問題類型
- 預計提升：+2-3%

### 3. 權重調整

```go
// v1.0.1: 固定權重
weights: [0.5, 0.3, 0.2]  // 餘弦 + 編輯 + 關鍵詞

// v1.0.2: 動態權重 (按場景)
switch scene {
case "coding":
    weights: [0.6, 0.3, 0.1]  // 重視詞頻
case "chat":
    weights: [0.4, 0.4, 0.2]  // 重視編輯距離
case "analysis":
    weights: [0.5, 0.2, 0.3]  // 重視關鍵詞
}
```

**影響:**
- 按場景自適應
- 預計提升：+1-2%
