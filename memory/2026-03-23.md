## 🔴 飞书机器人问题大修复

**时间**: 2026-03-23 晚上

**发现的问题：**
1. **回复太啰嗦** - 发 3 条长消息
2. **重复回复** - 多条消息说同一件事
3. **暴露技术细节** - "防爬蟲機制"、"沒有登錄微信賬號"
4. **指导用户行为** - "1.直接在微信中打開 2.使用微信客戶端..."
5. **@提及格式错误** - 发送`<at id="ou_xxx">`代码，暴露用户 ID
6. **身份混淆** - 把"机械师"当成机器人
7. **消息格式混乱** - 引用 + 卡片 + 纯文本混用

**修复方案：**
1. ✅ 简洁回复（1-3 行）
2. ✅ 一条消息说完
3. ✅ 不暴露技术细节
4. ✅ 不指导用户
5. ✅ 使用 replyTo 代替@提及（后改为开通@提及权限）
6. ✅ 明确身份认知（RedOpenClaw=机器人，机械师=用户）
7. ✅ 统一纯文本格式

**规范整合：**
- 9 个分散文件 → 1 个核心规范
- `.learnings/feishu-bot-core-rules.md` - 核心规范（10 条原则）

**核心原则（10 条）：**
1. 简洁直接 - 1-3 行说完
2. 一条消息 - 不拆分
3. @提及用户 - 使用飞书 API mentions 参数
4. 不暴露隐私 - 不说用户 ID
5. 不说技术细节 - 不说"防爬蟲"
6. 不指导用户 - 不说"你应该"
7. 敏感信息私聊 - 不在群里说 API Key
8. 纯文本格式 - 不发送 JSON 卡片
9. 被@时必回 - 简洁回答
10. 错误立即纠正 - 承认 + 道歉 + 删除

2. **简洁是王道** - 1-3 行说完，不啰嗦
