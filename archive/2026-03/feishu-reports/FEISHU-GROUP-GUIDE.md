## 📋 权限状态

✅ 已授予的群组相关权限：
- `im:message.group_msg` - 发送群组消息
- `im:message.group_at_msg:readonly` - 读取@消息
- `im:chat` - 群组信息
- `im:chat.members:bot_access` - 获取群组成员

---

## 🛠️ 正确用法

### 1️⃣ 获取群组成员

```python
# 使用 feishu_chat 工具
feishu_chat(action="members", chat_id="聊天 ID")
```

### 2️⃣ @提及用户

飞书消息中的@语法：
```json
{
  "msg_type": "text",
  "content": {
    "text": "<at user_id=\"xxx\">张三</at> 你好"
  }
}
```

### 3️⃣ 区分上下文

群组中每条消息都有：
- `message_id` - 消息 ID
- `sender_id` - 发送者 ID
- `chat_id` - 群组 ID

## ⚠️ 当前限制

### 不建议在群组中进行的操作

| 操作 | 原因 |
|------|------|
| **复杂配置** | 输出长，容易被截断 |
| **软件安装** | 需要实时日志，群组体验差 |
| **敏感信息** | 群组中会泄露给所有人 |
| **代码调试** | 需要完整错误信息 |

### 建议在群组中进行的操作

| 操作 | 原因 |
|------|------|
| **通知推送** | 群组通知效果好 |
| **简单查询** | 快速回复 |
| **团队协作** | 多人可见 |

---

## 📝 使用建议

### 推荐工作流程

```
1. 复杂任务 → webUI 开始
2. 任务完成 → feishu 群组推送通知
3. 简单查询 → feishu 群组或私聊
```

### 避免的操作

- ❌ 在群组中发送密码、密钥
- ❌ 在群组中进行多轮复杂对话
- ❌ 依赖群组进行软件安装验证
