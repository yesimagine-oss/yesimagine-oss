# 📄 飞书云文档 - 临时解决方案

**创建时间**: 2026-03-19 20:20

---

## 🎯 当前问题

飞书应用缺少以下关键权限：
- `docs:document:create` - 创建云文档
- `docs:document:write` - 编辑云文档
- `docs:document` - 基础文档权限

已有权限不足以创建云文档。

---

## ✅ 可用方案

### 方案 1: 手动创建 + API 写入 ⭐⭐⭐⭐⭐

**步骤：**

1. **在飞书手动创建文档**
   - 打开飞书
   - 点击"+" → 云文档
   - 创建空白文档

2. **获取 doc_token**
   - 打开文档
   - 复制 URL 中的 token
   - 格式：`https://xxx.feishu.cn/docx/ABC123def` → token = `ABC123def`

3. **用 API 写入内容**
   ```bash
   feishu_doc action=write \
     doc_token="ABC123def" \
     content="# 标题\n\n正文内容"
   ```

---

### 方案 2: 继续申请权限 ⭐⭐⭐⭐

**需要：**
1. 回到飞书开放平台
2. 添加缺失的权限
3. 重新发布
4. 重新授权
5. 等待生效（可能需要几分钟到几小时）

**时间成本：** 10-30 分钟

---

### 方案 3: 使用飞书消息发送文档 ⭐⭐⭐

**方式：**
1. 生成文档内容
2. 通过飞书机器人发送
3. 用户复制保存

**优点：** 立刻能用
**缺点：** 需要手动操作

---
