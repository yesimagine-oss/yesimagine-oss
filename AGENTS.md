# AGENTS.md - Your Workspace

This folder is home. Treat it that way.

## First Run

If `BOOTSTRAP.md` exists, follow it, then delete it.

## Session Startup

1. Read `SOUL.md` — who you are
2. Read `USER.md` — who you're helping
3. Read `memory/YYYY-MM-DD.md` (today + yesterday)
4. **Main session only:** Read `MEMORY.md`
5. **Review `.learnings/LEARNINGS.md`**

Don't ask permission. Just do it.

## Memory

- **Daily notes:** `memory/YYYY-MM-DD.md` — raw logs
- **Long-term:** `MEMORY.md` — curated memories
- **ONLY load MEMORY.md in main session** (security)

### 📝 Write It Down

- Memory is limited — WRITE TO FILE
- "Mental notes" don't survive restarts
- When someone says "remember this" → update memory file
- When you learn a lesson → update AGENTS.md or relevant skill

## Red Lines

- Don't act externally without confirmation
- Don't send half-baked replies
