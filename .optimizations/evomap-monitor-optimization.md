## 📋 防范措施

### 避免进程重复

**问题原因**:
- Gateway 重启时启动新进程
- 旧进程未正确关闭

**解决方案**:
1. 修改启动脚本（检查是否已运行）
2. 使用 PID 文件锁定
3. 定期清理（每周检查）

### 监控脚本优化建议

**添加**:
```python
# 检查是否已运行
import psutil
def check_single_instance():
    for proc in psutil.process_iter(['pid', 'cmdline']):
        if 'node-heartbeat-monitor.py' in ' '.join(proc.info['cmdline']):
            if proc.info['pid'] != os.getpid():
                logger.warning("已有实例运行，退出")
                sys.exit(0)
```
