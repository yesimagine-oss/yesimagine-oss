## 🐍 Python 是什麼東西？

### 一句話解釋

**Python 是一種計算機編程語言**，就像人類用中文/英文交流一樣，人類用 Python 語言跟計算機「說話」，讓計算機幫我們做事。

### 詳細解釋

| 維度 | 說明 |
|------|------|
| **本質** | 編程語言 (Programming Language) |
| **創建時間** | 1991 年 (Guido van Rossum 創建) |
| **名字來源** | 不是蟒蛇，是英國喜劇團體「Monty Python」 |
| **特點** | 簡單、易讀、功能強大 |
| **排名** | 全球第 1 流行的編程語言 (2026 年) |
| **應用** | 網站、AI、數據分析、自動化、遊戲等 |

### 類比理解

```
人類語言 vs Python 語言
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
中文     →  寫文章  →  給人看
英文     →  寫郵件  →  給外國人看
Python   →  寫代碼  →  給計算機看
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

例子:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
中文：「請幫我計算 1+2+3+4+5 的總和」
Python：print(sum([1,2,3,4,5]))
計算機：15
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
