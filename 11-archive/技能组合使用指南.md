## 📊 工作流配置

### 工作流 1：任务 Claim

```
proactive-agent (检测新任务)
    ↓
serper (搜索任务信息)
    ↓
evomap (Claim 任务)
    ↓
proactive-agent (汇报状态)
    ↓
self-improving-agent (记录过程)
```

**预期效果:**
- 自动检测新任务
- 自动搜索背景信息
- 自动 Claim 高价值任务
- 即时汇报 Claim 结果
- 持续学习优化

---

### 工作流 2：任务执行

```
evomap (执行任务)
    ↓
serper (搜索解决方案)
    ↓
evomap (提交结果)
    ↓
proactive-agent (汇报结果)
    ↓
self-improving-agent (学习成功)
```

**预期效果:**
- 自动执行任务
- 自动搜索最佳方案
- 自动提交结果
- 即时汇报执行结果
- 积累成功经验

---

### 工作流 3：错误处理

```
proactive-agent (检测错误)
    ↓
self-improving-agent (记录错误)
    ↓
proactive-agent (发送告警)
    ↓
self-improving-agent (生成建议)
    ↓
self-improving-agent (应用优化)
```

**预期效果:**
- 5 分钟内发现错误
- 1 分钟内发送告警
- 自动生成优化建议
- 防止重复犯错

## 🔧 故障排查

### 问题 1：技能未响应

**检查步骤:**
```bash
# 1. 检查技能是否启用
cat config/skill-combo-config.json | grep enabled

# 2. 检查技能是否安装
ls /opt/openclaw/skills/ | grep <skill_name>
ls /home/admin/.openclaw/workspace/skills/ | grep <skill_name>

# 3. 重启 OpenClaw
openclaw restart
```

---

### 问题 2：工作流执行失败

**检查步骤:**
```bash
# 1. 查看日志
tail -50 /home/admin/.openclaw/workspace/ai 知识变现/evomap 项目/logs/skill-combo.log

# 2. 检查工作流配置
cat config/skill-combo-config.json | jq '.workflows'

# 3. 测试单步执行
python3 <skill_script>.py --test
```

---

### 问题 3：监控指标异常

**检查步骤:**
```bash
# 1. 查看监控数据
cat config/skill-combo-config.json | jq '.monitoring'

# 2. 检查告警配置
cat config/skill-combo-config.json | jq '.monitoring.alerts'

# 3. 测试告警
python3 tools/task-notifier.py problem "测试" "监控测试" "无"
```
