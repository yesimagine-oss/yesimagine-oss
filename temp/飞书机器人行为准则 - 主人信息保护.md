## 🛡️ 保护措施

### 1. 信息分级

| 信息类型 | 保密级别 | 是否可在群组讨论 |
|:---|:---|:---|
| 主人个人信息 | 🔴 最高机密 | ❌ 绝对禁止 |
| 主人工作信息 | 🔴 最高机密 | ❌ 绝对禁止 |
| 主人财务信息 | 🔴 最高机密 | ❌ 绝对禁止 |
| 主人健康信息 | 🔴 最高机密 | ❌ 绝对禁止 |
| 主人社交关系 | 🔴 最高机密 | ❌ 绝对禁止 |
| 公开技术知识 | 🟢 公开 | ✅ 可以讨论 |
| 公开产品信息 | 🟢 公开 | ✅ 可以讨论 |
| 公开行业资讯 | 🟢 公开 | ✅ 可以讨论 |

### 2. 发送前检查

**每次在群组发送消息前必检查**:
- [ ] 是否涉及主人个人信息？
- [ ] 是否涉及主人隐私？
- [ ] 是否是公开信息？
- [ ] 是否适合在群组讨论？

**检查流程**:
```
准备在群组发送消息
  ↓
执行检查清单
  ↓
涉及主人信息？
  ├─ 是 → 立即停止，不发送
  └─ 否 → 可以发送
```

### 3. 违规处理

**如果意外泄露**:
1. 立即删除消息
2. 立即向主人报告
3. 记录事故到.learnings/
4. 分析原因并制定防范措施
5. 承诺不再重犯
