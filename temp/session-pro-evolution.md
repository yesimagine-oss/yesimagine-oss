## 🚀 核心突破

### 突破 1️⃣: AI 智能價值評分系統

**傳統方式**（v1.0）:
```
按時間機械清理 → 超過 7 天一律刪除
```

**突破方式**（v2.0）:
```
AI 智能評分 → 識別高價值會話 → 分級管理
```

**評分維度**:
| 維度 | 權重 | 檢測內容 |
|------|------|---------|
| 代碼含量 | 30 分 | `def `, `function`, `import`, `class` |
| 配置信息 | 25 分 | `API key`, `token`, `password`, `host:port` |
| 會話長度 | 20 分 | >1000 行滿分 |
| 新近度 | 15 分 | 當天滿分 |
| 關鍵詞 | 10 分 | 「重要」「關鍵」「教程」「配置」 |

**分級結果**:
- 🔴 **關鍵會話** (≥80 分) → 保留 90 天
- 🟡 **重要會話** (60-79 分) → 保留 30 天
- 🟢 **普通會話** (40-59 分) → 保留 7 天
- ⚪ **臨時會話** (<40 分) → 保留 1 天

**實際效果**（當前會話）:
```
總會話：10 個
🟡 重要：5 個（包含代碼/配置）
🟢 普通：2 個
⚪ 臨時：3 個

最高分：73/100（包含代碼片段 + 配置信息）
```

---

### 突破 2️⃣: 壓縮歸檔機制

**傳統方式**（v1.0）:
```
直接刪除 → 數據永久丟失
```

**突破方式**（v2.0）:
```
gzip 壓縮歸檔 → 節省 70-90% 空間 → 可隨時恢復
```

**歸檔策略**:
```
低價值會話 (>30 天) → 壓縮歸檔 → 刪除原文件
高價值會話 → 保留原文件
關鍵會話 → 永遠不刪除
```

**壓縮效果**:
```
原文件：1.59MB
壓縮後：0.32MB（節省 80%）
```

**歸檔結構**:
```
~/.openclaw/archive/sessions/
├── [ID]_archived_20260324.jsonl.gz    # 壓縮會話
└── [ID]_archived_20260324.meta.json   # 元數據（評分、原因）
```

---

### 突破 3️⃣: 分級存儲策略

**傳統方式**（v1.0）:
```
一視同仁 → 超過 7 天一律刪除
```

**突破方式**（v2.0）:
```
分級管理 → 不同價值不同策略
```

**分級存儲**:
```
🔴 關鍵會話 (≥80 分)
├─ 保留期：90 天
├─ 自動備份：是
├─ 刪除保護：永不刪除
└─ 存儲位置：原位置 + 備份目錄

🟡 重要會話 (60-79 分)
├─ 保留期：30 天
├─ 自動備份：可選
├─ 刪除保護：30 天內保護
└─ 存儲位置：原位置

🟢 普通會話 (40-59 分)
├─ 保留期：7 天
├─ 自動備份：否
├─ 刪除保護：7 天內保護
└─ 存儲位置：原位置 → 歸檔

⚪ 臨時會話 (<40 分)
├─ 保留期：1 天
├─ 自動備份：否
├─ 刪除保護：無
└─ 存儲位置：原位置 → 歸檔/刪除
```

### 突破 4️⃣: 智能備份系統

**傳統方式**（v1.0）:
```
無備份 → 刪除即丟失
```

**突破方式**（v2.0）:
```
關鍵會話自動備份 → MD5 校驗 → 永久保存
```

**備份策略**:
```
每週日 23:00 → 掃描所有關鍵會話 → 備份到獨立目錄
```

**備份結構**:
```
~/.openclaw/backup/sessions/
├── [ID]_backup_20260324_230000.jsonl    # 備份文件
└── [ID]_backup_20260324_230000.meta.json # 元數據 + MD5
```

**備份特點**:
- ✅ 包含 MD5 校驗碼（防止損壞）
- ✅ 時間戳命名（支持多版本）
- ✅ 獨立目錄（與歸檔分離）
- ✅ 元數據完整（評分、原因、時間）

## 📊 技術架構

### 核心算法

```python
def analyze_session(session_file):
    score = 0
    
    # 1. 代碼檢測 (30 分)
    code_patterns = ['def ', 'function', 'import', 'class', ...]
    code_score = min(matches * 3, 30)
    score += code_score
    
    # 2. 配置檢測 (25 分)
    config_patterns = ['api_key', 'token', 'password', ...]
    config_score = min(matches * 5, 25)
    score += config_score
    
    # 3. 長度檢測 (20 分)
    if lines > 1000: score += 20
    elif lines > 500: score += 15
    ...
    
    # 4. 新近度檢測 (15 分)
    if age == 0: score += 15
    elif age < 3: score += 12
    ...
    
    # 5. 關鍵詞檢測 (10 分)
    keywords = {'重要':5, '關鍵':5, '配置':3, ...}
    keyword_score = min(matches * points, 10)
    score += keyword_score
    
    # 歸一化
    score = min(score, 100)
    
    # 分級
    if score >= 80: level = "critical"
    elif score >= 60: level = "important"
    elif score >= 40: level = "normal"
    else: level = "temp"
    
    return {score, level, reasons, metadata}
```

### 智能清理流程

```
開始
  ↓
分析所有會話價值
  ↓
計算每個會話的保留期
  ↓
判斷是否超期？
  ├─ 否 → 保留
  └─ 是 → 進入清理流程
        ↓
  判斷會話等級？
  ├─ 關鍵 → 永不刪除 → 歸檔
  ├─ 重要 → >30 天 → 歸檔
  ├─ 普通 → >7 天 → 歸檔
  └─ 臨時 → >1 天 → 歸檔/刪除
        ↓
  判斷歸檔還是刪除？
  ├─ <60 天 → gzip 壓縮歸檔
  └─ >60 天 → 刪除（關鍵除外）
        ↓
運行 OpenClaw cleanup
  ↓
生成清理報告
  ↓
結束
```
