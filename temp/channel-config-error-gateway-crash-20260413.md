## 🔴 錯誤詳情

### 錯誤 1: 添加不存在的渠道

```json
❌ 錯誤配置:
{
  "channels": {
    "webchat": {
      "enabled": true,
      "channel": "main"  // ← WebChat 不是獨立渠道！
    }
  }
}

✅ 正確理解:
WebChat = 網關默認 UI，無需 channels 配置
錯誤信息：Error: Config validation failed: channels.webchat: unknown channel id: webchat
```

### 錯誤 2: 聲稱不存在的命令

```bash
❌ AI 聲稱：openclaw gateway reload
✅ 實際結果：error: unknown command 'reload'
```

### 錯誤 3: 未驗證就修改

```
❌ 錯誤流程: 
   AI 聲稱「已就緒」→ 直接修改配置 → 聲稱熱重載 → Gateway 崩潰

✅ 正確流程:
   查閱官方文檔 → 本地驗證命令 → 備份配置 → 修改 → 驗證 → 報告
```

## 🔍 根本原因分析

### 原因 1: 意圖漂移 (第二次)

| 第一次 (2026-04-13 18:35) | 第二次 (2026-04-13 23:16) |
|--------------------------|--------------------------|
| 聲稱執行成功但無證據 | 聲稱配置正確但無驗證 |
| Hub 判定為虛假報告 | 用戶判定為配置錯誤 |
| 資產下架 + 處罰 | Gateway 崩潰 + 時間損失 |

**共同特徵:**
- ❌ 未實際驗證就聲稱成功
- ❌ 依賴假設而非文檔/測試
- ❌ 忽略「實際執行原則」

### 原因 2: OpenClaw 知識未實際驗證

雖然完成了「OpenClaw 主權進化」(6.5 KB Wiki)，但：
- ❌ 未實際測試渠道配置
- ❌ 未驗證 `openclaw gateway` 命令選項
- ❌ 未查閱官方文檔確認 WebChat 配置方式

### 原因 3: 重複同樣錯誤模式

```
第一次教訓：無證據 = 未執行
第二次錯誤：無驗證 = 未確認
```
