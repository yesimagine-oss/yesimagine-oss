## 2. ECS vs 輕量服務器

### 2.1 詳細對比

| 特性 | 輕量服務器 (SAS) | ECS |
|------|----------------|-----|
| **定位** | 入門級/個人 | 企業級/生產 |
| **CPU** | 共享/突發 | 獨享/穩定 |
| **內存** | 1-16GB | 1-512GB+ |
| **帶寬** | 3-30Mbps | 1-200Mbps+ |
| **網絡** | 單網卡 | 多網卡/彈性網卡 |
| **磁盤** | 系統盤 + 可選數據盤 | 多塊雲盤 |
| **快照** | 支持 | 支持 + 自動快照 |
| **鏡像** | 公共/應用/自定義 | 共享鏡像市場 |
| **網絡隔離** | 基礎防火牆 | VPC + 安全組 |
| **負載均衡** | 不支持 | SLB |
| **監控** | 基礎監控 | 雲監控 + 自定義 |
| **API** | 有限 | 完整 API |
| **價格** | ¥24-¥500/月 | ¥50-¥50000+/月 |
| **適用** | 個人/測試/小網站 | 企業/生產/大規模 |

### 2.2 升級路徑

**輕量服務器 → ECS**

```bash
# 遷移方案
1. 創建輕量服務器快照
2. 基於快照創建自定義鏡像
3. 使用鏡像創建 ECS 實例
4. 測試驗證
5. 切換 DNS 解析
6. 釋放輕量服務器
```

### 2.3 混合架構

```
個人項目：輕量服務器（開發/測試）
         ↓
生產環境：ECS + SLB + RDS（正式上線）
```

## 3. SLB 負載均衡實戰

### 3.1 什麼是 SLB

**SLB (Server Load Balancer)**: 將訪問流量分發到多台後端服務器

**優勢**：
- 提高可用性（單點故障自動切換）
- 提高擴展性（橫向擴展）
- 提高安全性（隱藏後端 IP）

### 3.2 SLB 類型

| 類型 | 協議 | 適用場景 |
|------|------|---------|
| **四層 SLB** | TCP/UDP | 數據庫、遊戲、郵件 |
| **七層 SLB** | HTTP/HTTPS | Web 應用、API 服務 |

### 3.3 創建 SLB 實例

**步驟**：
```
1. 控制台 → 負載均衡 SLB → 創建實例
2. 選擇地域（與 ECS 相同）
3. 選擇實例規格
   - 性能保障型
   - 標準型
4. 選擇網絡類型（VPC）
5. 設置帶寬（按使用量/按帶寬）
6. 確認訂單
```

### 3.4 配置監聽

**HTTP 監聽配置**：
```yaml
前端協議：HTTP
前端端口：80
後端協議：HTTP
後端端口：80
健康檢查：
  檢查路徑：/health
  檢查間隔：5 秒
  超時時間：5 秒
  健康閾值：3 次
  不健康閾值：3 次
```

### 3.5 添加後端服務器

```yaml
後端服務器組:
  - ECS1: 172.16.1.10 (權重 100)
  - ECS2: 172.16.1.11 (權重 100)
  - ECS3: 172.16.1.12 (權重 100)

調度算法:
  - 輪詢 (默认)
  - 加權輪詢
  - 最小連接數
  - 源 IP Hash
```

### 3.6 實戰案例：Web 應用高可用

```
                    用戶訪問
                       ↓
                  SLB (公網 IP)
                       ↓
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
    ECS1 (Web)     ECS2 (Web)     ECS3 (Web)
        ↓              ↓              ↓
        └──────────────┼──────────────┘
                       ↓
                  RDS (MySQL)
                       ↓
                  OSS (靜態資源)
```

**配置步驟**：
1. 創建 3 台 ECS 實例
2. 部署相同的 Web 應用
3. 創建 SLB 實例
4. 配置 HTTP 監聽
5. 添加 3 台 ECS 為後端服務器
6. 配置健康檢查
7. 測試故障切換

## 4. RDS 雲數據庫

### 4.1 RDS 優勢

| 對比項 | 自建 MySQL | RDS MySQL |
|--------|-----------|-----------|
| **部署** | 手動安裝 | 一鍵創建 |
| **備份** | 手動腳本 | 自動備份 |
| **監控** | 自行配置 | 內置監控 |
| **高可用** | 自行搭建 | 默認主從 |
| **擴展** | 遷移困難 | 無縫升級 |
| **維護** | 人工運維 | 自動維護 |
| **成本** | 時間成本高 | 節省人力 |

### 4.2 創建 RDS 實例

**步驟**：
```
1. 控制台 → 雲數據庫 RDS → 創建實例
2. 選擇地域（與 ECS 相同）
3. 選擇引擎
   - MySQL 5.7/8.0
   - PostgreSQL
   - SQL Server
   - MariaDB
4. 選擇系列
   - 基礎版（單節點）
   - 高可用版（主從）
   - 集群版（多節點）
5. 選擇規格
   - 1 核 1GB ~ 32 核 256GB
6. 選擇存儲
   - SSD 雲盤
   - ESSD 雲盤
7. 設置白名單
8. 設置賬號密碼
```

### 4.3 連接 RDS

```bash
# 內網連接（ECS 訪問 RDS）
mysql -h rm-xxxxx.mysql.rds.aliyuncs.com -u root -p

# 公網連接（本地訪問）
mysql -h rm-xxxxx.mysql.rds.aliyuncs.com \
  -P 3306 \
  -u root \
  -p \
  --ssl-mode=REQUIRED
```

### 4.4 白名單配置

**推薦配置**：
```yaml
# 白名單 1：ECS 內網 IP
172.16.1.0/24

# 白名單 2：辦公 IP
123.45.67.89/32

# 白名單 3：家庭 IP
98.76.54.32/32

# ⚠️ 不建議：0.0.0.0/0（允許所有 IP）
```

### 4.5 備份與恢復

## 5. OSS 對象存儲

### 5.1 OSS 使用場景

| 場景 | 說明 | 示例 |
|------|------|------|
| **靜態資源** | 圖片/CSS/JS | 網站圖片庫 |
| **視頻音頻** | 多媒體文件 | 在線教育視頻 |
| **備份存檔** | 數據備份 | 數據庫備份 |
| **大文件分發** | 軟件下載 | APP 安裝包 |
| **數據湖** | 大數據分析 | 日志存儲 |

### 5.2 創建 Bucket

**步驟**：
```
1. 控制台 → 對象存儲 OSS → 創建 Bucket
2. 選擇地域
3. 權限設置
   - 私有（推薦）
   - 公共讀
   - 公共讀寫
4. 存儲類型
   - 標準存儲（頻繁訪問）
   - 低頻訪問（每月訪問幾次）
   - 歸檔存儲（長期保存）
5. 填寫 Bucket 名稱（全局唯一）
```

### 5.3 上傳文件

**控制台上傳**：
```
1. 進入 Bucket
2. 點擊「上傳文件」
3. 選擇文件/文件夾
4. 設置 ACL（可選）
5. 確認上傳
```

**ossutil 工具**：
```bash
# 安裝
wget https://gosspublic.alicdn.com/ossutil/1.7.13/ossutil64
chmod +x ossutil64
./ossutil64 config

# 上傳文件
./ossutil64 cp localfile.txt oss://mybucket/remotefile.txt

# 上傳文件夾
./ossutil64 cp -r ./images oss://mybucket/images

# 下載文件
./ossutil64 cp oss://mybucket/file.txt ./file.txt

# 列出文件
./ossutil64 ls oss://mybucket
```

### 5.4 CDN 加速 OSS

**配置步驟**：
```
1. CDN 控制台 → 添加域名
2. 填寫加速域名
3. 業務類型：圖片小文件/視頻點播
4. 源站類型：OSS 域名
5. 選擇 OSS Bucket
6. 確認添加
7. 配置 CNAME
```

### 5.5 費用優化

| 優化策略 | 節省比例 | 說明 |
|----------|---------|------|
| **存儲類型** | 30-80% | 使用低頻/歸檔 |
| **生命周期** | 20-50% | 自動轉儲 |
| **壓縮處理** | 40-70% | 圖片壓縮 |
| **CDN 回源** | 10-30% | 減少回源流量 |

**生命周期規則**：
```yaml
規則 1:
  前綴：logs/
  30 天後：轉為低頻訪問
  90 天後：轉為歸檔存儲
  365 天後：刪除

規則 2:
  前綴：uploads/
  7 天後：刪除過期文件
```

## 6. CDN 內容分發

### 6.1 CDN 工作原理

```
用戶請求 → CDN 邊緣節點（命中）→ 返回內容
            ↓ (未命中)
        源站（OSS/ECS）→ 緩存到邊緣 → 返回用戶
```

### 6.2 創建 CDN 實例

**步驟**：
```
1. CDN 控制台 → 域名管理 → 添加域名
2. 填寫加速域名
3. 業務類型
   - 圖片小文件
   - 視頻點播
   - 網頁加速
   - 全站加速
4. 源站信息
   - OSS 域名
   - ECS IP
   - 其他域名
5. 端口：80/443
6. 確認添加
```

### 6.3 配置 CNAME

```dns
# 域名解析設置
類型：CNAME
主機記錄：www
記錄值：example.com.w.kunlun.com（CDN 分配）
TTL: 10 分鐘
```

### 6.4 HTTPS 配置

```
1. CDN 控制台 → SSL 證書
2. 上傳證書
   - 證書文件
   - 私鑰文件
3. 開啟 HTTPS
4. 強制跳轉 HTTPS（推薦）
5. HTTP/2（推薦）
```

### 6.5 緩存配置

**緩存規則**：
```yaml
# 靜態資源（長緩存）
路徑：/*.jpg,/*.png,/*.css,/*.js
緩存時間：30 天
忽略參數：是

# 動態內容（短緩存）
路徑：/api/*
緩存時間：不緩存

# 首頁（短緩存）
路徑：/
緩存時間：5 分鐘
```

**刷新緩存**：
```
1. CDN 控制台 → 刷新預熱
2. 填寫 URL
3. 選擇刷新類型
   - URL 刷新
   - 目錄刷新
4. 確認刷新
```

## 8. RAM 訪問控制

### 8.1 為什麼需要 RAM

**風險場景**：
- 主賬號洩露 → 所有資源危險
- 員工離職 → 權限未回收
- 第三方合作 → 權限過大

**RAM 優勢**：
- 最小權限原則
- 權限可回收
- 操作可審計

### 8.2 創建 RAM 用戶

**步驟**：
```
1. RAM 控制台 → 用戶 → 創建用戶
2. 填寫用戶名
3. 訪問方式
   - 控制台訪問（設置密碼）
   - 編程訪問（AccessKey）
4. 完成創建
```

### 8.3 授權策略

**系統策略**：
| 策略 | 權限 | 適用 |
|------|------|------|
| AdministratorAccess | 所有權限 | 管理員 |
| ECSFullAccess | ECS 所有權限 | 運維人員 |
| ECSReadOnlyAccess | ECS 只讀 | 審計人員 |
| OSSFullAccess | OSS 所有權限 | 存儲管理 |
| ReadOnlyAccess | 所有服務只讀 | 監控人員 |

**自定義策略**：
```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ecs:Describe*",
        "ecs:StartInstance",
        "ecs:StopInstance"
      ],
      "Resource": "*"
    }
  ]
}
```

### 8.4 安全組配置

**MFA 多因素認證**：
```
1. RAM 控制台 → 安全設置
2. 啟用 MFA
3. 下載阿里雲 APP
4. 掃描二維碼
5. 輸入驗證碼
```

**密碼策略**：
```yaml
最小長度：10 位
包含大寫：是
包含小寫：是
包含數字：是
包含特殊字符：是
定期更換：90 天
禁止重複：最近 3 次
```

## 9. API 與自動化

### 9.1 API 調用方式

**方式 1：控制台 API 探索器**
```
1. 訪問：https://next.api.aliyun.com/
2. 選擇產品（例如 ECS）
3. 選擇 API（例如 DescribeInstances）
4. 填寫參數
5. 在線調試

```

**方式 2：CLI 工具**
```bash
# 安裝
pip install aliyun-python-sdk-ecs
pip install aliyun-cli

# 配置
aliyun configure

# 示例：查詢實例
aliyun ecs DescribeInstances --RegionId cn-hangzhou
```

**方式 3：SDK（Python）**：
```python
from aliyunsdkcore.client import AcsClient
from aliyunsdkecs.request.v20140526 import DescribeInstancesRequest

# 初始化
client = AcsClient('<accessKeyId>', '<accessSecret>', 'cn-hangzhou')

# 創建請求
request = DescribeInstancesRequest.DescribeInstancesRequest()
request.set_PageSize(10)

# 發送請求
response = client.do_action_with_exception(request)
print(response)
```

```bash
SNAPSHOT_NAME="auto-$(date +%Y%m%d-%H%M%S)"

# 創建快照
aliyun ecs CreateSnapshot \
  --RegionId $REGION \
  --DiskId $DISK_ID \
  --SnapshotName $SNAPSHOT_NAME

echo "Snapshot created: $SNAPSHOT_NAME"
```

**定時任務**：
```bash
# 每天凌晨 2 點執行
crontab -e
0 2 * * * /root/auto-snapshot.sh >> /var/log/snapshot.log 2>&1
```
