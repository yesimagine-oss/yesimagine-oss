## 2. 實例管理

### 2.1 創建實例

**步驟**：
1. 點擊「創建實例」
2. 選擇地域（推薦：離用戶最近的地域）
3. 選擇實例規格
   - 入門型：1 核 1GB/2GB
   - 標準型：2 核 2GB/4GB
   - 進階型：4 核 8GB/16GB
4. 選擇系統鏡像
   - 公共鏡像：Ubuntu、CentOS、Debian、Windows
   - 應用鏡像：WordPress、LAMP、LNMP
   - 自定義鏡像：自己創建的鏡像
5. 選擇數據盤（可選）
6. 設置登錄密碼
7. 確認訂單並支付

### 2.2 實例狀態管理

| 操作 | 說明 | 注意事項 |
|------|------|----------|
| **啟動** | 開機 | 已停止狀態可用 |
| **重啟** | 軟重啟 | 系統內執行 `reboot` |
| **強制重啟** | 硬重啟 | 可能丟失未保存數據 |
| **停止** | 關機 | 停止計費（部分資源） |
| **重置系統** | 重裝系統 | 數據會丟失，需提前備份 |

### 2.3 遠程連接方式

#### 方式 1：VNC 遠程連接（控制台內置）
```
位置：實例詳情頁 → 遠程連接
優點：無需配置，直接訪問
缺點：速度較慢，功能有限
```

#### 方式 2：SSH 連接（Linux）
```bash
# 本地終端連接
ssh root@47.104.30.181

# 指定端口
ssh -p 22 root@47.104.30.181

# 使用密鑰
ssh -i ~/.ssh/id_rsa root@47.104.30.181
```

#### 方式 3：RDP 連接（Windows）
```
1. 實例詳情頁獲取公網 IP
2. 本地運行 mstsc.exe
3. 輸入 IP 地址
4. 輸入管理員密碼
```

### 2.4 實例配置升降級

**升級配置**：
1. 實例詳情頁 → 升級配置
2. 選擇新規格
3. 支付差價
4. 重啟生效

**注意**：
- 降級可能需要重置系統
- 升級後帶寬立即生效
- 系統盤不支持單獨升級

## 3. 網絡與安全

### 3.1 防火牆（安全組）

**位置**：實例詳情頁 → 防火牆

#### 放行端口規則

| 端口 | 協議 | 用途 | 建議 |
|------|------|------|------|
| 22 | TCP | SSH | 僅信任 IP |
| 80 | TCP | HTTP | 開放 |
| 443 | TCP | HTTPS | 開放 |
| 3306 | TCP | MySQL | 內網或信任 IP |
| 6379 | TCP | Redis | 內網或信任 IP |
| 9090 | TCP | Mihomo Dashboard | 信任 IP |
| 11276 | TCP | OpenClaw Gateway | 信任 IP |

#### 添加防火牆規則

```bash
# 控制台操作：
1. 點擊「添加規則」
2. 填寫端口範圍（例如：9090/9090）
3. 選擇協議（TCP/UDP）
4. 授權對象（0.0.0.0/0 表示所有 IP）
5. 描述（備註用途）
6. 確認添加
```

#### 最佳實踐

```yaml
# 推薦的防火牆配置
SSH:
  端口：22
  授權對象：僅允許信任 IP（例如家庭 IP）
  描述：SSH 遠程管理

Web:
  端口：80,443
  授權對象：0.0.0.0/0
  描述：Web 服務

應用:
  端口：9090,11276
  授權對象：家庭 IP/辦公 IP
  描述：管理界面
```

### 3.2 公網帶寬

**帶寬模式**：
- 按帶寬計費：固定帶寬峰值
- 按使用量計費：用多少付多少（輕量服務器通常為固定帶寬）

**帶寬升級**：
1. 實例詳情頁 → 升級帶寬
2. 選擇新帶寬值
3. 支付差價
4. 立即生效

### 3.3 內網通信

**同地域內網互通**：
- 同地域的輕量服務器可以通過內網 IP 通信
- 內網通信免費
- 速度快，延遲低

**示例**：
```bash
# 服務器 A 訪問服務器 B（同地域）
ssh root@172.19.12.100  # 內網 IP

# 配置 hosts 文件
echo "172.19.12.100  server-b" >> /etc/hosts
ssh root@server-b
```

## 4. 存儲管理

### 4.1 系統盤

| 項目 | 說明 |
|------|------|
| **類型** | SSD 雲盤 |
| **容量** | 根據實例規格（通常 40GB-100GB） |
| **可擴容** | 不支持單獨擴容 |
| **備份** | 通過快照備份 |

### 4.2 數據盤

**添加數據盤**：
1. 實例詳情頁 → 磁盤 → 添加磁盤
2. 選擇容量（20GB-2TB）
3. 選擇類型（SSD/高效雲盤）
4. 支付並創建

**格式化與掛載**：
```bash
# 查看新磁盤
lsblk

# 格式化（假設新磁盤為 /dev/vdb）
mkfs.ext4 /dev/vdb

# 創建掛載點
mkdir /data

# 掛載
mount /dev/vdb /data

# 開機自動掛載
echo "/dev/vdb /data ext4 defaults 0 0" >> /etc/fstab
```

### 4.3 快照管理

**創建快照**：
1. 實例詳情頁 → 快照 → 創建快照
2. 選擇磁盤（系統盤/數據盤）
3. 填寫快照名稱
4. 確認創建

**使用快照**：
- 恢復磁盤：將磁盤恢復到快照時的狀態
- 創建自定義鏡像：基於快照創建鏡像
- 跨實例恢復：將快照應用到其他實例

## 9. 常見問題

### 9.1 無法 SSH 連接

**排查步驟**：
```bash
# 1. 檢查防火牆是否放行 22 端口
# 控制台 → 防火牆 → 確認 22 端口已添加

# 2. 檢查服務器 SSH 服務
systemctl status sshd

# 3. 檢查安全組規則
# 確認授權對象包含您的 IP

# 4. 使用 VNC 連接排查
# 控制台 → 遠程連接
```

### 9.2 磁盤空間不足

**解決方案**：
```bash
# 1. 查看磁盤使用
df -h

# 2. 查找大文件
du -ah / | sort -rh | head -20

# 3. 清理日誌
journalctl --vacuum-time=7d

# 4. 清理緩存
apt-get clean  # Ubuntu/Debian
yum clean all  # CentOS

# 5. 擴容（需要創建快照後操作）
```

### 9.3 網站訪問慢

**排查步驟**：
1. 檢查帶寬使用率（控制台監控）
2. 檢查服務器負載（`uptime`）
3. 檢查數據庫性能
4. 使用 CDN 加速
5. 升級帶寬或實例規格

### 9.4 快照恢復失敗

**可能原因**：
- 磁盤容量不足
- 快照損壞
- 實例狀態異常

**解決方案**：
1. 檢查實例狀態（需為停止狀態）
2. 檢查磁盤容量
3. 嘗試創建新實例從快照恢復

## 10. 最佳實踐

### 10.1 安全配置

```bash
# 1. 修改 SSH 端口
sed -i 's/#Port 22/Port 2222/' /etc/ssh/sshd_config
systemctl restart sshd

# 2. 禁用 root 密碼登錄
# 使用 SSH 密鑰認證

# 3. 配置防火牆
# 僅開放必要端口

# 4. 定期更新系統
apt-get update && apt-get upgrade -y

# 5. 安裝失敗登錄防護
apt-get install fail2ban
```

### 10.2 性能優化

```bash
# 1. 配置 Swap（防止內存不足）
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo "/swapfile none swap sw 0 0" >> /etc/fstab

# 2. 優化內核參數
cat >> /etc/sysctl.conf << EOF
vm.swappiness=10
vm.overcommit_memory=1
net.core.somaxconn=65535
EOF
sysctl -p

# 3. 使用系統監控
apt-get install htop iotop
```

### 10.3 備份策略

| 備份類型 | 頻率 | 保留時間 |
|----------|------|----------|
| **系統快照** | 每週 | 4 週 |
| **數據備份** | 每天 | 7 天 |
| **配置備份** | 每次變更 | 永久 |
| **數據庫備份** | 每天 | 30 天 |

### 10.4 成本優化

1. **選擇合適規格**：根據實際需求選擇
2. **利用活動**：關注阿里雲促銷活動
3. **長期優惠**：包年比包月優惠
4. **清理資源**：及時釋放不用的實例和磁盤
5. **快照管理**：定期清理舊快照
