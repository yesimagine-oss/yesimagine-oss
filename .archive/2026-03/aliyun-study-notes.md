## Day 1 - 2026-03-18：輕量服務器控制台

### 學習內容

#### 1. 控制台概覽

**訪問地址:** https://swas.console.aliyun.com/

**界面組成:**

| 區域 | 功能 |
|------|------|
| 導航欄 | 實例、磁盤、快照、防火牆、自定義鏡像 |
| 實例列表 | 顯示所有輕量服務器實例 |
| 快捷操作 | 重啟、關機、重置密碼、遠程連接 |
| 監控概覽 | CPU、內存、帶寬使用情況 |

**實例信息卡片:**
```yaml
實例 ID: swas-xxxxxxxxx
實例名稱：可自定義
地域：例如 華東 1（杭州）
可用區：例如 可用區 B
實例規格：例如 2 核 2GB
系統鏡像：例如 Ubuntu 22.04
網絡類型：VPC
內網 IP: 172.19.x.x
公網 IP: 47.104.x.x
狀態：運行中/已停止/重啟中
```

#### 2. 實例管理

**創建實例步驟:**
1. 點擊「創建實例」
2. 選擇地域（推薦：離用戶最近的地域）
3. 選擇實例規格（入門型/標準型/進階型）
4. 選擇系統鏡像（公共鏡像/應用鏡像/自定義鏡像）
5. 選擇數據盤（可選）
6. 設置登錄密碼
7. 確認訂單並支付

**實例狀態操作:**

| 操作 | 說明 | 注意事項 |
|------|------|----------|
| 啟動 | 開機 | 已停止狀態可用 |
| 重啟 | 軟重啟 | 系統內執行 `reboot` |
| 強制重啟 | 硬重啟 | 可能丟失未保存數據 |
| 停止 | 關機 | 停止計費（部分資源） |
| 重置系統 | 重裝系統 | 數據會丟失，需提前備份 |

**遠程連接方式:**
- VNC 遠程連接（控制台內置）
- SSH 連接（Linux）
- RDP 連接（Windows）

#### 3. 網絡與安全

**防火牆配置（安全組）:**

| 端口 | 協議 | 用途 | 建議 |
|------|------|------|------|
| 22 | TCP | SSH | 僅信任 IP |
| 80 | TCP | HTTP | 開放 |
| 443 | TCP | HTTPS | 開放 |
| 3306 | TCP | MySQL | 內網或信任 IP |
| 6379 | TCP | Redis | 內網或信任 IP |
| 9090 | TCP | Mihomo Dashboard | 信任 IP |
| 11276 | TCP | OpenClaw Gateway | 信任 IP |

**添加防火牆規則步驟:**
```
1. 實例詳情頁 → 防火牆 → 添加規則
2. 填寫端口範圍（例如：9090/9090）
3. 選擇協議（TCP/UDP）
4. 授權對象（0.0.0.0/0 表示所有 IP）
5. 描述（備註用途）
6. 確認添加
```

**最佳實踐:**
```yaml
SSH:
  端口：22
  授權對象：僅允許信任 IP（例如家庭 IP）
  描述：SSH 遠程管理

Web:
  端口：80,443
  授權對象：0.0.0.0/0
  描述：Web 服務

應用:
  端口：9090,11276
  授權對象：家庭 IP/辦公 IP
  描述：管理界面
```

**公網帶寬:**
- **帶寬模式**: 按帶寬計費（固定帶寬峰值）
- **帶寬升級**: 控制台 → 升級帶寬 → 支付差價 → 立即生效

**內網通信:**
- 同地域的輕量服務器可通過內網 IP 通信
- 內網通信免費，速度快，延遲低
- 示例：`ssh root@172.19.12.100`（內網 IP）

**域名解析:**
- 綁定域名到實例
- DNS 解析設置（A 記錄指向公網 IP）
- HTTPS 證書配置（阿里雲 SSL 證書或 Let's Encrypt）

#### 4. 監控與警報

**監控指標詳情:**

| 指標 | 說明 | 告警閾值建議 |
|------|------|-------------|
| **CPU 使用率** | 處理器使用情況 | > 80% 持續 5 分鐘 |
| **內存使用率** | 內存使用情況 | > 85% 持續 5 分鐘 |
| **磁盤使用率** | 磁盤空間使用 | > 80% |
| **網絡流入** | 入站流量 | 根據帶寬設定 |
| **網絡流出** | 出站流量 | 根據帶寬設定 |

**查看監控:**
```
位置：實例詳情頁 → 監控信息

時間範圍選項:
- 1 小時
- 6 小時
- 24 小時
- 7 天
- 自定義
```

**設置告警（雲監控控制台）:**
```
1. 訪問：https://cms.console.aliyun.com/
2. 創建告警規則
3. 選擇監控指標
4. 設置告警閾值
5. 設置通知方式（短信、郵件、釘釘）
```

**告警通知方式:**
- **短信**: 緊急告警
- **郵件**: 常規告警
- **釘釘機器人**: 團隊通知
- **Webhook**: 自定義通知

**警報歷史:**
- 查看歷史告警記錄
- 分析告警趨勢
- 優化告警閾值
