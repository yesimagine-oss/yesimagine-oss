## 📊 API 概览

### 支持的搜索类型

| 类型 | 端点 | 说明 |
|------|------|------|
| **Web 搜索** | `/search` | Google 网页搜索 |
| **图片搜索** | `/images` | Google 图片搜索 |
| **新闻搜索** | `/news` | Google 新闻搜索 |
| **地点搜索** | `/places` | Google 地点搜索 |
| **学术搜索** | `/scholar` | Google 学术搜索 |

### 主要功能

- ✅ 实时 Google 搜索结果
- ✅ 支持多种搜索类型
- ✅ 结构化 JSON 响应
- ✅ 快速响应时间
- ✅ 高可用性
