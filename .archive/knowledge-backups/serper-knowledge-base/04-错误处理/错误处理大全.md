## 📋 错误代码总览

| 错误码 | 名称 | 说明 | 解决方案 |
|--------|------|------|---------|
| 400 | Bad Request | 请求参数错误 | 检查参数格式 |
| 401 | Unauthorized | API Key 无效 | 检查 API Key |
| 402 | Payment Required | 信用点数不足 | 充值或等待重置 |
| 429 | Too Many Requests | 请求频率过高 | 降低请求频率 |
| 500 | Internal Server Error | 服务器错误 | 稍后重试 |
| 503 | Service Unavailable | 服务不可用 | 稍后重试 |

## 🔴 400 Bad Request

### 错误信息

```json
{
  "error": "Invalid request parameters",
  "code": 400,
  "details": "Missing required parameter: q"
}
```

### 原因

| 原因 | 说明 |
|------|------|
| 缺少必填参数 | 如缺少 `q` 参数 |
| 参数格式错误 | 如 `page` 不是数字 |
| 参数值无效 | 如 `gl` 不是有效国家代码 |
| JSON 格式错误 | 请求体不是有效 JSON |

### 解决方案

```python
# ❌ 错误：缺少 q 参数
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={"num": 10}  # 缺少 q
)

# ✅ 正确：包含所有必填参数
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "search query",
        "num": 10
    }
)

# ❌ 错误：参数类型错误
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "search query",
        "page": "1"  # 应该是数字
    }
)

# ✅ 正确：参数类型正确
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "search query",
        "page": 1  # 数字类型
    }
)
```

### 预防措施

```python
def validate_params(params):
    """验证请求参数"""
    required = ['q']
    for param in required:
        if param not in params:
            raise ValueError(f"Missing required parameter: {param}")
    
    if 'page' in params and not isinstance(params['page'], int):
        raise ValueError("Parameter 'page' must be an integer")
    
    if 'num' in params and not isinstance(params['num'], int):
        raise ValueError("Parameter 'num' must be an integer")
    
    return True
```

## 🔴 401 Unauthorized

### 错误信息

```json
{
  "error": "Invalid API key",
  "code": 401
}
```

### 原因

| 原因 | 说明 |
|------|------|
| API Key 错误 | 输入的 API Key 不正确 |
| API Key 缺失 | 未提供 `X-API-KEY` header |
| API Key 格式错误 | Header 格式不正确 |
| API Key 已失效 | API Key 被撤销或过期 |

### 解决方案

```python
# ❌ 错误：缺少 API Key
response = requests.post(
    "https://google.serper.dev/search",
    headers={
        "Content-Type": "application/json"
    },
    json={"q": "search query"}
)

# ✅ 正确：包含 API Key
response = requests.post(
    "https://google.serper.dev/search",
    headers={
        "X-API-KEY": "your_api_key_here",
        "Content-Type": "application/json"
    },
    json={"q": "search query"}
)

# ✅ 最佳实践：使用环境变量
import os

API_KEY = os.getenv('SERPER_API_KEY')

response = requests.post(
    "https://google.serper.dev/search",
    headers={
        "X-API-KEY": API_KEY,
        "Content-Type": "application/json"
    },
    json={"q": "search query"}
)
```

### 验证 API Key

```python
def validate_api_key(api_key):
```

## 🔴 402 Payment Required

### 错误信息

```json
{
  "error": "Insufficient credits",
  "code": 402,
  "details": "You have 0 credits remaining. Please top up to continue."
}
```

### 原因

| 原因 | 说明 |
|------|------|
| Credits 用尽 | 账户余额为 0 |
| 超出限额 | 达到套餐上限 |
| 未充值 | 免费额度已用完 |

### 解决方案

```python
# 检查 Credits 余额
def check_credits(api_key):
    """检查 Credits 余额"""
    response = requests.get(
        "https://google.serper.dev/dashboard/credits",
        headers={"X-API-KEY": api_key}
    )
    return response.json()

# 处理 Credits 不足
def search_with_retry(query, api_key, max_retries=3):
    """搜索失败时检查 Credits"""
    for attempt in range(max_retries):
        response = requests.post(
            "https://google.serper.dev/search",
            headers={"X-API-KEY": api_key},
            json={"q": query}
        )
        
        if response.status_code == 402:
            print("Credits insufficient. Please top up.")
            # 可以选择：
            # 1. 等待下个月重置
            # 2. 充值账户
            # 3. 使用备用 API Key
            return None
        elif response.status_code == 200:
            return response.json()
        else:
            # 其他错误，重试
            time.sleep(2 ** attempt)
    
    return None
```

### 预防措施

```python
class SerperClient:
    def __init__(self, api_key):
        self.api_key = api_key
        self.credits_cache = None
        self.credits_expiry = 0
    
    def get_credits(self):
        """获取 Credits 余额（带缓存）"""
        import time
        
        # 检查缓存是否过期（5 分钟）
        if time.time() < self.credits_expiry:
            return self.credits_cache
        
        # 获取最新余额
        response = requests.get(
            "https://google.serper.dev/dashboard/credits",
            headers={"X-API-KEY": self.api_key}
        )
        
        credits = response.json().get('credits', 0)
        self.credits_cache = credits
        self.credits_expiry = time.time() + 300  # 5 分钟缓存
        
        return credits
    
    def can_search(self, estimated_cost=1):
        """检查是否有足够 Credits"""
        credits = self.get_credits()
        return credits >= estimated_cost
```

## 🔴 429 Too Many Requests

### 错误信息

```json
{
  "error": "Rate limit exceeded",
  "code": 429,
  "details": "You have exceeded your QPS limit. Please slow down."
}
```

### 原因

| 原因 | 说明 |
|------|------|
| 超过 QPS 限制 | 每秒请求数超过套餐限制 |
| 并发过高 | 同时发送过多请求 |
| 短时间内大量请求 | 频率过高 |

### QPS 限制

| 套餐 | QPS 限制 |
|------|---------|
| **Starter** | 50 QPS |
| **Standard** | 100 QPS |
| **Scale** | 200 QPS |
| **Ultimate** | 300 QPS |
| **免费** | 10 QPS |

### 解决方案

```python
# 实现速率限制
import time
from collections import deque

class RateLimiter:
    def __init__(self, qps_limit):
        self.qps_limit = qps_limit
        self.requests = deque()
    
    def wait_if_needed(self):
        """如果需要，等待以满足速率限制"""
        now = time.time()
        
        # 移除 1 秒前的请求
        while self.requests and self.requests[0] < now - 1:
            self.requests.popleft()
        
        # 如果达到限制，等待
        if len(self.requests) >= self.qps_limit:
            sleep_time = 1 - (now - self.requests[0])
            if sleep_time > 0:
                time.sleep(sleep_time)
        
        # 记录当前请求
        self.requests.append(time.time())

# 使用示例
limiter = RateLimiter(qps_limit=50)  # Starter 套餐

def search_with_rate_limit(query):
    limiter.wait_if_needed()
    
    response = requests.post(
        "https://google.serper.dev/search",
        headers=headers,
        json={"q": query}
    )
    
    if response.status_code == 429:
        # 如果仍然被限流，等待后重试
        time.sleep(1)
        return search_with_rate_limit(query)
    
    return response.json()
```

### 指数退避重试

```python
def search_with_backoff(query, max_retries=5):
    """使用指数退避重试"""
    for attempt in range(max_retries):
        response = requests.post(
            "https://google.serper.dev/search",
            headers=headers,
            json={"q": query}
        )
        
        if response.status_code == 429:
            # 指数退避：1s, 2s, 4s, 8s, 16s
            wait_time = 2 ** attempt
            print(f"Rate limited. Waiting {wait_time}s...")
            time.sleep(wait_time)
        else:
            return response.json()
    
    raise Exception("Max retries exceeded")
```

## 🔴 500 Internal Server Error

### 错误信息

```json
{
  "error": "Internal server error",
  "code": 500
}
```

### 原因

| 原因 | 说明 |
|------|------|
| 服务器故障 | Serper 服务器出现问题 |
| 临时错误 | 短暂的服务器问题 |
| 维护中 | 服务器正在维护 |

### 解决方案

```python
def search_with_retry(query, max_retries=3):
    """500 错误时重试"""
    for attempt in range(max_retries):
        response = requests.post(
            "https://google.serper.dev/search",
            headers=headers,
            json={"q": query}
        )
        
        if response.status_code == 500:
            if attempt == max_retries - 1:
                raise Exception("Server error after max retries")
            
            # 等待后重试
            wait_time = 2 ** attempt
            print(f"Server error. Retrying in {wait_time}s...")
            time.sleep(wait_time)
        else:
            return response.json()
    
    return None
```

## 🔴 503 Service Unavailable

### 错误信息

```json
{
  "error": "Service unavailable",
  "code": 503
}
```

### 原因

| 原因 | 说明 |
|------|------|
| 服务维护 | 服务器正在维护 |
| 过载 | 服务器负载过高 |
| 临时不可用 | 短暂的服务中断 |

### 解决方案

```python
def search_with_503_handling(query):
    """处理 503 错误"""
    max_retries = 5
    base_wait = 5  # 5 秒
    
    for attempt in range(max_retries):
        response = requests.post(
            "https://google.serper.dev/search",
            headers=headers,
            json={"q": query}
        )
        
        if response.status_code == 503:
            # 检查 Retry-After header
            retry_after = response.headers.get('Retry-After')
            
            if retry_after:
                wait_time = int(retry_after)
            else:
                # 指数退避
                wait_time = base_wait * (2 ** attempt)
            
            print(f"Service unavailable. Retrying in {wait_time}s...")
            time.sleep(wait_time)
        else:
            return response.json()
    
    raise Exception("Service unavailable after max retries")
```

## 🛡️ 完整的错误处理类

```python
import requests
import time
from typing import Optional, Dict

class SerperAPIError(Exception):
    """Serper API 错误基类"""
    pass

class AuthenticationError(SerperAPIError):
    """认证错误 (401)"""
    pass

class CreditError(SerperAPIError):
    """Credits 不足 (402)"""
    pass

class RateLimitError(SerperAPIError):
    """速率限制 (429)"""
    pass

class ServerError(SerperAPIError):
    """服务器错误 (500, 503)"""
    pass

class SerperClient:
    def __init__(self, api_key: str, qps_limit: int = 50):
        self.api_key = api_key
        self.base_url = "https://google.serper.dev"
        self.session = requests.Session()
        self.session.headers.update({
            "X-API-KEY": api_key,
            "Content-Type": "application/json"
        })
        
        # 速率限制
        self.qps_limit = qps_limit
        self.request_times = []
    
    def _wait_for_rate_limit(self):
        """等待以满足速率限制"""
        now = time.time()
        
        # 移除 1 秒前的请求
        self.request_times = [t for t in self.request_times if t > now - 1]
        
        # 如果达到限制，等待
        if len(self.request_times) >= self.qps_limit:
            sleep_time = 1 - (now - self.request_times[0])
            if sleep_time > 0:
                time.sleep(sleep_time)
        
        self.request_times.append(time.time())
    
    def _request(self, endpoint: str, payload: Dict, max_retries: int = 3) -> Dict:
        """发送请求（带错误处理）"""
        url = f"{self.base_url}{endpoint}"
        
        for attempt in range(max_retries):
            try:
                # 速率限制
                self._wait_for_rate_limit()
                
                response = self.session.post(url, json=payload)
                
                # 处理错误
                if response.status_code == 400:
                    raise SerperAPIError(f"Bad Request: {response.text}")
                
                elif response.status_code == 401:
                    raise AuthenticationError("Invalid API Key")
                
                elif response.status_code == 402:
                    raise CreditError("Insufficient credits")
                
                elif response.status_code == 429:
                    if attempt == max_retries - 1:
                        raise RateLimitError("Rate limit exceeded after max retries")
                    wait_time = 2 ** attempt
                    time.sleep(wait_time)
                    continue
                
                elif response.status_code >= 500:
                    if attempt == max_retries - 1:
                        raise ServerError(f"Server error: {response.status_code}")
                    wait_time = 2 ** attempt
                    time.sleep(wait_time)
                    continue
                
                # 成功
                response.raise_for_status()
                return response.json()
                
            except requests.exceptions.RequestException as e:
                if attempt == max_retries - 1:
                    raise SerperAPIError(f"Request failed: {str(e)}")
                time.sleep(2 ** attempt)
        
        return {}
    
    def search(self, query: str, **params) -> Dict:
        """执行搜索"""
        payload = {"q": query, **params}
        return self._request("/search", payload)
    
    def search_images(self, query: str, **params) -> Dict:
        """搜索图片"""
        payload = {"q": query, **params}
        return self._request("/images", payload)
    
    def search_news(self, query: str, **params) -> Dict:
        """搜索新闻"""
        payload = {"q": query, **params}
        return self._request("/news", payload)

# 使用示例
if __name__ == "__main__":
    client = SerperClient(api_key="your_api_key", qps_limit=50)
    
    try:
        results = client.search("AI agent")
        print(results)
    except AuthenticationError:
        print("API Key 无效")
    except CreditError:
        print("Credits 不足")
    except RateLimitError:
        print("请求频率过高")
    except ServerError:
        print("服务器错误")
    except SerperAPIError as e:
        print(f"API 错误：{e}")
```
