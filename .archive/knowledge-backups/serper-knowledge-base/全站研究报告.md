### 5. API 文档

**基础信息:**
- Base URL: `https://google.serper.dev`
- 认证：`X-API-KEY` header
- 方法：POST
- 响应：JSON

**通用参数:**
- q (搜索关键词)
- gl (国家代码)
- hl (语言代码)
- page (页码)
- num (结果数量)
- autocorrect (自动纠正)
- tbs (时间过滤)
- location (地理位置)
