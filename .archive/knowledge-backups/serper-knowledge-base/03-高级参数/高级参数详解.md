## 📋 参数总览

| 参数 | 类型 | 必填 | 说明 | 默认值 |
|------|------|------|------|--------|
| `q` | string | ✅ | 搜索关键词 | - |
| `gl` | string | ❌ | 国家代码 | `us` |
| `hl` | string | ❌ | 语言代码 | `en` |
| `page` | number | ❌ | 页码 | `1` |
| `num` | number | ❌ | 结果数量 | `10` |
| `autocorrect` | boolean | ❌ | 自动纠正 | `true` |
| `tbs` | string | ❌ | 时间过滤 | - |
| `location` | string | ❌ | 地理位置 | - |

## 🔧 高级参数详解

### 1. 时间过滤 (`tbs`)

**用途:** 过滤特定时间范围内的搜索结果

**语法:** `tbs=qdr:X`

| 值 | 说明 | 示例 |
|------|------|------|
| `qdr:h` | 过去 1 小时 | `"tbs": "qdr:h"` |
| `qdr:d` | 过去 1 天 | `"tbs": "qdr:d"` |
| `qdr:w` | 过去 1 周 | `"tbs": "qdr:w"` |
| `qdr:m` | 过去 1 月 | `"tbs": "qdr:m"` |
| `qdr:y` | 过去 1 年 | `"tbs": "qdr:y"` |

**使用示例:**

```python
# 搜索过去 24 小时的新闻
response = requests.post(
    "https://google.serper.dev/news",
    headers=headers,
    json={
        "q": "AI technology",
        "tbs": "qdr:d"
    }
)

# 搜索过去 1 周的内容
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "machine learning",
        "tbs": "qdr:w"
    }
)
```

---

### 2. 地理位置 (`location`)

**用途:** 定制搜索的地理位置

**语法:** `location: 城市，国家`

**示例值:**
- `"New York, USA"`
- `"London, UK"`
- `"Tokyo, Japan"`
- `"Beijing, China"`

**使用示例:**

```python
# 搜索纽约的餐厅
response = requests.post(
    "https://google.serper.dev/places",
    headers=headers,
    json={
        "q": "restaurants",
        "location": "New York, USA"
    }
)

# 搜索伦敦的新闻
response = requests.post(
    "https://google.serper.dev/news",
    headers=headers,
    json={
        "q": "tech news",
        "location": "London, UK"
    }
)
```

### 3. 国家代码 (`gl`)

**用途:** 指定搜索结果的国家来源

**常用值:**

| 代码 | 国家 |
|------|------|
| `us` | 美国 |
| `gb` | 英国 |
| `cn` | 中国 |
| `de` | 德国 |
| `fr` | 法国 |
| `jp` | 日本 |
| `kr` | 韩国 |
| `in` | 印度 |
| `br` | 巴西 |
| `au` | 澳大利亚 |

**使用示例:**

```python
# 搜索美国结果
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "AI agent",
        "gl": "us"
    }
)

# 搜索英国结果
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "AI agent",
        "gl": "gb"
    }
)
```

### 4. 语言代码 (`hl`)

**用途:** 指定搜索结果的语言

**常用值:**

| 代码 | 语言 |
|------|------|
| `en` | 英语 |
| `zh-CN` | 简体中文 |
| `zh-TW` | 繁体中文 |
| `es` | 西班牙语 |
| `fr` | 法语 |
| `de` | 德语 |
| `ja` | 日语 |
| `ko` | 韩语 |

**使用示例:**

```python
# 搜索中文结果
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "人工智能",
        "hl": "zh-CN"
    }
)

# 搜索日语结果
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "人工知能",
        "hl": "ja"
    }
)
```

---

### 5. 结果数量 (`num`)

**用途:** 指定返回的搜索结果数量

**限制:** 最多 100 条/页

**使用示例:**

```python
# 获取 20 个结果
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "AI agent",
        "num": 20
    }
)

# 获取 100 个结果（最大）
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "AI agent",
        "num": 100
    }
)
```

---

### 6. 页码 (`page`)

**用途:** 获取分页结果

**说明:** 每页最多 10 个结果（默认）

**使用示例:**

```python
# 获取第 1 页
response1 = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={"q": "AI agent", "page": 1}
)

# 获取第 2 页
response2 = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={"q": "AI agent", "page": 2}
)

# 获取第 3 页
response3 = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={"q": "AI agent", "page": 3}
)
```

---

### 7. 自动纠正 (`autocorrect`)

**用途:** 启用/禁用搜索关键词自动纠正

**值:**
- `true` (默认): 启用自动纠正
- `false`: 禁用自动纠正

**使用示例:**

```python
# 启用自动纠正（默认）
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "machne learning",  # 拼写错误
        "autocorrect": True
    }
)
# 会自动纠正为 "machine learning"

# 禁用自动纠正
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={
        "q": "machne learning",
        "autocorrect": False
    }
)
```

## ⚠️ 使用限制

| 限制 | 说明 |
|------|------|
| **num 最大值** | 100 条/页 |
| **page 最大值** | 无限制（但受 Credits 限制） |
| **tbs 格式** | 必须为 `qdr:X` 格式 |
| **location 格式** | `城市，国家` |
| **gl 代码** | 2 字母国家代码 |
| **hl 代码** | 语言代码（部分带地区） |

---

## 📊 参数优先级

当多个参数冲突时，优先级如下：

1. `location` > `gl` (地理位置优先于国家代码)
2. `hl` 独立 (语言代码独立生效)
3. `tbs` 独立 (时间过滤独立生效)
4. `num` 和 `page` 独立 (分页参数独立生效)

## 💡 最佳实践

### 1. 精准搜索

```python
# 组合使用 location 和 gl 实现精准定位
response = requests.post(
    "https://google.serper.dev/search",
    headers=headers,
    json={

        "location": "San Francisco, CA",

```

### 2. 时效性搜索

```python
# 搜索最新内容
response = requests.post(
    "https://google.serper.dev/news",
    headers=headers,
    json={
        "q": "breaking news",
        "tbs": "qdr:h"  # 过去 1 小时
    }
)
```

### 3. 多语言搜索

```python
# 搜索多语言结果
languages = ['en', 'zh-CN', 'ja', 'ko']

for lang in languages:
    response = requests.post(
        "https://google.serper.dev/search",
        headers=headers,
        json={
            "q": "AI technology",
            "hl": lang
        }
    )
    # 处理结果...
```

### 4. 批量分页获取

```python
def get_all_results(query, max_pages=5):
    all_results = []
    for page in range(1, max_pages + 1):
        response = requests.post(
            "https://google.serper.dev/search",
            headers=headers,
            json={"q": query, "page": page}
        )
        results = response.json().get('organic', [])
        if not results:
            break
        all_results.extend(results)
    return all_results
```
