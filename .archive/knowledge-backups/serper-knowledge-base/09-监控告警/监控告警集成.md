## 📊 监控指标

### 核心指标

| 指标 | 类型 | 说明 | 告警阈值 |
|------|------|------|---------|
| `serper_requests_total` | Counter | 总请求数 | - |
| `serper_requests_failed` | Counter | 失败请求数 | > 1% |
| `serper_request_duration` | Histogram | 请求延迟 | P95 > 5s |
| `serper_credits_remaining` | Gauge | 剩余额度 | < 1000 |
| `serper_rate_limit_hits` | Counter | 限流次数 | > 0 |

## 🔧 Prometheus 集成

### 指标导出器

```python
# monitoring/prometheus_exporter.py
from prometheus_client import Counter, Histogram, Gauge, start_http_server
import time
import requests

# 指标定义
REQUESTS_TOTAL = Counter('serper_requests_total', 'Total Serper API requests', ['endpoint', 'status'])
REQUEST_DURATION = Histogram('serper_request_duration_seconds', 'Request duration', ['endpoint'])
CREDITS_REMAINING = Gauge('serper_credits_remaining', 'Remaining API credits')
RATE_LIMIT_HITS = Counter('serper_rate_limit_hits_total', 'Rate limit hits')

class SerperMonitor:
    def __init__(self, api_key, prom_port=8000):
        self.api_key = api_key
        self.base_url = "https://google.serper.dev"
        start_http_server(prom_port)
        print(f"Prometheus metrics available on port {prom_port}")
    
    def search(self, query, endpoint="search"):
        """带监控的搜索"""
        start_time = time.time()
        status = "success"
        
        try:
            response = requests.post(
                f"{self.base_url}/{endpoint}",
                headers={"X-API-KEY": self.api_key},
                json={"q": query},
                timeout=30
            )
            
            if response.status_code == 429:
                RATE_LIMIT_HITS.inc()
                status = "rate_limited"
            elif response.status_code >= 400:
                status = f"error_{response.status_code}"
            
            REQUESTS_TOTAL.labels(endpoint=endpoint, status=status).inc()
            REQUEST_DURATION.labels(endpoint=endpoint).observe(time.time() - start_time)
            
            # 更新 Credits (从响应中获取)
            if response.status_code == 200:
                data = response.json()
                if "credits" in data:
                    CREDITS_REMAINING.set(data.get("creditsRemaining", 0))
            
            return response.json()
            
        except Exception as e:
            REQUESTS_TOTAL.labels(endpoint=endpoint, status="exception").inc()
            raise

# 使用示例
if __name__ == "__main__":
    monitor = SerperMonitor(api_key="01529847d4aa3cf47b86ca87d28519110db06390")
    result = monitor.search("AI agent")
```

## 🚨 告警规则

### Alertmanager 配置

```yaml
# alertmanager.yml
groups:
  - name: serper-alerts
    rules:
      - alert: SerperHighErrorRate
        expr: rate(serper_requests_total{status=~"error.*"}[5m]) > 0.01
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Serper API 错误率过高"
          description: "错误率超过 1%"

      - alert: SerperHighLatency
        expr: histogram_quantile(0.95, rate(serper_request_duration_seconds_bucket[5m])) > 5
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Serper API 延迟过高"
          description: "P95 延迟超过 5 秒"

      - alert: SerperLowCredits
        expr: serper_credits_remaining < 1000
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "Serper API 额度不足"
          description: "剩余额度低于 1000"

      - alert: SerperRateLimited
        expr: rate(serper_rate_limit_hits_total[5m]) > 0
        for: 1m
        labels:
          severity: warning
        annotations:
          summary: "Serper API 触发限流"
          description: "检测到速率限制"
```

### 钉钉通知

```python
# monitoring/dingtalk_notifier.py
import requests
import json

class DingTalkNotifier:
    def __init__(self, webhook_url):
        self.webhook_url = webhook_url
    
    def send_alert(self, alert_name, message, severity="warning"):
        """发送告警到钉钉"""
        color = "warning" if severity == "warning" else "danger"
        
        payload = {
            "msgtype": "markdown",
            "markdown": {
                "title": f"Serper API 告警：{alert_name}",
                "text": f"## Serper API 告警\n\n"
                        f"**告警名称:** {alert_name}\n\n"
                        f"**严重程度:** {severity.upper()}\n\n"
                        f"**详情:** {message}\n\n"
                        f"**时间:** {self._get_timestamp()}"
            }
        }
        
        response = requests.post(
            self.webhook_url,
            json=payload,
            headers={"Content-Type": "application/json"}
        )
        return response.status_code == 200
    
    def _get_timestamp(self):
        from datetime import datetime
        return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# 使用示例
notifier = DingTalkNotifier("https://oapi.dingtalk.com/robot/send?access_token=xxx")
notifier.send_alert("额度不足", "剩余 Credits: 500", severity="critical")
```

## 📋 健康检查

### 健康检查脚本

```python
# monitoring/health_check.py
import requests
import time
import sys

def check_serper_health(api_key):
    """检查 Serper API 健康状态"""
    endpoints = [
        ("search", {"q": "health check"}),
        ("images", {"q": "test"}),
        ("news", {"q": "test"})
    ]
    
    results = {}
    all_healthy = True
    
    for endpoint, payload in endpoints:
        try:
            start = time.time()
            response = requests.post(
                f"https://google.serper.dev/{endpoint}",
                headers={"X-API-KEY": api_key},
                json=payload,
                timeout=10
            )
            latency = time.time() - start
            
            results[endpoint] = {
                "status": "healthy" if response.status_code == 200 else "unhealthy",
                "latency_ms": round(latency * 1000, 2),
                "status_code": response.status_code
            }
            
            if response.status_code != 200:
                all_healthy = False
                
        except Exception as e:
            results[endpoint] = {
                "status": "unhealthy",
                "error": str(e)
            }
            all_healthy = False
    
    return all_healthy, results

if __name__ == "__main__":
    api_key = "01529847d4aa3cf47b86ca87d28519110db06390"
    healthy, results = check_serper_health(api_key)
    
    print(f"Health Check: {'✅ PASS' if healthy else '❌ FAIL'}")
    for endpoint, result in results.items():
        print(f"  {endpoint}: {result}")
    
    sys.exit(0 if healthy else 1)
```

### 结构化日志

```python
# monitoring/logging_config.py
import logging
import json
from datetime import datetime

class JSONFormatter(logging.Formatter):
    def format(self, record):
        log_entry = {
            "timestamp": datetime.utcnow().isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "module": record.module,
            "function": record.funcName,
            "line": record.lineno
        }
        if hasattr(record, 'extra_data'):
            log_entry.update(record.extra_data)
        return json.dumps(log_entry)

def setup_logging():
    logger = logging.getLogger("serper")
    logger.setLevel(logging.INFO)
    
    handler = logging.StreamHandler()
    handler.setFormatter(JSONFormatter())
    logger.addHandler(handler)
    
    return logger

# 使用示例
logger = setup_logging()
logger.info("API request", extra={"extra_data": {"endpoint": "search", "query": "AI"}})
```

## 📞 告警响应流程

### 告警处理 SOP

| 告警类型 | 响应时间 | 处理流程 |
|---------|---------|---------|
| 额度不足 | 1 小时 | 1. 确认用量 2. 充值或优化 3. 通知团队 |
| 错误率高 | 15 分钟 | 1. 检查日志 2. 重试机制 3. 联系支持 |
| 延迟过高 | 30 分钟 | 1. 检查网络 2. 降级策略 3. 切换备用 |
| 服务不可用 | 5 分钟 | 1. 启用备用 2. 通知用户 3. 联系支持 |
