## 代码贡献

### 开发环境搭建

**1. 克隆项目**

```bash
git clone https://github.com/EvoMap/evolver.git
cd evolver
```

**2. 安装依赖**

```bash
npm install
```

**3. 配置环境**

```bash
cp .env.example .env
# 编辑 .env 文件，填入测试配置
```

**4. 运行测试**

```bash
npm test
```

### 贡献流程

**1. Fork 项目**

```bash
# 在 GitHub 上点击 Fork 按钮
# 然后克隆你的 Fork
git clone https://github.com/your-username/evolver.git
cd evolver
```

**2. 创建分支**

```bash
git checkout -b feature/your-feature-name
# 或
git checkout -b fix/issue-123
```

**分支命名规范:**

| 类型 | 前缀 | 示例 |
|------|------|------|
| 新功能 | feature/ | feature/add-new-api |
| Bug 修复 | fix/ | fix/memory-leak |
| 文档更新 | docs/ | docs/update-readme |
| 性能优化 | perf/ | perf/improve-query-speed |
| 代码重构 | refactor/ | refactor/simplify-logic |
| 测试添加 | test/ | test/add-unit-tests |

**3. 开发代码**

```javascript
// 遵循项目代码规范
// 添加必要的注释
// 编写单元测试
```

**代码规范:**

```javascript
// ✅ 推荐
// 使用有意义的变量名
function calculateAssetScore(asset, signals) {
  let score = 0;
  for (const signal of signals) {
    if (asset.signals_match.includes(signal)) {
      score += 1;
    }
  }
  return score;
}

// ❌ 避免
function calc(a, b) {
  let s = 0;
  for (const i of b) {
    if (a.includes(i)) s += 1;
  }
  return s;
}
```

**4. 提交代码**

```bash
# 添加变更
git add .

# 提交（遵循提交规范）
git commit -m "feat: add new API endpoint for batch operations

- Added /api/batch endpoint
- Implemented rate limiting
- Added comprehensive tests

Closes #123"
```

**提交信息规范:**

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Type 类型:**

| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | Bug 修复 |
| docs | 文档更新 |
| style | 代码格式 |
| refactor | 重构 |
| perf | 性能优化 |
| test | 测试相关 |
| chore | 构建/工具 |

**5. 推送代码**

```bash
git push origin feature/your-feature-name
```

**6. 创建 Pull Request**

- 在 GitHub 上创建 PR
- 填写 PR 描述
- 关联 Issue
- 等待审核

**PR 描述模板:**

```markdown
## 变更说明
简要描述本次变更的内容

## 相关 Issue
Closes #123

## 测试
- [ ] 已添加单元测试
- [ ] 已运行集成测试
- [ ] 已手动测试

## 截图/录屏
如适用，请提供截图或录屏

## 检查清单
- [ ] 代码遵循项目规范
- [ ] 已添加必要注释
- [ ] 已更新相关文档
- [ ] 测试全部通过
```
