# 社区贡献指南

**最后更新:** 2026-03-14  
**难度:** ⭐⭐ 初级

---

## 🎯 贡献方式

### 1. 文档贡献

**可以贡献:**
- ✅ 修正错别字和语法错误
- ✅ 补充遗漏内容
- ✅ 添加新的示例
- ✅ 翻译多语言版本
- ✅ 更新过时信息

**如何贡献:**
1. Fork 知识库仓库
2. 创建分支 (`git checkout -b docs/xxx`)
3. 修改文档
4. 提交 PR (`git push origin docs/xxx`)
5. 等待审核

---

### 2. 案例分享

**可以分享:**
- ✅ 真实项目案例
- ✅ 问题解决方案
- ✅ 性能优化经验
- ✅ 故障排查记录

**案例格式:**
```markdown
# 案例标题

## 背景
问题描述、症状

## 分析过程
如何定位问题

## 解决方案
具体实现

## 效果验证
优化前后对比

## 经验教训
学到的东西
```

---

### 3. 代码贡献

**可以贡献:**
- ✅ 工具函数
- ✅ 示例代码
- ✅ 测试用例
- ✅ 自动化脚本

**代码要求:**
- ✅ 遵循代码规范
- ✅ 包含注释
- ✅ 有测试覆盖
- ✅ 无安全漏洞

---

### 4. 社区帮助

**可以帮助:**
- ✅ Discord 回答问题
- ✅ 审查新手资产
- ✅ 分享经验技巧
- ✅ 组织社区活动

---

## 📋 贡献流程

### 文档贡献流程

```
1. 发现问题或改进点
   ↓
2. Fork 仓库
   ↓
3. 创建分支
   ↓
4. 修改内容
   ↓
5. 本地验证
   ↓
6. 提交 PR
   ↓
7. 等待审核
   ↓
8. 合并完成
```

### 案例提交流程

```
1. 准备案例内容
   ↓
2. 遵循案例格式
   ↓
3. 提交到案例库
   ↓
4. 社区审核
   ↓
5. 发布展示
```

## 📝 贡献规范

### 文档规范

**格式要求:**
- ✅ 使用 Markdown
- ✅ 标题层级清晰
- ✅ 代码块标注语言
- ✅ 链接有效

**内容要求:**
- ✅ 准确无误
- ✅ 清晰易懂
- ✅ 实用性强
- ✅ 无版权问题

### 代码规范

**风格要求:**
```javascript
// ✅ 推荐
function calculateTotal(products) {
  return products.reduce((sum, p) => sum + p.price, 0);
}

// ❌ 避免
function c(p) { return p.reduce((s,i)=>s+i.p,0); }
```

**注释要求:**
```javascript
// ✅ 推荐：解释为什么
// 使用快速排序因为数据量大时性能更好
const sorted = data.sort((a, b) => a - b);

// ❌ 避免：解释是什么
// 排序数组
const sorted = data.sort((a, b) => a - b);
```

## 🎓 贡献者等级

### Level 1: 新手贡献者

**要求:**
- 完成 1 次文档修正
- 参与社区讨论

**权益:**
- 贡献者徽章（铜）
- +5 声誉

---

### Level 2: 活跃贡献者

**要求:**
- 完成 5 次文档修正
- 或分享 2 个案例
- 或提交 3 个代码 PR

**权益:**
- 贡献者徽章（银）
- +15 声誉
- 优先支持

---

### Level 3: 核心贡献者

**要求:**
- 完成 20 次文档修正
- 或分享 10 个案例
- 或提交 10 个代码 PR
- 或社区帮助 50+ 次

**权益:**
- 贡献者徽章（金）
- +50 声誉
- 决策参与权
- 官方认可
