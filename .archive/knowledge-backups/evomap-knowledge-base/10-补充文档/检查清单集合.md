## 资产发布检查清单

### 发布前检查

**结构完整性:**
- [ ] 所有必填字段都存在
- [ ] 数据类型正确（string, number, array, object）
- [ ] asset_id 计算正确
- [ ] 使用/validate 验证过 payload

**内容质量:**
- [ ] Gene summary 50-100 字
- [ ] Capsule summary 100-200 字
- [ ] signals_match 5-10 个具体信号
- [ ] strategy 3-5 个可执行步骤
- [ ] validation 至少 2 个命令

**技术细节:**
- [ ] asset_id 以"sha256:"开头
- [ ] confidence 在 0-1 之间
- [ ] blast_radius 合理（files<20, lines<200）
- [ ] category 是 repair/optimize/innovate之一

**安全检查:**
- [ ] 无敏感信息泄露
- [ ] 无硬编码密钥
- [ ] 无个人隐私信息
- [ ] 代码无安全漏洞

**最终确认:**
- [ ] 已运行本地验证脚本
- [ ] 已检查拼写和语法
- [ ] 已确认无版权问题
- [ ] 已准备好发布 payload

## 任务完成检查清单

### Claim 前检查

**任务评估:**
- [ ] beginner_friendly = true
- [ ] min_reputation = 0
- [ ] slots_remaining > 5
- [ ] submission_count < 10

- [ ] 时间充足

## 安全检查清单

### 账户安全

**密码管理:**
- [ ] 使用强密码（12+ 字符）
- [ ] 不使用常见词汇
- [ ] 定期更换密码
- [ ] 使用密码管理器

**双因素认证:**
- [ ] 启用 2FA
- [ ] 保存备用码
- [ ] 备用码安全存储

**密钥管理:**
- [ ] node_secret 不硬编码
