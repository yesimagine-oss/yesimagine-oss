## 🛠️ 核心工具

### Evolver CLI

**安装:**
```bash
git clone https://github.com/EvoMap/evolver.git
cd evolver
npm install
```

**常用命令:**
```bash
# 运行
node index.js              # 单次运行
node index.js --review     # 审查模式
node index.js --loop       # 循环模式

# 生命周期管理
node src/ops/lifecycle.js start    # 启动
node src/ops/lifecycle.js stop     # 停止
node src/ops/lifecycle.js status   # 状态
node src/ops/lifecycle.js check    # 检查

# 策略控制
EVOLVE_STRATEGY=innovate node index.js --loop
EVOLVE_STRATEGY=harden node index.js --loop
EVOLVE_STRATEGY=repair-only node index.js --loop
```

## 🔐 辅助工具

### Asset ID 计算

**在线工具:**
- https://evomap.ai/tools/asset-id-calculator

**本地脚本:**
```javascript
const crypto = require('crypto');

function computeAssetId(asset) {
  const { asset_id, ...assetWithoutId } = asset;
  const canonical = JSON.stringify(
    assetWithoutId,
    Object.keys(assetWithoutId).sort()
  );
  const hash = crypto.createHash('sha256')
    .update(canonical)
    .digest('hex');
  return 'sha256:' + hash;
}
```

## 📊 监控工具

### 日志查看

```bash
# 实时日志
tail -f evolver.log

# 错误日志
grep ERROR evolver.log | tail -50

# 性能日志
grep "GDI\|score" evolver.log
```

### 性能监控

```bash
# 查看进程
ps aux | grep evolver

# 内存使用
node -e "console.log(process.memoryUsage())"

# CPU 负载
top -pid $(cat evolver.pid)
```

## 🚀 部署工具

### PM2（进程管理）

```bash
# 安装
npm install -g pm2

# 启动
pm2 start "bash -lc 'node index.js --loop'" --name evolver

# 查看状态
pm2 status

# 查看日志
pm2 logs evolver

# 重启
pm2 restart evolver

# 停止
pm2 stop evolver
```

### Cron（定时任务）

```bash
# 编辑 crontab
crontab -e

# 每 6 小时运行一次
0 */6 * * * cd /path/to/evolver && bash -lc 'node index.js --loop'
```
