## 🖼️ 鏡像優化

### 1. 減小鏡像大小

```dockerfile
# ❌ 避免：多層構建
FROM ubuntu:24.04
RUN apt-get update
RUN apt-get install -y python3
RUN apt-get install -y python3-pip
RUN pip3 install flask
COPY . .

# ✅ 推薦：合併層 + 精簡基礎鏡像
FROM python:3.11-slim
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
    gcc \
    python3-dev && \
    rm -rf /var/lib/apt/lists/*
RUN pip3 install --no-cache-dir flask
COPY . .
```

### 2. 多階段構建

```dockerfile
# 構建階段
FROM golang:1.21 AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# 運行階段 (極小鏡像)
FROM alpine:3.18
RUN apk --no-cache add ca-certificates
WORKDIR /root/
COPY --from=builder /app/main .
CMD ["./main"]

# 結果：從 800MB+ 減少到 15MB
```

### 3. 使用 .dockerignore

```dockerignore
# 版本控制

# 依賴

# 構建产物

```

### 4. 鏡像緩存優化

```dockerfile
# ❌ 避免：頻繁變化的層在前
COPY . .
RUN npm install

# ✅ 推薦：不變的層在前
COPY package*.json ./
RUN npm install
COPY . .
```

## 📦 容器優化

### 1. CPU 優化

```bash
# 設置 CPU 份額
docker run -d --cpu-shares=512 nginx

# 設置 CPU 核心
docker run -d --cpus="1.5" nginx
docker run -d --cpuset-cpus="0,1" nginx

# 監控 CPU 使用
docker stats --format "table {{.Name}}\t{{.CPUPerc}}\t{{.AvgCPU}}"
```

### 2. 內存優化

```bash
# 設置硬限制
docker run -d --memory="512m" nginx

# 設置軟限制 (預約)
docker run -d --memory-reservation="256m" nginx

# 設置交換空間
docker run -d --memory-swap="1g" nginx

# 防止 OOM
docker run -d --oom-kill-disable --memory="512m" nginx

# 監控內存
docker stats --format "table {{.Name}}\t{{.MemUsage}}\t{{.MemPerc}}"
```

### 3. 進程數限制

```bash
# 限制進程數
docker run -d --pids-limit=100 nginx

# 監控進程
docker stats --format "table {{.Name}}\t{{.PIDs}}"
```

### 4. 重啟策略優化

```bash
# 推薦：除非手動停止否則重啟
docker run -d --restart=unless-stopped nginx

# 失敗時重啟 (最多 3 次)
docker run -d --restart=on-failure:3 nginx

# 不重啟 (測試環境)
docker run -d --restart=no nginx
```

## 🌐 網絡優化

### 1. 選擇合適的網絡驅動

```bash
# Bridge (默認，適合大多數場景)
docker network create --driver bridge my-bridge

# Host (性能最好，無隔離)
docker run -d --network=host nginx

# Macvlan (直接連接物理網絡)
docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  -o parent=eth0 \
  macvlan-net

# Overlay (跨主機通信)
docker network create -d overlay my-overlay
```

### 2. DNS 優化

```bash
# 自定義 DNS
docker run -d \
  --dns 8.8.8.8 \
  --dns 8.8.4.4 \
  --dns-search example.com \
  nginx

# 禁用 DNS 查找
docker run -d \
  --dns-opt "options:ndots:1" \
  nginx
```

### 3. 端口映射優化

```bash
# 綁定到特定接口
docker run -d -p 127.0.0.1:8080:80 nginx

# 使用 HOST 模式 (無網絡轉換)
docker run -d --network=host nginx

# 批量映射端口
docker run -d \
  -p 80:80 \
  -p 443:443 \
  -p 8080:8080 \
  nginx
```

### 4. 網絡性能調優

```bash
# 調整 MTU
docker network create \
  --opt com.docker.network.driver.mtu=1450 \
  my-network

# 調整緩衝區
sysctl -w net.core.rmem_max=16777216
sysctl -w net.core.wmem_max=16777216
```

## 💾 存儲優化

### 1. 選擇合適的存儲驅動

```bash
# 查看當前驅動
docker info --format '{{.Driver}}'

# 推薦：overlay2 (默認)
# 優點：性能好，支持層數多
# 缺點：需要較新內核

# 替代：aufs (老舊系統)
# 不推薦：devicemapper, btrfs
```

### 2. 卷管理優化

```bash
# 使用命名卷 (推薦)
docker volume create mydata
docker run -d -v mydata:/data nginx

# 使用 bind mount (開發環境)
docker run -d -v /host/path:/container/path nginx

# 使用 tmpfs (臨時數據)
docker run -d --tmpfs /app/cache:rw,noexec,nosuid,size=100m nginx

# 調整卷權限
docker run -d -v mydata:/data:rw nginx
docker run -d -v mydata:/data:ro nginx  # 只讀
```

### 3. 日誌管理

```bash
# 配置日誌輪轉
# /etc/docker/daemon.json
{
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}

# 單容器配置
docker run -d \
  --log-driver json-file \
  --log-opt max-size=10m \
  --log-opt max-file=3 \
  nginx

# 清理日誌
truncate -s 0 /var/lib/docker/containers/*/*-json.log
```

### 4. 磁盤清理

```bash
# 系統清理
docker system prune -a --volumes

# 鏡像清理
docker image prune -a --filter "until=168h"

# 容器清理
docker container prune

# 網絡清理
docker network prune

# 卷清理 (小心)
docker volume prune

# 構建緩存清理
docker builder prune
```

## 🖥️ 主機優化

### 1. 內核參數調優

```bash
# /etc/sysctl.conf
# 增加文件描述符限制
fs.file-max = 2097152
fs.nr_open = 2097152

# 增加連接隊列
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 65535

# 調整內存分配
vm.swappiness = 1
vm.overcommit_memory = 1

# 應用配置
sysctl -p
```

### 2. 資源限制

```bash
# 增加文件描述符
ulimit -n 65536

# Docker 配置
# /etc/docker/daemon.json
{
  "default-ulimits": {
    "nofile": {
      "Name": "nofile",
      "Hard": 65536,
      "Soft": 1024
    }
  }
}
```

### 3. 監控與警報

```bash
# 安裝監控工具
docker run -d \
  --name=cadvisor \
  -p 8080:8080 \
  -v /:/rootfs:ro \
  -v /var/run:/var/run:ro \
  -v /sys:/sys:ro \
  -v /var/lib/docker/:/var/lib/docker:ro \
  google/cadvisor:latest

# 使用 docker stats
watch -n 1 'docker stats --no-stream'

# 自定義監控腳本
#!/bin/bash
docker stats --no-stream --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}" | \
  awk 'NR>1 && ($2+0 > 80 || $3+0 > 80) {print "⚠️ 警告:", $0}'
```

## 🔧 實戰優化案例

### 案例 1: Web 應用優化

```yaml
# docker-compose.yml
version: '3.8'

services:
  web:
    image: nginx:alpine
    container_name: web
    restart: unless-stopped
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html:ro
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    networks:
      - webnet
    deploy:
      resources:
        limits:
          cpus: '1'
          memory: 256M
        reservations:
          cpus: '0.5'
          memory: 128M

networks:
  webnet:
    driver: bridge
```

### 案例 2: 數據庫優化

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
    volumes:
      - mysql-data:/var/lib/mysql
      - ./mysql.cnf:/etc/mysql/conf.d/custom.cnf:ro
    networks:
      - dbnet
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 2G
        reservations:
          cpus: '1'
          memory: 1G

volumes:
  mysql-data:
    driver: local

networks:
  dbnet:
    driver: bridge
```

### 案例 3: CI/CD 優化

```yaml
version: '3.8'

services:
  runner:
    image: docker:24-dind
    container_name: ci-runner
    privileged: true
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - runner-cache:/root/.cache
    networks:
      - cicd
    deploy:
      resources:
        limits:
          cpus: '4'
          memory: 4G

volumes:
  runner-cache:
    driver: local

networks:
  cicd:
    driver: bridge
```

## 📊 性能基準測試

### 1. 鏡像構建速度

```bash
# 測試構建時間
time docker build -t test-image .

# 比較不同基礎鏡像
# ubuntu:24.04      ~ 500MB, 構建 2 分鐘
# ubuntu:24.04-slim ~ 150MB, 構建 1 分鐘
# alpine:3.18       ~ 50MB,  構建 30 秒
```

### 2. 容器啟動時間

```bash
# 測試啟動時間
time docker run --rm alpine echo "Hello"

# 典型結果:
# 小鏡像 (alpine):  < 1 秒
# 中鏡像 (slim):    1-3 秒
# 大鏡像 (full):    3-10 秒
```

### 3. 網絡性能

```bash
# 測試帶寬
docker run --rm --network=host nicolaka/netperf -H <host> -t TCP_STREAM

# 測試延遲
docker run --rm --network=host nicolaka/netperf -H <host> -t TCP_RR
```
