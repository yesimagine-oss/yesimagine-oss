## 💡 優化建議

### 立即執行

```bash
# 1. 清理未使用鏡像
docker image prune -a --filter "until=168h"

# 2. 為 searxng 配置端口映射
docker stop searxng
docker rm searxng
docker run -d \
  --name searxng \
  -p 8080:8080 \
  --restart unless-stopped \
  searxng/searxng:latest

# 3. 配置內存限制
docker update --memory 512m --memory-swap 512m searxng
```

### 短期優化

```bash
# 1. 創建專用網絡
docker network create searxng-network

# 2. 使用命名卷重新部署
docker volume create searxng-config
docker volume create searxng-data

# 3. 配置日誌輪轉
# /etc/docker/daemon.json
{
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
```

### 長期優化

```bash
# 1. 增強安全配置
docker run --security-opt no-new-privileges \
  --read-only \
  --cap-drop=ALL \
  --cap-add=NET_BIND_SERVICE \
  ...

# 2. 配置監控
docker run -d \
  --name cadvisor \
  -v /:/rootfs:ro \
  -v /var/run:/var/run:ro \
  google/cadvisor:latest

docker run -d \
```

## 🔧 配置建議

### /etc/docker/daemon.json

```json
{
  "default-address-pools": [
    {
      "base": "10.255.0.0/16",
      "size": 24
    }
  ],
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  },
  "live-restore": true,
  "userland-proxy": false
}
```

### Docker Compose (建議)

```yaml
version: '3.8'

services:
  searxng:
    image: searxng/searxng:latest
    container_name: searxng
    ports:
      - "8080:8080"
    volumes:
      - searxng-config:/etc/searxng
      - searxng-data:/var/cache/searxng
    networks:
      - searxng-network
    restart: unless-stopped
    mem_limit: 512m
    memswap_limit: 512m
    security_opt:
      - no-new-privileges:true
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080"]
      interval: 30s
      timeout: 10s
      retries: 3

networks:
  searxng-network:
    driver: bridge

volumes:
  searxng-config:
  searxng-data:
```
