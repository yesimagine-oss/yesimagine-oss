## 📦 鏡像基礎

### 1. 鏡像分層原理

```
┌─────────────────────────────┐
│     可寫容器層 (Container)   │ ← 運行時創建
├─────────────────────────────┤
│     應用層 (Application)     │ ← COPY/ADD
├─────────────────────────────┤
│     依賴層 (Dependencies)    │ ← pip/npm install
├─────────────────────────────┤
│     運行時層 (Runtime)       │ ← Python/Node.js
├─────────────────────────────┤
│     基礎鏡像層 (Base Image)  │ ← FROM ubuntu
└─────────────────────────────┘
```

### 2. 鏡像操作命令

```bash
# 拉取鏡像
docker pull nginx:latest
docker pull node:22-bookworm-slim

# 查看鏡像
docker images
docker image ls

# 查看鏡像詳情
docker inspect nginx:latest

# 查看鏡像歷史
docker history nginx:latest

# 刪除鏡像
docker rmi nginx:latest
docker image rm nginx:latest

# 批量刪除
docker image prune -a
```

## 🏷️ 標籤管理

### 1. 標籤最佳實踐

```bash
# ✅ 推薦：使用具體版本
FROM node:22.11.0-bookworm
FROM python:3.11.6-slim
FROM ubuntu:24.04

# ✅ 推薦：使用主要版本
FROM node:22-bookworm
FROM python:3.11-slim

# ⚠️ 謹慎：使用最新標籤
FROM node:latest
FROM python:latest

# ❌ 避免：無標籤
FROM node
FROM python
```

### 2. 標籤策略

```bash
# 多標籤策略
# 開發環境
myapp:dev
myapp:dev-2026-03-19
myapp:dev-abc123

# 測試環境
myapp:test
myapp:test-v1.0.0

# 生產環境
myapp:prod
myapp:1.0.0
myapp:latest  # 指向最新穩定版
```

### 3. 標籤管理腳本

```bash
#!/bin/bash
# tag-manager.sh

IMAGE="myapp"
VERSION="1.0.0"
BUILD_HASH=$(git rev-parse --short HEAD)
DATE=$(date +%Y%m%d)

# 構建並打標籤
docker build -t ${IMAGE}:${VERSION} .
docker tag ${IMAGE}:${VERSION} ${IMAGE}:latest
docker tag ${IMAGE}:${VERSION} ${IMAGE}:${BUILD_HASH}
docker tag ${IMAGE}:${VERSION} ${IMAGE}:${DATE}

# 推送到倉庫
docker push ${IMAGE}:${VERSION}
docker push ${IMAGE}:latest
docker push ${IMAGE}:${BUILD_HASH}
docker push ${IMAGE}:${DATE}
```

## 📝 Dockerfile 最佳實踐

### 1. 基礎鏡像選擇

```dockerfile
# ❌ 避免：過大鏡像
FROM ubuntu:24.04
FROM debian:bookworm

# ✅ 推薦：精簡鏡像
FROM ubuntu:24.04-slim
FROM debian:bookworm-slim

# ✅ 推薦：極簡鏡像
FROM alpine:3.18

# ✅ 推薦：語言特定精簡鏡像
FROM python:3.11-slim
FROM node:22-bookworm-slim
FROM golang:1.21-alpine
```

### 2. 層優化

```dockerfile
# ❌ 避免：每個命令一層
RUN apt-get update
RUN apt-get install -y python3
RUN apt-get install -y python3-pip
RUN pip3 install flask

# ✅ 推薦：合併命令
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
    python3 \
    python3-pip && \
    pip3 install --no-cache-dir flask && \
    rm -rf /var/lib/apt/lists/*
```

### 3. 緩存優化

```dockerfile
# ❌ 避免：頻繁變化的在前
COPY . .
RUN npm install

# ✅ 推薦：不變的在前
COPY package.json package-lock.json ./
RUN npm ci --only=production
COPY . .
```

### 4. 多階段構建

```dockerfile
# 構建階段
FROM node:22 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 生產階段
FROM node:22-slim
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
USER node
CMD ["node", "dist/index.js"]
```

### 5. 安全最佳實踐

```dockerfile
# 使用非 root 用戶
RUN useradd -r -s /bin/false appuser
USER appuser

# 只讀文件系統
VOLUME ["/tmp", "/var/log"]

# 健康檢查
HEALTHCHECK --interval=30s --timeout=3s \
  CMD curl -f http://localhost/ || exit 1

# 明確版本
ENV APP_VERSION=1.0.0
ENV APP_ENV=production
```

## 🧹 鏡像清理

### 1. 清理懸空鏡像

```bash
# 刪除懸空鏡像 (dangling)
docker image prune

# 刪除所有未使用鏡像
docker image prune -a

# 刪除指定時間前的鏡像
docker image prune -a --filter "until=168h"
```

### 2. 清理策略

```bash
#!/bin/bash
# cleanup-images.sh

# 保留最近 7 天的鏡像
docker image prune -a --filter "until=168h" --force

# 刪除特定標籤的鏡像
docker images | grep "<none>" | awk '{print $3}' | xargs docker rmi

# 刪除舊版本
docker images myapp --format "{{.Tag}}" | \
  grep -v "latest" | \
  grep -v "$(git describe --tags --abbrev=0)" | \
  xargs -I {} docker rmi myapp:{}
```

### 3. 自動化清理 (Cron)

```bash
# /etc/cron.weekly/docker-cleanup
#!/bin/bash
docker system prune -a --volumes --force
```

## 🏭 鏡像構建優化

### 1. 構建上下文優化

```bash
# ❌ 避免：發送整個目錄
docker build .

# ✅ 推薦：使用 .dockerignore
# .dockerignore
node_modules
npm-debug.log
.git
.gitignore
README.md
*.log
dist
build

# ✅ 推薦：指定構建上下文
docker build -f Dockerfile.prod .
```

### 2. 構建緩存利用

```dockerfile
# 利用層緩存
FROM node:22-slim
WORKDIR /app

# 先複製依賴文件
COPY package*.json ./
RUN npm ci --only=production

# 再複製源代碼
COPY . .

# 最後構建
RUN npm run build
```

### 3. 構建參數

```dockerfile
# 使用 ARG 和 ENV
ARG NODE_ENV=production
ENV NODE_ENV=${NODE_ENV}

ARG APP_VERSION=1.0.0
ENV APP_VERSION=${APP_VERSION}

RUN echo "Building version ${APP_VERSION}"
```

```bash
# 構建時傳入參數
docker build \
  --build-arg NODE_ENV=production \
  --build-arg APP_VERSION=1.0.0 \
  -t myapp:1.0.0 .
```

## 📊 鏡像掃描

### 1. Docker Scan

```bash
# 掃描鏡像
docker scan nginx:latest

# 輸出 JSON
docker scan --json nginx:latest

# 只顯示高危漏洞
docker scan --severity high nginx:latest
```

### 2. Trivy

```bash
# 安裝
wget -qO - https://aquasecurity.github.io/trivy-repo/deb/public.key | \
  sudo apt-key add -
echo "deb https://aquasecurity.github.io/trivy-repo/deb $(lsb_release -sc) main" | \
  sudo tee -a /etc/apt/sources.list.d/trivy.list
sudo apt update && sudo apt install trivy

# 掃描
trivy image nginx:latest

# 輸出格式
trivy image --format table nginx:latest
trivy image --format json nginx:latest

# 只顯示高危
trivy image --severity HIGH,CRITICAL nginx:latest
```

### 3. CI/CD 集成

```yaml
# GitHub Actions
name: Scan
on: [push]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Build
        run: docker build -t myapp .
      - name: Scan
        run: trivy image --exit-code 1 myapp
```

## 📦 鏡像倉庫

### 1. Docker Hub

```bash
# 登錄
docker login

# 標籤
docker tag myapp:latest username/myapp:1.0.0

# 推送
docker push username/myapp:1.0.0

# 拉取
docker pull username/myapp:1.0.0
```

### 2. 私有倉庫

```bash
# 運行私有倉庫
docker run -d -p 5000:5000 --name registry registry:2

# 標籤
docker tag myapp:latest localhost:5000/myapp:1.0.0

# 推送
docker push localhost:5000/myapp:1.0.0

# 拉取
docker pull localhost:5000/myapp:1.0.0
```

### 3. Harbor

```bash
# 登錄
docker login harbor.example.com

# 標籤
docker tag myapp:latest harbor.example.com/project/myapp:1.0.0

# 推送
docker push harbor.example.com/project/myapp:1.0.0
```
