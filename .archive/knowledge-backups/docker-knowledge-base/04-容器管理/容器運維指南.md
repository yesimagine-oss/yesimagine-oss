## 📦 容器生命周期管理

### 1. 創建容器

```bash
# 創建但不啟動
docker create --name myapp nginx:latest

# 創建並啟動
docker run -d --name myapp nginx:latest

# 交互式容器
docker run -it --name myapp ubuntu:24.04 /bin/bash

# 臨時容器 (退出後自動刪除)
docker run --rm -it ubuntu:24.04 echo "Hello"
```

### 2. 啟動/停止容器

```bash
# 啟動容器
docker start myapp
docker start container_id

# 停止容器 (寬限期 10 秒)
docker stop myapp
docker stop -t 30 myapp  # 寬限期 30 秒

# 重啟容器
docker restart myapp
docker restart -t 30 myapp

# 暫停/恢復容器
docker pause myapp
docker unpause myapp
```

### 3. 刪除容器

```bash
# 刪除已停止容器
docker rm myapp

# 強制刪除運行中容器
docker rm -f myapp

# 批量刪除
docker rm $(docker ps -aq)

# 刪除退出容器
docker container prune
```

## 🔍 容器信息查看

### 1. 列出容器

```bash
# 運行中容器
docker ps
docker container ls

# 所有容器
docker ps -a
docker container ls -a

# 自定義格式
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
docker ps --format "{{.Names}}: {{.Status}}"

# 過濾器
docker ps --filter "status=running"
docker ps --filter "status=exited"
docker ps --filter "label=env=prod"
docker ps --filter "ancestor=nginx"
```

### 2. 容器詳情

```bash
# 完整信息
docker inspect myapp

# 特定字段
docker inspect --format '{{.State.Status}}' myapp
docker inspect --format '{{.NetworkSettings.IPAddress}}' myapp
docker inspect --format '{{.HostConfig.Memory}}' myapp

# JSON 輸出
docker inspect --format '{{json .}}' myapp | python3 -m json.tool
```

### 3. 容器日誌

```bash
# 查看日誌
docker logs myapp

# 跟隨輸出
docker logs -f myapp

# 顯示時間戳
docker logs -t myapp

# 最近 N 行
docker logs --tail 100 myapp

# 時間範圍
docker logs --since 10m myapp
docker logs --until 2026-03-19T10:00:00 myapp
```

## 🔧 容器操作

### 1. 執行命令

```bash
# 執行單條命令
docker exec myapp ls -la
docker exec myapp cat /etc/os-release

# 交互式執行
docker exec -it myapp /bin/bash
docker exec -it myapp /bin/sh

# 指定用戶
docker exec -u root myapp apt-get update

# 設置環境變量
docker exec -e MY_VAR=value myapp env
```

### 2. 文件操作

```bash
# 從容器複製文件
docker cp myapp:/etc/nginx/nginx.conf ./nginx.conf

# 複製文件到容器
docker cp ./index.html myapp:/usr/share/nginx/html/

# 複製整個目錄
docker cp myapp:/var/log ./logs
docker cp ./config myapp:/app/config
```

### 3. 容器更新

```bash
# 更新資源限制
docker update --memory 512m myapp
docker update --cpus 1 myapp
docker update --restart unless-stopped myapp

# 批量更新
docker update --restart unless-stopped $(docker ps -q)
```

## 🌐 容器網絡

### 1. 端口映射

```bash
# 映射端口
docker run -d -p 8080:80 nginx

# 映射到特定接口
docker run -d -p 127.0.0.1:8080:80 nginx

# 映射多個端口
docker run -d -p 80:80 -p 443:443 nginx

# 動態端口
docker run -d -P nginx  # 自動映射到隨機端口
```

### 2. 網絡連接

```bash
# 查看容器網絡
docker network inspect bridge

# 連接網絡
docker network connect my-network myapp

# 斷開網絡
docker network disconnect my-network myapp

# 創建時指定網絡
docker run -d --network my-network myapp
```

### 3. 容器間通信

```bash
# 使用容器名稱
docker run -d --name web nginx
docker run -d --link web:web myapp

# 使用網絡別名
docker run -d --network my-network --alias web nginx
docker run -d --network my-network myapp curl web:80
```

## 💾 容器存儲

### 1. 卷管理

```bash
# 創建卷
docker volume create mydata

# 查看卷
docker volume ls
docker volume inspect mydata

# 使用卷
docker run -d -v mydata:/data nginx

# 刪除卷
docker volume rm mydata
docker volume prune
```

### 2. Bind Mount

```bash
# 掛載主機目錄
docker run -d -v /host/path:/container/path nginx

# 只讀掛載
docker run -d -v /host/path:/container/path:ro nginx

# 相對路徑
docker run -d -v ./data:/app/data nginx
```

### 3. tmpfs 掛載

```bash
# 臨時文件系統
docker run -d --tmpfs /app/cache nginx

# 指定選項
docker run -d --tmpfs /app/cache:rw,noexec,nosuid,size=100m nginx
```

## 🛠️ 實用腳本

### 1. 容器備份

```bash
#!/bin/bash
# backup-container.sh

CONTAINER=$1
BACKUP_DIR="./backups"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

# 導出容器
docker export $CONTAINER > $BACKUP_DIR/${CONTAINER}_${DATE}.tar

# 備份卷
docker run --rm \
  -v $CONTAINER-data:/source \
  -v $BACKUP_DIR:/backup \
  alpine tar czf /backup/${CONTAINER}_data_${DATE}.tar.gz -C /source .

echo "備份完成：$BACKUP_DIR"
```

### 2. 容器清理

```bash
#!/bin/bash
# cleanup-containers.sh

echo "=== Docker 容器清理 ==="

# 刪除退出容器
echo "刪除退出容器..."
docker container prune -f

# 刪除懸空鏡像
echo "刪除懸空鏡像..."
docker image prune -f

# 清理未使用資源
echo "清理未使用資源..."
docker system prune -f

echo "清理完成"
```

### 3. 健康檢查

```bash
#!/bin/bash
# health-check.sh

echo "=== 容器健康檢查 ==="

for container in $(docker ps --format '{{.Names}}'); do
  status=$(docker inspect --format '{{.State.Health.Status}}' $container 2>/dev/null)
  
  if [ "$status" = "unhealthy" ]; then
    echo "❌ $container: 不健康"
  elif [ "$status" = "healthy" ]; then
    echo "✅ $container: 健康"
  else
    echo "⚠️ $container: 無健康檢查"
  fi
done
```

### 4. 資源監控警報

```bash
#!/bin/bash
# resource-alert.sh

THRESHOLD_CPU=80
THRESHOLD_MEM=80

docker stats --no-stream --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemPerc}}" | \
  tail -n +2 | \
  while read name cpu mem; do
    cpu_val=${cpu%\%*}
    mem_val=${mem%\%*}
    
    if (( $(echo "$cpu_val > $THRESHOLD_CPU" | bc -l) )); then
      echo "⚠️ CPU 警告：$name (${cpu})"
    fi
    
    if (( $(echo "$mem_val > $THRESHOLD_MEM" | bc -l) )); then
      echo "⚠️ 內存警告：$name (${mem})"
    fi
  done
```

## 🚨 常見問題

### 容器無法啟動

```bash
# 查看日誌
docker logs myapp

# 檢查配置
docker inspect myapp

# 測試運行
docker run --rm -it myapp /bin/bash
```

### 容器性能差

```bash
# 查看資源
docker stats myapp

# 調整限制
docker update --memory 1g --cpus 2 myapp

# 檢查主機
top
free -h
iostat
```

### 容器磁盤滿

```bash
# 查看磁盤使用
docker system df

# 清理資源
docker system prune -a

# 清理日誌
truncate -s 0 /var/lib/docker/containers/*/*-json.log
```
