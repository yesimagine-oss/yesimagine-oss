## 🚀 快速部署入口

### 方式 1: 阿里云一键部署

1. 访问活动页：https://www.aliyun.com/activity/ecs/clawdbot
2. 点击「立即部署」
3. 选择服务器配置
4. 确认订单并支付
5. 等待自动部署完成

### 方式 2: SWAS 镜像市场

1. 登录 SWAS 控制台
2. 创建服务器时选择「镜像市场」
3. 搜索「OpenClaw」
4. 选择并创建

### 方式 3: 手动部署

```bash
# 1. 购买服务器后 SSH 连接
ssh root@your-server-ip

# 2. 安装 OpenClaw
curl -fsSL https://openclaw.ai/install.sh | bash

# 3. 配置模型
openclaw dashboard

# 4. 开始使用
openclaw chat "Hello"
```
