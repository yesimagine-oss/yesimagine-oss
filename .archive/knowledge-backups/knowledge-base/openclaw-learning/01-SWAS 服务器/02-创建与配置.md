## 🚀 创建流程

### 步骤 1: 选择地域
- 选择离目标用户最近的地域
- 推荐：华东 1（杭州）、华东 2（上海）、华北 2（北京）

### 步骤 2: 选择套餐
| 套餐类型 | CPU | 内存 | 系统盘 | 月流量 | 参考价格 |
|----------|-----|------|--------|--------|----------|
| 入门版 | 1 核 | 2GB | 40GB | 1TB | ~¥24/月 |
| 标准版 | 2 核 | 4GB | 60GB | 2TB | ~¥60/月 |
| 进阶版 | 4 核 | 8GB | 80GB | 3TB | ~¥120/月 |

### 步骤 3: 选择镜像
- **推荐**: Ubuntu 22.04 LTS 或 Debian 11
- 原因：社区活跃、文档丰富、兼容性好

### 步骤 4: 设置密码
- 设置 root 登录密码
- 建议：使用强密码，包含大小写字母+数字+符号

### 步骤 5: 确认购买
- 选择购买时长（1 月/3 月/6 月/1 年）
- 确认配置后付款

## 🔧 初始配置

### SSH 连接
```bash
# Linux/Mac
ssh root@<服务器公网 IP>

# Windows (PowerShell)
ssh root@<服务器公网 IP>
```

### 基础环境更新
```bash
# 更新软件包列表
apt update && apt upgrade -y

# 安装常用工具
apt install -y curl wget git vim htop net-tools
```

### 安全配置
```bash
# 配置防火墙（UFW）
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP
ufw allow 443/tcp   # HTTPS
ufw enable
```

### 创建普通用户（推荐）
```bash
# 创建新用户
adduser admin

# 赋予 sudo 权限
usermod -aG sudo admin

# 切换到新用户
su - admin
```

## 📝 注意事项

1. **备份**: 创建快照后再进行重大配置变更

3. **监控**: 定期检查 CPU、内存、磁盘使用率
4. **日志**: 关注 /var/log 下的系统日志
