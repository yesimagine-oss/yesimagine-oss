# 轻量应用服务器 (SWAS) - 产品概述

## 🎯 产品定位

轻量应用服务器 (Simple Web Application Server, SWAS) 是阿里云提供的一种**开箱即用**的云服务器产品，面向**个人开发者**和**中小企业**的建站及应用部署需求。

---

## ✨ 核心特点

### 1. 轻量化
- 融合计算、存储、网络等常用基础云服务
- 简化云服务器和应用系统的创建流程
- 提供简单易用的控制台和 OpenAPI

### 2. 贴近应用
- 提供常用的热门镜像预装，包括：
  - 运维面板
  - 建站系统
  - 游戏面板
  - AI 应用
  - 其他常用应用模板

### 3. 账单确定性强
- 打包计算、存储、网络套餐式售卖
- **仅提供包年包月**的付费方式
- 无按量付费的波动风险

### 4. 可进化
- 持续获得市场主流高性价比资源
- 无缝对接阿里云完整云上生态
- 可随时升级至更高级的 ECS 产品

---

## 🆚 与 ECS 的区别

| 特性 | SWAS (轻量) | ECS (弹性计算) |
|------|-------------|----------------|
| 定位 | 个人/小企业简单应用 | 企业级复杂应用 |
| 配置复杂度 | 低，开箱即用 | 高，需自行配置 |
| 计费方式 | 仅包年包月 | 包年包月 + 按量付费 |
| 网络配置 | 简化 | 完整 VPC 配置 |
| 适用场景 | 建站、小型应用、开发测试 | 生产环境、高可用架构 |
