## 📊 经验积累工具

### 1. 经验记录本

```bash
# 创建经验记录目录
mkdir -p ~/openclaw-experience/{problems,configs,optimizations,lessons}

# 创建记录模板
cat > ~/openclaw-experience/templates/problem.md << 'EOF'
# 问题记录

## 日期
YYYY-MM-DD

## 问题
[描述]

## 解决
[方案]

## 教训
[经验]
EOF
```

### 2. 自动化记录

```bash
#!/bin/bash
# ~/scripts/daily-log.sh

# 每日自动记录
DATE=$(date +%Y-%m-%d)
LOG_FILE=~/openclaw-experience/daily/$DATE.md

cat > $LOG_FILE << EOF
# 每日记录 - $DATE

## 运行情况
- 服务状态：$(systemctl is-active openclaw)
- CPU 平均：$(top -bn1 | grep "Cpu(s)" | awk '{print $2}')
- 内存平均：$(free | grep Mem | awk '{printf("%.2f"), $3/$2 * 100.0}')

## API 用量
$(openclaw models usage)

## 问题记录
[今日遇到的问题]

## 优化建议
[今日想到的优化点]
EOF
```
