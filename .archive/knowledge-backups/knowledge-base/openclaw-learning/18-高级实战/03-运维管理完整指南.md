## 🔍 监控告警体系

### 监控指标

| 类别 | 指标 | 告警阈值 |
|------|------|----------|
| 系统 | CPU 使用率 | > 80% |
| 系统 | 内存使用率 | > 85% |
| 系统 | 磁盘使用率 | > 80% |
| 应用 | 服务状态 | 离线 |
| 应用 | 响应时间 | > 5 秒 |
| 应用 | 错误率 | > 5% |
| 业务 | API 用量 | > ¥10/天 |
| 业务 | 消息量 | 异常波动 |

### 监控脚本

```bash
#!/bin/bash
# ~/scripts/monitor.sh

# 配置
ALERT_EMAIL="your@email.com"
ALERT_TELEGRAM="your_bot"
CPU_THRESHOLD=80
MEM_THRESHOLD=85
DISK_THRESHOLD=80

# 检查 CPU
CPU=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
if (( $(echo "$CPU > $CPU_THRESHOLD" | bc -l) )); then
  send_alert "CPU 告警：${CPU}%"
fi

# 检查内存
MEM=$(free | grep Mem | awk '{printf("%.2f"), $3/$2 * 100.0}')
if (( $(echo "$MEM > $MEM_THRESHOLD" | bc -l) )); then
  send_alert "内存告警：${MEM}%"
fi

# 检查磁盘
DISK=$(df -h / | tail -1 | awk '{print $5}' | sed 's/%//')
if [ $DISK -gt $DISK_THRESHOLD ]; then
  send_alert "磁盘告警：${DISK}%"
fi

# 检查服务
if ! systemctl is-active --quiet openclaw; then
  send_alert "服务告警：OpenClaw 未运行"
fi

# 告警函数
send_alert() {
  echo "⚠️ $1" | \
    curl -X POST "https://api.telegram.org/bot$ALERT_TELEGRAM/sendMessage" \
    -d "chat_id=YOUR_CHAT_ID&text=$1"
}
```

## 💾 备份恢复体系

### 备份策略

| 类型 | 频率 | 保留期 | 内容 |
|------|------|--------|------|
| 配置备份 | 每次变更 | 永久 | config.json |
| 数据备份 | 每日 | 30 天 | sessions, memory |
| 完整备份 | 每周 | 90 天 | 全部数据 |
| 异地备份 | 每月 | 1 年 | 完整备份 |

### 备份脚本

```bash
#!/bin/bash
# ~/scripts/backup.sh

BACKUP_DIR=~/backups
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

# 创建备份目录
mkdir -p $BACKUP_DIR/{config,data,full}

# 备份配置
echo "📋 备份配置..."
cp -r ~/.openclaw/config $BACKUP_DIR/config/config-$DATE

# 备份数据
echo "📁 备份数据..."
tar -czf $BACKUP_DIR/data/data-$DATE.tar.gz \
  --exclude='*.log' \
  --exclude='cache/*' \
  ~/.openclaw/workspace/

# 完整备份
echo "📦 完整备份..."
tar -czf $BACKUP_DIR/full/full-$DATE.tar.gz \
  ~/.openclaw/

# 生成备份清单
cat > $BACKUP_DIR/manifest-$DATE.txt << EOF
OpenClaw 备份清单
==================
备份时间：$(date)
配置版本：$(openclaw --version)
工作区大小：$(du -sh ~/.openclaw/workspace | cut -f1)
备份位置：$BACKUP_DIR/full/full-$DATE.tar.gz
EOF

# 清理旧备份
echo "🧹 清理 $RETENTION_DAYS 天前的备份..."
find $BACKUP_DIR -name "*.tar.gz" -mtime +$RETENTION_DAYS -delete

# 验证备份
echo "🔍 验证备份..."
tar -tzf $BACKUP_DIR/full/full-$DATE.tar.gz > /dev/null
if [ $? -eq 0 ]; then
  echo "✅ 备份验证通过"
else
  echo "❌ 备份验证失败"
  send_alert "备份验证失败"
fi

# 发送到远程存储（可选）
# rsync -av $BACKUP_DIR/ user@remote:/backups/openclaw/

echo "✅ 备份完成"
```

### 恢复流程

```bash
#!/bin/bash
# ~/scripts/restore.sh

BACKUP_FILE=$1

if [ -z "$BACKUP_FILE" ]; then
  echo "用法：$0 <备份文件>"
  exit 1
fi

# 停止服务
echo "⏹️ 停止服务..."
openclaw stop

# 备份当前状态
echo "💾 备份当前状态..."
cp -r ~/.openclaw ~/.openclaw.bak.$(date +%Y%m%d)

# 恢复备份
echo "♻️ 恢复备份..."
tar -xzf $BACKUP_FILE -C ~/

# 修复权限
echo "🔐 修复权限..."
chmod -R 755 ~/.openclaw/
chown -R $USER:$USER ~/.openclaw/

# 验证配置
echo "🔍 验证配置..."
openclaw config --validate

# 启动服务
echo "▶️ 启动服务..."
openclaw start

# 测试
echo "🧪 测试..."
openclaw chat "恢复测试"

echo "✅ 恢复完成"
```

```bash
#!/bin/bash
# ~/scripts/security-hardening.sh

echo "=== 安全加固 ==="

# 1. SSH 加固
echo "1. SSH 加固..."
sudo sed -i 's/#Port 22/Port 2222/' /etc/ssh/sshd_config
sudo sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart sshd

# 2. 防火墙配置
echo "2. 防火墙配置..."
sudo ufw enable
sudo ufw default deny incoming
sudo ufw allow 2222/tcp  # SSH
sudo ufw allow 18789/tcp # OpenClaw
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS

# 3. 安装 Fail2Ban
echo "3. 安装 Fail2Ban..."
sudo apt install fail2ban -y
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# 4. 文件权限
echo "4. 文件权限..."
chmod 600 ~/.openclaw/config/*.json
chmod 700 ~/.openclaw/

# 5. 日志审计
echo "5. 日志审计..."
sudo apt install auditd -y
sudo systemctl enable auditd
sudo systemctl start auditd

echo "✅ 安全加固完成"
```

### 日志轮转配置

```bash
# /etc/logrotate.d/openclaw
~/.openclaw/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 644 $USER $USER
    postrotate
        openclaw gateway restart
    endscript
}
```

### 日志分析

```bash
#!/bin/bash
# ~/scripts/log-analysis.sh

LOG_FILE=~/.openclaw/logs/openclaw.log

echo "=== 日志分析 ==="

# 今日错误数
echo "今日错误数:"
grep "ERROR" $LOG_FILE | \
  grep "$(date +%Y-%m-%d)" | wc -l

# 常见错误 TOP 5
echo ""
echo "常见错误 TOP 5:"
grep "ERROR" $LOG_FILE | \
  awk -F': ' '{print $2}' | \
  sort | uniq -c | sort -rn | head -5

# API 调用统计
echo ""
echo "API 调用统计:"
grep "api" $LOG_FILE | wc -l

# 慢查询
echo ""
echo "慢查询 (>5 秒):"
grep "timeout\|slow" $LOG_FILE | tail -10

echo "=== 分析完成 ==="
```
