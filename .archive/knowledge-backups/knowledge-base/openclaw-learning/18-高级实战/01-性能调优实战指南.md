## 🔧 性能优化措施

### 1. 模型调用优化

#### 使用缓存

```javascript
// ~/.openclaw/workspace/skills/response-cache/index.js
const NodeCache = require('node-cache');
const cache = new NodeCache({ stdTTL: 300 });

module.exports = {
  async execute(context, params) {
    const cacheKey = this.generateCacheKey(params.message);
    
    // 检查缓存
    const cached = cache.get(cacheKey);
    if (cached) {
      return { content: cached, fromCache: true };
    }
    
    // 调用 AI
    const response = await this.callAI(params.message);
    
    // 存入缓存
    cache.set(cacheKey, response);
    
    return { content: response, fromCache: false };
  },
  
  generateCacheKey(message) {
    const crypto = require('crypto');
    return crypto.createHash('md5').update(message).digest('hex');
  }
};
```

#### 批量处理

```javascript
// 批量处理多个请求
async function batchProcess(messages) {
  const batchSize = 5;
  const results = [];
  
  for (let i = 0; i < messages.length; i += batchSize) {
    const batch = messages.slice(i, i + batchSize);
    const batchResults = await Promise.all(
      batch.map(msg => callAI(msg))
    );
    results.push(...batchResults);
    
    // 避免速率限制
    await sleep(100);
  }
  
  return results;
}
```

## 🔍 性能问题诊断

### 诊断流程

```
性能问题
    │
    ▼
1. 检查资源使用 (htop)
    │
    ├── CPU 高 → 检查进程
    ├── 内存高 → 检查泄漏
    └── 磁盘高 → 清理文件
    │
    ▼
2. 检查网络延迟 (ping/mtr)
    │
    ├── 延迟高 → 更换地域
    └── 丢包 → 检查网络
    │
    ▼
3. 检查 API 响应 (curl)
    │
    ├── 响应慢 → 更换模型
    └── 失败 → 检查 Key
    │
    ▼
4. 查看日志 (openclaw logs)
    │
    ├── 错误多 → 修复配置
    └── 警告多 → 优化配置
```

### 常见性能问题

| 问题 | 症状 | 解决方案 |
|------|------|----------|
| 内存泄漏 | 内存持续增长 | 重启服务、更新版本 |
| CPU 过高 | 响应变慢 | 减少并发、优化查询 |
| 磁盘满 | 无法写入 | 清理日志、扩容 |
| 网络慢 | 响应延迟 | 更换地域、优化路由 |
| API 慢 | 等待时间长 | 使用缓存、更换模型 |

## 📊 性能优化案例

### 案例 1: 响应时间从 5 秒优化到 1.5 秒

**问题**: 每次对话响应慢

**分析**:
```
1. 检查日志：API 调用耗时 4 秒
2. 检查模型：使用 qwen3-max（能力强但慢）
3. 检查缓存：无缓存机制
```

**解决**:
```
1. 切换到 qwen3.5-plus（简单对话）
2. 添加响应缓存（5 分钟 TTL）
3. 批量处理请求
```

**结果**:
```
响应时间：5 秒 → 1.5 秒
API 成本：¥100/月 → ¥40/月
```

---

### 案例 2: 内存从 800MB 优化到 250MB

**问题**: 内存占用过高

**分析**:
```
1. 检查进程：Node.js 占用 800MB
2. 检查堆内存：未设置上限
3. 检查会话：积累大量旧会话
```

**解决**:
```
1. 设置 NODE_OPTIONS="--max-old-space-size=512"
2. 添加会话自动清理（7 天）
3. 使用 PM2 管理进程（自动重启）
```

**结果**:
```
内存占用：800MB → 250MB
稳定性：每日崩溃 → 稳定运行
```
