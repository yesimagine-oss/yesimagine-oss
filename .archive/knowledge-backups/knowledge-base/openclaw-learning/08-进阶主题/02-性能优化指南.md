## 🚀 服务器优化

### 1. 系统层面优化

```bash

sudo apt update && sudo apt upgrade -y

# 2. 清理不必要的服务

sudo systemctl disable <unnecessary-service>

sudo vim /etc/sysctl.conf
```

## 📈 监控与告警

### 1. 性能监控脚本

```bash
#!/bin/bash
# ~/scripts/openclaw-monitor.sh

LOG_FILE=~/openclaw-performance.log

# CPU 使用率
CPU=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}')

# 内存使用率
MEM=$(free | grep Mem | awk '{printf("%.2f"), $3/$2 * 100.0}')

# 磁盘使用率
DISK=$(df -h / | tail -1 | awk '{print $5}' | sed 's/%//')

echo "$(date): CPU=${CPU}%, MEM=${MEM}%, DISK=${DISK}%" >> $LOG_FILE

# 告警
if (( $(echo "$MEM > 85" | bc -l) )); then
    echo "⚠️ 内存告警：${MEM}%" | mail -s "OpenClaw 告警" admin@example.com
fi
```

### 2. 配置定时监控

```bash
# 添加到 crontab
crontab -e

# 每 5 分钟检查一次
*/5 * * * * ~/scripts/openclaw-monitor.sh
```
