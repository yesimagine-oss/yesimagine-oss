## 💬 Telegram 通道配置

### 步骤 1: 创建 Bot

1. 打开 Telegram，搜索 @BotFather
2. 发送 `/newbot` 创建新机器人
3. 按提示设置：
   - 名称：OpenClaw Assistant
   - 用户名：openclaw_yourname_bot
4. 获取 Token（格式：`123456:ABC-DEF1234...`）

### 步骤 2: 配置 OpenClaw

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11",
      "allowedUsers": [],
      "allowedGroups": [],
      "reply": true,
      "voice": false,
      "maxMessageLength": 4096
    }
  }
}
```

### 步骤 3: 获取用户/群组 ID

```bash
# 方法 1: 发送消息给 bot，查看日志
openclaw logs --grep telegram

# 方法 2: 使用 @userinfobot
# 发送消息给 @userinfobot 获取你的 ID

# 方法 3: 群组 ID（需要 bot 在群组中）
# 发送消息到群组，查看日志获取群组 ID（负数）
```

### 步骤 4: 限制访问（可选）

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_TOKEN",
      "allowedUsers": ["123456789", "987654321"],
      "allowedGroups": ["-1001234567890"]
    }
  }
}
```

### 步骤 5: 测试

```bash
# 重启 OpenClaw
openclaw restart

# 在 Telegram 中发送消息给 bot
# 应该收到回复
```

## 🎮 Discord 通道配置

### 步骤 1: 创建 Discord 应用

1. 访问 https://discord.com/developers/applications
2. 点击 "New Application"
3. 设置名称和图标

### 步骤 2: 创建 Bot

1. 左侧菜单选择 "Bot"
2. 点击 "Add Bot"
3. 点击 "Reset Token" 获取 Token
4. 关闭 "Public Bot"（如仅自己使用）

### 步骤 3: 邀请 Bot 到服务器

1. 左侧菜单选择 "OAuth2" → "URL Generator"
2. 选择 scopes: `bot`
3. 选择 permissions:
   - Read Messages
   - Send Messages
   - Read Message History
4. 复制生成的 URL，在浏览器打开
5. 选择服务器，授权

### 步骤 4: 配置 OpenClaw

```json
{
  "channels": {
    "discord": {
      "enabled": true,
      "botToken": "MTIzNDU2Nzg5MDEyMzQ1Njc4OQ.GaBcDe.FgHiJkLmNoPqRsTuVwXyZ123456789",
      "guildId": "123456789012345678",
      "channelId": "123456789012345678",
      "allowedUsers": [],
      "reply": true
    }
  }
}
```

### 步骤 5: 获取 ID

```
用户 ID: 开启开发者模式，右键用户 → 复制 ID
服务器 ID: 右键服务器图标 → 复制 ID
频道 ID: 右键频道 → 复制 ID
```

## 📱 WhatsApp 通道配置

### 方式 1: 使用官方 API（企业）

```json
{
  "channels": {
    "whatsapp": {
      "enabled": true,
      "provider": "official",
      "phoneNumberId": "123456789012345",
      "accessToken": "EAAB...",
      "verifyToken": "my_verify_token"
    }
  }
}
```

### 方式 2: 使用 whatsapp-web.js（个人）

```bash
# 安装依赖
npm install whatsapp-web.js qrcode-terminal
```

```json
{
  "channels": {
    "whatsapp": {
      "enabled": true,
      "provider": "web",
      "sessionPath": "~/.openclaw/whatsapp-session",
      "headless": true
    }
  }
}
```

### 首次配置

1. 启动 OpenClaw
2. 扫描终端显示的二维码
3. 使用 WhatsApp 手机应用扫描
4. 会话保存后可重复使用

## 💼 Slack 通道配置

### 步骤 1: 创建 Slack App

1. 访问 https://api.slack.com/apps
2. 点击 "Create New App"
3. 选择工作区

### 步骤 2: 配置权限

1. 左侧菜单 "OAuth & Permissions"
2. 添加 Scopes:
   - `chat:write`
   - `channels:read`
   - `im:read`
   - `im:history`

### 步骤 3: 安装 App

1. 左侧菜单 "Install App"
2. 点击 "Install to Workspace"
3. 获取 Bot User OAuth Token

### 步骤 4: 配置 OpenClaw

```json
{
  "channels": {
    "slack": {
      "enabled": true,
      "botToken": "xoxb-123456789012-1234567890123-AbCdEfGhIjKlMnOpQrStUvWx",
      "signingSecret": "1234567890abcdef1234567890abcdef",
      "appToken": "xapp-1-..."
    }
  }
}
```

## ⚠️ 常见问题

### Q1: Telegram bot 无响应
**检查**:
- Token 是否正确
- Bot 是否被禁用
- 查看日志错误信息

### Q2: Discord bot 无法发送消息
**检查**:
- Bot 权限是否足够
- 频道 ID 是否正确
- Intents 是否开启

### Q3: WhatsApp 会话失效
**解决**:
- 删除 session 目录
- 重新扫描二维码
