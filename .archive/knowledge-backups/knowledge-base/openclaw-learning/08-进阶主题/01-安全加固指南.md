## 🖥️ 服务器安全

### 1. SSH 安全加固

```bash
# 1. 修改 SSH 端口（非 22）
sudo vim /etc/ssh/sshd_config
# 修改：Port 2222

# 2. 禁用 root 登录
PermitRootLogin no

# 3. 禁用密码登录（使用密钥）
PasswordAuthentication no

# 4. 限制用户登录
AllowUsers admin openclaw

# 5. 重启 SSH 服务
sudo systemctl restart sshd
```

### 2. 配置 SSH 密钥登录

```bash
# 本地生成密钥
ssh-keygen -t ed25519 -C "openclaw@$(hostname)"

# 复制公钥到服务器
ssh-copy-id -p 2222 admin@your-server-ip

# 测试密钥登录
ssh -p 2222 admin@your-server-ip
```

### 3. 安装 Fail2Ban

```bash
# 安装
sudo apt install fail2ban -y

# 配置
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo vim /etc/fail2ban/jail.local

# 添加 SSH 保护
[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 3600

# 启动服务
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# 查看状态
sudo fail2ban-client status
```

### 4. 配置防火墙（UFW）

```bash
# 启用 UFW
sudo ufw enable

# 允许 SSH（自定义端口）
sudo ufw allow 2222/tcp

# 允许 HTTP/HTTPS（如需要）
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 查看状态
sudo ufw status verbose
```

## 🔑 API Key 安全

### 1. 使用环境变量

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
export OPENCLAW_BAILIAN_KEY="sk-your-api-key"

# 在配置中引用
{
  "models": {
    "providers": {
      "bailian": {
        "apiKey": "${OPENCLAW_BAILIAN_KEY}"
      }
    }
  }
}
```

### 2. 配置文件权限

```bash
# 限制配置文件权限
chmod 600 ~/.openclaw/config/*.json

# 限制目录权限
chmod 700 ~/.openclaw/
```

### 3. 定期轮换 Key

```bash
# 创建轮换提醒（每月 1 号）
{
  "crons": {
    "tasks": [
      {
        "id": "api-key-reminder",
        "schedule": "0 9 1 * *",
        "command": "提醒我轮换百炼 API Key，已使用 30 天",
        "channel": "telegram"
      }
    ]
  }
}
```

### 4. Key 泄露应急响应

```
1. 立即在百炼控制台删除泄露的 Key
2. 创建新的 API Key
3. 更新 OpenClaw 配置
4. 检查日志是否有异常调用
5. 审查访问记录
```

## 🛡️ OpenClaw 安全配置

### 1. 限制通道访问

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_TOKEN",
      "allowedUsers": ["123456789", "987654321"],
      "allowedGroups": ["-1001234567890"]
    }
  }
}
```

### 2. 配置技能权限

```json
{
  "skills": {
    "config": {
      "message": {
        "allowedChannels": ["telegram", "webchat"],
        "maxMessagePerHour": 100
      },
      "browser": {
        "allowedDomains": ["github.com", "aliyun.com"],
        "blockDownloads": true
      }
    }
  }
}
```

### 3. 启用日志审计

```bash
# 配置日志级别
openclaw config --edit

# 添加日志配置
{
  "logging": {
    "level": "info",
    "file": "~/.openclaw/logs/openclaw.log",
    "maxSize": "10MB",
    "maxFiles": 5,
    "audit": true
  }
}
```

### 4. 限制资源使用

```json
{
  "limits": {
    "maxTokensPerRequest": 50000,
    "maxRequestsPerHour": 100,
    "maxConcurrentSessions": 5,
    "maxMemoryMB": 1024
  }
}
```

## ⚠️ 安全事件响应

### 发现异常调用

```bash
# 1. 立即查看日志
openclaw logs --tail 500

# 2. 暂停服务
openclaw stop

# 3. 撤销 API Key
# 在百炼控制台删除 Key

# 4. 分析原因
# 检查日志、配置、访问记录

# 5. 恢复服务
# 创建新 Key，更新配置，重启
openclaw start
```

### 发现未授权访问

```bash
# 1. 立即封锁 IP
sudo ufw deny from xxx.xxx.xxx.xxx

# 2. 修改所有密码
passwd admin
passwd root

# 3. 检查登录记录
last
lastb

# 4. 审查配置文件
# 查看是否有未授权修改
```
