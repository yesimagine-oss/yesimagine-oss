# OpenClaw 术语表

**创建时间**: 2026-03-12
**用途**: 快速查阅专业术语和概念

---

## A

### API Key
应用程序接口密钥，用于认证和授权访问云服务（如阿里云百炼）。

### ACP (Agent Communication Protocol)
代理通信协议，OpenClaw 用于子代理间通信的标准协议。

---

## B

### Bailian (百炼)
阿里云大模型服务平台，提供通义千问等模型的 API 访问。

### Bot
机器人，自动化程序的统称，在 OpenClaw 中指 AI 助手实例。

---

## C

### Channel (通道)
消息收发渠道，如 Telegram、Discord、WhatsApp、Webchat 等。

### Coding Plan
阿里云面向代码开发场景的专属模型服务，针对编程任务优化。

### Cron
定时任务调度器，用于按固定时间间隔执行任务。

### Cron 表达式
5 字段时间格式，定义任务执行时间：`分 时 日 月 星期`

---

## D

### DashScope
阿里云灵积模型服务平台，提供多种 AI 模型 API。

---

## G

### Gateway
OpenClaw 网关服务，负责消息路由和通道管理。

---

## H

### Heartbeat (心跳)
定期执行的任务，用于检查系统状态和执行周期性检查。

### Hooks
钩子函数，在特定事件发生时自动触发的代码。

---

## K

### Key Rotation (密钥轮换)
定期更换 API Key 的安全实践，降低泄露风险。

---

## M

### Model (模型)
AI 语言模型，如 Qwen3.5-Plus、GPT-4 等。

### Model Studio
阿里云百炼的旧称，现统一称为百炼。

---

## O

### OpenClaw
开源个人 AI 助手平台，支持多通道、多模型、技能扩展。

### Onboarding
新用户引导流程，帮助快速配置和使用 OpenClaw。

---

## P

### Provider (提供商)
模型服务提供商，如 Bailian（阿里云）、OpenAI 等。

---

## Q

### Qwen
通义千问，阿里云开发的大语言模型系列。

---

## S

### Skill (技能)
OpenClaw 的功能扩展模块，提供特定能力（如天气查询、网页搜索）。

### SWAS (Simple Web Application Server)
阿里云轻量应用服务器，面向个人开发者的云服务器产品。

### Session (会话)
用户与 AI 的一次对话交互过程。

### Subagent (子代理)
由主代理 spawn 的独立代理实例，用于并行处理任务。

---

## T

### Token
- **认证 Token**: 用于 API 认证的字符串
- **模型 Token**: AI 模型处理文本的基本单位（约 1 token = 0.75 单词）

### TUI (Text User Interface)
文本用户界面，OpenClaw 的终端交互界面。

### TTS (Text-to-Speech)
语音合成技术，将文本转换为语音。

---

## W

### WAL (Write-Ahead Logging)
预写日志，用于保证数据一致性的技术。

### Webchat
OpenClaw 内置的 Web 聊天界面。

### Workspace
OpenClaw 工作区目录，存放技能、记忆、配置等文件。
