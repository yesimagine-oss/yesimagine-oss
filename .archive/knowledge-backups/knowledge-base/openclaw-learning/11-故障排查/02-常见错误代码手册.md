## 🔴 严重错误 (Critical)

### E001: 服务无法启动

```
Error: Cannot start OpenClaw service
Port 3000 is already in use
```

**原因**: 端口被占用

**解决**:
```bash
# 查找占用进程
lsof -i :3000

# 杀死进程
kill $(lsof -t -i:3000)

# 或修改配置使用其他端口
openclaw dashboard
```

---

### E002: 配置文件损坏

```
Error: Failed to parse config.json
Unexpected token } in JSON at position 123
```

**原因**: JSON 语法错误

**解决**:
```bash
# 验证配置
openclaw config --validate

# 使用 JSON 工具格式化
cat config.json | json_pp

# 从备份恢复
cp config.json.bak config.json
```

---

### E003: API Key 无效

```
Error: Authentication failed
Invalid API key provided
```

**原因**: API Key 错误或被撤销

**解决**:
```bash
# 1. 在百炼控制台创建新 Key
# 2. 更新配置
openclaw dashboard

# 3. 验证
openclaw chat "test"
```

## 🟡 技能错误 (Skill)

### S001: 技能未找到

```
Error: Skill not found
weather is not installed
```

**原因**: 技能未安装

**解决**:
```bash
# 安装技能
openclaw skills install weather

# 或启用技能
openclaw skills enable weather
```

---

### S002: 技能加载失败

```
Error: Failed to load skill
Cannot find module './index.js'
```

**原因**: 技能文件缺失

**解决**:
```bash
# 1. 检查技能文件
ls -la ~/.openclaw/workspace/skills/weather/

# 2. 重新安装
openclaw skills uninstall weather
openclaw skills install weather
```

---

### S003: 技能执行错误

```
Error: Skill execution failed
TypeError: Cannot read property 'query' of undefined
```

**原因**: 技能代码错误或参数缺失

**解决**:
```bash
# 1. 查看技能日志
openclaw logs --grep "skill" --tail 50

# 2. 检查参数
# 3. 联系技能作者
```

---

### S004: 技能依赖缺失

```
Error: Missing dependency
Cannot find module 'node-fetch'
```

**原因**: npm 依赖未安装

**解决**:
```bash
# 进入技能目录
cd ~/.openclaw/workspace/skills/<skill-name>

# 安装依赖
npm install

# 或重新安装技能
openclaw skills install <skill-name> --force
```

### K003: 时区问题

```
Warning: Cron running in UTC timezone
Expected timezone: Asia/Shanghai
```

**原因**: 系统时区配置问题

**解决**:
```bash
# 设置时区
sudo timedatectl set-timezone Asia/Shanghai

# 验证
timedatectl

# 重启服务
openclaw restart
```

## 🟣 系统错误 (System)

### SY001: 内存不足

```
Error: JavaScript heap out of memory
```

**原因**: 内存不足

**解决**:
```bash
# 1. 增加 Swap
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 2. 增加 Node 内存限制
export NODE_OPTIONS="--max-old-space-size=2048"

# 3. 升级服务器配置
```

---

### SY002: 磁盘空间不足

```
Error: ENOSPC: no space left on device
```

**原因**: 磁盘已满

**解决**:
```bash
# 1. 检查磁盘使用
df -h

# 2. 清理空间
openclaw clean --cache
openclaw clean --logs --days 7

# 3. 查找大文件
find ~ -type f -size +100M
```

---

### SY003: 权限不足

```
Error: EACCES: permission denied
```

**原因**: 文件权限问题

**解决**:
```bash
# 修复权限
chmod -R 755 ~/.openclaw/
chown -R $USER:$USER ~/.openclaw/

# 或使用 sudo 运行（不推荐）
sudo openclaw start
```
