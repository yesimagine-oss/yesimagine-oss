## ❌ 问题 1: 安装失败

### 症状
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
# 报错或无响应
```

### 排查步骤
- [ ] 检查网络连接 `curl -I https://openclaw.ai`
- [ ] 检查 Node.js 版本 `node -v`（需要 v22+）
- [ ] 检查磁盘空间 `df -h`
- [ ] 检查权限（是否需要 sudo）

### 解决方案
```bash
# 升级 Node.js
nvm install 22
nvm use 22

# 手动下载安装
git clone https://github.com/openclaw/openclaw.git
cd openclaw
npm install
```

## ❌ 问题 2: 模型调用失败

### 症状
```
Error: API request failed
或
无回复/超时
```

### 排查步骤
- [ ] 检查 API Key 是否正确
- [ ] 检查 baseUrl 配置
- [ ] 检查网络连接 `curl -I https://coding.dashscope.aliyuncs.com`
- [ ] 查看模型配置 `openclaw config`
- [ ] 检查余额/用量

### 解决方案
```bash
# 重新配置模型
openclaw dashboard

# 测试 API 连通性
curl -H "Authorization: Bearer sk-YOUR_KEY" \
  https://coding.dashscope.aliyuncs.com/v1/models

# 查看详细错误
openclaw logs --tail 100
```

## ❌ 问题 3: 技能无法使用

### 症状
```
Skill not found
或
技能启用但无响应
```

### 排查步骤
- [ ] 检查技能是否已启用 `openclaw skills list`
- [ ] 检查技能文件是否存在
- [ ] 查看技能依赖是否安装
- [ ] 检查技能配置

### 解决方案
```bash
# 重新安装技能
openclaw skills uninstall <name>
openclaw skills install <name>

# 检查技能目录
ls -la ~/.openclaw/workspace/skills/

# 查看技能详情
openclaw skills show <name>
```

## ❌ 问题 4: 定时任务不执行

### 症状
- 到时间没有收到提醒
- cron 任务似乎没运行

### 排查步骤
- [ ] 检查 cron 是否启用
- [ ] 检查 cron 表达式是否正确
- [ ] 检查任务是否 enabled
- [ ] 查看 cron 日志

### 解决方案
```bash
# 查看 cron 相关日志
openclaw logs --grep cron

# 验证 cron 表达式
# 使用 https://crontab.guru 验证

# 手动触发测试
openclaw chat "你的 cron 命令"

# 重启服务
openclaw restart
```

## ❌ 问题 5: 通道消息不发送

### 症状
- Telegram/Discord 收不到消息
- 消息发送失败

### 排查步骤
- [ ] 检查通道是否启用
- [ ] 检查 Bot Token 是否正确
- [ ] 检查网络连接
- [ ] 查看通道日志

### 解决方案
```bash
# 检查通道配置
openclaw config | grep -A 10 channels

# 测试通道
openclaw channels list

# 重新配置通道
openclaw channels config telegram

# 重启服务
openclaw restart
```

## ❌ 问题 6: 服务频繁崩溃

### 症状
- OpenClaw 运行一段时间后停止
- 需要频繁重启

### 排查步骤
- [ ] 检查内存使用 `free -h`
- [ ] 检查 CPU 使用 `htop`
- [ ] 查看崩溃日志
- [ ] 检查系统资源

### 解决方案
```bash
# 增加 swap（如内存不足）
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 减少并发技能
# 升级服务器配置
# 查看具体错误日志
openclaw logs --tail 200
```

## ❌ 问题 7: 配置无法保存

### 症状
- 修改配置后重启丢失
- 配置不生效

### 排查步骤
- [ ] 检查配置文件权限
- [ ] 检查配置语法
- [ ] 确认配置模式（merge/replace）

### 解决方案
```bash
# 验证配置语法
openclaw config --validate

# 检查文件权限
ls -la ~/.openclaw/config/

# 备份后重新配置
cp config.json config.json.bak
openclaw dashboard
```

## ❌ 问题 8: SSH 连接失败

### 症状
```
ssh: connect to host xxx port 22: Connection refused
或
Permission denied (publickey,password)
```

### 排查步骤
- [ ] 检查服务器是否运行
- [ ] 检查 SSH 服务状态
- [ ] 检查防火墙设置
- [ ] 检查密码/密钥

### 解决方案
```bash
# 检查服务器状态（控制台）
# 检查 SSH 服务
systemctl status sshd

# 重启 SSH 服务
sudo systemctl restart sshd

# 检查防火墙
sudo ufw status
sudo ufw allow 22/tcp
```
