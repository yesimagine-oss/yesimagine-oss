## 📚 概述

### 什么是模型微调

模型微调（Fine-tuning）是在预训练模型基础上，使用特定领域数据继续训练，使模型适应特定任务。

### 适用场景

- 客服对话优化
- 专业领域问答
- 特定风格文本生成
- 企业知识库问答

---

## 🔧 微调流程

### 步骤 1: 准备数据集

```json
[
  {
    "messages": [
      {"role": "system", "content": "你是客服助手"},
      {"role": "user", "content": "如何退款？"},
      {"role": "assistant", "content": "退款流程如下：1... 2... 3..."}
    ]
  },
  {
    "messages": [
      {"role": "user", "content": "发货时间？"},
      {"role": "assistant", "content": "一般 24 小时内发货"}
    ]
  }
]
```

### 数据格式要求

| 要求 | 说明 |
|------|------|
| 格式 | JSONL |
| 编码 | UTF-8 |
| 最小样本 | 100 条 |
| 推荐样本 | 1000+ 条 |
| 最大样本 | 10000 条 |

---

### 步骤 2: 上传数据集

```bash
# 使用阿里云 CLI
aliyun bssopenapi CreateDataset \
  --DatasetName my-finetune-data \
  --DatasetType TEXT \
  --DataSource @data.jsonl
```

---

### 步骤 3: 创建微调任务

```bash
aliyun bssopenapi CreateFinetuneJob \
  --JobName my-finetune-job \
  --BaseModel qwen3.5-plus \
  --DatasetId dataset-xxx \
  --Epochs 3 \
  --LearningRate 1e-5 \
  --BatchSize 16
```

---

### 步骤 4: 配置微调参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| Epochs | 训练轮数 | 3-5 |
| LearningRate | 学习率 | 1e-5 ~ 1e-4 |
| BatchSize | 批次大小 | 16-32 |
| MaxSeqLength | 最大序列长度 | 2048 |
| LoRARank | LoRA 秩 | 8-64 |

---

### 步骤 5: 监控训练

```bash
# 查看训练状态
aliyun bssopenapi DescribeFinetuneJob \
  --JobId job-xxx
```

---

### 步骤 6: 部署模型

```bash
# 部署微调后的模型
aliyun bssopenapi DeployModel \
  --ModelId model-xxx \
  --EndpointName my-endpoint
```

## 💻 Python SDK 示例

### 安装 SDK

```bash
pip install dashscope
```

### 准备数据集

```python
import json

# 准备训练数据
data = [
    {
        "messages": [
            {"role": "system", "content": "你是客服助手"},
            {"role": "user", "content": "如何退款？"},
            {"role": "assistant", "content": "退款流程如下..."}
        ]
    }
]

# 保存为 JSONL
with open('train_data.jsonl', 'w') as f:
    for item in data:
        f.write(json.dumps(item) + '\n')
```

### 上传数据集

```python
import dashscope
from dashscope import Dataset

dashscope.api_key = 'YOUR_API_KEY'

# 上传数据集
dataset = Dataset.upload(
    file_path='train_data.jsonl',
    name='my-finetune-data',
    description='客服对话数据'
)
print(f'Dataset ID: {dataset.id}')
```

### 创建微调任务

```python
from dashscope import Finetune

# 创建微调任务
job = Finetune.create(
    model='qwen3.5-plus',
    train_dataset_id=dataset.id,
    hyperparameters={
        'epochs': 3,
        'learning_rate': 1e-5,
        'batch_size': 16
    }
)
print(f'Job ID: {job.id}')
```

### 监控训练

```python
# 轮询训练状态
import time

while True:
    job = Finetune.get(job.id)
    print(f'Status: {job.status}')
    
    if job.status in ['SUCCEEDED', 'FAILED']:
        break
    
    time.sleep(60)
```

### 使用微调模型

```python
from dashscope import Generation

# 使用微调后的模型
response = Generation.call(
    model='qwen3.5-plus-finetuned',
    messages=[
        {'role': 'user', 'content': '如何退款？'}
    ]
)
print(response.output.text)
```

## ⚠️ 最佳实践

### 1. 数据质量

- 确保数据准确性
- 去除重复数据
- 平衡数据分布
- 标注清晰一致

### 2. 参数调优

```python
# 学习率调优
learning_rates = [1e-5, 5e-5, 1e-4]
for lr in learning_rates:
    job = Finetune.create(
        model='qwen3.5-plus',
        train_dataset_id=dataset.id,
        hyperparameters={'learning_rate': lr}
    )
    # 评估效果
```

### 3. 防止过拟合

- 使用验证集
- 早停策略
- 正则化
- Dropout

### 4. 评估效果

```python
# 准备测试集
test_data = [...]

# 批量测试
correct = 0
for item in test_data:
    response = Generation.call(
        model='qwen3.5-plus-finetuned',
        messages=item['messages'][:-1]
    )
    if response.output.text == item['messages'][-1]['content']:
        correct += 1

accuracy = correct / len(test_data)
print(f'Accuracy: {accuracy}')
```

## 📋 常见问题

### Q1: 微调后效果不如预期

**解决**:
- 检查数据质量
- 增加训练数据
- 调整超参数
- 增加训练轮数

### Q2: 训练成本过高

**解决**:
- 减少数据量
- 使用 LoRA 微调
- 降低训练轮数
- 选择更小模型

### Q3: 训练失败

**检查**:
- 数据格式是否正确
- 数据量是否足够
- 账户余额是否充足
- 查看错误日志
