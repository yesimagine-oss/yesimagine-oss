## 🔧 场景 1: 下载目录自动整理

### 问题
下载目录文件杂乱，需要手动分类。

### 解决方案

创建自动整理脚本：

```bash
#!/bin/bash
# ~/.openclaw/workspace/scripts/organize-downloads.sh

DOWNLOAD_DIR=~/Downloads
DATE=$(date +%Y-%m-%d)

# 创建分类目录
mkdir -p $DOWNLOAD_DIR/{图片，文档，视频，安装包，其他}

# 移动图片
mv $DOWNLOAD_DIR/*.{jpg,jpeg,png,gif,webp,bmp} $DOWNLOAD_DIR/图片/ 2>/dev/null

# 移动文档
mv $DOWNLOAD_DIR/*.{pdf,doc,docx,xls,xlsx,ppt,pptx,txt,md} $DOWNLOAD_DIR/文档/ 2>/dev/null

# 移动视频
mv $DOWNLOAD_DIR/*.{mp4,avi,mkv,mov,wmv,flv} $DOWNLOAD_DIR/视频/ 2>/dev/null

# 移动安装包
mv $DOWNLOAD_DIR/*.{exe,dmg,pkg,deb,rpm} $DOWNLOAD_DIR/安装包/ 2>/dev/null

# 生成报告
echo "📁 下载目录整理完成 - $DATE"
echo ""
echo "分类统计:"
for dir in 图片 文档 视频 安装包 其他; do
  count=$(ls -1 $DOWNLOAD_DIR/$dir 2>/dev/null | wc -l)
  echo "  $dir: $count 个文件"
done
```

### 配置定时任务

```json
{
  "crons": {
    "tasks": [
      {
        "id": "organize-downloads",
        "schedule": "0 2 * * *",
        "command": "执行 ~/scripts/organize-downloads.sh 并发送报告",
        "channel": "telegram",
        "enabled": true
      }
    ]
  }
}
```

## 🔧 场景 2: 重要文件自动备份

### 监控目录

```bash
# 创建监控列表
cat > ~/.openclaw/workspace/config/backup-dirs.txt << EOF
~/Documents/工作
~/Documents/个人
~/Projects
~/.openclaw/workspace
EOF
```

### 备份脚本

```bash
#!/bin/bash
# ~/.openclaw/workspace/scripts/backup-important.sh

BACKUP_DIR=~/backups
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE=$BACKUP_DIR/backup_$DATE.tar.gz

# 读取要备份的目录
DIRS_TO_BACKUP=$(cat ~/.openclaw/workspace/config/backup-dirs.txt)

# 创建备份
tar -czf $BACKUP_FILE $DIRS_TO_BACKUP 2>/dev/null

# 压缩率统计
ORIG_SIZE=$(du -sh $DIRS_TO_BACKUP 2>/dev/null | awk '{sum+=$1} END {print sum}')
BACKUP_SIZE=$(du -sh $BACKUP_FILE | awk '{print $1}')

# 生成报告
cat << EOF
📦 备份完成

时间：$(date)
备份文件：$BACKUP_FILE
原始大小：$ORIG_SIZE
备份大小：$BACKUP_SIZE

备份内容:
$(tar -tzf $BACKUP_FILE | head -20)
...
EOF
```

### 配置定时任务

```json
{
  "crons": {
    "tasks": [
      {
        "id": "daily-backup",
        "schedule": "0 3 * * *",
        "command": "执行 ~/scripts/backup-important.sh 并发送报告",
        "channel": "telegram",
        "enabled": true
      },
      {
        "id": "weekly-backup-cleanup",
        "schedule": "0 4 * * 0",
        "command": "清理 30 天前的备份",
        "channel": "log",
        "enabled": true
      }
    ]
  }
}
```

### 清理旧备份

```bash
#!/bin/bash
# ~/.openclaw/workspace/scripts/cleanup-old-backups.sh

BACKUP_DIR=~/backups

# 删除 30 天前的备份
find $BACKUP_DIR -name "backup_*.tar.gz" -mtime +30 -delete

# 报告
REMAINING=$(ls -1 $BACKUP_DIR/backup_*.tar.gz 2>/dev/null | wc -l)
echo "✅ 备份清理完成，剩余 $REMAINING 个备份文件"
```

## 🔧 场景 3: 文件变化监控

### 监控脚本

```bash
#!/bin/bash
# ~/.openclaw/workspace/scripts/monitor-files.sh

WATCH_DIR=~/Documents/工作
STATE_FILE=~/.openclaw/workspace/state/file-monitor-state.json
LOG_FILE=~/.openclaw/logs/file-monitor.log

# 获取当前文件列表
CURRENT_STATE=$(find $WATCH_DIR -type f -newer $STATE_FILE 2>/dev/null)

if [ -n "$CURRENT_STATE" ]; then
    echo "📁 文件变化检测" >> $LOG_FILE
    echo "$(date): 发现新文件" >> $LOG_FILE
    echo "$CURRENT_STATE" >> $LOG_FILE
    
    # 发送通知（通过 OpenClaw）
    openclaw chat "检测到文件变化：
$CURRENT_STATE"
fi

# 更新状态
touch $STATE_FILE
```

### 配置定时任务

```json
{
  "crons": {
    "tasks": [
      {
        "id": "file-monitor",
        "schedule": "*/15 * * * *",
        "command": "执行 ~/scripts/monitor-files.sh",
        "channel": "log",
        "enabled": true
      }
    ]
  }
}
```

## 🔧 场景 4: 云同步状态检查

### 同步检查脚本

```bash
#!/bin/bash
# ~/.openclaw/workspace/scripts/check-sync-status.sh

# 检查磁盘空间
DISK_USAGE=$(df -h /home | tail -1 | awk '{print $5}')
DISK_AVAIL=$(df -h /home | tail -1 | awk '{print $4}')

# 检查同步进程（如使用 syncthing/rclone）
SYNC_STATUS="正常"
if pgrep -x "syncthing" > /dev/null; then
    SYNC_STATUS="运行中"
else
    SYNC_STATUS="未运行"
fi

# 生成报告
cat << EOF
☁️ 云同步状态检查

磁盘使用：$DISK_USAGE
可用空间：$DISK_AVAIL
同步服务：$SYNC_STATUS

$(date)
EOF
```

## ⚠️ 常见问题

### Q1: 脚本无权限执行
**解决**: `chmod +x ~/scripts/*.sh`

### Q2: 中文文件名乱码
**解决**: 确保系统 locale 设置为 UTF-8

### Q3: 磁盘空间不足
**解决**: 定期清理旧备份，监控磁盘使用
