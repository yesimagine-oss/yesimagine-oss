## 🔧 HuggingFace 热门模型推送

### 配置步骤

```bash
openclaw cron add \
  --name "hf-trending-models" \
  --cron "0 9 * * 1" \
  --tz "Asia/Shanghai" \
  --message '请使用 curl 命令执行以下请求获取 HuggingFace 上最近热门的大语言模型：
curl -s "https://hf-mirror.com/api/models?sort=trendingScore&direction=-1&limit=10&pipeline_tag=text-generation"
解析返回的 JSON 数据，列出前 10 个模型，每个包含：
1. 模型名称
2. 发布日期
3. 下载量和点赞数
4. 模型页面链接（格式为 https://huggingface.co/）
重点标注最近一个月内新发布的模型，并用中文简要说明每个模型的特点（如参数量、所属机构等）。' \
  --channel dingtalk \
  --announce \
  --timeout-seconds 120
```

---

### HuggingFace API 参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| sort | 排序字段 | `trendingScore` |
| direction | 排序方向 | `-1` (降序) |
| limit | 返回数量 | `10` |
| pipeline_tag | 模型类型 | `text-generation` |

### 可选模型类型

| 类型 | pipeline_tag |
|------|--------------|
| 文本生成 | `text-generation` |
| 图像分类 | `image-classification` |
| 文本分类 | `text-classification` |
| 问答 | `question-answering` |
| 翻译 | `translation` |
| 语音识别 | `automatic-speech-recognition` |

## 🔧 GitHub 热门项目推送

### 配置步骤

```bash
openclaw cron add \
  --name "github-trending" \
  --cron "0 9 * * 1" \
  --tz "Asia/Shanghai" \
  --message '请获取过去一周内 GitHub 上新创建的热门项目（按 Star 数排序前 10），每个项目列出名称、Star 数、简介（中文翻译）、编程语言和链接，重点标注 Star 数超过 1000 的项目。请先用 date 命令计算 7 天前的日期，然后通过 GitHub Search API 的 created 参数筛选。' \
  --channel dingtalk \
  --announce \
  --timeout-seconds 120
```

---

### GitHub API 详解

#### API 端点

```
https://api.github.com/search/repositories
```

#### 请求参数

| 参数 | 说明 | 示例 |
|------|------|------|
| q | 搜索查询 | `created:>2026-03-05` |
| sort | 排序字段 | `stars` |
| order | 排序方向 | `desc` |
| per_page | 每页数量 | `10` |

#### 搜索查询语法

```
# 按创建时间
created:>2026-03-05

# 按语言
language:python

# 按 Star 数
stars:>1000

# 组合查询
created:>2026-03-05 language:python stars:>1000
```
