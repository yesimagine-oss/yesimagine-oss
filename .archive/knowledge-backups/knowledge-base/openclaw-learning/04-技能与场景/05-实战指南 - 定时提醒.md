---

## 🎯 场景描述

设置一次性或周期性提醒，确保重要事项不遗漏。

---

## 📋 前置条件

- [ ] OpenClaw 已安装
- [ ] qqbot-cron 技能已启用

---

## 🔧 配置步骤

### 步骤 1: 启用 qqbot-cron 技能

```bash
# 启用技能
openclaw skills enable qqbot-cron
```

### 步骤 2: 设置一次性提醒

直接发送消息：

```
"提醒我 30 分钟后去开会"
"提醒我今晚 8 点给妈妈打电话"
"提醒我明天上午 10 点提交报告"
```

### 步骤 3: 设置周期性提醒

```
"每天早上 9 点提醒我喝水"
"每周一早上 8 点提醒我开例会"
"每月 1 号提醒我交房租"
```

## 🔨 高级用法

### 1. 带条件的提醒

```
"如果明天下雨，提醒我带伞"
"如果明天温度低于 10 度，提醒我加外套"
```

### 2. 多步骤提醒

```
"会议前 30 分钟提醒我准备材料，前 10 分钟提醒我进入会议室"
```

### 3. 提醒 + 任务

```
"每天早上 7 点提醒我晨跑，并告诉我今天天气"
"每周五下午 5 点提醒我写周报，并附上本周日历"
```

## 📊 Cron 表达式参考

| 描述 | Cron 表达式 |
|------|-------------|
| 每天早上 8 点 | `0 8 * * *` |
| 每周一 9 点 | `0 9 * * 1` |
| 每月 1 号 | `0 0 1 * *` |
| 每 30 分钟 | `*/30 * * * *` |
| 工作日 9-17 点每小时 | `0 9-17 * * 1-5` |
| 每天早晚各一次 | `0 8,20 * * *` |

## ⚠️ 常见问题

### Q1: 提醒没有触发
**检查**:
1. qqbot-cron 技能是否启用
2. cron 服务是否运行
3. 查看日志 `openclaw logs --grep cron`

### Q2: 提醒时间不对
**解决**:
- 检查服务器时区设置
- 确认 cron 表达式正确
- 使用 24 小时制

### Q3: 想取消提醒
**方法**:
```
"取消我设置的所有提醒"
"取消明天上午的会议提醒"
```
