## 🔧 配置步骤

### 步骤 1: 启用搜索技能

```bash
# 查看可用技能
openclaw skills list

# 启用 searxng（推荐，无需 API Key）
openclaw skills enable searxng

# 或启用 web_search（需要 Brave API Key）
openclaw skills enable web_search
```

### 步骤 2: 配置定时任务

```json
{
  "crons": {
    "enabled": true,
    "tasks": [
      {
        "id": "tech-news-daily",
        "schedule": "0 9 * * *",
        "description": "每日科技新闻摘要",
        "command": "搜索今天的科技新闻，总结最重要的 5 条，每条一句话",
        "channel": "telegram",
        "enabled": true
      }
    ]
  }
}
```

### 步骤 3: 优化搜索配置（可选）

```json
{
  "skills": {
    "config": {
      "searxng": {
        "instanceUrl": "https://searx.be",
        "categories": ["news", "general"],
        "language": "zh-CN",
        "maxResults": 10
      }
    }
  }
}
```

### 步骤 4: 测试运行

```bash
# 手动测试
openclaw chat "搜索最新的 AI 新闻，总结 3 条最重要的"
```

## ⚠️ 常见问题

### Q1: 搜索结果太少
**解决**: 
- 增加 maxResults
- 放宽搜索关键词
- 更换 searxng 实例

### Q2: 新闻不够新
**解决**:
- 在命令中指定"今天"或"24 小时内"
- 使用 freshness 参数（如支持）

### Q3: 摘要质量不高
**解决**:
- 调整 prompt，明确格式要求
- 使用更强的模型（如 qwen3-max）
