## 📉 成本优化建议

### 1. 选择合适的模型

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 日常对话 | qwen3.5-plus | 性价比高 |
| 代码生成 | qwen3-coder-plus | 代码优化 |
| 复杂推理 | qwen3-max | 能力强 |
| 简单任务 | glm-4.7 | 便宜够用 |

### 2. 减少不必要调用

```javascript
// 使用缓存
const cache = new Map();

async function queryAI(prompt) {
  if (cache.has(prompt)) {
    return cache.get(prompt);
  }
  const result = await callAI(prompt);
  cache.set(prompt, result);
  return result;
}
```

### 3. 优化 Prompt

```
// 不好的 Prompt（冗长）
"请你帮我分析一下这个问题，我觉得可能是以下几个原因..."

// 好的 Prompt（简洁）
"分析问题原因，列出 3 点。"
```

### 4. 设置用量限制

```json
{
  "limits": {
    "dailyBudget": 10,
    "monthlyBudget": 200,
    "maxTokensPerRequest": 10000
  }
}
```

## 📊 用量监控脚本

```bash
#!/bin/bash
# ~/scripts/check-api-usage.sh

API_KEY="sk-YOUR_KEY"
THRESHOLD=10  # 告警阈值（元）

# 查询今日用量
USAGE=$(curl -s "https://bailian.console.aliyun.com/api/usage/daily" \
  -H "Authorization: Bearer $API_KEY" | jq '.todayCost')

echo "今日 API 用量：¥$USAGE"

# 超过阈值发送告警
if (( $(echo "$USAGE > $THRESHOLD" | bc -l) )); then
  echo "⚠️ API 用量告警：今日已使用 ¥$USAGE" | \
    openclaw chat --channel telegram
fi
```
