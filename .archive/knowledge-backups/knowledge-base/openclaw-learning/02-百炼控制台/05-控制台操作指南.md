## 🔑 API-KEY 管理

### 创建 API Key

1. 登录百炼控制台
2. 左侧菜单选择「API-KEY 管理」
3. 点击「创建新的 API-KEY」
4. 输入名称（如：openclaw-main）
5. 选择权限范围
6. 确认创建
7. **立即复制并保存 Key**（只显示一次）

### 管理 API Key

| 操作 | 步骤 |
|------|------|
| 查看 Key | API-KEY 管理 → 点击 Key 名称 |
| 禁用 Key | API-KEY 管理 → 点击「禁用」 |
| 删除 Key | API-KEY 管理 → 点击「删除」 |
| 查看用量 | API-KEY 管理 → 点击 Key → 用量明细 |

### 安全建议

- ✅ 定期轮换（每 3 个月）
- ✅ 最小权限原则
- ✅ 不要提交到代码仓库
- ✅ 使用环境变量存储

## 🤖 模型管理

### 查看可用模型

1. 左侧菜单选择「模型广场」
2. 浏览或搜索模型
3. 点击模型查看详情

### 模型详情信息

| 信息项 | 说明 |
|--------|------|
| 模型名称 | 如 qwen3.5-plus |
| 上下文窗口 | 支持的最大输入长度 |
| 最大输出 | 单次最大输出 token 数 |
| 支持类型 | 文本/图像/多模态 |
| 价格 | 输入/输出价格 |

### 模型对比

1. 选择多个模型
2. 点击「对比」
3. 查看参数对比表

---

## 📊 用量统计

### 查看用量

1. 左侧菜单选择「用量统计」
2. 选择时间范围
3. 查看用量图表

### 用量明细

| 字段 | 说明 |
|------|------|
| 时间 | 调用时间 |
| 模型 | 使用的模型 |
| 输入 Token | 输入 token 数 |
| 输出 Token | 输出 token 数 |
| 费用 | 本次调用费用 |

### 导出用量

1. 选择时间范围
2. 点击「导出」
3. 下载 CSV 文件

## 💰 计费管理

### 查看账单

1. 左侧菜单选择「计费管理」

2. 点击「充值」
3. 选择充值金额
4. 选择支付方式
5. 完成支付

1. 进入「预算管理」

3. 配置告警通知
