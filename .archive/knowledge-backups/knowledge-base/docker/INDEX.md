## 📚 Docker 技术全景图

### 1️⃣ 核心概念

| 概念 | 说明 | 重要性 | 变现关联 |
|------|------|--------|---------|
| **镜像 (Image)** | 只读模板，包含应用 + 依赖 | ⭐⭐⭐⭐⭐ | 基础 |
| **容器 (Container)** | 镜像的运行实例 | ⭐⭐⭐⭐⭐ | 基础 |
| **Dockerfile** | 镜像构建脚本 | ⭐⭐⭐⭐⭐ | 高 |
| **Registry** | 镜像仓库 (Docker Hub) | ⭐⭐⭐⭐ | 中 |
| **Volume** | 数据持久化 | ⭐⭐⭐⭐ | 中 |
| **Network** | 容器网络通信 | ⭐⭐⭐⭐ | 中 |

### 2️⃣ 核心功能模块

| 模块 | 功能 | 重要性 | 变现关联 |
|------|------|--------|---------|
| **镜像管理** | build/pull/push/tag | ⭐⭐⭐⭐⭐ | 高 |
| **容器管理** | run/start/stop/rm | ⭐⭐⭐⭐⭐ | 高 |
| **数据卷** | volume/bind mount | ⭐⭐⭐⭐ | 中 |
| **网络** | bridge/host/overlay | ⭐⭐⭐⭐ | 中 |
| **Docker Compose** | 多容器编排 | ⭐⭐⭐⭐⭐ | 高 |
| **Docker Swarm** | 集群编排 | ⭐⭐⭐ | 中 |
| **Kubernetes** | 容器编排 | ⭐⭐⭐⭐⭐ | 高 |
