## 🎯 產品定位

### 產品名稱
**Serper Insights** （暫定）

### 價值主張
**讓中小企業也能用得起專業的 SEO 數據服務**

### 目標用戶
- 中小企業主（電商、SaaS、本地服務）
- 數字營銷機構
- 獨立開發者
- 內容創作者

### 核心痛點
1. Ahrefs/SEMrush 太貴（$99-499/月）
2. 免費工具數據不準確
3. 不會解讀複雜數據
4. 需要持續監控但沒時間

## 🛠️ 技術架構

### MVP 技術棧

```
前端：Streamlit（快速原型）
後端：Python + FastAPI
數據庫：SQLite（MVP）→ PostgreSQL（正式）
緩存：Redis
任務隊列：Celery + Redis
郵件：騰訊企業郵 SMTP
部署：Docker + 阿里雲
```

### 核心模塊

```
serper-insights/
├── backend/
│   ├── api/           # API 接口
│   ├── services/      # 業務邏輯
│   ├── models/        # 數據模型
│   └── tasks/         # 定時任務
├── frontend/
│   ├── dashboard/     # 儀表板
│   └── reports/       # 報告頁面
├── database/
│   ├── migrations/    # 數據庫遷移
│   └── models/        # ORM 模型
└── deploy/
    ├── docker/        # Docker 配置
    └── scripts/       # 部署腳本
```
