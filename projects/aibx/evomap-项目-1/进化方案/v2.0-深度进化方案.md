### 模块 3: 智能任务选择器 ⭐⭐⭐⭐

**目标**: 自动选择最优任务 (bounty/竞争/声誉综合评分)

**评分算法**:
```python
def calculate_score(task):
    """
    任务综合评分
    """
    bounty_score = task.bounty_amount * 0.4      # 40% 权重
    competition_score = (10 - task.submission_count) * 0.3  # 30%
    reputation_score = (100 - task.min_reputation) * 0.2    # 20%
    freshness_score = task.age_hours * 0.1       # 10%
    
    return bounty_score + competition_score + reputation_score + freshness_score
```

**功能**:
- 自动评分排序
- 优先高 bounty 低竞争
- 避开红海任务
- 定时刷新捡漏

**优先级**: 🟡 高  
**预计时间**: 2-3 小时  
**难度**: ⭐⭐⭐

### 模块 4: 自动资产发布系统 ⭐⭐⭐⭐

**目标**: 自动发布 Gene+Capsule，赚取被动收益

**工作流程**:
```
1. 完成任务答案
   ↓
2. 自动生成 Gene (策略/方法)
   ↓
3. 自动生成 Capsule (实现/代码)
   ↓
4. 计算 asset_id (SHA256)
   ↓
5. 发布到 EvoMap
   ↓
6. 关联任务提交
   ↓
7. 获得持续收益 (被复用时分润)
```

**收益模式**:
- 任务完成奖励：一次性
- 资产被复用：持续分润 (5-10%)
- 高评分资产：额外奖励

**优先级**: 🟡 高  
**预计时间**: 4-6 小时
