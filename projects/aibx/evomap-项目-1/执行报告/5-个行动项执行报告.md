## 5️⃣ 实现 Agent Hooks

### 三种 Hook 类型

| 类型 | 触发时机 | 用途 |
|------|---------|------|
| **Pre-hooks** | 执行前 | 验证输入、注入上下文、阻止执行 |
| **Post-hooks** | 执行后 | 转换输出、记录日志、触发下游 |
| **Error hooks** | 失败时 | 重试、降级、优雅退化 |

### 已实现 Hooks

#### Pre-hooks

1. **ValidateInputHook** - 验证输入
2. **InjectContextHook** - 注入上下文
3. **AuthHeaderHook** - 注入 Auth Header
4. **RateLimitHook** - 速率限制

#### Post-hooks

1. **LogOutputHook** - 记录输出
2. **ValidateOutputHook** - 验证输出
3. **TransformOutputHook** - 转换输出
4. **TriggerDownstreamHook** - 触发下游动作

#### Error Hooks

1. **RetryHook** - 重试（指数退避 + jitter）
2. **FallbackHook** - 降级方案
3. **CircuitBreakerHook** - 断路器
4. **ErrorLoggingHook** - 错误记录

### Hook 管理器

```python
class HookManager:
    def __init__(self):
        self.pre_hooks = []
        self.post_hooks = []
        self.error_hooks = []
    
    def add_pre_hook(self, hook: PreHook):
        self.pre_hooks.append(hook)
    
    def decorate(self, agent: Agent):
        """装饰 Agent 的所有方法"""
        # 依次应用所有 hooks
        for hook in self.pre_hooks + self.post_hooks + self.error_hooks:
            agent.execute = hook(agent.execute)
        return agent
```

### 使用示例

```python
# 创建 HookManager
hook_manager = HookManager()

# 添加 Pre-hooks
hook_manager.add_pre_hook(ValidateInputHook())
hook_manager.add_pre_hook(InjectContextHook({'project': 'my-project'}))

# 添加 Post-hooks
hook_manager.add_post_hook(LogOutputHook('agent.log'))
hook_manager.add_post_hook(ValidateOutputHook({'result': str}))

# 添加 Error-hooks
hook_manager.add_error_hook(RetryHook(max_retries=3))
hook_manager.add_error_hook(CircuitBreakerHook(failure_threshold=5))

# 装饰 Agent
agent = hook_manager.decorate(Agent())

# 现在可以直接使用
result = agent.execute({'task': 'analyze this code'})
```

## 📈 关键洞察

### 1. MCP 是接口层

**定位**:
```
Knowledge (文档) → Interface (MCP) → Operation (Skill) → Evolution (GEP)
                          ↑
                      MCP 在这里
```

**价值**: 标准化接口，让 Agent 可以调用外部工具

### 2. Swarm Intelligence 是放大器

**价值**:
- 复杂任务分解为简单子任务
- 多 Agent 并行解决
- 聚合为超越任何个体的答案

**适用场景**:
- 复杂代码审查
- 架构决策
- 多模态分析

### 3. Agent Hooks 是安全网

**价值**:
- Pre-hooks: 防止错误输入
- Post-hooks: 保证输出质量
- Error hooks: 优雅处理失败

**最佳实践**:
- 优先 Stateless hooks
- 副作用包含
- 可观察性不是可选的
