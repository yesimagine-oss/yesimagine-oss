## 4.2 悬赏过期退款 (Bounty Expired)

### 退款规则

```
退款金额 = 悬赏金额 × 100%
```

### 示例

```
创建悬赏：
- 悬赏金额：200 积分
- 期限：7 天

情况 1：有人回答并被采纳
- 回答者获得：170 积分（扣除 15% 佣金）
- 平台收入：30 积分
- 你获得：解决方案

情况 2：过期无人回答
- 退款：200 积分（100%）
- 平台收入：0 积分
- 你获得：无损失
```

### 策略建议

1. ✅ **设置合理期限** - 给足够时间回答
2. 💰 **不用担心损失** - 过期全退
3. 🎯 **合理定价** - 吸引高质量回答

## 4.3 Boost 过期退款 (Boost Expired)

### 退款规则

```
退款金额 = Boost 费用 × 50%
```

### 示例

```
Boost 悬赏：
- 悬赏金额：200 积分
- Boost 层级 2：300 积分
- 总锁定：500 积分

情况 1：任务完成
- 回答者获得：170 积分
- 平台收入：30 + 300 = 330 积分
- Boost 效果：优先级提升

情况 2：过期未完成
- 悬赏退款：200 积分（100%）
- Boost 退款：150 积分（50%）
- 总退款：350 积分
- 实际损失：150 积分（Boost 费用的一半）
```

### 风险评估

| Boost 层级 | 费用 | 过期损失 | 建议 |
|-----------|------|---------|------|
| 层级 1 | 100 | 50 | 低风险 |
| 层级 2 | 300 | 150 | 中风险 |
| 层级 3 | 500 | 250 | 高风险 |

### 使用策略

1. ⏰ **紧急任务** - 值得使用 Boost
2. 📊 **评估必要性** - 非紧急不 Boost
3. 💰 **预算控制** - 考虑过期损失

## 4.4 Validator 解锁退款 (Validator Unstake)

### 退款规则

```
退款金额 = 质押金额 × 100%
```

### 流程

```
1. 申请 unstake
2. 等待处理（可能有锁定期）
3. 全额退还 500 积分
```

### 风险分析

- **资金风险：** 无（全额退还）
- **机会成本：** 质押期间无法使用积分
- **声誉影响：** 频繁 unstake 可能影响声誉

### 建议

1. ✅ **长期参与** - 质押后稳定参与
2. 📊 **评估收益** - 验证收益 vs 机会成本
3. ⏰ **规划时间** - 避免频繁进出

## 4.5 KG 操作失败退款 (KG Operation Failed)

### 退款规则

```
退款金额 = 操作费用 × 100%
```

### 适用场景

- 查询失败
- 写入失败
- 系统错误

### 示例

```
KG 查询：
- 费用：10 积分
- 结果：失败（系统错误）
- 退款：10 积分（100%）
```

### 建议

1. ✅ **无需担心** - 失败自动退款
2. 📊 **监控成功率** - 评估 KG 可靠性
3. 💰 **批量操作** - 减少失败概率
