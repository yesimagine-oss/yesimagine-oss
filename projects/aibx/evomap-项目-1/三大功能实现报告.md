## 🧠 3. 学习循环 (learning_loop.py)

### 功能列表
- ✅ `analyze_failure()` - 分析失败原因
- ✅ `_classify_error()` - 错误分类（6 大类）
- ✅ `_analyze_root_cause()` - 根因分析
- ✅ `_generate_lesson()` - 生成教训
- ✅ `generate_improvements()` - 生成改进建议
- ✅ `verify_improvement()` - 验证改进效果
- ✅ `print_learning_report()` - 打印学习报告

### 错误分类体系
| 类型 | 识别关键词 | 典型错误 |
|------|----------|---------|
| **network_error** | 503/timeout/busy | 服务器繁忙 |
| **validation_error** | validation/schema | 格式验证失败 |
| **auth_error** | auth/unauthorized/401 | 认证失败 |
| **resource_error** | points/credits/balance | 积分不足 |
| **logic_error** | already/not found/404 | 任务已 Claim |
| **unknown** | 其他 | 未知错误 |

### 学习流程
```
失败发生
   ↓
错误分类（6 大类）
   ↓
根因分析（可能原因）
   ↓
教训提取（具体建议）
   ↓
改进建议（优先级排序）
   ↓
效果验证（追踪改进）
```

### 使用示例
```python
from learning_loop import LearningLoop
loop = LearningLoop()

# 分析失败
loop.analyze_failure(
    task_id='task_001',
    error='503 Service Temporarily Unavailable',
    context={'task_type': 'bounty', 'bounty': 100}
)

# 生成改进建议
improvements = loop.generate_improvements()

# 验证改进效果
loop.verify_improvement(
    improvement_name='claim_with_retry',
    success=True,
    metrics={'success_rate': 0.85}
)

# 打印报告
loop.print_learning_report()
```

## 💡 关键设计决策

### 1. 为什么用 Python 而不是 Node.js？
- ✅ 与 OpenClaw 深度集成
- ✅ 便于自动化（HEARTBEAT）
- ✅ 团队技术栈统一

### 2. 为什么分类 6 大类错误？
- ✅ 覆盖所有已知错误场景
- ✅ 每类有明确的改进方向
- ✅ 便于统计分析

### 3. 为什么分开三个模块？
- ✅ 单一职责原则
- ✅ 便于独立测试
- ✅ 可按需使用

### 4. 为什么用 JSONL 而不是 JSON？
- ✅ 追加写入高效
- ✅ 便于流式处理
- ✅ 易于分割和归档
