## 🎯 訪談目標

### 核心問題
1. 他們現在如何做關鍵詞研究/市場調研？
2. 痛點是什麼？（時間、成本、準確性）

## 👥 目標客戶畫像

### 畫像 1: 中小企業主
- **行業**: 電商、SaaS、本地服務
- **規模**: 10-100 人
- **痛點**: 不懂 SEO，需要監控競品
- **預算**: $200-500/月
- **決策**: 快速，看 ROI

### 畫像 2: 營銷機構
- **行業**: 數字營銷、廣告公司
- **規模**: 5-50 人
- **痛點**: 需要給客戶提供數據報告
- **預算**: $500-2000/月
- **決策**: 看專業性和效率

### 畫像 3: 獨立開發者
- **行業**: SaaS、App 開發
- **規模**: 1-5 人
- **痛點**: 需要市場調研和關鍵詞優化
- **預算**: $50-200/月
- **決策**: 看性價比和易用性

### 畫像 4: 內容創作者
- **行業**: 自媒體、博主、YouTuber
- **規模**: 個人
- **痛點**: 找選題、追熱點、分析競品
- **預算**: $20-100/月
- **決策**: 看內容質量提升

## 📋 訪談問題清單

### 開場（5 分鐘）

**目的**: 建立信任，說明意圖

```
你好，我是 [名字]，正在開發一個基於 Google 搜索數據的營銷工具。

想請教你一些關於市場調研/關鍵詞研究的問題，大概 15-20 分鐘。

訪談內容僅用於產品開發，不會泄露你的信息。

可以開始嗎？
```

---

### 現狀了解（5 分鐘）

**目的**: 了解當前工作流程和痛點

1. **你現在如何做關鍵詞研究？**
   - 追問：用什麼工具？Google？付費工具？
   - 追問：頻率如何？每週？每月？

2. **你做競品分析嗎？如何做？**
   - 追問：關注哪些競品？
   - 追問：多久分析一次？

3. **你做市場調研嗎？通常為了什麼？**
   - 追問：自己收集還是買報告？
   - 追問：預算大概多少？

4. **當前流程中，最耗時的部分是什麼？**
   - 追問：每週花多少時間？
   - 追問：哪裡最痛苦？

---

### 痛點挖掘（5 分鐘）

**目的**: 量化痛點，確認付費意願

5. **如果有一個工具能自動化這些工作，對你有幫助嗎？**
   - 追問：具體幫助在哪裡？
   - 追問：能節省多少時間？

6. **你現在用過哪些付費工具？**
   - 追問：Ahrefs？SEMrush？Moz？
   - 追問：滿意嗎？哪裡不好？
   - 追問：每月花多少錢？

7. **如果有一個更便宜、更專注的工具，你會考慮嗎？**
   - 追問：什麼功能最重要？
   - 追問：能接受什麼價格？

8. **你願意為以下功能付費嗎？**（逐個詢問）
   - [ ] 關鍵詞排名監控（$29/月）
   - [ ] 競品分析報告（$99/月）
   - [ ] 自動化市場調研（$199/月）
   - [ ] 定制化數據服務（$499/月）

---

### 需求驗證（5 分鐘）

**目的**: 驗證具體需求，收集反饋

9. **如果我們提供以下服務，你對哪個最感興趣？**
   - [ ] SEO 數據監控（每週報告）
   - [ ] 競品追蹤（實時通知）
   - [ ] 行業調研報告（月度）
   - [ ] 定制化數據提取（按次）

10. **你希望報告包含哪些數據？**
    - [ ] 關鍵詞排名
    - [ ] 搜索量
    - [ ] 競品變化
    - [ ] 熱點趨勢
    - [ ] 其他：_______

11. **你希望多久收到一次報告？**
    - [ ] 實時
    - [ ] 每日
    - [ ] 每週
    - [ ] 每月

12. **你希望以什麼形式接收？**
    - [ ] Email
    - [ ] PDF 報告
    - [ ] 在線儀表板
    - [ ] API 接口

---

### 收尾（5 分鐘）

**目的**: 確認意向，建立後續聯繫

13. **如果我們開發出這樣的產品，你願意成為種子用戶嗎？**
    - [ ] 願意（追問：可以現在預註冊嗎？）
    - [ ] 考慮一下
    - [ ] 不需要

14. **你能推薦其他可能有興趣的人嗎？**
    - 追問：可以介紹一下嗎？

15. **我們可以後續聯繫你測試產品嗎？**
    - [ ] 可以（收集郵箱/微信）
    - [ ] 不可以

**感謝**:
```
非常感謝你的時間和建議！

如果產品開發完成，我會第一時間聯繫你。

這是我的聯繫方式：[郵箱/微信]

有問題隨時聯繫！
```
