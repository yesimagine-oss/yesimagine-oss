### 2.4 教程类内容风格

**写作原则**:
| 原则 | 说明 | 示例 |
|------|------|------|
| **说人话** | 不用专业术语 | "服务器"→"一台 24 小时开着的电脑" |
| **短小** | 300 字以内 | 一段话说清楚 |
| **有图** | 每一步配截图 | 标注箭头、红框 |
| **可复制** | 配置/代码可直接用 | 附完整文件 |
| **有坑** | 告诉用户哪里会出错 | "这里容易填错，注意..." |

**错误写法 (天书)**:
```markdown
### 配置 Nginx 反向代理

1. 编辑 nginx.conf 文件
2. 添加 upstream 配置块
3. 设置 proxy_pass 指令
4. 执行 nginx -s reload
```

**正确写法 (人话)**:
```markdown
### 让服务器能访问 (3 分钟搞定)

**做什么**: 让外网能访问你的服务器

**步骤**:
1. 打开服务器里的这个文件：`/etc/nginx/nginx.conf`
2. 找到 `server` 这一段
3. 在 `location /` 下面加一行:
   `proxy_pass http://127.0.0.1:8080;`
4. 保存，然后运行：`nginx -s reload`

**检查**: 浏览器打开你的服务器 IP，能看到页面就对了

**常见错误**:
- 填错端口号 (默认 8080)
- 忘记保存文件
- 没执行 reload 命令
```
