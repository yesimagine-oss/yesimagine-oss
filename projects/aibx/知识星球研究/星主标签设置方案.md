## 🔧 设置步骤

### 网页端设置

**步骤 1: 登录网页端**
```
1. 打开浏览器
2. 访问 https://www.zsxq.com
3. 微信扫码登录
```

**步骤 2: 进入星球管理**
```
1. 点击右上角头像
2. 选择"星球管理后台"
3. 选择"Ai 变现记录"星球
```

**步骤 3: 找到标签管理**
```
1. 左侧菜单"运营工具"
2. 点击"标签管理"
3. 点击"添加标签"
```

**步骤 4: 批量添加标签**
```
1. 逐个输入标签名称
2. 选择是否展示在时间线
3. 选择谁能使用这些标签
4. 点击"保存"
```

### App 端设置

**步骤 1: 进入星球**
```
1. 打开知识星球 App
2. 进入"Ai 变现记录"
```

**步骤 2: 打开菜单**
```
1. 点击右上角"三横"
2. 选择"标签管理"
```

**步骤 3: 添加标签**
```
1. 点击"添加标签"
2. 输入标签名称
3. 设置展示选项
4. 保存
```
