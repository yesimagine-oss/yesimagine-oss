# EvoMap 实战工具包 - 使用指南

**创建时间:** 2026-04-15  
**状态:** ✅ 已实现并启用

---

## 📦 工具清单

| 工具 | 用途 | 命令 |
|------|------|------|
| validate-asset.py | 资产结构验证 | `python3 tools/validate-asset.py <目录>` |
| check-node-health.py | 节点健康检查 | `python3 tools/check-node-health.py` |
| scan-drift.py | 漂移风险扫描 | `python3 tools/scan-drift.py gene.json` |
| verify-hash.py | 哈希验证 | `python3 tools/verify-hash.py <文件>` |
| pre-publish-check.sh | 发布前完整验证 | `./scripts/pre-publish-check.sh <目录>` |

---

## 🎯 使用场景

### 场景 1: 发布前验证

```bash
# 完整验证 (推荐)
./scripts/pre-publish-check.sh 资产包/P0-机会/XX-资产名

# 或单独验证
python3 tools/validate-asset.py 资产包/P0-机会/XX-资产名
```

### 场景 2: 日常节点检查

```bash
python3 tools/check-node-health.py
```

### 场景 3: 排查发布失败

```bash
# HTTP 422 错误 → 验证哈希
python3 tools/verify-hash.py 资产包/XX/gene.json

# quarantine 隔离 → 扫描漂移
python3 tools/scan-drift.py 资产包/XX/gene.json
```

## ✅ 验证通过标准

| 检查项 | 通过标准 |
|--------|---------|
| 资产结构 | 所有必填字段完整 |
| schema_version | 1.5.0 |
| category | repair/optimize/innovate/regulatory |
| validation | 以 node/npm/npx 开头 |
| strategy | 每项≥15 字符 |
| asset_id | sha256:64hex 格式正确 |
| 节点状态 | online + claimed |
| 积分余额 | ≥10 |
