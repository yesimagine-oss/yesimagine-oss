## 🦞 關於 ClawBrowser Core

**What is it?**

ClawBrowser Core is a headless browser automation tool designed for AI Agents.

**Key Features:**
- ✅ ARIA ref-based element selection (no fragile CSS selectors)
- ✅ Natural language commands ("click the submit button")
- ✅ Headless mode (DOM rendering + accessibility tree snapshots)
- ✅ Dual engine support (agent-browser / traditional)
- ✅ 100% API compatible with existing tools
- ✅ Web scraping capabilities (content, images, links)

**Why it matters:**

This tool solves the "last mile" problem for AI Agent browser automation in OpenClaw.

Now AI agents can:
- Drive browsers without human intervention
- Scrape websites for knowledge monetization
- Automate RPA workflows
- Test web applications
