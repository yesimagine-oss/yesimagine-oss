## 💡 工作原理

```
用户提问 → goToken 拦截 → 检查缓存
    ↓
命中？→ 是 → 返回缓存答案 (~5ms)
    ↓
    否 → 调用 API → 缓存答案 → 返回
```

**缓存键**: 问题原文（精确匹配）  
**缓存 TTL**: 2 小时  
**限流**: 最多 2 个并发请求
