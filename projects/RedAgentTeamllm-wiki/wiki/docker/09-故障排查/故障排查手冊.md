## 🚨 常見問題與解決方案

### 1. 容器無法啟動

#### 症狀
```bash
$ docker run myapp
Error response from daemon: ...
```

#### 排查步驟

```bash
# 1. 查看容器日誌
docker logs <container_id>

# 2. 檢查容器詳細信息
docker inspect <container_id>

# 3. 查看系統日誌
journalctl -u docker.service

# 4. 檢查資源
docker stats --no-stream
```

#### 常見原因

| 原因 | 錯誤信息 | 解決方案 |
|------|---------|---------|
| 端口被占用 | `Bind for 0.0.0.0:80 failed: port is already allocated` | 更改端口或停止占用進程 |
| 鏡像不存在 | `image not found` | `docker pull <image>` |
| 磁盤空間不足 | `no space left on device` | `docker system prune` |
| 內存不足 | `OCI runtime create failed: no memory` | 釋放內存或減少限制 |

### 2. 容器網絡問題

#### 症狀
- 容器無法訪問外網
- 容器間無法通信
- 端口映射無效

#### 排查步驟

```bash
# 1. 檢查網絡配置
docker network ls
docker network inspect bridge

# 2. 測試容器網絡
docker exec <container> ping -c 3 8.8.8.8
docker exec <container> curl -I https://www.google.com

# 3. 檢查端口映射
docker port <container>
netstat -tlnp | grep <port>

# 4. 檢查防火牆
iptables -L -n | grep docker
```

#### 解決方案

```bash
# 重啟網絡
systemctl restart docker

# 重建網絡
docker network rm my-network
docker network create my-network

# 檢查 iptables
iptables -t nat -L -n | grep docker
```

### 3. 容器性能問題

#### 症狀
- 容器響應慢
- CPU/內存使用率高
- 磁盤 I/O 瓶頸

#### 排查步驟

```bash
# 1. 實時監控
docker stats

# 2. 檢查容器資源
docker inspect <container> --format '{{.HostConfig}}'

# 3. 檢查系統資源
top
htop
iostat -x 1

# 4. 檢查容器進程
docker top <container>
```

#### 優化方案

```bash
# 設置資源限制
docker run -d \
  --cpus="1" \
  --memory="512m" \
  --memory-swap="512m" \
  myapp

# 調整 I/O 優先級
docker run -d \
  --device-read-bps="/dev/sda:1mb" \
  --device-write-bps="/dev/sda:1mb" \
  myapp

# 使用本地卷而非 bind mount
docker volume create mydata
docker run -d -v mydata:/data myapp
```

### 4. 鏡像構建失敗

#### 症狀
```bash
$ docker build -t myapp .
Step X/Y : RUN ...
The command '/bin/sh -c ...' returned a non-zero code: 1
```

#### 排查步驟

```bash
# 1. 查看完整輸出
docker build --progress=plain -t myapp .

# 2. 測試失敗的步驟
docker run -it --rm <base_image> /bin/bash
# 手動執行失敗的命令

# 3. 檢查緩存
docker builder prune

# 4. 無緩存構建
docker build --no-cache -t myapp .
```

#### 常見原因

| 原因 | 解決方案 |
|------|---------|
| 網絡問題 | 配置代理或更換鏡像源 |
| 依賴下載失敗 | 使用國內鏡像源 |
| 權限問題 | 添加 `USER root` 或調整權限 |
| 磁盤空間不足 | `docker system prune` |

### 5. 容器日誌問題

#### 症狀
- 日誌文件過大
- 無法查看日誌
- 日誌丟失

#### 解決方案

```bash
# 1. 配置日誌輪轉
# /etc/docker/daemon.json
{
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}

# 重啟 Docker
systemctl restart docker

# 2. 查看日誌
docker logs <container>
docker logs --tail 100 <container>
docker logs -f <container>  # 跟隨

# 3. 清理日誌
truncate -s 0 /var/lib/docker/containers/*/*-json.log

# 4. 導出日誌
docker logs <container> > app.log 2>&1
```

### 6. Docker 服務無法啟動

#### 症狀
```bash
$ systemctl start docker
Job for docker.service failed...
```

#### 排查步驟

```bash
# 1. 查看服務狀態
systemctl status docker.service

# 2. 查看詳細日誌
journalctl -u docker.service -n 50

# 3. 檢查配置文件
cat /etc/docker/daemon.json

# 4. 檢查存儲驅動
ls -la /var/lib/docker/

# 5. 檢查端口
netstat -tlnp | grep 2375
netstat -tlnp | grep 2376
```

#### 解決方案

```bash
# 1. 修復配置文件
mv /etc/docker/daemon.json /etc/docker/daemon.json.bak
systemctl start docker

# 2. 清理存儲 (危險！會刪除所有數據)
systemctl stop docker
rm -rf /var/lib/docker
systemctl start docker

# 3. 檢查依賴
systemctl status containerd
systemctl restart containerd
```

### 7. 磁盤空間不足

#### 症狀
```bash
$ docker build ...
no space left on device
```

#### 排查步驟

```bash
# 1. 檢查磁盤使用
df -h
du -sh /var/lib/docker/*

# 2. 檢查 Docker 資源
docker system df

# 3. 查看大文件
du -ah /var/lib/docker | sort -rh | head -20
```

#### 清理方案

```bash
# 安全清理
docker system prune -a --volumes

# 刪除懸空鏡像
docker image prune

# 刪除未使用容器
docker container prune

# 刪除未使用網絡
docker network prune

# 刪除未使用卷 (小心！)
docker volume prune

# 手動清理日誌
find /var/lib/docker/containers -name "*.log" -exec truncate -s 0 {} \;
```

## 🛠️ 診斷工具

### 1. docker info

```bash
# 完整信息
docker info

# 特定格式
docker info --format '{{.Driver}}'
docker info --format '{{json .}}'
```

### 2. docker inspect

```bash
# 容器詳細信息
docker inspect <container>

# 特定字段
docker inspect --format '{{.NetworkSettings.IPAddress}}' <container>
docker inspect --format '{{.State.Status}}' <container>

# 鏡像信息
docker inspect <image>
```

### 3. docker events

```bash
# 實時事件
docker events

# 過濾事件
docker events --filter 'type=container'
docker events --filter 'event=start'

# 查看歷史事件
docker events --since '2026-03-19T00:00:00'
```

### 4. docker logs

```bash
# 查看日誌
docker logs <container>

# 跟隨輸出
docker logs -f <container>

# 顯示時間戳
docker logs -t <container>

# 最近 N 行
docker logs --tail 100 <container>

# 時間範圍
docker logs --since 10m <container>
docker logs --until 2026-03-19T10:00:00 <container>
```

### 5. docker stats

```bash
# 實時統計
docker stats

# 單次輸出
docker stats --no-stream

# 特定容器
docker stats <container1> <container2>

# 自定義格式
docker stats --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}"
```

## 🔧 修復腳本

### 1. 快速修復腳本

```bash
#!/bin/bash
# docker-quick-fix.sh

echo "=== Docker 快速修復 ==="

# 清理資源
echo "清理未使用的資源..."
docker system prune -f

# 重啟服務
echo "重啟 Docker 服務..."
systemctl restart docker

# 檢查狀態
echo "檢查狀態..."
docker info --format '{{.ServerVersion}}'
docker ps -a --format "table {{.Names}}\t{{.Status}}"

echo "=== 修復完成 ==="
```

### 2. 日誌清理腳本

```bash
#!/bin/bash
# docker-logs-cleanup.sh

echo "=== 清理 Docker 日誌 ==="

# 清理所有容器日誌
find /var/lib/docker/containers -name "*.log" -exec truncate -s 0 {} \;

# 或者使用 docker 命令
for container in $(docker ps -q); do
    docker logs --tail 0 $container 2>/dev/null
done

echo "日誌清理完成"
```

### 3. 磁盤空間檢查腳本

```bash
#!/bin/bash
# docker-disk-check.sh

echo "=== Docker 磁盤使用檢查 ==="

# 總體使用
echo "系統磁盤:"
df -h /

echo ""
echo "Docker 資源:"
docker system df

echo ""
echo "大文件:"
du -ah /var/lib/docker | sort -rh | head -10

echo ""
echo "建議清理:"
docker system prune -a --dry-run
```
