# OpenClaw 配置缓存问题排查

## 🚨 常见问题：API Key 401 错误

### 错误信息

```
HTTP 401: Incorrect API key provided.
```

---

## 🔍 可能原因

| 原因 | 说明 | 解决方案 |
|------|------|----------|
| API Key 无效 | Key 本身错误或过期 | 重新获取 API Key |
| Key 不匹配 | Key 与端点环境不匹配 | 确认是 Coding Plan 专属 Key |
| 格式错误 | Key 复制不完整或有空格 | 重新复制，确保无空格 |
| 配置缓存 | 历史配置缓存导致冲突 | 删除缓存文件 |
| 订阅过期 | Coding Plan 订阅已过期 | 检查订阅状态 |

---

## 🔧 解决方案

### 方案 1: 删除配置缓存（推荐）

```bash
# 1. 停止 OpenClaw 服务
openclaw stop

# 2. 删除缓存文件
rm ~/.openclaw/agents/main/agent/models.json

# 3. 重新配置
openclaw dashboard

# 4. 重启服务
openclaw start
```

---

### 方案 2: 手动清理配置

```bash
# 1. 编辑配置文件
nano ~/.openclaw/openclaw.json

# 2. 找到并删除 providers.bailian 配置项
{
  "models": {
    "providers": {
      "bailian": {  // 删除整个 bailian 配置块
        "baseUrl": "...",
        "apiKey": "..."
      }
    }
  }
}

# 3. 保存并退出

# 4. 重新配置
openclaw dashboard

# 5. 重启服务
openclaw gateway restart
```

---

### 方案 3: 完全重置配置

```bash
# 1. 备份当前配置
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak.$(date +%Y%m%d)

# 2. 停止服务
openclaw stop

# 3. 删除配置目录
rm -rf ~/.openclaw/config/*

# 4. 重新初始化
openclaw config --reset

# 5. 重新配置
openclaw dashboard

# 6. 启动服务
openclaw start
```

## 🛠️ 预防措施

### 1. 正确复制 API Key

```bash
# 从控制台复制时：
# 1. 确保复制完整
# 2. 确保无前后空格
# 3. 确保是 Coding Plan 专属 Key

# 验证 Key 格式
echo "sk-xxxxxxxxxxxxxxxxxxxxxxxx" | grep -E "^sk-[a-zA-Z0-9]{32}$"
```

---

### 2. 使用环境变量

```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加
export OPENCLAW_BAILIAN_KEY="sk-YOUR_API_KEY"

# 在配置中引用
{
  "models": {
    "providers": {
      "bailian": {
        "apiKey": "${OPENCLAW_BAILIAN_KEY}"
      }
    }
  }
}
```

**解决**:
```bash
# 确认 Key 来源

openclaw dashboard
```

---

### 场景 2: Key 权限不足

**问题**: API Key 权限范围不包含所需功能

**解决**:
```bash
# 在百炼控制台检查 Key 权限
# 添加必要权限
# 重新配置
```

---

### 场景 3: 配置合并问题

**问题**: 添加新配置时覆盖了原有配置

**解决**:
```bash
# 使用 merge 模式
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "apiKey": "NEW_KEY"
      }
    }
  }
}
```
