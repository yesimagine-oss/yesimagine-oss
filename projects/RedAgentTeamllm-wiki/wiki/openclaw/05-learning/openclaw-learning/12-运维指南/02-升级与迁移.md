## 🔄 升级指南

### 升级前准备

```bash
# 1. 检查当前版本
openclaw --version

# 2. 查看更新日志
# https://github.com/openclaw/openclaw/releases

# 3. 备份配置
openclaw config --export > ~/openclaw-backup-$(date +%Y%m%d).json

# 4. 备份工作区
tar -czf ~/workspace-backup-$(date +%Y%m%d).tar.gz ~/.openclaw/workspace/

# 5. 记录当前配置
openclaw config > ~/openclaw-config-before.txt
```

---

### 标准升级流程

```bash
# 1. 停止服务
openclaw stop

# 2. 执行升级
openclaw update

# 3. 验证升级
openclaw --version

# 4. 检查配置兼容性
openclaw config --validate

# 5. 更新技能
openclaw skills update --all

# 6. 重启服务
openclaw start

# 7. 测试基本功能
openclaw chat "Hello, test after upgrade"

# 8. 检查日志
openclaw logs --tail 50
```

## 🚚 迁移指南

### 场景 1: 服务器迁移

#### 源服务器操作

```bash
# 1. 停止服务
openclaw stop

# 2. 完整备份
tar -czf ~/openclaw-full-backup.tar.gz \
  ~/.openclaw/config/ \
  ~/.openclaw/workspace/ \
  ~/.openclaw/logs/

# 3. 传输到新服务器
scp ~/openclaw-full-backup.tar.gz user@new-server:~/

# 4. 导出配置清单
openclaw config > ~/config-list.txt
openclaw skills list > ~/skills-list.txt
```

#### 目标服务器操作

```bash
# 1. 安装 OpenClaw
curl -fsSL https://openclaw.ai/install.sh | bash

# 2. 停止服务（如已运行）
openclaw stop

# 3. 恢复备份
tar -xzf ~/openclaw-full-backup.tar.gz -C ~/

# 4. 修复权限
chmod -R 755 ~/.openclaw/
chown -R $USER:$USER ~/.openclaw/

# 5. 验证配置
openclaw config --validate

# 6. 启动服务
openclaw start

# 7. 测试功能
openclaw status
openclaw chat "Migration test"
```

### 场景 2: 模型提供商迁移

#### 从 OpenAI 迁移到阿里云

```json
// 原配置
{
  "models": {
    "providers": {
      "openai": {
        "baseUrl": "https://api.openai.com/v1",
        "apiKey": "sk-openai-key",
        "models": [{"id": "gpt-4", "name": "GPT-4"}]
      }
    }
  }
}

// 新配置
{
  "models": {
    "providers": {
      "bailian": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "sk-alibaba-key",
        "models": [
          {"id": "qwen3.5-plus", "name": "通义千问 3.5 Plus"}
        ]
      }
    },
    "default": "qwen3.5-plus"
  }
}
```

#### 迁移步骤

```bash
# 1. 获取新 API Key
# 登录百炼控制台创建 Key

# 2. 备份原配置
cp ~/.openclaw/config/models.json ~/.openclaw/config/models.json.bak

# 3. 更新配置
openclaw dashboard

# 4. 测试新模型
openclaw chat "Hello from new model" --model qwen3.5-plus

# 5. 更新默认模型
openclaw models default qwen3.5-plus

# 6. 验证所有功能
# - 对话
# - 技能
# - 定时任务
```

### 场景 3: 通道迁移

#### 从 Telegram 迁移到 Discord

{

    "telegram": {
      "enabled": true,

    }
  }
}

      "botToken": "discord-token",
      "guildId": "server-id",

```bash
# 1. 创建 Discord Bot
# https://discord.com/developers/applications

# 3. 更新配置
openclaw channels config discord

# 4. 测试 Discord 通道
openclaw chat "Discord migration test"

# 5. 通知用户新通道
# 在 Telegram 发送最后一条消息通知迁移
```

## 🔙 回滚指南

### 回滚到旧版本

```bash
# 1. 停止服务
openclaw stop

# 2. 备份当前状态
tar -czf ~/openclaw-current.tar.gz ~/.openclaw/

# 3. 恢复旧备份
tar -xzf ~/openclaw-backup-20260310.tar.gz -C ~/

# 4. 安装旧版本（如需要）
npm install -g openclaw@1.2.3

# 5. 启动服务
openclaw start

# 6. 验证
openclaw --version
openclaw status
```

### 回滚配置

```bash
# 恢复配置文件
cp ~/.openclaw/config/models.json.bak ~/.openclaw/config/models.json

# 验证
openclaw config --validate

# 重启
openclaw restart
```
