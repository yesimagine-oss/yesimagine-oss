## 🔍 关键发现

### 1. 架构差异

**官方 OpenClaw** vs **阿里云 OpenClaw (Coding Plan)**

| 特性 | 官方 OpenClaw | 阿里云 OpenClaw |
|------|---------------|-----------------|
| 定位 | 自托管 Gateway | 阿里云部署版本 |
| 模型 | Pi Agent / 多提供商 | 阿里云百炼 (Coding Plan) |
| 通道 | 20+ 原生通道 | 钉钉/飞书等 |
| 安装 | npm/curl 脚本 | SWAS 一键部署 |
| 配置 | `~/.openclaw/openclaw.json` | 相同 |
| 技能 | ClawHub | ClawHub + 阿里云技能市场 |

**关键发现**: 这是两个**不同但相关**的项目！
- 官方 OpenClaw: https://github.com/openclaw/openclaw
- 阿里云 OpenClaw: 基于官方版本的阿里云定制部署
