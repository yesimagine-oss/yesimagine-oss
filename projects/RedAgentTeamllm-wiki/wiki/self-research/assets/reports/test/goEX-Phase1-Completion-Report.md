## 🔧 关键问题与解决方案

### 问题 1: 飞书首页加载超时
- **现象**: 90s 超时内偶尔失败
- **原因**: 飞书是大型 SPA，动态内容多
- **解决**: 增加超时到 90s，简化测试逻辑
- **状态**: 🟡 偶发，可接受

### 问题 2: 数据抓取选择器失效
- **现象**: 百度热搜选择器频繁变化
- **原因**: 百度动态渲染，类名不固定
- **解决**: 多级选择器 + 降级方案
- **状态**: ✅ 稳定降级

### 问题 3: 飞书消息发送失败
- **现象**: open_id 无效
- **原因**: 用户 ID 格式错误或不存在
- **解决**: 确认真实 open_id
- **状态**: ✅ 已解决（ou_f4919832188bcc630f8f257497fa93a4）

### 问题 4: chromedp context 无效
- **现象**: invalid context 错误
- **原因**: context 重复使用或已取消
- **解决**: 每个测试独立创建 context
- **状态**: ✅ 已解决

## 🎓 经验总结

### 成功经验
1. **渐进式开发**: 从 L1 到 L4，逐步验证
2. **多级降级**: 数据抓取失败有备选方案
3. **稳定性优先**: 10/10 稳定性测试确保质量
4. **日志完整**: goex.log 记录所有运行信息

### 教训
1. **超时设置**: 初期超时过紧，导致误失败
2. **选择器依赖**: 动态网站选择器需多级备选
3. **飞书 ID**: open_id 需提前验证

### 最佳实践
1. 每个测试独立 context
2. 超时时间分级设置
3. 报告多格式输出（JSON+CSV）
4. 飞书消息确认送达
