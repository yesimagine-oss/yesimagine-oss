# goEX 设计基因

## 🎯 核心设计理念

### 1. 用户心血 > 代码整洁

**来源**: 2026-04-22 P0 事故教训

**内容**:
- 任何重构不能以牺牲功能为代价
- 代码可以乱，功能不能丢
- 变更前必须列出功能清单，逐项确认

**基因编码**: `goEX_design_001`

---

### 2. 插件化 + 完整性双轨制

**设计思路**:
```
┌─────────────────────────────────┐
│         goEX v0.5.0             │
├─────────────────────────────────┤
│  插件系统 (可扩展)  │  核心功能  │
│  ┌──────────────┐  │  (必须保留)│
│  │ wiki-ingest  │  │  ┌──────┐ │
│  │ wechat-grab  │  │  │ 17 项 │ │
│  │ feishu-notify│  │  └──────┘ │
│  └──────────────┘  │            │
└─────────────────────────────────┘
```

**原则**:
- 插件可选，核心功能必须保留
- 新功能走插件，旧功能不删除

**基因编码**: `goEX_design_002`

---

### 3. 渐进式超时策略

**设计思路**:

| 网站类型 | 超时 | 原因 |
|---------|------|------|
| 国内 (feishu/wechat) | 90s | 网络较慢 |
| 代码托管 (github/gitee) | 60s | 中等速度 |
| 默认 | 45s | 快速失败 |

**基因编码**: `goEX_design_003`

---

### 4. 重试 + 降级机制

**重试策略**:
```
尝试 1 → 失败 → 等待 3s → 尝试 2 → 失败 → 等待 3s → 尝试 3
```

**降级策略**:
- 热搜抓取失败 → 降级为页面标题
- 代理不可用 → 自动切换直连

**基因编码**: `goEX_design_004`

---

### 5. 报告驱动开发

**每次测试自动生成**:
- `test_report.json` - JSON 格式
- `test_report_table.csv` - 飞书/Excel 兼容
- `scrape_report.csv` - 抓取报告
- `test_baidu.png` - 截图证据

**基因编码**: `goEX_design_005`
