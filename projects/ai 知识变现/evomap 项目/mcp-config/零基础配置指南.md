## 📝 第一步：获取 GITHUB_TOKEN（5 分钟）

### 1.1 打开 GitHub

**操作**:
1. 打开浏览器
2. 访问：https://github.com
3. 登录你的 GitHub 账号

**截图**:
```
[浏览器地址栏输入]
https://github.com
```

---

### 1.2 创建 Token

**操作步骤**:

1. **点击右上角头像** → 出现下拉菜单

2. **点击 "Settings"** → 进入设置页面

3. **滚动到页面最底部** → 找到 "Developer settings"

4. **点击 "Personal access tokens"** → 进入 token 管理

5. **点击 "Generate new token"** → 选择 "Generate new token (classic)"

6. **填写信息**:
   - **Note**: 输入 `EvoMap` (备注)
   - **Expiration**: 选择 `No expiration` (永不过期)

7. **选择权限** (勾选以下 3 个):
   - ✅ `repo` (Full control of private repositories)
   - ✅ `workflow` (Update GitHub Action workflows)
   - ✅ `read:org` (Read org and team membership)

8. **点击 "Generate token"** → 页面底部出现 token

9. **复制 token** → 点击复制按钮 (📋图标)

**重要**: 
- ⚠️ token 只会显示一次！
- ⚠️ 立即复制到记事本保存
- ⚠️ 格式：`ghp_xxxxxxxxxxxx` (30-40 个字符)

---

### 1.3 验证 Token

**操作**:

1. 打开浏览器
2. 访问：https://api.github.com/user
3. 页面显示你的用户信息 → ✅ Token 有效

## 🗄️ 第二步：配置 PostgreSQL 数据库（5 分钟）

### 方案 A：使用在线数据库（最简单，推荐）

**推荐服务**: [Neon](https://neon.tech) (免费、无需安装)

**操作步骤**:

1. **访问 Neon**
   - 打开浏览器
   - 访问：https://neon.tech

2. **注册账号**
   - 点击 "Sign Up"
   - 使用 Google 账号登录 (最简单)

3. **创建数据库**
   - 点击 "Create a project"
   - 输入项目名称：`evomap`
   - 点击 "Create project"

4. **获取连接字符串**
   - 页面显示 "Connection details"
   - 复制 "Connection string"
   - 格式：`postgresql://user:password@host/neondb`

**完成!** ✅

### 3.2 填写配置

**文件内容**:

```bash

# 1. GitHub Token (从第一步复制)
GITHUB_TOKEN='ghp_你的 token 粘贴在这里'

# 2. 数据库连接 (从第二步复制)
DATABASE_URL='postgresql://你的连接字符串粘贴在这里'

# 3. EvoMap 配置 (已配置好，无需修改)
EVOMAP_API_KEY='bcc7b8e55de75908ae237155cf52a11ac8925b42931e29ea0882b1d456fc7c3a'
EVOMAP_NODE_ID='node_67c3b8b37becd262'
```

**操作步骤**:

1. **替换 GITHUB_TOKEN**:
   - 找到 `GITHUB_TOKEN='ghp_...'`
   - 删除 `ghp_...`
   - 粘贴你的 token
   - 保留引号 `'`

2. **替换 DATABASE_URL**:
   - 找到 `DATABASE_URL='...'`
   - 删除引号内的内容
   - 粘贴你的连接字符串
   - 保留引号 `'`

3. **保存文件**:
   - 按 `Ctrl + S` (Windows) 或 `Cmd + S` (Mac)
   - 关闭文件
