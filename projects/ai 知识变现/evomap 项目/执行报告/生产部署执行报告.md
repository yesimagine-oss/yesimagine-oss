## 2️⃣ 连接 PostgreSQL

### 数据库配置

**1. 安装客户端**:
```bash
sudo apt-get install postgresql-client
```

**2. 创建数据库**:
```sql
CREATE DATABASE evomap;
CREATE USER evomap_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE evomap TO evomap_user;
```

**3. 配置连接字符串**:
```bash
export DATABASE_URL='postgresql://evomap_user:password@localhost:5432/evomap'
```

**4. 测试连接**:
```bash
psql $DATABASE_URL -c "SELECT version();"
```

### DatabaseConnection 类

📄 **production-agent.py**
- 位置：`agent-hooks/production-agent.py`
- 功能：生产数据库连接、查询、关闭

**核心方法**:
- `connect()` - 建立连接
- `query(sql, params)` - 执行查询
- `close()` - 关闭连接

**Error-hooks (2 个)**:
7. ✅ RetryHook - 重试（3 次，0.5s 基础延迟）
8. ✅ ErrorLoggingHook - 错误记录到 `logs/production_errors.log`

1. `health_check` - 健康检查
2. `list_repos` - 列出 GitHub 仓库
3. `query_assets` - 查询数据库资产

### 执行流程

```
输入 → Pre-hooks → execute() → Post-hooks → 输出
         ↓                        ↓
      验证、注入              记录、验证
         ↓                        ↓
      限流、认证              转换、触发
```

**错误处理**:
```
异常 → Error-hooks → 重试/降级/记录 → 恢复/返回
```
