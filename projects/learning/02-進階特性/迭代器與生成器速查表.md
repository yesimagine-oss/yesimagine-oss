## 📋 核心概念速查

### 1. 迭代器協議

```python
class MyIterator:
    def __init__(self, data):
        self.data = data
        self.index = 0
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.index >= len(self.data):
            raise StopIteration
        value = self.data[self.index]
        self.index += 1
        return value
```

### 2. 生成器函數

```python
def my_generator(n):
    for i in range(n):
        yield i  # 產生值並暫停

gen = my_generator(5)
next(gen)  # 0
next(gen)  # 1
```

### 3. 生成器表達式

```python
# 語法：(expression for item in iterable if condition)
squares = (x ** 2 for x in range(10))
evens = (x for x in range(20) if x % 2 == 0)
```

## 🔧 itertools 模塊速查

### 無限迭代器

| 函數 | 說明 | 示例 |
|------|------|------|
| `count(start, step)` | 無限計數 | `count(10, 5)` → 10, 15, 20... |
| `cycle(iterable)` | 循環迭代 | `cycle('ABC')` → A, B, C, A, B, C... |
| `repeat(obj, times)` | 重複對象 | `repeat('A', 3)` → A, A, A |

### 有限迭代器

| 函數 | 說明 | 示例 |
|------|------|------|
| `chain(*iterables)` | 鏈接多個可迭代對象 | `chain([1,2], [3,4])` → 1, 2, 3, 4 |
| `compress(data, selectors)` | 根據選擇器過濾 | `compress('ABCD', [1,0,1,0])` → A, C |
| `dropwhile(pred, iterable)` | 丟棄直到條件為假 | `dropwhile(lambda x: x<5, [1,4,6,7])` → 6, 7 |
| `takewhile(pred, iterable)` | 取直到條件為假 | `takewhile(lambda x: x<5, [1,4,6,7])` → 1, 4 |
| `islice(iterable, start, stop, step)` | 切片 | `islice(range(10), 2, 8, 2)` → 2, 4, 6 |
| `tee(iterable, n=2)` | 創建 n 個獨立迭代器 | `tee([1,2,3], 2)` |
| `zip_longest(*iterables, fillvalue)` | 填充缺失值 | `zip_longest([1,2], [3,4,5], fillvalue=0)` |

### 組合迭代器

| 函數 | 說明 | 示例 |
|------|------|------|
| `product(*iterables, repeat=1)` | 笛卡爾積 | `product('AB', '12')` → (A,1), (A,2), (B,1), (B,2) |
| `permutations(iterable, r)` | 排列 | `permutations('ABC', 2)` → (A,B), (A,C), (B,A)... |
| `combinations(iterable, r)` | 組合 | `combinations('ABC', 2)` → (A,B), (A,C), (B,C) |
| `combinations_with_replacement(iterable, r)` | 可重複組合 | `combinations_with_replacement('ABC', 2)` → (A,A), (A,B)... |

### 分組迭代器

| 函數 | 說明 | 示例 |
|------|------|------|
| `groupby(iterable, key)` | 分組 (需先排序) | `groupby(data, key=lambda x: x[0])` |

## 🎯 常用模式

### 1. 惰性計算大文件

```python
def read_large_file(filename):
    with open(filename, 'r') as f:
        for line in f:
            yield line.strip()

# 使用
for line in read_large_file('huge.log'):
    process(line)
```

### 2. 管道式數據處理

```python
data = read_data()
filtered = (x for x in data if x > 0)
transformed = (x * 2 for x in filtered)
result = list(transformed)
```

### 3. 分批處理

```python
import itertools

def batch(iterable, size):
    it = iter(iterable)
    while True:
        batch = list(itertools.islice(it, size))
        if not batch:
            break
        yield batch

# 使用
for batch in batch(range(100), 10):
    process_batch(batch)
```

### 4. 扁平化嵌套列表

```python
nested = [[1, 2], [3, 4], [5, 6]]
flattened = itertools.chain.from_iterable(nested)
print(list(flattened))  # [1, 2, 3, 4, 5, 6]
```

### 5. 查找相鄰元素

```python
import itertools

def pairwise(iterable):
    a, b = itertools.tee(iterable)
    next(b, None)
    return zip(a, b)

# 使用
for current, next_item in pairwise([1, 2, 3, 4]):
    print(f"{current} -> {next_item}")
```

## ⚡ 性能優化技巧

### 1. 使用生成器節省內存

```python
# ❌ 列表推導式 - 占用大量內存
squares = [x ** 2 for x in range(1000000)]

# ✅ 生成器表達式 - 占用極少內存
squares = (x ** 2 for x in range(1000000))
```

### 2. 鏈式調用避免中間結果

```python
# ❌ 創建中間列表
data = range(100)
squared = [x ** 2 for x in data]
even = [x for x in squared if x % 2 == 0]
result = sum(even)

# ✅ 鏈式生成器
data = range(100)
result = sum(x ** 2 for x in data if x ** 2 % 2 == 0)
```

### 3. 使用 itertools 代替手寫循環

```python
# ❌ 手寫循環
result = []
for i in range(len(a)):
    result.append((a[i], b[i]))

# ✅ 使用 zip
result = list(zip(a, b))

# ✅ 或使用 itertools
result = list(itertools.zip_longest(a, b, fillvalue=None))
```

## 🐛 常見陷阱

### 陷阱 1: 生成器只能使用一次

```python
gen = (x for x in range(5))
print(list(gen))  # [0, 1, 2, 3, 4]
print(list(gen))  # [] - 已耗盡！

# 解決：重新創建生成器
```

### 陷阱 2: groupby 需要先排序

```python
data = [('A', 1), ('B', 2), ('A', 3)]

# ❌ 錯誤
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, list(group))
# A: [('A', 1)]
# B: [('B', 2)]
# A: [('A', 3)] - A 被分成了兩組

# ✅ 正確
data.sort(key=lambda x: x[0])
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, list(group))
# A: [('A', 1), ('A', 3)]
# B: [('B', 2)]
```

### 陷阱 3: 無限迭代器需要手動停止

```python
# ❌ 會無限循環
# for i in itertools.count():
#     print(i)

# ✅ 正確
for i in itertools.count():
    if i >= 10:
        break
    print(i)
```
