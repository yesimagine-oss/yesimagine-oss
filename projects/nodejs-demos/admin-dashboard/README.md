# 後台管理系統 Demo - Node.js + Vue.js

**功能**: 完整的後台管理系統  
**技術棧**: Node.js + Express + Vue.js + Element Plus

## 📦 功能清單

- [x] 用戶管理
- [x] 角色權限
- [x] 菜單管理
- [x] 日誌管理
- [x] 數據統計
- [x] 文件上傳

## 🎨 界面預覽

- 登錄頁面
- 儀表板
- 用戶管理
- 系統設置

## 🚀 快速開始

```bash
# 後端
cd backend
npm install
npm start

# 前端
cd frontend
npm install
npm run serve
```
