## 📋 功能说明

### 核心功能

1. **按需启动**
   - 检测到外网请求时自动启动代理
   - 无需手动启动

2. **闲置自动关闭**
   - 10 分钟无连接自动关闭
   - 节省资源

3. **自动监控**
   - 每分钟检查一次
   - 自动记录日志

---

## ⚙️ 配置参数

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| **闲置超时** | 10 分钟 | 无连接自动关闭 |
| **检查间隔** | 1 分钟 | 多久检查一次 |
| **代理端口** | 7890 | Clash 混合端口 |
| **PID 文件** | `~/.openclaw/proxy.pid` | 进程 ID 文件 |
| **日志文件** | `~/.openclaw/logs/proxy-manager.log` | 管理器日志 |

## 🚀 使用方法

### 手动操作

**启动代理**:
```bash
python3 tools/proxy-manager.py start
```

**停止代理**:
```bash
python3 tools/proxy-manager.py stop
```

**查看状态**:
```bash
python3 tools/proxy-manager.py status
```

**启动监控** (后台运行):
```bash
python3 tools/proxy-manager.py monitor
```

### 自动监控

**已设置开机自启动**:

## 📋 注意事项

1. **首次启动需要手动**
   - 第一次使用需要先启动一次代理
   - 之后会自动管理

2. **日志文件会增长**
   - 定期清理日志文件
   - 建议每周清理一次

3. **PID 文件很重要**
   - 不要手动删除 PID 文件
   - 如果丢失，需要手动停止代理
