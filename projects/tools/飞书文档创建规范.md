# 飞书文档创建规范

**目的**: 避免发送空白文档给用户  
**执行时间**: 2026-03-26 起强制执行

---

## ❌ 错误流程（禁止使用）

```
1. feishu_doc create → 创建文档
2. 立即发送链接给用户  ❌
3. feishu_doc write → 写入内容
```

**问题**: 用户可能在第 2 步打开链接，看到空白文档

---

## ✅ 正确流程（强制执行）

```
1. feishu_doc create → 创建文档
2. feishu_doc write → 写入内容
3. feishu_doc read → 验证内容
4. IF 内容为空:
     重新 write
     重新 read
5. IF 内容不为空:
     发送链接给用户  ✅
```

**预期输出**:
```json

  "content": "文档内容...",

    "Text": 50,

  }

```

**如果 block_count = 1** → ❌ 空白文档，需要重新写入

## ⚠️ 常见错误

### 错误 1: 创建后立即发送

```python
# ❌ 错误
doc = feishu_doc.create(title="...")
send_link(doc.url)  # 太早了！
feishu_doc.write(doc.id, content="...")
```

```python
# ✅ 正确
doc = feishu_doc.create(title="...")
feishu_doc.write(doc.id, content="...")
content = feishu_doc.read(doc.id)
if content.block_count > 1:
    send_link(doc.url)
else:
    # 重新写入
    feishu_doc.write(doc.id, content="...")
    send_link(doc.url)
```

---

### 错误 2: 不验证就发送

```python
# ❌ 错误
feishu_doc.write(doc.id, content="...")
send_link(doc.url)  # 没有验证！
```

```python
# ✅ 正确
feishu_doc.write(doc.id, content="...")
content = feishu_doc.read(doc.id)
assert content.block_count > 1, "文档为空！"
send_link(doc.url)
```

## 🎯 最佳实践

### 1. 使用封装函数

```python
def create_and_send_doc(title: str, content: str):
    """创建文档并验证后发送"""
    
    # 创建
    doc = feishu_doc.create(title=title)
    
    # 写入
    feishu_doc.write(doc.id, content=content)
    
    # 验证（最多重试 3 次）
    for i in range(3):
        content = feishu_doc.read(doc.id)
        if content.block_count > 1:
            break
        print(f"⚠️ 文档为空，重试 {i+1}/3")
        feishu_doc.write(doc.id, content=content)
    
    # 最终验证
    if content.block_count <= 1:
        raise Exception("文档创建失败，内容为空")
    
    # 发送
    send_link(doc.url)
    print(f"✅ 文档已发送：{doc.url}")
```
