## 🎯 項目概述

### 核心目標
> **用 85% 更少 Token，做 100% 相同的事。**

### 使用目的

| 場景 | 目的 |
|------|------|
| **重複問答** | 緩存命中，不浪費 Token |
| **模板化內容** | 一次生成，多次复用 |
| **額度緊張** | 限流保護，避免超額 |

### 🚫 不做什麼

| 排除 | 理由 |
|------|------|
| **實時數據** | 緩存會過期 (天氣/股價/新聞) |
| **個性化對話** | 無法复用 (每個用戶問題不同) |
| **長文本生成** | 壓縮會丟失上下文 |

### 📊 成功指標

| 指標 | 目標 | 測量方式 |
|------|------|---------|
| **緩存命中率** | ≥85% | `hits / total * 100` |
| **Token 節省** | ≥85% | `(1 - actual/expected) * 100` |
| **響應速度** | 緩存<10ms | 平均響應時間 |
| **API 錯誤率** | <1% | `errors / total * 100` |

## 🔧 問題與解決

### P0-001: JSON 錯誤處理缺失

**發現時間:** 2026-04-20 04:15  
**嚴重程度:** 🔴 高  
**狀態:** ⏳ 待修復

**問題描述:**
```go
// ❌ 當前代碼
body, _ := json.Marshal(req)
json.Unmarshal(resp.Body(), &result)
```

**風險:**
- 序列化失敗時發送空請求
- 解析失敗時返回空結果
- 難以排查問題

**解決方案:**
```go
// ✅ 修復後
body, err := json.Marshal(req)
if err != nil {
 skill.Log("ERROR", "JSON 序列化失敗：%v", err)
 return "", fmt.Errorf("請求格式化失敗")
}

err = json.Unmarshal(resp.Body(), &result)
if err != nil {
 skill.Log("ERROR", "JSON 解析失敗：%v", err)
 return "", fmt.Errorf("響應解析失敗")
}
```

**修復進度:** 0%

### P1-002: 緩存無限增長

**發現時間:** 2026-04-20 04:15  
**嚴重程度:** 🟡 中  
**狀態:** ⏳ 待實施

**問題描述:**
```go
// ❌ 當前代碼
cache.m[query] = cacheEntry{...}
// 無清理機制，無限增長
```

**風險:**
- 內存洩漏
- 長期運行後性能下降
- 可能 OOM 崩潰

**解決方案:**

**方案 A: 定期清理**
```go
go func() {
 ticker := time.NewTicker(1 * time.Hour)
 for range ticker.C {
  cache.Lock()
  now := time.Now()
  for k, v := range cache.m {
   if now.After(v.ExpireAt) {
    delete(cache.m, k)
   }
  }
  cache.Unlock()
 }
}()
```

**方案 B: LRU 淘汰**
```go
// 限制最大緩存數量
const maxCacheSize = 1000
if len(cache.m) >= maxCacheSize {
 // 淘汰最舊的 10%
}
```

**推薦:** 方案 A (簡單有效)  
**實施進度:** 0%
