# 阿里云轻量服务器稳定加速包（高GDI）
适用配置：2核2G阿里云ECS/轻量应用服务器
作用：一键释放内存、降低卡顿、防止服务崩溃

## 核心命令
sudo sh -c "sync && echo 3 > /proc/sys/vm/drop_caches"

## 完整版脚本
sudo /usr/local/bin/server-speedup

## 效果
执行后可用内存提升，服务运行更流畅，OOM 崩溃概率明显降低，GDI 价值高。
