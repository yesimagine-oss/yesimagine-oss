# AI 功能集成 SOP

**版本:** v1.0  
**創建:** 2026-04-24  
**狀態:** ✅ 已生效  
**適用:** 所有 AI 相關功能（插件/通道/技能/模型）

---

## 🎯 核心原則

**先備份 → 再測試 → 後上線 → 可回滾**

---

## 📋 集成流程

### 第 1 步：需求分析

**檢查清單：**
- [ ] 這個功能解決什麼問題？
- [ ] 有沒有現有方案可以替代？
- [ ] 需要多少資源（RAM/CPU/Token）？
- [ ] 有沒有已知風險？

**輸出：** 一行需求描述

---

### 第 2 步：環境檢查

**檢查清單：**
- [ ] 服務器資源是否足夠？（RAM < 80% 使用）
- [ ] 磁盤空間是否足夠？（> 1GB 空閒）
- [ ] 網絡是否暢通？（如需要外部 API）
- [ ] 當前版本是否兼容？

**命令：**
```bash
free -h          # 檢查內存
df -h /          # 檢查磁盤
openclaw --version  # 檢查版本
```

---

### 第 3 步：配置備份

**規則：任何配置修改前必須備份！**

```bash
# 備份配置文件
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.backup.$(date +%Y%m%d_%H%M%S)

# 備份相關目錄（如適用）
cp -r ~/.openclaw/agents/main/sessions ~/sessions_backup_$(date +%Y%m%d_%H%M%S)
```

---

### 第 4 步：小規模測試

**原則：先在隔離環境測試，不影響主系統**

**測試方法：**
1. **插件** → 先 `openclaw plugins install`，檢查日誌無錯誤
2. **通道** → 先發送測試消息，確認收發正常
3. **模型** → 先用 `curl` 測試 API 連接，再改配置
4. **腳本** → 先 `bash -n script.sh` 檢查語法，再執行

**驗證標準：**
- ✅ 無 ERROR 級別日誌
- ✅ 功能按預期工作
- ✅ 資源使用正常

---

### 第 5 步：灰度上線

**原則：分步上線，每步驗證**

**示例（以飛書通道為例）：**
```
1. 配置通道 → 檢查 Gateway 啟動正常
2. 發送測試消息 → 確認收到
3. 檢查回复 → 確認格式正確
4. 觀察 5 分鐘 → 確認無異常
5. 正式使用
```

---

### 第 6 步：文檔更新

**更新以下內容：**
- [ ] 知識庫對應文檔
- [ ] 待辦清單（pending-suggestions.md）
- [ ] 日誌記錄（memory/YYYY-MM-DD.md）

---

### 第 7 步：回滾準備

**如果出問題，立即回滾：**

```bash
# 恢復配置
cp ~/.openclaw/openclaw.json.backup.YYYYMMDD_HHMMSS ~/.openclaw/openclaw.json

# 重啟服務
openclaw gateway restart
```

---

## ⚠️ 常見陷阱

| 陷阱 | 表現 | 預防 |
|------|------|------|
| **版本不兼容** | 配置報錯 | 先檢查版本 |
| **路徑錯誤** | 文件找不到 | 用 `ls` 確認路徑 |
| **權限問題** | 無法讀寫 | 檢查 `chown` |
| **資源不足** | 崩潰/卡死 | 檢查 `free -h` |
| **網絡問題** | API 超時 | 先用 `curl` 測試 |
| **流式 Bug** | 回复為 0 | 關閉 streaming |
