# 知識入庫回復標準 SOP

**創建時間:** 2026-04-24 12:07  
**狀態:** ✅ 生效中  
**優先級:** P0（強制執行）

---

## 目的

解決入庫回復不規範、不完整的問題。

---

## 標準回復格式（必須遵循）

```markdown
**來源**: [URL 或 無]
**資產**: [X Genes + Y Capsules]
**置信度**: [0.XX]
**GDI**: [XX 或 待計算]
**評分**: [X.X/10]
**入庫**: ✅ `10-raw/[filename].md` + `01-openclaw/[filename].md`
**Git**: `[commit_hash]`

**狀態**: [🟢完成/🟡待深度/🔴有問題]
```

---

## 字段說明

| 字段 | 說明 | 示例 |
|------|------|------|
| **來源** | 知識來源 URL 或說明 | `https://github.com/...` 或 `用戶提供` |
| **資產** | 生成的 Gene 和 Capsule 數量 | `0 Genes + 0 Capsules` |
| **置信度** | 0-1 數值，基於證據 | `0.5`（僅原文）、`0.9`（原文 + 實測） |
| **GDI** | 基因完整性評分（0-100） | `85` 或 `待計算` |
| **評分** | 整體質量評分（0-10） | `8.5/10` |
| **入庫** | 實際存儲路徑 | `10-raw/` + `01-openclaw/` |
| **Git** | 提交 hash | `abc1234` |
| **狀態** | 入庫狀態 | `🟢完成`、`🟡待深度`、`🔴有問題` |

---

## 入庫原則

| 原則 | 說明 | 違反後果 |
|------|------|----------|
| **無原文不入庫** | 必須有真實來源原文 | 🔴 刪除文件 |
| **無實測不生成 Gene** | Gene 需要實測驗證 | 🟡 標註候选 |
| **無實測不生成 Capsule** | Capsule 需要執行證據 | 🟡 標註候选 |
| **真實性第一** | 禁止編造任何內容 | 🔴 事故記錄 |
| **分類清晰** | 按主題放入正確目錄 | 🟡 重新分類 |
| **報告完整** | 必須有入庫報告 | 🟡 補齊報告 |

---

## 入庫流程

```
1. 原始采樣 → 10-raw/
   ↓
2. 知識提煉 → 01-openclaw/ 或其他主題目錄
   ↓
3. 生成資產 → 08-genes/ + 09-capsules/（如有實測）
   ↓
4. 入庫報告 → 06-reports/
   ↓
5. Git 提交 → 記錄 commit_hash
   ↓
6. 標準回復 → 使用本 SOP 格式
```

---

## 可信度評估標準

| 等級 | 標準 | 置信度 |
|------|------|--------|
| **高可信** | 原文 + 實測 | 0.9-1.0 |
| **中可信** | 僅原文（權威來源） | 0.6-0.8 |
| **低可信** | 僅原文（未知來源） | 0.3-0.5 |
| **候选** | 無法驗證 | 0.1-0.2 |
| **無證據** | 編造內容 | 0（禁止入庫） |

## 分類規則

| 主題 | 目錄 | 示例 |
|------|------|------|
| OpenClaw 平台 | `01-openclaw/` | 配置、架構、故障排除 |
| EvoMap | `02-evomap/` | 資產、任務、協議 |
| 項目知識 | `03-projects/` | Node.js、Python、Serper |
| 技能工具 | `04-skills/` | API、腳本、集成 |
| 事故記錄 | `05-accidents/` | P0/P1 事故 |
| 報告 | `06-reports/` | 入庫報告、週報、月報 |
| 學習記錄 | `07-learnings/` | SOP、Gene、改進 |
| Gene 資產 | `08-genes/` | 可執行規則 |
| Capsule 資產 | `09-capsules/` | 實例膠囊 |
| 原始素材 | `10-raw/` | 頁面采樣、命令采樣 |
| 歸檔 | `11-archive/` | 歷史文件 |

## 違反處理

| 違反 | 處理 | 記錄位置 |
|------|------|----------|
| 編造內容 | 刪除文件 + P0 事故 | `.learnings/` |
| 無原文入庫 | 刪除文件 + P1 事故 | `.learnings/` |
| 回復不完整 | 補齊 + P1 錯誤 | `.learnings/` |
| 分類錯誤 | 重新分類 | - |
| 缺少報告 | 補齊報告 | - |

## 示例

### 示例 1：高可信入庫（原文 + 實測）

```markdown
**來源**: https://nodejs.org/docs/latest/api/fs.html
**資產**: 2 Genes + 1 Capsule
**置信度**: 0.95
**GDI**: 92
**評分**: 9.2/10
**入庫**: ✅ `10-raw/nodejs-fs-2026-04-24.md` + `03-projects/nodejs-fs-api.md`
**Git**: `abc1234`

**狀態**: 🟢完成
```

```markdown
**置信度**: 0.5
```

```markdown
**入庫**: ❌ 不入庫（無真實原文）

```
