## 📋 核心協議速查

### 1. 上下文管理器協議

```python
class ManagedResource:
    def __enter__(self):
        # 進入上下文時調用
        # 返回的對象綁定到 with 語句的目標變量
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        # 退出上下文時調用
        # 返回值決定是否吞掉異常：
        # True = 吞掉異常，False/None = 讓異常繼續傳播
        return False
```

### 2. contextmanager 裝飾器

```python
from contextlib import contextmanager

@contextmanager
def managed_resource(name):
    # 設置
    resource = acquire(name)
    try:
        yield resource  # 返回給 with 語句
    finally:
        # 清理
        release(resource)

# 使用
with managed_resource('db') as resource:
    use(resource)
```

### 3. ExitStack - 動態上下文

```python
from contextlib import ExitStack

with ExitStack() as stack:
    # 動態添加上下文
    file1 = stack.enter_context(open('file1.txt'))
    file2 = stack.enter_context(open('file2.txt'))
    
    # 註冊回調
    stack.callback(cleanup_func)
    
    # 使用資源
    process(file1, file2)
# 退出時按相反順序清理
```

```python

### 模式 1: 原子寫入

@contextmanager
def atomic_write(filename, mode='w'):
    temp = filename + '.tmp'
    try:
        with open(temp, mode) as f:
            yield f
        shutil.move(temp, filename)
    except:
        if os.path.exists(temp):
            os.remove(temp)
        raise
```

## 📊 __exit__ 參數說明

```python
def __exit__(self, exc_type, exc_val, exc_tb):
    """
    exc_type: 異常類型 (無異常時為 None)
    exc_val:  異常實例 (無異常時為 None)
    exc_tb:   異常追蹤 (無異常時為 None)
    
    返回值:
    - True:  吞掉異常，繼續執行
    - False/None: 讓異常繼續傳播
    """
```

### 示例

```python
class SafeOperation:
    def __exit__(self, exc_type, exc_val, exc_tb):
        if exc_type is None:
            print("無異常")
        elif exc_type == ValueError:
            print(f"值錯誤：{exc_val}")
            return True  # 吞掉
        elif exc_type == TypeError:
            print(f"類型錯誤：{exc_val}")
            return True  # 吞掉
        return False  # 其他異常繼續傳播
```

## ⚡ 最佳實踐

### ✅ 推薦做法

1. **總是使用 with 語句** - 確保資源清理
2. **優先使用 contextmanager** - 比類更簡潔
3. **使用 ExitStack 管理多個資源** - 動態添加
4. **在 finally 中清理資源** - 確保執行
5. **明確是否吞掉異常** - 返回適當值

### ❌ 避免做法

1. **避免手動 try/finally** - 使用上下文管理器
2. **避免吞掉所有異常** - 只忽略預期的異常
3. **避免在 __exit__ 中引發新異常** - 會掩蓋原異常
4. **避免忘記關閉資源** - 使用 with 語句

## 🐛 常見錯誤

### 錯誤 1: 忘記在 finally 中清理

```python
# ❌ 錯誤
@contextmanager
def bad_resource():
    resource = acquire()
    yield resource
    resource.release()  # 如果有異常，這行不會執行

# ✅ 正確
@contextmanager
def good_resource():
    resource = acquire()
    try:
        yield resource
    finally:
        resource.release()
```

### 錯誤 2: 錯誤的返回值

```python
# ❌ 錯誤 - 吞掉所有異常
def __exit__(self, *args):
    return True

# ✅ 正確 - 只吞掉預期的異常
def __exit__(self, exc_type, exc_val, exc_tb):
    if exc_type == ExpectedError:
        return True
    return False
```

### 錯誤 3: ExitStack 使用不當

```python
# ❌ 錯誤 - 手動管理
stack = ExitStack()
file = stack.enter_context(open('file.txt'))
# 忘記關閉

# ✅ 正確 - 使用 with
with ExitStack() as stack:
    file = stack.enter_context(open('file.txt'))
    # 自動關閉
```
