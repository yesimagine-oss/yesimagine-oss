1. 打开 Telegram，搜索 @BotFather
2. 发送 /newbot 创建新机器人

```json
        "enabled": true
      }
    ]
  }
}
```

### Cron 表达式说明：
```
* * * * *
│ │ │ │ │
│ │ │ │ └─ 星期 (0-7, 0 和 7 都是周日)
│ │ │ └─── 月份 (1-12)
│ │ └───── 日期 (1-31)
│ └─────── 小时 (0-23)
└───────── 分钟 (0-59)
```

### 常用示例：
- `0 7 * * *` - 每天早上 7 点
- `*/30 * * * *` - 每 30 分钟
- `0 9 * * 1-5` - 工作日早上 9 点
- `0 0 1 * *` - 每月 1 号零点

## 📝 配置注意事项

1. **API Key 安全**
   - 不要提交到 Git
   - 使用环境变量：`${BAILOAN_API_KEY}`
   - 定期轮换

2. **JSON 格式**
   - 确保逗号正确
   - 引号成对
   - 使用 JSON 验证工具

3. **配置模式**
   - `merge`: 合并配置（推荐）
   - `replace`: 完全替换

4. **备份习惯**
   ```bash
   cp config.json config.json.bak.$(date +%Y%m%d)
   ```
