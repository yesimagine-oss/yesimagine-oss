## 🎯 实战目标

配置一个**晨间报告**功能，每天早上 7 点自动发送：
- 天气情况
- 新闻摘要
- 日程提醒

---

## 📋 前置准备（5 分钟）

确保已完成快速入门：
- [ ] OpenClaw 已安装
- [ ] API Key 已配置
- [ ] 基础对话可正常使用的

---

## 🔧 步骤 1: 启用必要技能（5 分钟）

```bash
# 启用天气技能
openclaw skills enable weather

# 启用搜索技能
openclaw skills enable searxng

# 启用定时任务技能
openclaw skills enable qqbot-cron

# 验证技能状态
openclaw skills list
```

---

## 🔧 步骤 2: 配置晨间报告任务（10 分钟）

编辑配置文件，添加 cron 任务：

```json
{
  "crons": {
    "enabled": true,
    "tasks": [
      {
        "id": "morning-report",
        "schedule": "0 7 * * *",
        "description": "每日晨间报告",
        "command": "生成晨间报告，包含：1)北京今天天气 2)3 条科技新闻摘要 3)友好问候语。用 Markdown 格式，简洁明了。",
        "channel": "webchat",
        "enabled": true
      }
    ]
  }
}
```

### 通过 Web UI 配置：

```bash
openclaw dashboard
```

在配置页面添加上述 cron 配置。
