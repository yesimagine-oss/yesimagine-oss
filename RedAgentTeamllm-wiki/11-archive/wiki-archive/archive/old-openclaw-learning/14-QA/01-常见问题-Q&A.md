# OpenClaw 常见问题 Q&A

**创建时间**: 2026-03-12
**用途**: 快速解答常见问题

---

## 🚀 入门问题

### Q1: OpenClaw 是什么？

**A**: OpenClaw 是一个开源的个人 AI 助手平台，支持：
- 多种消息渠道（Telegram、Discord、微信等）
- 多种 AI 模型（通义千问、GPT-4 等）
- 可扩展的技能系统
- 定时任务和自动化

---

### Q2: 我需要有什么基础才能使用？

**A**: 建议具备：
- 基本的命令行操作
- 简单的配置文件编辑
- 云服务器使用经验（可选）

但即使零基础，按照文档也能完成部署。

---

### Q3: 使用 OpenClaw 需要付费吗？

**A**: OpenClaw 本身免费，但使用需要：
- 服务器费用（约 ¥50-100/月）
- AI 模型 API 费用（按用量计费）
- 可选：域名、SSL 证书等

---

### Q4: 可以在本地电脑运行吗？

**A**: 可以，但不推荐：
- ✅ 开发测试可以在本地
- ❌ 生产环境建议用服务器
- 原因：需要 24 小时在线，本地电脑会关机/断网

---

## 📦 安装部署

### Q5: 安装失败怎么办？

**A**: 检查以下几点：
```bash
# 1. Node.js 版本
node -v  # 需要 v22+

# 2. 网络连接
curl -I https://openclaw.ai

# 3. 权限问题
# 不要用 sudo 安装，使用普通用户
```

---

### Q6: 应该选择什么服务器配置？

**A**: 推荐配置：
| 用途 | CPU | 内存 | 磁盘 | 月费用 |
|------|-----|------|------|--------|
| 基础使用 | 2 核 | 4GB | 60GB | ~¥60 |
| 中度使用 | 4 核 | 8GB | 80GB | ~¥120 |
| 重度使用 | 8 核 | 16GB | 100GB | ~¥240 |

---

### Q7: 支持哪些操作系统？

**A**: 
- ✅ Ubuntu 20.04/22.04（推荐）
- ✅ Debian 11/12
- ✅ macOS
- ✅ Windows（PowerShell）
- ⚠️ CentOS/其他 Linux（可能需要额外配置）

## 🔑 模型配置

### Q8: 支持哪些 AI 模型？

**A**: 主流模型都支持：
- 阿里云：Qwen3.5-Plus、Qwen3-Max、Qwen-Coder
- OpenAI: GPT-4、GPT-3.5-Turbo
- 其他：通过 OpenAI 兼容 API 接入

---

### Q9: 哪个模型性价比最高？

**A**: 推荐：
- **日常使用**: Qwen3.5-Plus（便宜、够用）
- **复杂任务**: Qwen3-Max（更强、稍贵）
- **代码任务**: Qwen-Coder（代码优化）

---

### Q10: API Key 泄露了怎么办？

**A**: 
1. 立即在控制台删除泄露的 Key
2. 创建新的 API Key
3. 更新 OpenClaw 配置
4. 检查日志是否有异常调用

## 🧩 技能使用

### Q11: 如何安装新技能？

**A**: 
```bash
# 从 ClawHub 安装
openclaw skills install <skill-name>

# 或手动安装
git clone <skill-repo> ~/.openclaw/workspace/skills/<skill-name>
openclaw skills enable <skill-name>
```

### Q15: Telegram Bot 怎么创建？

**A**: 
1. Telegram 搜索 @BotFather
2. 发送 /newbot
3. 按提示设置名称
4. 获取 Token
5. 填入 OpenClaw 配置

详细步骤见文档。

---

### Q16: 可以同时使用多个通道吗？

**A**: 可以！配置多个通道后，消息会同步到所有启用的通道。

## ⏰ 定时任务

### Q17: 定时任务不执行怎么办？

**A**: 
```bash
# 1. 检查 cron 配置
openclaw config | grep -A 20 crons

# 2. 验证 cron 表达式
# 使用 https://crontab.guru

# 3. 查看日志
openclaw logs --grep cron

# 4. 检查时区
timedatectl
```

---

### Q18: 时区不对怎么办？

**A**: 
```bash
# 设置为中国时区
sudo timedatectl set-timezone Asia/Shanghai

# 验证
timedatectl

# 重启服务
openclaw restart
```

## 🔧 故障排查

### Q19: 服务启动失败

**A**: 
```bash
# 查看详细错误
openclaw start --verbose

# 常见原因:
# 1. 端口占用：lsof -i :3000
# 2. 配置错误：openclaw config --validate
# 3. 权限问题：chmod -R 755 ~/.openclaw
```

---

### Q20: 模型调用失败

**A**: 
```bash
# 1. 检查 API Key
openclaw config | grep apiKey

# 2. 测试 API
curl -H "Authorization: Bearer sk-xxx" \
  https://coding.dashscope.aliyuncs.com/v1/models

# 3. 查看余额
# 登录控制台检查
```

---

### Q21: 收不到消息通知

**A**: 
```bash
# 1. 检查通道状态
openclaw channels list

# 2. 测试通道
# 发送消息给 bot

# 3. 查看日志
openclaw logs --grep telegram
```

## 🔒 安全隐私

### Q24: 数据存在哪里？安全吗？

**A**: 
- 数据存储在本地服务器
- 不会自动上传到云端
- 建议：启用磁盘加密
- 建议：定期备份

---

### Q25: AI 会泄露我的隐私吗？

**A**: 
- OpenClaw 是开源的，代码可审计
- 数据在你自己的服务器上
- API 调用通过官方渠道
- 建议：不要分享敏感信息
