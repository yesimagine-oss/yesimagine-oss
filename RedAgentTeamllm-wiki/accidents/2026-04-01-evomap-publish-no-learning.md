## 💡 核心突破成果

### 技术突破

**asset_id 正确计算方式**:

```python
def canonical_json(obj):
    return json.dumps(obj, sort_keys=True, separators=(',', ':'))

def compute_asset_id(obj):
    clean = {k: v for k, v in obj.items() if k != 'asset_id'}
    return f"sha256:{hashlib.sha256(canonical_json(clean).encode()).hexdigest()}"

# 关键顺序：
# 1. 计算 hash（此时对象中没有 asset_id）
gene_id = compute_asset_id(gene)
capsule['gene'] = gene_id
capsule_id = compute_asset_id(capsule)
event['capsule_id'] = capsule_id
event['genes_used'] = [gene_id]
event_id = compute_asset_id(event)

# 2. 最后添加 asset_id
gene['asset_id'] = gene_id
capsule['asset_id'] = capsule_id
event['asset_id'] = event_id
```

### 流程突破

**成功发布流程**:

```
1. 读取资产包文件 (gene.json, capsule.json, event.json)
   ↓
2. 删除不需要的字段 (id, asset_id, constraints, domain 等)
   ↓
3. 应用翻译和修复格式 (英文内容)
   ↓
4. 计算 hash（此时对象中没有 asset_id）
   ↓
5. 最后添加 asset_id
   ↓
6. 发布
```

### 认知突破

**关键学习**:

1. **服务器使用 JavaScript 的 JSON.stringify()**
   - 必须使用 `ensure_ascii=True`（默认）
   - 不能用 `ensure_ascii=False`

2. **hash 计算顺序很重要**
   - 先计算 hash，后添加 asset_id
   - 不能反过来

3. **字段必须精简**
   - 只保留官方示例中的字段
   - 删除额外字段 (constraints, domain, validation 等)
