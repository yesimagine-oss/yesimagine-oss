## 🔌 網絡驅動類型

### 1. Bridge (橋接) - 默認

```bash
# 查看網橋
docker network ls
docker network inspect bridge

# 創建自定義網橋
docker network create my-bridge

# 創建時指定子網
docker network create \
  --subnet=172.20.0.0/16 \
  --gateway=172.20.0.1 \
  my-bridge

# 使用自定義網絡
docker run -d --network=my-bridge --name=web nginx
docker run -d --network=my-bridge --name=db mysql

# 容器間通信
docker exec web ping db
```

### 2. Host (主機)

```bash
# 直接使用主機網絡
docker run -d --network=host nginx

# 優點：無網絡轉換，性能最好
# 缺點：無網絡隔離，端口可能衝突
```

### 3. None (無網絡)

```bash
# 完全隔離
docker run -d --network=none alpine

# 只有 loopback 接口
docker exec -it container ip addr
```

### 4. Container (共享)

```bash
# 共享另一個容器的網絡
docker run -d --name=web nginx
docker run -d --network=container:web alpine

# 兩個容器共享同一個網絡命名空間
```

### 5. Overlay (跨主機)

```bash
# 需要 Docker Swarm
docker network create -d overlay my-overlay

# 跨主機容器通信
# 節點 1
docker run -d --network=my-overlay --name=service1 alpine

# 節點 2
docker run -d --network=my-overlay --name=service2 alpine
```

### 6. Macvlan (直接連接物理網絡)

```bash
# 創建 Macvlan 網絡
docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  -o parent=eth0 \
  macvlan-net

# 運行容器
docker run -d --network=macvlan-net --name=container1 alpine

# 容器將獲得物理網絡中的 IP
```

## 🔧 網絡操作

### 1. 查看網絡

```bash
# 列出網絡
docker network ls

# 查看詳情
docker network inspect bridge

# 查看連接的容器
docker network inspect bridge --format='{{range .Containers}}{{.Name}}{{end}}'
```

### 2. 連接/斷開網絡

```bash
# 連接網絡
docker network connect my-bridge container1

# 斷開網絡
docker network disconnect my-bridge container1

# 運行時指定多個網絡
docker run -d \
  --network=web-net \
  --network=db-net \
  nginx
```

### 3. 刪除網絡

```bash
# 刪除網絡
docker network rm my-bridge

# 刪除未使用網絡
docker network prune
```

## 🌍 端口映射

### 1. 基礎映射

```bash
# 映射單個端口
docker run -d -p 8080:80 nginx

# 映射到特定接口
docker run -d -p 127.0.0.1:8080:80 nginx

# 映射多個端口
docker run -d \
  -p 80:80 \
  -p 443:443 \
  -p 8080:8080 \
  nginx
```

### 2. 動態端口

```bash
# 自動映射到隨機端口
docker run -d -P nginx

# 查看映射端口
docker port container_id
```

### 3. 端口範圍

```bash
# 映射端口範圍
docker run -d -p 8000-8010:8000-8010 nginx
```

## 📡 DNS 配置

### 1. 自定義 DNS

```bash
# 指定 DNS 服務器
docker run -d \
  --dns 8.8.8.8 \
  --dns 8.8.4.4 \
  nginx

# 指定搜索域
docker run -d \
  --dns-search example.com \
  nginx
```

### 2. 容器間 DNS

```bash
# 使用容器名稱解析
docker run -d --network=my-bridge --name=web nginx
docker run -d --network=my-bridge --name=db mysql

# web 容器可以通過 "db" 訪問數據庫
docker exec web ping db
```

### 3. 自定義 hosts

```bash
# 添加 hosts 條目
docker run -d \
  --add-host=myhost:192.168.1.100 \
  alpine
```

## 🔒 網絡安全

### 1. 網絡隔離

```bash
# 創建內部網絡 (無外網訪問)
docker network create \
  --driver bridge \
  --internal \
  internal-net

# 運行容器
docker run -d --network=internal-net alpine
```

### 2. 限制端口暴露

```bash
# 只綁定到 localhost
docker run -d -p 127.0.0.1:3306:3306 mysql

# 使用防火牆限制
iptables -A INPUT -p tcp --dport 3306 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 3306 -j DROP
```

### 3. 網絡加密

```bash
# Overlay 網絡加密
docker network create -d overlay \
  --opt encrypted \
  secure-overlay
```

## 🔍 故障排查

### 1. 檢查網絡連接

```bash
# 查看容器 IP
docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' container

# 測試連接
docker exec container ping 8.8.8.8
docker exec container curl -I https://www.google.com
```

### 2. 檢查 DNS

```bash
# 查看 DNS 配置
docker exec container cat /etc/resolv.conf

# 測試 DNS 解析
docker exec container nslookup google.com
```

### 3. 檢查 iptables

```bash
# 查看 Docker 規則
iptables -L -n | grep docker
iptables -t nat -L -n | grep docker
```

### 4. 重啟網絡

```bash
# 重啟 Docker 網絡
sudo systemctl restart docker

# 重建網橋
sudo ip link set dev docker0 down
sudo ip link del dev docker0
sudo systemctl restart docker
```

## 📊 網絡性能優化

### 1. 選擇合適的驅動

```
性能排序：
Host > Macvlan > Bridge > Overlay
```

### 2. 調整 MTU

```bash
# 查看 MTU
ip link show docker0

# 創建時指定 MTU
docker network create \
  --opt com.docker.network.driver.mtu=1450 \
  my-network
```

### 3. 調整緩衝區

```bash
# 系統級調整
sysctl -w net.core.rmem_max=16777216
sysctl -w net.core.wmem_max=16777216
```

## 📋 最佳實踐

### ✅ 推薦做法

1. **使用自定義網橋** - 更好的隔離和 DNS 解析
2. **限制端口暴露** - 只暴露必要的端口
3. **使用內部網絡** - 數據庫等服務不暴露外網
4. **配置 DNS** - 使用可靠的 DNS 服務器
5. **網絡隔離** - 生產環境使用獨立網絡

### ❌ 避免做法

1. **避免 Host 模式** - 除非必要
2. **避免暴露所有端口** - 使用 -P
3. **避免共享網絡** - 除非必要
4. **避免無防火牆** - 配置 iptables 規則
