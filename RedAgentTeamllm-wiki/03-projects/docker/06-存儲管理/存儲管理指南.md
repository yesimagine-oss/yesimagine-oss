## 📦 存儲類型

### 1. 卷 (Volumes) - 推薦

```bash
# 創建卷
docker volume create mydata

# 查看卷
docker volume ls
docker volume inspect mydata

# 使用卷
docker run -d -v mydata:/data nginx

# 只讀卷
docker run -d -v mydata:/data:ro nginx

# 多個卷
docker run -d \
  -v data-vol:/var/lib/mysql \
  -v config-vol:/etc/mysql \
  mysql
```

### 2. Bind Mount (綁定掛載)

```bash
# 掛載主機目錄
docker run -d -v /host/path:/container/path nginx

# 相對路徑
docker run -d -v ./data:/app/data nginx

# 只讀掛載
docker run -d -v ./config:/app/config:ro nginx

# 完整語法
docker run -d \
  --mount type=bind,source=/host/path,target=/container/path \
  nginx
```

### 3. tmpfs (臨時文件系統)

```bash
# 使用 tmpfs
docker run -d --tmpfs /app/cache nginx

# 指定選項
docker run -d \
  --tmpfs /app/cache:rw,noexec,nosuid,size=100m \
  nginx
```

## 🔧 卷管理

### 1. 創建和刪除

```bash
# 創建卷
docker volume create myvol

# 創建時指定驅動
docker volume create \
  --driver local \
  --opt type=none \
  --opt device=/opt/data \
  --opt o=bind \
  myvol

# 刪除卷
docker volume rm myvol

# 刪除未使用卷
docker volume prune
```

### 2. 查看卷信息

```bash
# 查看卷詳情
docker volume inspect myvol

# 查看卷使用情況
docker system df -v

# 查找使用卷的容器
docker ps --filter "volume=myvol"
```

### 3. 備份和恢復

```bash
# 備份卷
docker run --rm \
  -v myvol:/source \
  -v $(pwd):/backup \
  alpine \
  tar czf /backup/backup.tar.gz -C /source .

# 恢復卷
docker run --rm \
  -v myvol:/target \
  -v $(pwd):/backup \
  alpine \
  tar xzf /backup/backup.tar.gz -C /target
```

## 🧹 存儲清理

### 1. 清理懸空資源

```bash
# 清理懸空卷
docker volume prune

# 清理懸空鏡像
docker image prune

# 清理懸空容器
docker container prune

# 清理懸空網絡
docker network prune
```

### 2. 系統清理

```bash
# 清理所有未使用資源
docker system prune

# 包括卷
docker system prune -a --volumes

# 查看可清理空間
docker system df
```

### 3. 手動清理

```bash
# 清理日誌
sudo truncate -s 0 /var/lib/docker/containers/*/*-json.log

# 清理構建緩存
docker builder prune

# 清理特定卷
docker volume rm $(docker volume ls -qf dangling=true)
```

## 📈 存儲性能優化

### 1. 選擇合適的存儲類型

```
性能排序：
tmpfs > 本地卷 > Bind Mount > NFS > 遠程存儲
```

### 2. 使用本地卷

```bash
# 推薦：本地卷
docker run -d -v mydata:/data nginx

# 避免：NFS (除非必要)
docker run -d -v nfs-server:/data:/data nginx
```

### 3. 調整 I/O 優先級

```bash
# 限制讀取速度
docker run -d \
  --device-read-bps="/dev/sda:1mb" \
  nginx

# 限制寫入速度
docker run -d \
  --device-write-bps="/dev/sda:1mb" \
  nginx
```

## 🔒 存儲安全

### 1. 權限控制

```bash
# 只讀掛載
docker run -d -v data:/data:ro nginx

# 指定用戶
docker run -d \
  -u 1000:1000 \
  -v data:/data \
  nginx
```

### 2. 敏感數據保護

```bash
# 使用 Docker Secrets (Swarm)
echo "mypassword" | docker secret create db_password -

docker service create \
  --secret db_password \
  mysql
```

### 3. 加密卷

```bash
# 使用加密卷驅動
docker volume create \
  --driver local \
  --opt type=encrypted \
  secure-data
```

## 🔍 故障排查

### 1. 檢查存儲使用

```bash
# 查看磁盤使用
df -h

# 查看 Docker 存儲
du -sh /var/lib/docker/*

# 查看卷使用
docker system df -v
```

### 2. 檢查權限問題

```bash
# 查看卷權限
ls -la /var/lib/docker/volumes/

# 修復權限
sudo chown -R docker:docker /var/lib/docker
```

### 3. 存儲空間不足

```bash
# 清理資源
docker system prune -a

# 移動 Docker 目錄
sudo systemctl stop docker
sudo mv /var/lib/docker /new/location
sudo ln -s /new/location /var/lib/docker
sudo systemctl start docker
```

## 📋 最佳實踐

### ✅ 推薦做法

1. **使用卷而非 Bind Mount** - 更好的可移植性
2. **命名卷** - 易於管理
3. **定期清理** - 防止磁盤寫滿
4. **備份重要數據** - 定期備份卷
5. **使用只讀掛載** - 配置文件使用只讀

### ❌ 避免做法

1. **避免在容器內存儲重要數據** - 容器刪除後數據丟失
2. **避免無限制日誌** - 配置日誌輪轉
3. **避免共享卷無鎖** - 多容器訪問需加鎖
4. **避免使用 root 權限** - 使用特定用戶
