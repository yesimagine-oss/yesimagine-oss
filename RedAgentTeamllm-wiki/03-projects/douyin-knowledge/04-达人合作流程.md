# 达人合作流程

> 借力打力，用别人的流量赚自己的钱

---

## 一、达人合作模式

### 1.1 五种合作模式

| 模式 | 说明 | 适合阶段 | 成本 |
|------|------|---------|------|
| **纯佣合作** | 按销售额分成，无坑位费 | 新手首选 | 佣金 20-40% |
| **坑位费 + 佣金** | 固定费用 + 销售分成 | 成熟品牌 | 坑位费 1 万 -50 万 + 佣金 |
| **保量合作** | 承诺最低销量，未达标退款 | 高客单价 | 溢价 20-30% |
| **年度框架** | 长期合作，打包优惠 | 品牌方 | 年框 50 万 + |
| **股权合作** | 达人入股，深度绑定 | 战略级 | 股权 5-20% |

### 1.2 模式选择建议

**新手品牌（月销 < 50 万）：**
```
✅ 纯佣合作为主
✅ 找中小达人（1-10 万粉）
✅ 多达人分散投放
✅ 单场投入 < 5000 元
```

**成长品牌（月销 50-200 万）：**
```
✅ 坑位费 + 佣金
✅ 找腰部达人（10-50 万粉）
✅ 打造 3-5 个核心达人
✅ 单场投入 1-5 万元
```

**成熟品牌（月销 200 万 +）：**
```
✅ 年度框架 + 股权合作
✅ 找头部达人（100 万粉 +）
✅ 自建达人矩阵
✅ 单场投入 10 万 +
```

## 二、达人筛选标准

### 2.1 核心数据指标

| 指标 | 达标线 | 优秀线 | 说明 |
|------|--------|--------|------|
| **粉丝量** | 1 万 + | 10 万 + | 不是唯一标准 |
| **场均观看** | 5000+ | 5 万 + | 比粉丝量更重要 |
| **转化率** | > 2% | > 5% | 核心指标 |
| **GPM** | > 300 元 | > 1000 元 | 千次观看成交额 |
| **粉丝粘性** | > 3% | > 8% | 互动率/粉丝量 |
| **退货率** | < 20% | < 10% | 售后成本 |

### 2.2 达人分级标准

**S 级达人（头部）：**
```
- 粉丝量：100 万 +
- 场均观看：50 万 +
- 坑位费：10 万 -50 万
- 佣金：15-25%
- 特点：流量大，成本高，难合作
```

**A 级达人（腰部）：**
```
- 粉丝量：10-100 万
- 场均观看：5-50 万
- 坑位费：1-10 万
- 佣金：20-30%
- 特点：性价比高，配合度好
```

**B 级达人（尾部）：**
```
- 粉丝量：1-10 万
- 场均观看：5000-5 万
- 坑位费：0-1 万
- 佣金：25-40%
- 特点：成本低，易合作，适合测款
```

**C 级达人（素人）：**
```
- 粉丝量：<1 万
- 场均观看：<5000
- 坑位费：0
- 佣金：30-50%
- 特点：纯佣，铺量，种草
```

### 2.3 达人画像匹配

| 品牌定位 | 达人类型 | 粉丝画像 |
|---------|---------|---------|
| 高端奢侈品 | 精致生活博主 | 一二线，25-40 岁，高消费 |
| 大众消费品 | 剧情/搞笑博主 | 全年龄段，下沉市场 |
| 美妆护肤 | 美妆博主 | 女性，18-35 岁 |
| 母婴用品 | 宝妈博主 | 已婚女性，25-40 岁 |
| 数码产品 | 科技博主 | 男性，18-35 岁 |
| 食品饮料 | 美食博主 | 全年龄段，吃货群体 |

## 三、达人寻找渠道

### 3.1 官方渠道（推荐）

#### 抖音精选联盟
```
路径：创作者服务中心 → 商品橱窗 → 精选联盟 → 达人广场

筛选条件：
- 类目匹配
- 粉丝量区间
- 带货等级（L1-L6）
- 近 30 天带货数据
- 佣金比例

优点：官方数据，真实可靠
缺点：竞争大，优质达人难联系
```

#### 巨量星图（官方任务平台）
```
网址：https://star.toutiao.com

功能：
- 发布带货任务
- 达人主动报名
- 平台担保交易
- 数据监控

服务费：5%（从达人收入扣除）

优点：正规安全，有平台保障
缺点：服务费高，流程较长
```

### 3.3 手动挖掘方法

**方法 1：竞品达人挖掘**
```
1. 找到竞品品牌
2. 查看竞品合作过的达人
3. 联系同款达人
4. 话术："看到您推过 XXX，我们也是同类产品..."

2. 筛选"用户"标签

## 四、合作洽谈流程

### 4.1 首次联系话术

**模板 1：纯佣合作**
```
您好，我是 [品牌名] 的 [职位][姓名]。

关注您很久了，您的 [具体视频内容] 印象特别深刻，
感觉和我们品牌调性非常匹配。

我们是 [一句话介绍品牌]，天猫/抖音月销 [数据]。

想邀请您合作带货，纯佣模式，佣金 [X]%，
产品 [产品名] 客单价 [X] 元，转化率 [X]%。

如果您感兴趣，可以寄样品给您体验，
觉得好再安排排期。

期待您的回复！🤝

联系方式：[微信/电话]
```

**模板 2：坑位费 + 佣金**
```
[前段同上]

我们希望能和您建立长期合作关系，
本次合作预算：坑位费 [X] 万 + 佣金 [X]%。

期望排期：[日期范围]
直播时长：[X] 分钟讲解
产品数量：[X] 个 SKU

如果您档期合适，我们可以进一步沟通细节。

期待您的回复！🤝

联系方式：[微信/电话]
```

### 4.2 洽谈要点清单

| 要点 | 确认内容 | 备注 |
|------|---------|------|
| **合作模式** | 纯佣/坑位费/保量 | 明确结算方式 |
| **费用明细** | 坑位费金额、佣金比例 | 是否含税 |
| **排期时间** | 直播日期、时间段 | 避开大促冲突 |
| **讲解时长** | 产品讲解几分钟 | 写入合同 |
| **产品数量** | 上几个 SKU | 避免临时增加 |
| **优惠机制** | 专属券、赠品 | 成本核算 |
| **保量条款** | 是否保销量、保多少 | 未达标如何补偿 |
| **素材授权** | 能否切片二次传播 | 授权期限 |
| **付款方式** | 预付款比例、尾款时间 | 通常 50% 预付 |
| **违约责任** | 爽约、迟到、早退 | 明确赔偿 |

### 4.3 价格谈判技巧

**压价话术：**
```
"我们预算有限，但可以提供更高佣金"
"这是首次合作，如果效果好可以长期"
"我们可以配合您的档期，灵活调整"
"我们提供专属优惠券，提高转化率"
"我们可以提供独家机制，您这边独家"
```

**增值服务（代替降价）：**
```
✅ 提供更高佣金比例
✅ 承担样品费用
✅ 配合达人粉丝福利
✅ 提供专属优惠券
✅ 配合视频预热
✅ 授权切片二次传播
✅ 长期合作优先权
```

## 五、合同签署要点

### 5.1 合同必备条款

```
1. 合作双方信息
   - 甲方（品牌方）：公司全称、统一社会信用代码
   - 乙方（达人方）：姓名/公司、身份证号/统一信用代码

2. 合作内容
   - 直播时间：YYYY-MM-DD HH:MM-HH:MM
   - 直播平台：抖音
   - 直播间名称/ID：XXX
   - 产品清单：产品名称、规格、数量
   - 讲解时长：不少于 X 分钟

3. 费用及支付
   - 坑位费：¥XXX（税前/税后）
   - 佣金比例：X%
   - 预付款：X%，签约后 X 日内
   - 尾款：X%，直播后 X 日内
   - 结算方式：银行转账

4. 双方权利义务
   - 甲方：提供产品、优惠券、售后
   - 乙方：按时直播、保证讲解时长、配合宣传

5. 保量条款（如有）
   - 保底销售额：¥XXX
   - 未达标处理：退还 X% 坑位费/补播一场

6. 违约责任
   - 乙方爽约：退还全部费用 + 赔偿 X%
   - 乙方迟到/早退：按比例扣除费用
   - 甲方未按时付款：滞纳金 X%/日

7. 知识产权
   - 直播视频归属
   - 切片授权范围
   - 授权期限

8. 保密条款
   - 合作细节保密
   - 数据保密

9. 争议解决
   - 协商优先
   - 协商不成，甲方所在地法院

10. 其他
    - 合同生效条件
    - 合同份数
    - 签字盖章
```

### 5.2 合同避坑指南

| 坑 | 风险 | 解决方案 |
|----|------|---------|
| ❌ 口头约定 | 无法律保障 | 必须签书面合同 |
| ❌ 保量无补偿 | 销量差无法追责 | 明确未达标补偿 |
| ❌ 无违约责任 | 爽约无成本 | 明确违约金比例 |
| ❌ 授权无限期 | 被永久绑定 | 约定授权期限（1-3 年） |
| ❌ 税费不明确 | 额外成本 | 写明税前/税后 |
| ❌ 付款无节点 | 达人拖延 | 按进度付款 |

## 六、直播前准备

### 6.1 产品准备

**样品寄送清单：**
```
□ 产品样品（每款 2-3 件）
□ 产品质检报告
□ 产品授权书
□ 产品卖点文档
□ 常见问题 FAQ
□ 优惠券链接
□ 赠品（如有）
□ 产品包装盒（展示用）
```

**产品资料包：**
```
1. 产品基本信息
   - 产品名称、规格、成分
   - 适用人群、使用场景
   - 市场价格、直播价格

2. 核心卖点（3-5 个）
   - 差异化优势
   - 用户痛点解决
   - 权威背书

3. 对比竞品
   - 竞品名称
   - 我们的优势
   - 价格对比

4. 用户评价
   - 好评截图
   - 复购数据
   - KOL 推荐

5. 售后政策
   - 退换货政策
   - 质保期限
   - 客服联系方式
```

### 6.2 运营配合

**预热视频（直播前 1-3 天）：**
```
- 达人发布预热视频
- 品牌方配合转发
- 视频挂直播预约
- 粉丝群预告
```

**直播间布置：**
```
- 产品陈列
- 价格牌/手卡
- 优惠券二维码
- 背景板（品牌 logo）
```

**人员分工：**
```
- 主播：讲解产品
- 助播：演示、回复弹幕
- 运营：上链接、改价、发券
- 客服：处理售后问题
```

### 6.3 应急预案

| 突发情况 | 应对方案 |
|---------|---------|
| 直播中断 | 准备备用账号，立即重启 |
| 链接错误 | 运营立即修正，主播安抚 |
| 库存不足 | 下架链接，引导预售 |
| 负面评论 | 禁言处理，私信解决 |
| 价格错误 | 立即下架，联系达人说明 |
| 达人迟到 | 助播暖场，延迟开播 |

## 九、结算与售后

### 9.1 结算流程

```
1. 直播结束后 24 小时内
   → 双方确认销售数据
   → 导出抖音后台订单

2. 7 天无理由退货期后
   → 计算实际成交额
   → 扣除退货订单

3. 计算佣金
   → 成交额 × 佣金比例
   → 扣除平台服务费（如有）

4. 付款
   → 品牌方打款
   → 达人确认收款
   → 开具发票
```

### 9.2 售后处理

**退货处理：**
```
- 7 天无理由：品牌方承担
- 质量问题：品牌方承担 + 赔偿
- 物流破损：品牌方与物流协商
- 达人夸大宣传：达人承担部分
```

**差评处理：**
```
1. 客服 24 小时内回复
2. 私信用户解决问题
3. 引导修改评价
4. 严重问题联系达人协助
```

### 9.3 长期合作维护

**维护方法：**
```
✅ 定期节日问候
✅ 新品优先体验
✅ 专属优惠机制
✅ 年度合作返点
✅ 线下活动邀请
✅ 联合内容创作
```

**合作升级路径：**
```
单次合作 → 月度合作 → 季度框架 → 年度框架 → 股权合作
```

## 十、风险控制

### 10.1 常见风险

| 风险 | 预警信号 | 预防措施 |
|------|---------|---------|
| 达人爽约 | 沟通变慢、不确认细节 | 合同约束、预付款控制 |
| 数据造假 | 观看高转化低、评论异常 | 第三方数据验证 |
| 负面舆情 | 达人过往争议言论 | 背景调查、舆情监控 |
| 价格混乱 | 其他渠道破价 | 控价协议、保证金 |
| 知识产权 | 未经授权使用素材 | 合同明确授权范围 |

### 10.2 达人背调清单

```
□ 查看近 30 天视频内容
□ 检查是否有违规记录
□ 搜索负面新闻/舆情
□ 查看过往合作评价
□ 核实粉丝真实性（抽查评论）
□ 确认账号归属（个人/机构）

### 案例 1：新品牌冷启动

**背景：** 新品牌，0 知名度，预算 5 万

**策略：**
```
1. 选择 20 个 B 级达人（1-10 万粉）
2. 纯佣合作，佣金 35%
3. 产品客单价 99 元

```

**结果：**
```
- 总投入：5 万（样品 + 佣金）
- 总销售额：25 万
- ROI：1:5
- 新增粉丝：5000+
- 复购率：15%
```

**关键：** 多达人铺量，用佣金换流量

### 案例 2：爆款打造

- 单场销售额：80 万
- ROI：1:5.3
