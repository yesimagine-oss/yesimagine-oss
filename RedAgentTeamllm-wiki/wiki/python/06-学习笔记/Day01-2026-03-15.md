### 2. 使用 Python 作为计算器

#### 数字类型

**整数 (int):** 2, 4, 20  
**浮点数 (float):** 5.0, 1.6

**基本运算:**
```python
>>> 2 + 2
4
>>> 50 - 5*6
20
>>> (50 - 5*6) / 4
5.0
>>> 8 / 5  # 除法总是返回浮点数
1.6
```

**整除与取余:**
```python
>>> 17 // 3  # 整除，丢弃小数部分
5
>>> 17 % 3   # 取余
2
>>> 5 ** 2   # 幂运算
25
```

**变量赋值:**
```python
>>> width = 20
>>> height = 5 * 9
>>> width * height
900
```

**特殊变量 _ (下划线):**
```python
>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _  # _ 是上一次计算结果
113.0625
>>> round(_, 2)
113.06
```

#### 文本类型 (字符串)

**字符串定义:**
```python
>>> 'spam eggs'  # 单引号
'spam eggs'
>>> "Paris rabbit got your back :)! Yay!"  # 双引号
'Paris rabbit got your back :)! Yay!'
```

**转义字符:**
```python
>>> 'doesn\'t'  # 使用 \' 转义单引号
"doesn't"
>>> "doesn't"   # 或者使用双引号
"doesn't"
```

**换行符:**
```python
>>> print('First line.\nSecond line.')
First line.
Second line.
```

**原始字符串 (raw string):**
```python
>>> print(r'C:\this\name')  # r 前缀表示原始字符串
C:\this\name
```

**多行字符串:**
```python
>>> print("""\
... Usage: thingy [OPTIONS]
... -h Display this usage message
... -H hostname Hostname to connect to
... """)
Usage: thingy [OPTIONS]
 -h Display this usage message
 -H hostname Hostname to connect to
```

**字符串拼接:**
```python
>>> 3 * 'un' + 'ium'
'unununium'
>>> 'Py' 'thon'  # 字面量自动拼接
'Python'
>>> prefix = 'Py'
>>> prefix + 'thon'  # 变量需要使用 +
'Python'
```

**字符串索引:**
```python
>>> word = 'Python'
>>> word[0]  # 第一个字符
'P'
>>> word[5]  # 最后一个字符
'n'
>>> word[-1]  # 负数索引从右开始
'n'
>>> word[-2]
'o'
```

**字符串切片:**
```python
>>> word[0:2]  # 从 0 到 2 (不包括 2)
'Py'
>>> word[2:5]  # 从 2 到 5
'tho'
>>> word[:2]   # 省略第一个索引，默认为 0
'Py'
>>> word[4:]   # 省略第二个索引，默认为字符串长度
'on'
>>> word[-2:]  # 负数索引
'on'
```
