## 📝 关键配置项

### 模型相关
- `baseUrl`: API 服务端点
- `apiKey`: 认证密钥
- `contextWindow`: 上下文窗口大小
- `maxTokens`: 最大输出 token 数

### 通道相关
- `enabled`: 是否启用
- `botToken`: 机器人 Token
- `webhookUrl`: 回调地址

### 技能相关
- `enabled`: 启用的技能列表
- `disabled`: 禁用的技能列表
