## 🔨 自动化内容创作

### 定时生成内容

```json
{
  "crons": {
    "tasks": [
      {
        "id": "weekly-report",
        "schedule": "0 17 * * 5",
        "command": "根据本周工作记录生成周报草稿",
        "channel": "telegram",
        "enabled": true
      },
      {
        "id": "daily-social",
        "schedule": "0 10 * * *",
        "command": "根据行业动态生成 3 条社交媒体内容",
        "channel": "telegram",
        "enabled": true
      }
    ]
  }
}
```

### 内容创作脚本

```javascript
// ~/.openclaw/workspace/skills/content-writer/index.js

module.exports = {
  meta: {
    name: 'content-writer',
    version: '1.0.0'
  },

  config: {
    enabled: true,
    defaultModel: 'qwen3.5-plus',
    styles: {
      formal: '正式、专业语气',
      casual: '轻松、友好语气',
      creative: '富有创意、生动',
      concise: '简洁、直接'
    }
  },

  async execute(context, params) {
    const { type, content, style } = params;
    
    const prompts = {
      'weekly-report': this.getWeeklyReportPrompt(content),
      'email': this.getEmailPrompt(content, style),
      'social': this.getSocialPrompt(content, style),
      'polish': this.getPolishPrompt(content, style)
    };

    const prompt = prompts[type];
    const response = await this.callAI(prompt);
    
    return { content: response };
  },

  getWeeklyReportPrompt(workLog) {
    return `请根据以下工作记录生成周报：

${workLog}

要求：
1. 结构清晰（工作总结、问题、计划）
2. 数据量化成果
3. 专业正式语气
4. 600-800 字`;
  },

  getEmailPrompt(points, style) {
    return `请根据以下要点写邮件：

${points}

要求：
- 语气：${this.config.styles[style] || '正式'}
- 简洁明了
- 包含行动号召`;
  },

  getSocialPrompt(topic, style) {
    return `请写一条社交媒体帖子：

主题：${topic}

要求：
- 语气：${this.config.styles[style] || '轻松'}
- 使用 emoji
- 280 字以内
- 包含话题标签`;
  },

  getPolishPrompt(text, style) {
    return `请润色以下文字：

"${text}"

要求：
- 语气：${this.config.styles[style] || '专业'}
- 增强表达力
- 保持原意`;
  }
};
```
