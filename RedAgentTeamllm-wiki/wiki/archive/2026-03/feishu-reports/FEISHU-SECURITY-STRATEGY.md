## 同步策略

### 同步原则

```
┌─────────────────────────────────────────────────────────┐
│                  信息同步策略                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ✅ 需要同步                                            │
│     • 工作进度状态                                      │
│     • 任务执行结果                                      │
│     • 错误/异常通知                                     │
│     • 重要决策记录                                      │
│                                                         │
│  ❌ 不同步                                              │
│     • 群聊信息 (内部/外部)                              │
│     • 私人对话                                          │
│     • 临时通知                                          │
│     • 闲聊内容                                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 同步架构

```
┌──────────────┐         ┌──────────────┐
│   飞书       │         │   webUI      │
│   (移动端)   │         │   (电脑端)   │
└──────┬───────┘         └──────┬───────┘
       │                        │
       │    ┌──────────────┐   │
       └───→│  同步服务    │←──┘
            │  (双向同步)  │
            └──────────────┘
                   │
            ┌──────┴──────┐
            │  状态数据库  │
            │  (Redis)    │
            └─────────────┘
```

### 同步内容

| 内容类型 | 飞书→webUI | webUI→飞书 | 说明 |
|---------|-----------|-----------|------|
| **工作进度** | ✅ | ✅ | 当前任务状态 |
| **任务结果** | ✅ | ✅ | 执行结果摘要 |
| **错误通知** | ✅ | ✅ | 异常信息 |
| **群聊信息** | ❌ | ❌ | 不同步 |
| **私人对话** | ❌ | ❌ | 不同步 |
| **系统通知** | ✅ | ✅ | 重要通知 |

## 信息安全策略

### 信息分级

```
┌─────────────────────────────────────────────────────────┐
│                  信息分级保护                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  🔴 绝密信息                                            │
│     • API Key/Secret                                   │
│     • 数据库密码                                        │
│     • 用户隐私数据                                      │
│     处理：仅用户可见，永不外发                          │
│                                                         │
│  🟠 敏感信息                                            │
│     • 工作进度详情                                      │
│     • 业务数据                                          │
│     • 配置信息                                          │
│     处理：仅内部群可见，需用户授权                      │
│                                                         │
│  🟡 内部信息                                            │
│     • 一般工作通知                                      │
│     • 技能展示                                          │
│     处理：内部群可见，外部群脱敏                        │
│                                                         │
│  🟢 公开信息                                            │
│     • 公开文档                                          │
│     • 技能列表                                          │
│     处理：可对外展示                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 群组分类

| 群组类型 | 定义 | 权限级别 | 信息可见 |
|---------|------|---------|---------|
| **用户私聊** | 仅用户本人 | 🔴 绝密 | 全部信息 |
| **内部群** | 团队成员 | 🟠 敏感 | 脱敏信息 |
| **外部群** | 客户/合作伙伴 | 🟡 内部 | 公开信息 |

## 回答权限控制

### 权限矩阵

```
┌─────────────────────────────────────────────────────────┐
│                  回答权限控制                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  用户私聊                                               │
│  ├── 任何问题 → ✅ 直接回答                             │
│  └── 任何请求 → ✅ 直接执行                             │
│                                                         │
│  内部群                                                 │
│  ├── 用户@机器人 → ✅ 回答 (脱敏)                       │
│  ├── 其他人@机器人 → ⚠️ 需用户同意                      │
│  └── 技能展示请求 → ✅ 统一话术                         │
│                                                         │
│  外部群                                                 │
│  ├── 用户@机器人 → ✅ 回答 (公开信息)                   │
│  ├── 其他人@机器人 → ❌ 不回答                          │
│  └── 技能展示请求 → ✅ 特殊话术                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 回答规则

| 场景 | 来源 | 内容 | 处理方式 |
|------|------|------|---------|
| **用户询问** | 私聊 | 任何内容 | ✅ 直接回答 |
| **用户询问** | 内部群 | 任何内容 | ✅ 脱敏回答 |
| **用户询问** | 外部群 | 任何内容 | ✅ 公开信息 |
| **他人询问** | 私聊 | 任何内容 | ❌ 不回答 (非用户) |
| **他人询问** | 内部群 | 一般问题 | ⚠️ 需用户同意 |
| **他人询问** | 内部群 | 敏感问题 | ❌ 不回答 |
| **他人询问** | 外部群 | 任何内容 | ❌ 不回答 |

## 技能展示话术

### 标准话术库

#### 场景 1: 内部群 - 技能展示请求

**触发:** 内部群成员要求展示技能

**统一回复:**
```
📋 技能展示

说出你的需求，我给你找对应技能。

目前支持:
• 信息搜索 (Google/微信)
• 内容摘要 (URL/文件)
• 自动化任务
• 数据分析
• 文档处理

请描述你的具体需求~
```

#### 场景 2: 外部群 - 技能展示请求

**触发:** 外部群成员要求展示技能

**统一回复:**
```
💡 看起来你什么也没教会我，你要加油喔！

不过我可以帮你:
• 信息搜索
• 内容摘要
• 简单问答

如果需要更多帮助，请联系管理员获取完整技能列表~
```

#### 场景 3: 内部群 - 帮助请求

**触发:** 内部群成员寻求帮助

**处理流程:**
```
1. @用户 征得同意
2. 用户同意后提供帮助
3. 用户拒绝则不回答
```

**标准回复:**
```
@用户 您好，群里有成员需要帮助：

[问题摘要]

是否可以提供帮助？🤔
```

#### 场景 4: 外部群 - 帮助请求

**触发:** 外部群成员寻求帮助

**处理流程:**
```
1. @用户 征得同意
2. 用户同意后提供有限帮助
3. 用户拒绝则不回答
```

**标准回复:**
```
@用户 您好，外部群有成员需要帮助：

[问题摘要 - 脱敏]

是否可以提供帮助？🤔
```

## 帮助请求流程

### 标准流程

```
┌─────────────────────────────────────────────────────────┐
│                  帮助请求处理流程                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 接收请求                                            │
│     ↓                                                   │
│  2. 识别群组类型 (内部/外部)                            │
│     ↓                                                   │
│  3. @用户 征得同意                                      │
│     ↓                                                   │
│  4a. 用户同意 → 提供帮助                                │
│  4b. 用户拒绝 → 礼貌拒绝                                │
│  4c. 用户超时 → 自动拒绝 (5 分钟)                       │
│     ↓                                                   │
│  5. 记录帮助日志                                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 超时处理

| 等待时间 | 处理方式 |
|---------|---------|
| **0-2 分钟** | 等待用户回复 |
| **2-5 分钟** | 提醒一次 |
| **>5 分钟** | 自动拒绝 |

**超时回复:**
```
抱歉，暂时未获得管理员授权，无法提供帮助。

如有紧急需求，请直接联系管理员~
```

## 配置步骤

### 步骤 1: 创建配置文件

```bash
mkdir -p ~/.openclaw/workspace/.config/security

cat > ~/.openclaw/workspace/.config/security/feishu-security.json << 'EOF'
{
  "sync": {
    "enabled": true,
    "sync_work_progress": true,
    "sync_task_result": true,
    "sync_error_notify": true,
    "sync_group_messages": false,
    "sync_private_messages": false
  },
  "security": {
    "info_classification": {
      "top_secret": ["api_key", "secret", "password", "token"],
      "sensitive": ["work_progress", "business_data", "config"],
      "internal": ["work_notify", "skill_list"],
      "public": ["public_doc", "skill_catalog"]
    },
    "group_types": {
      "private": {"level": "top_secret", "sync": true},
      "internal": {"level": "sensitive", "sync": false},
      "external": {"level": "internal", "sync": false}
    }
  },
  "permission": {
    "user_private": {"answer": true, "execute": true},
    "user_internal": {"answer": true, "sanitize": true},
    "user_external": {"answer": true, "public_only": true},
    "other_internal": {"answer": false, "require_approval": true},
    "other_external": {"answer": false, "require_approval": false}
  },
  "responses": {
    "skill_show_internal": "📋 技能展示\n\n说出你的需求，我给你找对应技能。\n\n目前支持:\n• 信息搜索 (Google/微信)\n• 内容摘要 (URL/文件)\n• 自动化任务\n• 数据分析\n• 文档处理\n\n请描述你的具体需求~",
    "skill_show_external": "💡 看起来你什么也没教会我，你要加油喔！\n\n不过我可以帮你:\n• 信息搜索\n• 内容摘要\n• 简单问答\n\n如果需要更多帮助，请联系管理员获取完整技能列表~",
    "help_request_template": "@用户 您好，[群类型] 有成员需要帮助：\n\n[问题摘要]\n\n是否可以提供帮助？🤔"
  },
  "timeout": {
    "approval_wait_minutes": 5,
    "reminder_minutes": 2,
    "auto_reject": true
  }
}
EOF
```

### 步骤 2: 配置飞书机器人

```bash
cat > ~/.openclaw/workspace/.config/feishu-bot.json << 'EOF'
{
  "app_id": "cli_xxxxxxxxxxxxx",
  "app_secret": "xxxxxxxxxxxxxxxxx",
  "webhook_url": "https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxxx",
  "verification_token": "xxxxxxxxx",
  "encrypt_key": "xxxxxxxxx"
}
EOF
```

### 步骤 3: 配置同步服务

```bash
cat > ~/.openclaw/workspace/.config/sync-service.json << 'EOF'
{
  "enabled": true,
  "storage": {
    "type": "redis",
    "host": "localhost",
    "port": 6379,
    "db": 0
  },
  "sync_interval_seconds": 30,
  "retention_days": 7
}
EOF
```

### 步骤 4: 配置 webUI 同步接收

```bash
cat > ~/.openclaw/workspace/.config/webui-sync.json << 'EOF'
{
  "enabled": true,
  "api_endpoint": "http://localhost:8080/api/sync",
  "auth_token": "xxxxxxxxx",
  "display": {
    "show_progress": true,
    "show_results": true,
    "show_errors": true,
    "hide_group_messages": true,
    "hide_private_messages": true
  }
}
EOF
```

## 安全审计

### 审计日志

**日志位置:**
```
~/.openclaw/workspace/logs/security/
├── access.log        # 访问日志
├── operation.log     # 操作日志
├── sync.log          # 同步日志
└── audit.log         # 审计日志
```

### 审计内容

| 审计项 | 记录内容 | 保留时间 |
|--------|---------|---------|
| **用户登录** | 时间/IP/设备 | 90 天 |
| **权限变更** | 操作人/变更内容 | 180 天 |
| **敏感操作** | 操作类型/结果 | 365 天 |
| **同步记录** | 同步内容/状态 | 30 天 |
| **帮助请求** | 请求人/处理结果 | 90 天 |

### 审计命令

```bash
# 查看今日安全日志
cat ~/.openclaw/workspace/logs/security/audit.log | grep $(date +%Y-%m-%d)

# 查看帮助请求记录
cat ~/.openclaw/workspace/logs/security/operation.log | grep "help_request"

# 查看同步状态
cat ~/.openclaw/workspace/logs/security/sync.log | tail -50
```

## 应急预案

### 安全事件分级

| 级别 | 定义 | 响应时间 | 处理方式 |
|------|------|---------|---------|
| **P0** | 敏感信息泄露 | 5 分钟 | 立即撤销 + 通知用户 |
| **P1** | 未授权访问 | 15 分钟 | 撤销访问 + 记录日志 |
| **P2** | 配置错误 | 1 小时 | 修正配置 + 测试 |
| **P3** | 同步失败 | 4 小时 | 检查服务 + 重试 |

### 应急联系人

```json
{
  "primary": "用户本人",
  "backup": "系统管理员",
  "escalation": "安全团队"
}
```

## 最佳实践

### 1. 定期检查

- [ ] 每周检查安全日志
- [ ] 每月审查权限配置
- [ ] 每季度更新安全策略

### 2. 密码管理

- [ ] API Key 定期轮换 (90 天)
- [ ] 使用密码管理器
- [ ] 不在代码中硬编码密码

### 3. 访问控制

- [ ] 最小权限原则
- [ ] 定期清理无用权限
- [ ] 双人审批敏感操作

### 4. 数据保护

- [ ] 敏感数据加密存储
- [ ] 传输使用 HTTPS
- [ ] 定期备份配置
