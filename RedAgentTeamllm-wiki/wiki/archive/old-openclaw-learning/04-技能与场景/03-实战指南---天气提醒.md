# 实战指南：天气提醒技能配置

**学习时间**: 2026-03-12 10:24
**难度**: ⭐ 简单
**预计时间**: 15 分钟

---

## 🎯 场景描述

每天早上自动查询天气，如果可能下雨则提醒带伞。

---

## 📋 前置条件

- [ ] OpenClaw 已安装
- [ ] 至少一个通道已配置（Telegram/Webchat 等）
- [ ] weather 技能已启用

---

## 🔧 配置步骤

### 步骤 1: 启用 weather 技能

```bash
# 查看技能状态
openclaw skills list

# 启用 weather 技能
openclaw skills enable weather
```

### 步骤 2: 配置定时任务

编辑配置文件，添加 cron 任务：

```json
{
  "crons": {
    "enabled": true,
    "tasks": [
      {
        "id": "daily-weather",
        "schedule": "0 8 * * *",
        "description": "每日天气提醒",
        "command": "查询北京今天天气，如果可能下雨提醒我带伞",
        "channel": "telegram",
        "enabled": true
      }
    ]
  }
}
```

### 步骤 3: 验证配置

```bash
# 验证配置语法
openclaw config --validate

# 手动测试天气查询
openclaw chat "北京今天天气怎么样？需要带伞吗？"
```

### 步骤 4: 重启服务

```bash
openclaw restart
```

---

## 💬 预期效果

每天早上 8 点，你会收到类似消息：

```
🌤️ 北京天气提醒

日期：2026-03-12
天气：多云转小雨
温度：12°C - 18°C
降水概率：70%

☂️ 提醒：今天可能下雨，记得带伞！
```

---

## 🔨 自定义选项

### 修改查询城市

在命令中修改城市名：
```
"查询上海今天天气..."
```

### 修改发送时间

修改 cron 表达式：
- `0 7 * * *` - 早上 7 点
- `0 8 * * *` - 早上 8 点
- `0 9 * * *` - 早上 9 点

### 修改发送通道

```json
"channel": "telegram"  // 或 "webchat", "discord" 等
```

### 添加更多条件

```
"查询北京天气，如果温度低于 10 度提醒我加外套，如果紫外线强提醒防晒"
```

---

## ⚠️ 常见问题

### Q1: 收不到消息
**检查**:
1. 通道是否启用
2. cron 是否启用
3. 查看日志 `openclaw logs`

### Q2: 天气数据不准确
**解决**: weather 技能使用 wttr.in 或 Open-Meteo，可尝试：
```
openclaw chat "用 searxng 搜索北京天气"
```

### Q3: 想手动查询
**方法**: 直接发送消息
```
"今天天气怎么样？"
```
