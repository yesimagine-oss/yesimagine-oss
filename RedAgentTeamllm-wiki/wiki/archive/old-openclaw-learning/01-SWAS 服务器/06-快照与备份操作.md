## 📸 快照概述

### 什么是快照

快照是服务器在某一时刻的完整状态拷贝，包括：
- 系统盘数据
- 已安装的应用
- 配置文件
- 用户数据

### 快照用途

| 用途 | 说明 |
|------|------|
| 数据备份 | 定期备份重要数据 |
| 系统恢复 | 出错后快速恢复 |
| 环境克隆 | 创建相同环境的服务器 |
| 升级前备份 | 重大操作前备份 |

## 🔧 创建快照

### 方法 1: 控制台创建

1. 登录 SWAS 控制台
2. 选择目标服务器
3. 点击「快照」标签
4. 点击「创建快照」
5. 输入快照名称
6. 确认创建

### 方法 2: API 创建

```bash
curl -X POST "https://swas.aliyuncs.com/2020-03-03/CreateSnapshot" \
  -H "Authorization: YOUR_AUTH" \
  -d '{
    "InstanceId": "swas-xxx",
    "SnapshotName": "backup-20260312"
  }'
```

### 创建前准备

```bash
# 1. 停止不必要的服务
openclaw stop

# 2. 清理临时文件
rm -rf /tmp/*
rm -rf ~/.cache/*

# 3. 同步磁盘数据
sync
```

## 🔄 恢复快照

### 方法 1: 恢复系统盘

1. 登录 SWAS 控制台
2. 选择服务器
3. 点击「快照」标签
4. 找到目标快照
5. 点击「恢复」
6. 确认恢复

> ⚠️ 注意：恢复系统盘会覆盖当前系统数据

### 方法 2: 从快照创建新服务器

1. 创建新服务器
2. 选择「从快照创建」
3. 选择目标快照
4. 完成创建

## ⏰ 自动快照策略

### 配置自动快照

1. 登录 SWAS 控制台
2. 选择服务器
3. 点击「自动快照」标签
4. 点击「创建策略」
5. 配置执行时间
6. 设置保留天数
7. 确认创建

### 推荐策略

| 场景 | 频率 | 保留天数 |
|------|------|----------|
| 开发测试 | 每周 1 次 | 7 天 |
| 生产环境 | 每日 1 次 | 14 天 |
| 重要系统 | 每日 2 次 | 30 天 |

### 示例配置

```json
{
  "name": "daily-backup",
  "frequency": "daily",
  "time": "03:00",
  "retentionDays": 14,
  "enabled": true
}
```

## 🤖 备份脚本

### 本地备份脚本

```bash
#!/bin/bash
# ~/scripts/local-backup.sh

BACKUP_DIR=~/backups
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份 OpenClaw 配置
tar -czf $BACKUP_DIR/openclaw-config-$DATE.tar.gz \
  ~/.openclaw/config/

# 备份工作区
tar -czf $BACKUP_DIR/openclaw-workspace-$DATE.tar.gz \
  --exclude='*.log' \
  --exclude='cache/*' \
  ~/.openclaw/workspace/

# 清理 30 天前的备份
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete

echo "备份完成：$DATE"
```

### 远程备份脚本

```bash
#!/bin/bash
# ~/scripts/remote-backup.sh

REMOTE_USER="backup"
REMOTE_HOST="backup-server.com"
REMOTE_DIR="/backups/openclaw"
LOCAL_DIR=~/backups

# 同步到远程服务器
rsync -avz $LOCAL_DIR/ $REMOTE_USER@$REMOTE_HOST:$REMOTE_DIR/

echo "远程备份完成"
```

## 📝 备份最佳实践

### 3-2-1 原则

- **3** 份数据副本
- **2** 种不同介质
- **1** 份异地备份

### 推荐方案

```
本地：SWAS 自动快照（每日）
      ↓
远程：另一台服务器（每周）
      ↓
云端：对象存储 OSS（每月）
```

## ⚠️ 注意事项

1. **快照不是备份替代品**: 应配合其他备份方式
2. **快照有成本**: 定期清理不需要的快照
3. **恢复会覆盖数据**: 恢复前务必备份当前数据
4. **快照创建需要时间**: 大磁盘可能需要数分钟
5. **快照期间性能影响**: 创建快照时 IO 性能可能下降
