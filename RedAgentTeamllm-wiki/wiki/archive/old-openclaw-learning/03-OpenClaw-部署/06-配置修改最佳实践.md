## 📋 配置模式说明

### merge 模式（推荐）

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "YOUR_KEY"
      }
    }
  }
}
```

**特点**:
- ✅ 保留已有配置
- ✅ 只更新指定字段
- ✅ 安全，不易丢失配置

### replace 模式

```json
{
  "models": {
    "mode": "replace",
    "providers": {
      "bailian": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "YOUR_KEY"
      }
    }
  }
}
```

**特点**:
- ⚠️ 完全替换配置
- ⚠️ 可能丢失其他配置
- ⚠️ 仅用于完全重置

## 🔧 安全修改流程

### 步骤 1: 备份当前配置

```bash
# 导出当前配置
openclaw config --export > ~/openclaw-backup-$(date +%Y%m%d).json

# 或手动备份
cp ~/.openclaw/config/models.json ~/.openclaw/config/models.json.bak.$(date +%Y%m%d)
```

### 步骤 2: 查看当前配置

```bash
# 查看完整配置
openclaw config

# 或查看配置文件
cat ~/.openclaw/config/models.json
```

### 步骤 3: 使用 merge 模式修改

```json
// 只修改需要变更的部分
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "apiKey": "NEW_API_KEY"
      }
    }
  }
}
```

### 步骤 4: 验证配置

```bash
# 验证配置语法
openclaw config --validate

# 测试配置
openclaw chat "test"
```

### 步骤 5: 使配置生效

```bash
# 重启服务
openclaw restart

# 或重新加载
openclaw gateway restart
```

## 📝 常见修改场景

### 场景 1: 更换 API Key

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "apiKey": "sk-NEW_KEY"
      }
    }
  }
}
```

### 场景 2: 添加新模型

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "models": [
          {
            "id": "qwen3-max-2026-01-23",
            "name": "qwen3-max-2026-01-23",
            "reasoning": false,
            "input": ["text"],
            "contextWindow": 262144,
            "maxTokens": 65536
          }
        ]
      }
    }
  }
}
```

### 场景 3: 修改默认模型

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "bailian/qwen3-max-2026-01-23"
      }
    }
  }
}
```

### 场景 4: 添加新通道

```json
{
  "channels": {
    "mode": "merge",
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_TOKEN"
    }
  }
}
```

### 场景 5: 启用新技能

```json
{
  "skills": {
    "mode": "merge",
    "enabled": ["weather", "searxng", "new-skill"]
  }
}
```

## ⚠️ 避免覆盖的技巧

### ❌ 错误做法

```json
// 直接替换整个文件
{
  "models": {
    "providers": {
      "bailian": {
        "apiKey": "NEW_KEY"
      }
    }
  }
}
// 这样会丢失其他 providers 和配置
```

### ✅ 正确做法

```json
// 使用 merge 模式
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "apiKey": "NEW_KEY"
      }
    }
  }
}
// 只更新指定字段
```

## 💡 最佳实践

1. **小步修改**: 一次只改一个配置项
2. **及时验证**: 修改后立即测试
3. **保留备份**: 至少保留 3 个历史版本
4. **文档记录**: 记录每次修改内容和原因
5. **使用版本控制**: Git 管理配置文件

