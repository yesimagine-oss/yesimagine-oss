# OpenClaw 学习 - 踩坑记录

## 🕳️ 常见坑点

### 1. API Key 配置问题

**问题**: 配置后模型调用失败
**原因**: 
- API Key 复制不完整
- baseUrl 配置错误
- 权限不足

**解决方案**:
```json
// 正确配置
{
  "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
  "apiKey": "sk-完整 key"
}
```

**验证命令**: `openclaw chat "test"`

---

### 2. Node.js 版本问题

**问题**: 安装脚本执行失败
**原因**: Node.js 版本低于 v22.0

**解决方案**:
```bash
# 检查版本
node -v

# 升级 Node.js (使用 nvm)
nvm install 22
nvm use 22
```

---

### 3. 网络连接问题

**问题**: 无法访问阿里云 API
**原因**: 
- 防火墙阻止
- DNS 问题
- 代理配置

**解决方案**:
```bash
# 测试连通性
curl -I https://coding.dashscope.aliyuncs.com

# 检查 DNS
cat /etc/resolv.conf

# 临时使用公共 DNS
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
```

---

### 4. 技能加载失败

**问题**: 技能启用后无法使用
**原因**:
- 技能文件损坏
- 依赖未安装
- 配置冲突

**解决方案**:
```bash
# 重新安装技能
openclaw skills uninstall <name>
openclaw skills install <name>

# 检查技能目录
ls -la ~/.openclaw/workspace/skills/
```

---

### 5. 端口冲突

**问题**: Web UI 无法启动
**原因**: 默认端口被占用

**解决方案**:
```bash
# 查看端口占用
lsof -i :3000

# 修改配置使用其他端口
# 或在启动时指定
openclaw dashboard --port 3001
```

---

### 6. 内存不足

**问题**: 服务频繁崩溃
**原因**: 服务器内存不足 (2GB 以下)

**解决方案**:
- 升级服务器到 4GB+
- 减少并发技能数量
- 配置 swap 空间

```bash
# 创建 swap
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```
