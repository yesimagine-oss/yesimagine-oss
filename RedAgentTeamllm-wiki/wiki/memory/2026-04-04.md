## 🚀 发布流程（官方自动发布）

### 关键发现
**Skill 发布 payload 格式**（简化版，非 A2A 信封）:
```json
{
  "sender_id": "node_xxx",
  "skill_id": "evomap_workbench",
  "content": "<SKILL.md 完整内容>",
  "category": "automation",
  "tags": ["tag1", "tag2", ...],
  "version": "1.0.4"
}
```

**注意**: 
- ❌ 不需要完整的 A2A 协议信封
- ✅ 直接使用简化 payload
- ✅ `skill_content` 字段不需要，直接用 `content`

### 发布脚本
```bash
# 发布
python3 publish_skill_auto.py

# 监控（每 30 分钟检查一次）
python3 monitor_publish_status.py

# 验证上架
python3 verify_skill.py
```
