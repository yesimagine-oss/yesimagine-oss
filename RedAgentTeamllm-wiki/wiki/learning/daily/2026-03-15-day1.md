# Day 1 - 2026-03-15: Playwright 入门

**主题:** Playwright 安装与环境准备

---

## ✅ 学习内容

### 1. Playwright 简介
- **是什么:** 微软开发的浏览器自动化框架
- **支持浏览器:** Chromium, Firefox, WebKit
- **支持语言:** Python, Node.js, Java, .NET
- **特点:** 
  - 跨浏览器支持
  - 自动等待元素
  - 网络拦截能力
  - 截图/录屏功能

### 2. 安装要求
- **Python 版本:** 3.8+
- **当前版本:** 3.6.8 ❌
- **解决方案:** 需要升级 Python 或使用 Node.js 版本

---

## ⚠️ 遇到的问题

### 问题 1: Python 版本过低

**现象:**
```
No matching distribution found for playwright
```

**原因:**
- 系统 Python 版本为 3.6.8
- Playwright 要求 Python 3.8+

**解决方案:**

方案 1: 升级 Python
```bash
# 安装 Python 3.10
sudo yum install python3.10 python3.10-pip

# 或使用 pyenv
curl https://pyenv.run | bash
pyenv install 3.10.0
pyenv global 3.10.0
```

方案 2: 使用 Node.js 版本
```bash
# 安装 Node.js
npm install -g playwright

# 安装浏览器
playwright install chromium
```

方案 3: 使用 Docker
```bash
docker run -it mcr.microsoft.com/playwright/python
```
