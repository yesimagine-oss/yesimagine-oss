## 🛡️ 服务器安全

### SSH 加固

```bash
# 1. 修改默认端口
Port 2222

# 2. 禁用 root 登录
PermitRootLogin no

# 3. 仅允许密钥登录
PasswordAuthentication no
PubkeyAuthentication yes

# 4. 限制用户
AllowUsers admin openclaw

# 5. 登录超时
ClientAliveInterval 300
ClientAliveCountMax 2
```

### 防火墙配置

```bash
# UFW 配置
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 允许必要端口
sudo ufw allow 2222/tcp  # SSH
sudo ufw allow 443/tcp   # HTTPS (如有)

# 查看状态
sudo ufw status verbose
```

### 入侵检测

```bash
# 安装 Fail2Ban
sudo apt install fail2ban -y

# 配置 SSH 保护
cat > /etc/fail2ban/jail.local << EOF
[sshd]
enabled = true
port = 2222
maxretry = 3
bantime = 3600
EOF

sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

## 📁 数据安全

### 敏感数据加密

```bash
# 使用 age 加密敏感文件
# 安装
sudo apt install age -y

# 生成密钥
age-keygen -o ~/.age/key.txt

# 加密
age -R ~/.age/key.txt -o secrets.enc.json secrets.json

# 解密
age -d -i ~/.age/key.txt secrets.enc.json
```

### 备份加密

```bash
# 加密备份
tar -czf - ~/.openclaw/workspace | \
  age -R ~/.age/key.txt > \
  backup-$(date +%Y%m%d).enc.tar.gz
```

### 安全删除

```bash
# 安全删除文件
shred -u sensitive_file.json

# 或使用
srm -r sensitive_directory/
```

## 🌐 网络安全

### HTTPS 配置

```bash
# 使用 Let's Encrypt 获取证书
sudo apt install certbot -y

sudo certbot certonly --standalone \
  -d your-domain.com \
  --email your@email.com
```

### 反向代理

```nginx
# Nginx 配置
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 📊 安全监控
