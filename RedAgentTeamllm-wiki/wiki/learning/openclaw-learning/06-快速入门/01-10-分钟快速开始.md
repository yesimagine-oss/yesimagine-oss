# OpenClaw 10 分钟快速开始

**学习时间**: 2026-03-12 10:24
**目标**: 最快时间跑通全流程

---

## ⚡ 极速流程

### 第 1 分钟：获取 API Key

1. 访问 https://bailian.console.aliyun.com
2. 登录阿里云账号
3. 进入「API-KEY 管理」
4. 创建新 Key，复制保存

---

### 第 2-3 分钟：安装 OpenClaw

```bash
# macOS / Linux
curl -fsSL https://openclaw.ai/install.sh | bash

# Windows PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

按提示选择：
- Onboarding mode → **QuickStart**
- Model provider → **Skip for now**
- Configure skills → **No**
- Hatch mode → **Hatch in TUI**

---

### 第 4-5 分钟：配置模型

```bash
# 打开 Web UI
openclaw dashboard
```

在 Raw JSON 输入框中粘贴：

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "sk-你的 API_KEY",
        "api": "openai-completions"
      }
    }
  }
}
```

将 `sk-你的 API_KEY` 替换为你的真实 Key。

---

### 第 6-7 分钟：验证配置

```bash
# 检查状态
openclaw status

# 测试对话
openclaw chat "你好，请用一句话介绍你自己"
```

如果收到回复，说明配置成功！

---

### 第 8-9 分钟：启用技能

```bash
# 查看可用技能
openclaw skills list

# 启用常用技能
openclaw skills enable weather
openclaw skills enable searxng
openclaw skills enable qqbot-cron
```

---

### 第 10 分钟：测试功能

```bash
# 测试天气
openclaw chat "北京今天天气怎么样？"

# 测试搜索
openclaw chat "搜索最新的 AI 新闻"

# 设置提醒
openclaw chat "提醒我 30 分钟后喝水"
```
