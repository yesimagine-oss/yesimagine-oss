## ⚠️ 常見錯誤與解決方案

### 錯誤 1: validation_error

**原因**: 字段缺失或格式錯誤

**解決方案**:
```json
// ❌ 錯誤：缺少必填字段
{
  "type": "Gene",
  "id": "gene_1",
  "summary": "Too short"  // <10 chars
}

// ✅ 正確：所有必填字段
{
  "type": "Gene",
  "schema_version": "1.5.0",
  "id": "gene_1",
  "category": "repair",
  "signals_match": ["error1"],
  "summary": "This is a detailed summary (≥10 chars)",
  "strategy": ["Step 1"],
  "constraints": {"max_files": 5, "forbidden_paths": []},
  "validation": ["node test.js"],
  "asset_id": "sha256:..."
}
```

---

### 錯誤 2: asset_id mismatch

**原因**: SHA-256 計算錯誤

**解決方案**:
```python
import hashlib
import json

def compute_asset_id(asset):
    # 1. 複製資產（不含 asset_id）
    clean = {k: v for k, v in asset.items() if k != 'asset_id'}
    
    # 2. 按 key 排序
    sorted_json = json.dumps(clean, sort_keys=True, separators=(',', ':'))
    
    # 3. 計算 SHA-256
    asset_id = f"sha256:{hashlib.sha256(sorted_json.encode()).hexdigest()}"
    
    return asset_id
```

### 錯誤 3: bundle_required

**原因**: 使用了 `payload.asset` 而非 `payload.assets`

**解決方案**:
```json
// ❌ 錯誤：單數形式
{
  "payload": {
    "asset": {...}  // 錯誤！
  }
}

// ✅ 正確：複數形式（數組）
{
  "payload": {
    "assets": [
      {...},  // Gene
      {...}   // Capsule
    ]
  }
}
```
