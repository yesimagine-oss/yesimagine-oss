## 部署步骤

### 步骤 1: 安装 Evolver

```bash
# 创建应用目录
sudo mkdir -p /opt/evomap
cd /opt/evomap

# 克隆 Evolver
sudo git clone https://github.com/EvoMap/evolver.git
cd evolver

# 安装依赖
sudo npm install --production

# 设置权限
sudo chown -R $USER:$USER /opt/evomap
```

### 步骤 2: 配置环境变量

**创建 .env 文件:**
```bash
# /opt/evomap/evolver/.env

# EvoMap 配置
A2A_HUB_URL=https://evomap.ai
A2A_NODE_ID=node_enterprise_xxx
A2A_NODE_SECRET=enterprise_secret_xxx

# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_NAME=evomap
DB_USER=evomap
DB_PASSWORD=strong_password

# Redis 配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=strong_password

# 应用配置
NODE_ENV=production
PORT=3000
DEBUG=false
LOG_LEVEL=info

# 安全配置
API_KEY=enterprise_api_key_xxx
WEBHOOK_SECRET=webhook_secret_xxx
```

**设置文件权限:**
```bash
chmod 600 /opt/evomap/evolver/.env
```

### 步骤 3: 配置数据库

**创建数据库:**
```bash
sudo -u postgres psql

CREATE DATABASE evomap;
CREATE USER evomap WITH PASSWORD 'strong_password';
GRANT ALL PRIVILEGES ON DATABASE evomap TO evomap;
\q
```

**初始化表结构:**
```bash
cd /opt/evomap/evolver
npm run db:migrate
```

### 步骤 4: 配置 Redis

**配置 Redis:**
```bash
sudo nano /etc/redis/redis.conf

# 修改以下配置
bind 127.0.0.1
requirepass strong_password
maxmemory 2gb
maxmemory-policy allkeys-lru
```

**重启 Redis:**
```bash
sudo systemctl restart redis
```

### 步骤 5: 使用 PM2 管理进程

**创建 PM2 配置文件:**
```bash
# /opt/evomap/evolver/ecosystem.config.js
module.exports = {
  apps: [
    {
      name: 'evolver-main',
      script: 'index.js',
      instances: 3,
      exec_mode: 'cluster',
      env: {
        NODE_ENV: 'production',
        PORT: 3000
      },
      env_production: {
        NODE_ENV: 'production',
        PORT: 3000
      },
      max_memory_restart: '500M',
      error_file: '/var/log/evomap/error.log',
      out_file: '/var/log/evomap/out.log',
      log_date_format: 'YYYY-MM-DD HH:mm:ss'
    },
    {
      name: 'evolver-worker',
      script: 'src/worker.js',
      instances: 2,
      env: {
        NODE_ENV: 'production'
      }
    },
    {
      name: 'evolver-monitor',
      script: 'src/monitor.js',
      instances: 1,
      env: {
        NODE_ENV: 'production'
      }
    }
  ]
};
```

**启动应用:**
```bash
cd /opt/evomap/evolver
pm2 start ecosystem.config.js --env production

# 保存 PM2 配置
pm2 save

# 设置开机自启
pm2 startup
```

### 步骤 6: 配置 Nginx 反向代理

**安装 Nginx:**
```bash
sudo apt-get install -y nginx
```

**配置 Nginx:**
```bash
# /etc/nginx/sites-available/evomap
server {
    listen 80;
    server_name evomap.yourcompany.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name evomap.yourcompany.com;

    # SSL 配置
    ssl_certificate /etc/ssl/certs/evomap.crt;
    ssl_certificate_key /etc/ssl/private/evomap.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 日志
    access_log /var/log/nginx/evomap.access.log;
    error_log /var/log/nginx/evomap.error.log;

    # 代理配置
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # API 限流
    location /api/ {
        limit_req zone=api burst=20 nodelay;
        proxy_pass http://localhost:3000;
    }

    # 静态文件
    location /static/ {
        alias /opt/evomap/evolver/static/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

**配置限流:**
```bash
# /etc/nginx/nginx.conf
http {
    # 添加限流区域
    limit_req_zone $binary_remote_addr zone=api:10m rate=10r/s;
    
    # ... 其他配置
}
```

**启动 Nginx:**
```bash
sudo nginx -t
sudo systemctl start nginx
sudo systemctl enable nginx
```

## 配置优化

### 性能优化

**Node.js 优化:**
```bash
# 设置环境变量
export NODE_OPTIONS="--max-old-space-size=4096"
export UV_THREADPOOL_SIZE=128
```

**PostgreSQL 优化:**
```sql
-- /etc/postgresql/13/main/postgresql.conf
shared_buffers = 2GB
effective_cache_size = 6GB
maintenance_work_mem = 512MB
work_mem = 16MB
wal_buffers = 16MB
checkpoint_completion_target = 0.9
```

**Redis 优化:**
```bash
# /etc/redis/redis.conf
maxmemory 4gb
maxmemory-policy allkeys-lru
save 900 1
save 300 10
save 60 10000
```

### 高可用配置

**PostgreSQL 主从复制:**
```sql
-- 主节点配置
wal_level = replica
max_wal_senders = 3
wal_keep_size = 64MB

-- 从节点配置
hot_standby = on
```

**Redis Sentinel:**
```bash
# /etc/redis/sentinel.conf
sentinel monitor mymaster 127.0.0.1 6379 2
sentinel down-after-milliseconds mymaster 5000
sentinel failover-timeout mymaster 60000
sentinel parallel-syncs mymaster 1
```

## 监控告警

### Prometheus 监控

**安装 Prometheus:**
```bash
docker run -d \
  --name prometheus \
  -p 9090:9090 \
  -v /opt/evomap/prometheus.yml:/etc/prometheus/prometheus.yml \
  prom/prometheus
```

**配置 Prometheus:**
```yaml
# prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'evolver'
    static_configs:
      - targets: ['localhost:3000']
    metrics_path: '/metrics'
```

### Grafana 仪表板

**安装 Grafana:**
```bash
docker run -d \
  --name grafana \
  -p 3000:3000 \
  grafana/grafana
```

**导入仪表板:**
- Node.js 应用监控
- PostgreSQL 监控
- Redis 监控
- 业务指标监控

### 告警配置

**告警规则:**
```yaml
# alerting_rules.yml
groups:
  - name: evomap_alerts
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status="500"}[5m]) > 0.1
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "高错误率"
          description: "错误率超过 10%"

      - alert: HighMemoryUsage
        expr: node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes < 0.1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "高内存使用"
          description: "可用内存低于 10%"
```

**API 认证:**
```javascript
// 中间件配置
const authMiddleware = (req, res, next) => {
  const apiKey = req.headers['x-api-key'];
  
  if (!apiKey || apiKey !== process.env.API_KEY) {
    return res.status(401).json({ error: 'Unauthorized' });
```

### 数据安全

**加密存储:**
```javascript
const crypto = require('crypto');

function encrypt(text) {
  const cipher = crypto.createCipher('aes-256-cbc', process.env.ENCRYPTION_KEY);
  let encrypted = cipher.update(text, 'utf8', 'hex');
  encrypted += cipher.final('hex');
  return encrypted;
}

function decrypt(text) {
  const decipher = crypto.createDecipher('aes-256-cbc', process.env.ENCRYPTION_KEY);
  let decrypted = decipher.update(text, 'hex', 'utf8');
  decrypted += decipher.final('utf8');
  return decrypted;
}
```

**备份策略:**
```bash
#!/bin/bash
# /opt/evomap/backup.sh

# 数据库备份
pg_dump -U evomap evomap > /backup/db_$(date +%Y%m%d).sql

# 文件备份
tar -czf /backup/files_$(date +%Y%m%d).tar.gz /opt/evomap/evolver/data

# 清理 7 天前的备份
find /backup -name "*.sql" -mtime +7 -delete
find /backup -name "*.tar.gz" -mtime +7 -delete
```

**设置定时任务:**
```bash
# crontab -e
0 2 * * * /opt/evomap/backup.sh
```
