## 🎯 设计理念分析

### 1. 初衷（Why）

**核心洞察**：
- 知识付费市场规模庞大（2026 年预计超千亿）
- 用户面对海量付费课程难以选择
- 缺乏统一的课程筛选和评估标准
- 学习进度和成效难以追踪

**解决的问题**：
```
用户痛点 → 解决方案
------------------
课程太多不知道选哪个 → 按学习阶段/形式/考核筛选
付费后学习效果无法追踪 → 学习进度/掌握程度分析
名师信息不透明 → 名师履历/课程大纲透明化
互动问答分散 → 统一互动问答状态管理
```

---

### 2. 思维逻辑（How）

**设计思路**：
```
1. 筛选项设计
   ├── 学习阶段（K12/考研/职业考证/兴趣）
   ├── 教学形式（直播课/录播课/1 对 1/题库）
   └── 考核指标（难度等级/通过率/证书含金量）

2. 返回字段设计
   ├── 学习数据（时长/掌握程度/错题本）
   ├── 课程信息（名师/大纲/讲义）
   └── 互动数据（问答/模考/认证）

3. 使用场景
   ├── 快速上手（具体场景任务）
   └── 深度探索（核心功能玩法/优惠信息）
```
