```md
# OpenClaw 节点管理
OpenClaw 采用分布式节点架构，支持多机器、多实例横向扩容。
节点是 OpenClaw 分布式运行的基础单元，所有 Agent 实例、技能插件、任务调度均依托节点完成。

## 节点类型
- 控制节点：全局调度、设备管理、权限校验、配置分发
- 工作节点：承载实际任务执行、Skill 运行、工具调用
- 边缘节点：轻量化部署，适配低配置设备、内网隔离环境

## 节点核心能力
1. 节点注册与自动发现
2. 跨节点任务分发与负载均衡
3. 节点状态心跳上报与健康检测
4. 跨节点资源隔离与权限管控
5. 统一配置同步与版本管理

## 集群运行模式
- 单节点模式：单机独立运行，适合测试、小型部署
- 多节点集群模式：多机联动，生产级大规模负载场景

## 节点联动依赖
所有跨节点通信统一遵循 MCP 互联标准，保证异构设备、不同环境之间互联互通。
```
