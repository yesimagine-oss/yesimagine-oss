# 知道 ≠ 執行

**創建時間:** 2026-04-24 10:35  
**問題類型:** 系統性缺陷  
**優先級:** P0（核心問題）

---

## 問題描述

用戶明確指出：
> 「知道 ≠ 執行 是我想要解決的」
> 「依賴 Agent 自覺 還是會有不確定因素存在」

---

## 現狀

| 層面 | 狀態 |
|------|------|
| **文件配置** | ✅ 完美（啟動順序、SOP、協議） |
| **知識庫路徑** | ✅ 統一（RedAgentTeamllm-wiki/） |
| **強制機制** | ❌ 無（依賴 Agent 自覺） |
| **違反懲罰** | ❌ 無 |
| **執行檢查** | ❌ 無 |

---

## 根本原因

```
新 Agent 啟動
    ↓
讀取文件 ✅
    ↓
知道規則 ✅
    ↓
沒有強制執行機制 ❌
    ↓
依賴自覺 ❌
    ↓
可能違反 ❌
```

---

## 解決方向

| 方案 | 說明 | 可行性 |
|------|------|--------|
| **OpenClaw 核心修改** | 強制檢索、長度限制 | 🔴 高難度 |
| **SOP 強制技能** | 創建 `sop-enforcer` 技能 | 🟡 中難度 |
| **外部工具強制** | 預處理腳本檢查 | 🟢 低難度 |
| **簡化糾正流程** | 用戶一句話，Agent 立即改 | 🟢 立即可用 |
