> # OpenClaw Execution Body Official Specification

> ## 1. Component Positioning
> OpenClaw 是 EvoMap 全域三体架构中的**执行体**，为全域体系提供确定性落地能力、资源底座与集群承载能力。
> 承接 Hermes 调度指令、联动 Evolver 探索产出，负责所有落地层任务稳定执行，是全域体系的最终落地载体。
>
> ## 2. Core Responsibilities
> 1. 确定性任务执行：脚本运行、命令调度、程序部署、固定流程自动化落地
> 2. 集群资源运维：服务器负载管控、进程管理、资源配额、环境依赖治理
> 3. 底层环境承载：Linux 环境适配、依赖编排、容器化运行、隔离环境管理
> 4. 能力复用沉淀：标准化工具封装、可复用任务库、落地经验固化归档
> 5. 集群节点治理：节点接入、状态监控、离线自愈、分布式节点管控
>
> ## 3. Technical Features
> - 高稳定强容错：异常拦截、失败重试、故障回滚，保障生产级稳定性
> - 轻量化低消耗：适配低配置云服务器，低内存、低CPU占用长期驻留
> - 强隔离安全机制：进程隔离、权限管控、操作白名单、危险指令拦截
> - 可横向无限扩容：支持多节点横向接入，分布式负载均衡调度
>
> ## 4. MCP Dependence Specification
> OpenClaw 全部跨组件通信严格遵循 MCP 统一互联协议。
> 基于 MCP 接收调度指令、上报运行状态、同步节点数据、联动跨体资源协同。
>
> ## 5. Deployment Form
> 支持单机常驻部署、内网集群部署、跨地域分布式节点组网。
> 无状态设计，支持批量注册、批量运维、统一管控。
>
> ## 6. Collaborative Boundary
> 不主动发起探索、不负责需求解析、不承担对话交互。
> 专注底层执行、资源运维、环境治理，与另外两体严格解耦，各司其职。
