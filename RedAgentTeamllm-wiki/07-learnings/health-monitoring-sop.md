## 1️⃣ 健康指标体系

### Lint 指标 (技术健康 - 40% 权重)

| 指标 | 计算公式 | 🟢 健康 | 🟡 警告 | 🔴 危险 |
|------|---------|--------|--------|--------|
| **孤页率** | 孤页数/总文件数 | <1% | 1-5% | >5% |
| **矛盾率** | 矛盾对数/总文件数 | 0% | >0% | >3% |
| **过时率** | >90 天未更新数/总文件数 | <10% | 10-30% | >30% |
| **引用错误率** | 死链数/总链接数 | <1% | 1-5% | >5% |

### 运维指标 (运营健康 - 60% 权重)

| 指标 | 频率 | 🟢 健康 | 🟡 警告 | 🔴 危险 |
|------|------|--------|--------|--------|
| **日更新量** | 每日 | ≥30 条 | 20-29 条 | <20 条 |
| **周 Lint 完成率** | 每周 | 100% | 80-99% | <80% |
| **月增长率** | 每月 | ≥30% | 10-29% | <10% |
| **自动化率** | 每月 | ≥80% | 50-79% | <50% |
| **事故转化率** | 每月 | ≥30% | 10-29% | <10% |

### 综合健康分

```
健康分 = (Lint 分 × 40%) + (运维分 × 60%)

等级:
🟢 优秀: 90-100 分
🟡 良好: 75-89 分
🟠 一般: 60-74 分
🔴 警告: <60 分
```

| 类型 | 时间 | 执行内容 | 输出 |

## 3️⃣ 检查流程

### 3.1 自动检查 (脚本执行)

```bash
# 每日简化 Lint
./scripts/auto-lint.sh --mode=daily

# 每周完整 Lint
./scripts/auto-lint.sh --mode=weekly

# 每月深度审计
./scripts/auto-audit.sh
```

### 3.2 手动验证 (报告解读)

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 查看健康分 | 确认总体状态 |
| 2 | 检查🔴危险项 | 立即处理 |
| 3 | 检查🟡警告项 | 列入待办 |
| 4 | 趋势分析 | 对比上周/上月 |
| 5 | 记录异常 | 写入 log.md |

## 4️⃣ 异常分级响应

| 级别 | 定义 | 示例 | 响应时间 | 处理流程 |
|------|------|------|---------|---------|
| **P0** | 系统不可用/数据丢失 | Ingest 失败>24h、备份连续失败 3 天 | 立即 | 自动通知 → 手动介入 → 修复验证 |
| **P1** | 功能降级/指标异常 | 日更新<20 条、健康分<60 | 24 小时 | 自动记录 → 优先处理 → 周报汇总 |
| **P2** | 优化建议/轻微问题 | 孤页率 1-5%、单目录>50 文件 | 周度 | 批量处理 → 月度复盘 |

## 6️⃣ 文件结构优化

### 6.1 层级控制

| 指标 | 目标 | 检查频率 |
|------|------|---------|
| **最大层级** | ≤3 层 | 每月 |
| **单目录文件数** | 20-50 个 | 每月 |
| **查找步骤** | ≤3 步 | 每周 |

### 6.2 优化策略

```
1. 扁平化: 减少嵌套 (wiki/openclaw/gateway-auth.md 优于 wiki/openclaw/gateway/auth/token.md)
2. 标签系统: 添加 tags 快速筛选
3. 多索引: 按场景/类型提供不同入口
4. 定期归档: >3 个月未更新 → archive/
```

### 6.3 目录规范

```
RedAgentTeamllm-wiki/
├── wiki/                    # 知识主体 (≤3 层)
│   ├── openclaw/           # 按领域
│   ├── evomap/
│   └── system/
├── raw/                     # 原始素材 (自动清理)
├── learnings/               # 学习记录 (扁平)
├── reports/                 # 报告 (按月归档)
├── archive/                 # 历史归档 (按月)
└── scripts/                 # 工具脚本
```

## 7️⃣ 持续改进

### 7.1 健康趋势分析

**每月分析:**
- 健康分趋势 (连续 3 月↑/↓/→)
- 指标异常模式 (季节性/周期性)
- 瓶颈识别 (更新量/自动化率/转化率)
