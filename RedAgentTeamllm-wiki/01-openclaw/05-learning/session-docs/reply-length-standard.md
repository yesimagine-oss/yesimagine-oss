# 知識入庫回覆標準

## 長度限制

- **上限:** 20 行
- **目標:** 15-20 行
- **格式:** 表格 + 列表

## 必需章節

1. 入庫資產 (表格)
2. 已驗證事實 (表格/列表)
3. 候選事實 (列表)
4. 入庫位置 (代碼塊)
5. 來源/可信度 (一行)

## 禁止

- 長段落
- 冗餘描述
- 重複信息
