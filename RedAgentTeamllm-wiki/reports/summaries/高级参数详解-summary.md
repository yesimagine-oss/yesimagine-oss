## 📋 参数总览

| 参数 | 类型 | 必填 | 说明 | 默认值 |
|------|------|------|------|--------|
| `q` | string | ✅ | 搜索关键词 | - |
| `gl` | string | ❌ | 国家代码 | `us` |
| `hl` | string | ❌ | 语言代码 | `en` |
| `page` | number | ❌ | 页码 | `1` |
| `num` | number | ❌ | 结果数量 | `10` |
| `autocorrect` | boolean | ❌ | 自动纠正 | `true` |
| `tbs` | string | ❌ | 时间过滤 | - |
| `location` | string | ❌ | 地理位置 | - |
