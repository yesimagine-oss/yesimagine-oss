# WebChat 前端假死事故 - 2026-04-23

**状态:** ✅ 已解决  
**影响:** WebChat 前端无法加载  
**根因:** 1MB 异常会话文件导致前端渲染崩溃  
**解决时长:** ~15 分钟  

---

## 故障现象

| 项目 | 描述 |
|------|------|
| **表现** | 访问 `http://localhost:18789` 页面无响应/假死 |
| **触发** | 前端加载大量会话数据时渲染崩溃 |
| **影响范围** | WebChat 控制台无法使用 |
| **Gateway 状态** | 正常运行 |

---

## 排查过程

### 第一步：全量备份（100% 兜底）
```bash
cp -r ~/.openclaw/agents/main/sessions ~/sessions_full_backup_$(date +%Y%m%d)
```
**目的:** 确保任何操作可回滚

### 第二步：定位异常文件
```bash
cd ~/.openclaw/agents/main/sessions
ls -lhS | head -10
```
**发现:**
| 文件 | 大小 | 类型 |
|------|------|------|
| `sessions.json` | 6.4M | 会话索引（正常） |
| `a19e4b0b...jsonl` | 1MB | 异常会话⚠️ |
| `cd654b64...jsonl` | 534K | 正常 |
| 其他 | <100K | 正常 |

### 第三步：验证会话内容
```bash
head -5 a19e4b0b-4288-43f4-acc1-622324b73129.jsonl
```
**结论:** 文件格式正常，但体积异常（正常应<100KB）

### 第四步：重启测试（排除）
```bash
openclaw gateway restart
```
**结果:** ❌ 无效，确认非临时状态问题

### 第五步：移动异常文件
```bash
mv a19e4b0b-4288-43f4-acc1-622324b73129.jsonl ~/sessions_full_backup_20260423/
openclaw gateway restart
```
**结果:** ✅ WebChat 恢复正常

---

## 根因分析

**直接原因:** 单个会话文件达 1MB，超出前端渲染阈值

**可能来源:**
- 超长对话历史未压缩
- 大量工具调用记录累积
- 会话未正常归档

---

## 解决方案

| 方案 | 风险 | 效果 |
|------|------|------|
| 重启 Gateway | 无 | ❌ 无效 |
| 移动异常会话 | 低（有备份） | ✅ 有效 |
| 清空全部会话 | 高 | ⚠️ 不推荐 |

---

## 经验教训

### ✅ 成功要素
1. **零风险原则** — 先备份再操作，移动不删除
2. **逐步引导** — 每步确认后再继续
3. **实时鼓励** — 保持用户信心
4. **科学定位** — `ls -lhS` 按大小排序找异常
5. **回滚明确** — 备份目录随时可恢复

### 📋 标准操作流程（SOP）
```
1. 备份 → 2. 定位 → 3. 验证 → 4. 测试 → 5. 执行 → 6. 验证
```

### ⚠️ 注意事项
- 不要直接删除，先移动到备份目录
- 确认问题后再重启，避免无效操作
- 保留异常文件用于后续分析
