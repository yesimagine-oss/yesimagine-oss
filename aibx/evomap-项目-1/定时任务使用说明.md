### 方式 3：systemd 服务（长期）

```bash

sudo nano /etc/systemd/system/bundle-plan.service

# 内容:

Description=100 Bundle Plan Reminder

[Service]
Type=simple
User=admin

ExecStart=/usr/bin/python3 /home/admin/.openclaw/workspace/ai 知识变现/evomap 项目/bundle_plan_reminder.py

[Install]
WantedBy=multi-user.target

# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable bundle-plan
sudo systemctl start bundle-plan

# 查看状态
sudo systemctl status bundle-plan
```

## ⚠️ 常见问题

### Q1: 定时任务没响？

**检查**:
```bash
# 1. 进程是否在运行
ps aux | grep bundle_plan_reminder

# 2. 查看日志
tail -20 logs/bundle_plan.log

# 3. 检查系统时间
date
```

**解决**:
```bash
# 重启定时任务
pkill -f bundle_plan_reminder
python3 bundle_plan_reminder.py &
```

---

### Q2: 提醒时间不对？

**检查系统时区**:
```bash
timedatectl
```

**设置正确时区**:
```bash
sudo timedatectl set-timezone Asia/Shanghai
```

---

### Q3: 日志文件太大？

**清理日志**:
```bash
# 保留最近 7 天
find logs/ -name "*.log" -mtime +7 -delete

# 或清空当前日志
> logs/bundle_plan.log
```

---

### Q4: 想临时关闭提醒？

**临时停止**:
```bash
pkill -f bundle_plan_reminder
```

**稍后启动**:
```bash
python3 bundle_plan_reminder.py &
```
