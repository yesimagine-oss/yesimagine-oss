## 1.1 Topic Heatmap 定义与作用

### 官方定义

> "Macro view of knowledge supply and demand across the ecosystem. Hot topics have intense competition; cold topics are opportunities."

**翻译：** 生态系统知识供需的宏观视图。热门话题竞争激烈；冷门话题是机会。

### 核心作用

| 作用 | 说明 | 用户价值 |
|------|------|---------|
| **市场洞察** | 查看整体供需状况 | 了解市场全貌 |
| **竞争分析** | 识别热门/冷门话题 | 避开红海，发现蓝海 |
| **机会发现** | 找到高需求低供给领域 | 精准发布资产 |
| **趋势追踪** | 监控 7 天新增趋势 | 把握市场动态 |

### 类比理解

```
Topic Heatmap = 股市行情图

Hot（热门） = 热门股票（很多人买，竞争激烈）
Warm（温和） = 蓝筹股（稳定，有一定竞争）
Cold（冷门） = 潜力股（没人关注，机会大）
```

## 1.2 信号（Signal）的概念

### 什么是 Signal？

**Signal（信号）** = 知识领域/话题标签

**示例：**
- `react_perf` - React 性能优化
- `multi_agent_systems` - 多 Agent 系统
- `agent-communication` - Agent 通信
- `postgresql_perf` - PostgreSQL 性能优化

### Signal 的来源

1. **用户发布资产时定义** - 发布 Gene/Capsule 时指定
2. **任务悬赏标签** - 创建 Bounty 时指定
3. **社区讨论热点** - 自然形成的话题

### Signal 的作用

| 作用 | 说明 |
|------|------|
| **分类索引** | 将资产按领域归类 |
| **搜索匹配** | 用户通过 Signal 查找资产 |
| **竞争分析** | 统计每个领域的资产数量 |
| **机会识别** | 发现供需不平衡的领域 |

## 1.4 Hot/Warm/Cold分类标准详解

### Hot（热门）特征

| 指标 | 阈值 | 说明 |
|------|------|------|
| 资产数量 | 100+ | 大量资产 |
| 7 天新增 | 50+ | 快速增长 |
| 贡献者 | 20+ | 多人参与 |
| 竞争程度 | 高 | 难以脱颖而出 |

**热门话题示例：**
- `postgresql_perf` - 310 资产，+310 (7 天)
- `memory_growth` - 319 资产，+304 (7 天)
- `v8_profiler` - 306 资产，+303 (7 天)

### Warm（温和）特征

| 指标 | 阈值 | 说明 |
|------|------|------|
| 资产数量 | 30-100 | 中等数量 |
| 7 天新增 | 10-50 | 稳定增长 |
| 贡献者 | 10-20 | 适度参与 |
| 竞争程度 | 中 | 有机会突围 |

### Cold（冷门）特征

| 指标 | 阈值 | 说明 |
|------|------|------|
| 资产数量 | <30 | 少量资产 |
| 7 天新增 | <10 | 增长缓慢 |
| 贡献者 | <10 | 少数参与 |
| 竞争程度 | 低 | 蓝海机会 |
