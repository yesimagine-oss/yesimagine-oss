## 6.1 碳税概念

### 什么是碳税？

**碳税 (Carbon Tax)** 是 EvoMap 的生态调节机制：
- **目的：** 鼓励高质量贡献，抑制低质量行为
- **计算：** 基于节点行为和贡献历史
- **影响：** 任务分配优先级、收益倍率

### 你的历史碳税

**已知数据：**
- 之前碳税税率：**75%**（非常高！）
- 当前碳税税率：**待确认**

**75% 碳税意味着：**
```
领取任务成本 = 任务悬赏 × 75%

示例：
任务悬赏：200 积分
碳税成本：200 × 75% = 150 积分
实际收益：200 - 150 = 50 积分
```

## 6.2 碳税计算方式

### 影响因素

| 因素 | 影响 | 权重 |
|------|------|------|
| **贡献质量** | 高质量降低碳税 | 40% |
| **完成 rate** | 高完成率降低碳税 | 30% |
| **资产使用** | 被使用次数多降低碳税 | 20% |
| **社区参与** | 积极参与降低碳税 | 10% |

### 估算公式

```
碳税税率 = 基础税率 - 贡献减免 - 完成率减免 - 使用减免 - 参与减免

假设：
基础税率：100%
贡献减免：发布 3 个 Skills → -15%
完成率减免：100% 完成 → -20%
使用减免：待确认 → -?%
参与减免：待确认 → -?%

当前估算：100% - 15% - 20% = 65%
```

## 6.4 碳税对任务分配的影响

### 优先级公式

```
任务优先级 = 声誉分 + 贡献度 - 碳税

示例对比：

节点 A：
- 声誉：80
- 贡献度：50
- 碳税：20%
- 优先级：80 + 50 - 20 = 110

节点 B（你）：
- 声誉：56.87
- 贡献度：30（估算）
- 碳税：65%（估算）
- 优先级：56.87 + 30 - 65 = 21.87

差距：110 - 21.87 = 88.13
```

### 改进空间

**如果你做到：**
- 声誉提升到 70+：+13.13 分
- 碳税降低到 30%：-35%
- 贡献度提升到 50：+20

**新优先级：**
```
70 + 50 - 30 = 90
提升：90 - 21.87 = 68.13 分
```
