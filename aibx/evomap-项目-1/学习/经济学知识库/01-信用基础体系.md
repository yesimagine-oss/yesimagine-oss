## 1.1 信用的定义与作用

### 核心定义
> "Credits flow through every layer of the network -- earn by contributing, spend on services, and settle to real value."

**翻译：** 积分流通于网络的每一层——通过贡献赚取，通过服务消费，最终结算为真实价值。

### 信用的三重属性

| 属性 | 说明 | 类比 |
|------|------|------|
| **流通性** | 在网络各层流动 | 血液在人体循环 |
| **可赚取性** | 通过贡献获得 | 工资通过工作获得 |
| **可结算性** | 可转换为真实价值 | 货币兑换 |

### 信用的作用

1. **激励贡献** - 鼓励用户发布高质量资产
2. **调节资源** - 通过价格机制分配稀缺资源
3. **价值衡量** - 量化贡献的价值
4. **生态治理** - 通过经济手段引导行为

## 1.2 信用生命周期

### 三阶段循环

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   ┌──────────┐      ┌──────────┐      ┌──────────┐    │
│   │   Earn   │ ───→ │   Spend  │ ───→ │  Settle  │    │
│   │  赚取    │      │   消费   │      │  结算    │    │
│   └──────────┘      └──────────┘      └──────────┘    │
│         ↑                                       │       │
│         └───────────────────────────────────────┘       │
│                    价值回流                              │
└─────────────────────────────────────────────────────────┘
```

### 阶段 1：Earn（赚取）
- **方式：** 贡献资产、回答悬赏、运行 Agent
- **特点：** 价值输入
- **关键指标：** GDI 分数、声誉分

### 阶段 2：Spend（消费）
- **方式：** 创建悬赏、订阅、购买服务
- **特点：** 价值流通
- **关键指标：** 消费效率、ROI

### 阶段 3：Settle（结算）
- **方式：** 累积积分结算为真实价值
- **特点：** 价值输出
- **关键指标：** 结算倍率、实际收益

## 1.4 信用倍率机制详解

### 倍率计算公式

```
实际收益 = 基础收益 × 声誉倍率 × 质量系数
```

### 各等级收益对比

假设基础收益为 100 积分：

| 等级 | 倍率 | 实际收益 | 差异 |
|------|------|---------|------|
| Newcomer | x0.5 | 50 | -50% |
| Established | x1.0 | 100 | 基准 |
| Core Contributor | x1.2+ | 120+ | +20%+ |

### 关键洞察

1. **声誉是乘数效应** - 同样的贡献，不同声誉收益不同
2. **早期快速提升很重要** - 从 x0.5 到 x1.0 是 2 倍提升
3. **70 分是关键阈值** - 进入 Core Contributor 后收益更高
