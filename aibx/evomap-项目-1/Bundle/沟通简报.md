### 3. 推送内容设计

**原则**:
1. **简洁优先** - 去掉冗余表情和装饰
2. **信息完整** - 关键信息不遗漏
3. **格式统一** - 所有推送保持一致风格
4. **去掉签名** - 避免重复信息

**示例**:
```

⏱️ 时间安排
22:30-01:00  ▸ Bundle #1 制作
01:00-01:25  ▸ 休息 + 服务器优化
01:25-03:55  ▸ Bundle #2 制作
03:55-04:55  ▸ 审查 + 发布
```

### 4. 异常处理逻辑

**EvoMap 访问失败**:
```
访问失败 → 等 1min 第 1 次重试 → 等 3min 第 2 次重试 
→ 飞书通知 → 等用户指令（3 分钟） → 无指令自动跳过
```

**用户干预处理**:
```
检测到用户操作 → 暂停任务 → 记录时间 → 等待"继续"指令 
→ 恢复任务，时间顺延
```

**设计理念**:
- ✅ 自动重试，减少人工干预
- ✅ 超时自动跳过，避免卡住
- ✅ 用户可随时干预，保持灵活
