## 2. Solution

### 2.1 Weight Formula

```
Final Score = (Relevance × 0.5) + (Diversity × 0.3) + (Novelty × 0.2) + Random Factor (±5%)
```

| Component | Weight | Description |
|-----------|--------|-------------|
| Relevance | 50% | User-product match score |
| Diversity | 30% | Category/brand variety |
| Novelty | 20% | New/unseen products |
| Random | ±5% | Controlled randomness |

### 2.2 Pseudo-Random Algorithm

```python
import hashlib

def pseudo_random_seed(user_id, product_id, date):
    """Generate deterministic random seed"""
    key = f"{user_id}:{product_id}:{date}"
    hash_value = hashlib.sha256(key.encode()).hexdigest()
    return int(hash_value[:8], 16) / 0xFFFFFFFF
```

**Benefits:**
- ✅ Reproducible (same user sees same "random" products)
- ✅ Fair exposure (all products get chance)
- ✅ Controlled randomness (not pure chaos)

## 3. Implementation

### Core Algorithm

```python
class RandomWeightedRecommender:
    def __init__(self, diversity=0.3, novelty=0.2):
        self.diversity = diversity
        self.novelty = novelty
        self.relevance = 1.0 - diversity - novelty
    
    def calculate_final_score(self, user_id, product, history):
        relevance = self.get_relevance(user_id, product)
        diversity = self.get_diversity(history, product)
        novelty = self.get_novelty(user_id, product)
        random_factor = self.pseudo_random_factor(user_id, product['id'])
        
        return (relevance * self.relevance + 
                diversity * self.diversity + 
                novelty * self.novelty + 
                random_factor)
    
    def recommend(self, user_id, candidates, history, k=10):
        scored = [(p, self.calculate_final_score(user_id, p, history)) 
                  for p in candidates]
        scored.sort(key=lambda x: x[1], reverse=True)
        return [p for p, s in scored[:k]]
```

## 7. Troubleshooting

### CTR drops after implementation

**Fix:**
1. Reduce random factor to ±5%
2. Increase relevance weight to 0.5-0.7
3. A/B test with smaller treatment group (10%)

### Long-tail not getting exposure

**Fix:**
1. Increase novelty weight to 0.3
2. Add "new product" boost (+0.2 for <7 days)
3. Ensure minimum exposure (1 long-tail per 10 recs)
