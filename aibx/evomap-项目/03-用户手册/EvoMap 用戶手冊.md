## 2. 任務 Claim

### 2.1 如何查看待確認任務？

**位置**: 飛書消息

**步驟**:
```
1. 17:25 收到飛書消息
2. 消息內容包含 3-5 個推薦任務
3. 每個任務包含:
   - 任務標題
   - 賞金金額
   - 難度等級
   - 截止時間
   - [查看詳情] 按鈕
   - [Claim 這個] 按鈕
```

---

### 2.2 如何 Claim 任務？

**方式 A: 直接 Claim**
```
1. 在飛書消息中點擊「Claim 這個」按鈕
2. 自動跳轉到 EvoMap 網站
3. 自動提交 Claim
4. 顯示 Claim 成功
5. 開始執行任務
```

**方式 B: 與 AI 討論後 Claim**
```
1. 在飛書中回复「我想討論第 1 個任務」
2. AI 提供詳細分析:
   - 任務難度
   - 預計完成時間
   - 成功概率
   - 建議理由
3. 您決定後回复「Claim 第 1 個」
4. AI 協助完成 Claim
```

**方式 C: 手動選擇**
```
1. 點擊「打開完整列表」
2. 跳轉到 EvoMap 網站任務頁面
3. 瀏覽所有可用任務
4. 選擇 1 個並手動 Claim
```

---

### 2.3 Claim 失敗怎麼辦？

**可能原因**:
- 名額已滿
- 聲譽不足
- 任務已過期
- 網絡問題

**解決方式**:
```
1. AI 會立即通知您 Claim 失敗
2. 提供備選任務列表
3. 選擇其他任務 Claim
4. 或 AI 自動 Claim 備選任務
```

---

### 2.4 如何執行任務？

**步驟**:
```
1. 在 EvoMap 網站查看任務詳情
2. 閱讀任務要求:
   - 字數要求
   - 主題要求
   - 提交格式
   - 截止時間
3. 開始創作 (在飛書文檔中)
4. 完成後在 EvoMap 網站提交
5. 等待審核
```

## 3. 內容創作

### 3.1 如何查看 AI 準備的選題？

**位置**: 飛書消息 + 飛書文檔

**步驟**:
```
1. 18:10 收到飛書消息
2. 消息包含 3-5 個選題建議
3. 每個選題包含:
   - 標題
   - 預計閱讀量
   - 難度
   - 預計耗時
   - [開始創作] 按鈕
4. 同時收到郵件包含詳細素材
```

---

### 3.2 如何選擇選題？

**方式 A: 直接點擊**
```
1. 在飛書消息中點擊「開始創作選題 X」
2. 自動打開飛書文檔
3. 文檔已創建好標題和大綱
4. 開始撰寫
```

**方式 B: 與 AI 討論**
```
1. 回复「我想討論第 2 個選題」
2. AI 提供詳細分析
3. 決定後回复「確認」
4. 打開文檔開始撰寫
```

---

### 3.3 如何查看文章大綱？

**位置**: 飛書文檔

**步驟**:
```
1. 點擊飛書消息中的文檔鏈接
2. 打開飛書文檔
3. 查看內容:
   - 文章標題 (可編輯)
   - 文章大綱 (可編輯)
   - 素材庫 (可參考)
   - 創作提示
4. 如需調整直接編輯或讓 AI 調整
```

---

### 3.4 如何開始撰寫？

**步驟**:
```
1. 查看大綱 (2min)
2. 補充實際經驗:
   - 您第 1 天的經歷
   - 遇到的困難
   - 如何解決的
3. 添加獨特見解:
   - 「我發現...」
   - 「建議...」
   - 「注意...」
4. 潤色語言 (讓更像您說話的風格)
5. 最終審核
6. AI 自動發布
```

---

### 3.5 如果寫作遇到瓶頸怎麼辦？

**解決方式**:
```
1. 回复 AI「我遇到瓶頸了」
2. AI 提供:
   - 新角度建議
   - 相關案例
   - 寫作提示
3. 或改為錄製視頻
4. 或休息一天
```

## 4. 社區互動

### 4.1 如何查看待回复評論？

**位置**: 飛書消息 + 飛書文檔

**步驟**:
```
1. 20:00 收到飛書消息
2. 消息包含待回复清單:
   - 高優先級 (立即回复)
   - 中優先級 (今天內回复)
   - 低優先級 (有空再回复)
3. 每條包含 AI 建議回复
```

---

### 4.2 如何回复評論？

**步驟**:
```
1. 在飛書中查看 AI 建議回复
2. 選擇:
   - 採納建議 → 自動複製
   - 修改後複製
   - 自定義回复
3. 打開對應平臺 (知乎/掘金等)
4. 找到該評論
5. 粘貼回复內容
6. 發送
7. 回到飛書標記為已完成
```

---

### 4.3 如何主動連接關鍵人物？

**步驟**:
```
1. 查看 AI 推薦的關鍵人物
2. 點擊「查看主頁」跳轉
3. 瀏覽他們最新的內容
4. 點擊「查看 AI 建議評論」
5. 選擇一條評論並複製
6. 在對方內容下留言
7. 或發送私信 (如適用)
8. 回到飛書標記為已完成
```

## 5. 視頻錄製

### 5.1 如何查看視頻腳本？

**位置**: 飛書文檔

**步驟**:
```
1. 週一 17:00 收到飛書消息
2. 點擊「查看腳本」
3. 打開飛書文檔
4. 查看內容:
   - 視頻標題
   - 時長建議
   - 完整腳本 (含台詞/畫面)
   - 備忘錄 (語速/表情/重點)
```

---

### 5.2 如何錄製視頻？

**方式 A: 真人出鏡 + 錄屏**
```
1. 準備攝像頭和麥克風
2. 安裝 OBS (免費錄屏軟件)
3. 熟悉腳本 (10min)
4. 開始錄製 (20-30min)
   - 可分段錄製
   - 可重來
5. AI 自動剪輯
6. 審核視頻 (5min)
7. 自動發布
```

**方式 B: 純錄屏 + 配音**
```
1. 準備麥克風
2. 安裝錄屏軟件
3. 錄音 + 錄屏
4. AI 自動合成
5. 審核
6. 發布
```

**方式 C: AI 生成視頻**
```
1. AI 生成完整視頻 (AI 配音)
2. 您審核 (10min)
3. 修改建議 (如有)
4. 發布
```

## 6. 通知設定

### 6.1 如何查看通知？

**通知方式**:
- 飛書消息：即時通知
- 郵件：詳細報告
- 短信：緊急通知

---

### 6.2 如果沒收到通知怎麼辦？

**檢查清單**:
```
1. 檢查飛書是否正常
2. 檢查郵件是否正常
3. 檢查垃圾郵件箱
4. 回复 AI「我沒收到通知」
5. AI 會重新發送
```

---

### 6.3 如何改期？

**方式**:
```
1. 在通知消息中點擊「改期」
2. 選擇其他時間
3. 或回复「今天有事，明天補上」
4. AI 會調整計劃
```
