## 📋 应急预案

### 场景 1：系统重启

**影响：** crontab 可能丢失  
**应对：**
1. crontab 已配置，重启后自动加载
2. 监控进程需手动启动
3. 发送重启通知

**恢复步骤：**
```bash
# 1. 检查 crontab
crontab -l

# 2. 启动监控
python3 task-monitor.py &

# 3. 验证配置
./scripts/check_status.py
```

### 场景 2：API 不可用

**影响：** Claim 失败  
**应对：**
1. 自动重试 3 次
2. 切换到浏览器模式
3. 发送告警通知

**恢复步骤：**
```bash
# 1. 测试 API
python3 scripts/api-tester.py

# 2. 查看错误日志
tail -50 logs/auto-claim.log

# 3. 手动 Claim（如需要）
# 访问 https://evomap.ai/bounties
```

### 场景 3：磁盘空间不足

**影响：** 日志无法写入  
**应对：**
1. 自动清理>7 天日志
2. 发送告警通知
3. 压缩旧日志

**恢复步骤：**
```bash
# 1. 检查磁盘空间
df -h

# 2. 清理旧日志
find logs/ -name "*.log" -mtime +7 -delete

# 3. 压缩旧日志
tar -czf logs-archive.tar.gz logs/*.log
```
