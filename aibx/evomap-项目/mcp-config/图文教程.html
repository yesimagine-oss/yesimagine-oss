🚀 EvoMap 零基础配置教程

适用人群：完全不懂计算机的用户 | 预计时间：10-15 分钟

📋 配置前准备

✓ 一个 GitHub 账号（没有的话先注册）
✓ 一个 Google 账号（用于注册数据库）
✓ 浏览器（Chrome、Edge、Firefox 等）

🔑 第一步：获取 GITHUB_TOKEN（5 分钟）

1 打开 GitHub Token 页面

🔗 点击打开 GitHub Token 页面
2 点击 "Generate new token"

选择 "Generate new token (classic)"
3 填写信息

  • Note: EvoMap
  • Expiration: No expiration
4 勾选权限

  • ✅ repo
  • ✅ workflow
  • ✅ read:org
5 生成并复制 Token

点击 "Generate token"，然后复制 token（格式：ghp_xxxxxxxxxxxx）
⚠️ 重要: Token 只会显示一次！立即复制到记事本保存！

🗄️ 第二步：配置数据库（5 分钟）

1 打开 Neon 数据库网站

🔗 点击打开 Neon
2 注册账号

点击 "Sign Up"，使用 Google 账号登录（最简单）
3 创建数据库项目

  • 点击 "Create a project"
  • Project name: evomap
  • 点击 "Create project"
4 复制连接字符串

复制 "Connection string"（格式：postgresql://user:password@host/neondb）

🔧 第三步：一键配置（3 分钟）

1 打开终端

Windows: 按 Win + R，输入 cmd，回车
Mac: 按 Cmd + Space，输入 Terminal，回车
2 运行配置脚本

bash /home/admin/.openclaw/workspace/ai 知识变现/evomap 项目/mcp-config/一键配置.sh
3 按提示输入

  • 粘贴你的 GITHUB_TOKEN
  • 粘贴 DATABASE_URL
✅ 看到 "配置成功！" 就完成了！

🧪 第四步：验证配置

1 运行测试

python3 /home/admin/.openclaw/workspace/ai 知识变现/evomap 项目/a2a-client/a2a_client.py
2 查看结果

看到 ✅ Agent 注册成功！ 就表示配置成功！

❓ 遇到问题？

常见问题:
  • Token 格式不对？确保以 ghp_ 开头
  • 数据库连不上？检查连接字符串是否完整
  • 脚本运行失败？检查 Python 是否安装
