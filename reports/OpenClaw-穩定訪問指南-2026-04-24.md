## 🚀 推薦訪問方式（優先級排序）

### 方式 1：本地直接訪問（最穩定）⭐⭐⭐⭐⭐

**適用場景:** 在服務器本機操作

```
http://127.0.0.1:18789/chat?session=agent%3Amain%3Amain
```

**優點:** 永不失效，不需要 SSH，不需要域名  
**缺點:** 只能在服務器本機使用

---

### 方式 2：局域網 IP 訪問（推薦）⭐⭐⭐⭐

**適用場景:** 同一局域網內的其他設備

```
http://172.19.12.252:18789/chat?session=agent%3Amain%3Amain
```

**檢查當前局域網 IP:**
```bash
hostname -I | awk '{print $1}'
```

**優點:** 穩定，不需要 SSH 隧道  
**缺點:** 只能在同一局域網使用

---

### 方式 3：SSH 隧道（臨時使用）⭐⭐⭐

**適用場景:** 遠程訪問，臨時使用

**一鍵開啟隧道腳本:**
```bash
#!/bin/bash
# 保存為 ~/openclaw-tunnel.sh
ssh -f -N -L 18789:127.0.0.1:18789 admin@47.100.123.45
echo "SSH 隧道已開啟，訪問 http://127.0.0.1:18789"
```

**使用:**
```bash
chmod +x ~/openclaw-tunnel.sh
~/openclaw-tunnel.sh
```

**關閉隧道:**
```bash
pkill -f "ssh.*18789"
```

**優點:** 安全，可遠程訪問  
**缺點:** 需要手動開啟，會斷開

---

### 方式 4：域名訪問（需配置）⭐⭐⭐

**當前域名:** `openclaw.unvw.com`

**檢查域名解析:**
```bash
ping openclaw.unvw.com
# 應該返回 47.100.123.45
```

**如果解析錯誤:**
1. 登錄域名管理後台
2. 修改 A 記錄指向 `47.100.123.45`
3. 等待 DNS 生效（幾分鐘到幾小時）

**訪問地址:**
```
http://openclaw.unvw.com:18789/chat?session=agent%3Amain%3Amain
```

**優點:** 好記，可遠程  
**缺點:** 依賴 DNS，公網 IP 變化時需更新

## 🛠️ 一鍵檢查腳本

創建腳本 `~/check-openclaw.sh`:

```bash
#!/bin/bash
echo "=== OpenClaw 狀態檢查 ==="
echo ""

# 1. 檢查 Gateway 服務
echo "1. Gateway 服務狀態:"
systemctl --user status openclaw-gateway --no-pager | grep -E "Active|Loaded"
echo ""

# 2. 檢查端口監聽
echo "2. 端口監聽:"
netstat -tlnp 2>/dev/null | grep 18789 || echo "端口未監聽"
echo ""

# 3. 檢查本地訪問
echo "3. 本地訪問測試:"
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:18789/ && echo " ✅ 正常" || echo " ❌ 失敗"
echo ""

# 4. 顯示當前 IP
echo "4. 當前局域網 IP:"
hostname -I | awk '{print $1}'
echo ""

# 5. 檢查域名解析
echo "5. 域名解析檢查:"
ping -c 1 openclaw.unvw.com 2>/dev/null | grep "PING" || echo "域名解析失敗"
echo ""

echo "=== 檢查完成 ==="
```

**使用:**
```bash
chmod +x ~/check-openclaw.sh
~/check-openclaw.sh
```

## 🔧 常見問題解決

### 問題 1：Gateway 服務停止

```bash
systemctl --user restart openclaw-gateway
systemctl --user status openclaw-gateway
```

### 問題 2：端口被佔用

```bash
# 查看誰佔用端口
netstat -tlnp | grep 18789

# 殺死進程（謹慎）
kill -9 <PID>

# 重啟 Gateway
systemctl --user restart openclaw-gateway
```

### 問題 3：SSH 隧道斷開

```bash
# 重新開啟
~/openclaw-tunnel.sh

# 或配置自動重連（高級）
```

### 問題 4：域名無法訪問

```bash
# 1. 檢查 DNS
ping openclaw.unvw.com

# 2. 檢查防火牆（阿里雲控制台）
# 確保安全組放行 18789 端口

# 3. 檢查 Gateway 配置
cat ~/.openclaw/openclaw.json | grep -A 5 "gateway"
```
