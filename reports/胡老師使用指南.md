## 🎯 一句話總結

**在家用 MacBook → 開啟隧道 → 訪問本地地址**

---

## 📋 使用步驟

### 步驟 1：開啟 SSH 隧道（每次使用前）

**方法 A：使用腳本（推薦）**

在 MacBook 終端輸入：
```bash
~/openclaw-tunnel.sh
```

看到 `✅ SSH 隧道開啟成功！` 即可。

**方法 B：手動命令（備用）**

```bash
ssh -f -N -L 18789:127.0.0.1:18789 root@47.104.30.181
```

---

### 步驟 2：訪問 OpenClaw

在瀏覽器打開：
```
http://127.0.0.1:18789/chat?session=agent%3Amain%3Amain
```

**建議：加入收藏夾**

---

### 步驟 3：用完關閉（可選）

關閉終端即可，隧道會自動斷開。

或手動關閉：
```bash
pkill -f "ssh.*18789"
```

---

## ❓ 常見問題

### Q1: 腳本說「已經運行中」

**原因:** 隧道已經開啟

**解決:**
```bash
# 關閉現有的
pkill -f "ssh.*18789"

# 重新開啟
~/openclaw-tunnel.sh
```

---

### Q2: 連接失敗/密碼錯誤

**可能原因:**
1. 服務器密碼改了
2. 服務器關機了
3. 網絡問題

**解決:**
```bash
# 測試能否連上服務器
ssh root@47.104.30.181

# 如果能登錄，說明服務器正常
# 然後再運行隧道腳本
```

---

### Q3: 網頁打不開

**檢查:**
```bash
~/check-openclaw.sh
```

**如果顯示服務未運行:**
