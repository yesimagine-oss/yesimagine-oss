### 1. 平台定位

```
飞书 = 字节跳动旗下 AI 工作平台
定位：企业级协作 + AI 集成
核心优势：
- 即时通讯
- 云文档
- 日历会议
- 审批流程
- 开放平台（API 集成）
```

### 2. 开发者生态

```
开放平台：https://open.feishu.cn/
核心能力:
- API 接口（消息/日历/文档/用户等）
- 机器人开发
- 应用创建与发布
```
