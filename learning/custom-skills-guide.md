## 1️⃣ serper - Google Search API 集成

### 📛 名字由来

**名称:** `serper` = **Ser**per.dev API + OpenClaw 技能

**命名逻辑:**
- 直接采用 API 提供商名称 (Serper.dev)
- 简洁易记，一看就知道是搜索功能
- 与竞品技能命名保持一致 (如 `searxng`, `brave-search`)

### 🎯 核心功能

| 功能 | 说明 | 端点 |
|------|------|------|
| **Web 搜索** | Google 网页搜索 | `/search` |
| **图片搜索** | Google 图片搜索 | `/images` |
| **新闻搜索** | Google 新闻搜索 | `/news` |
| **地图搜索** | Google 地图搜索 | `/maps` |
| **地点搜索** | Google 地点搜索 | `/places` |
| **视频搜索** | Google 视频搜索 | `/videos` |
| **购物搜索** | Google 购物搜索 | `/shopping` |
| **学术搜索** | Google 学术搜索 | `/scholar` |
| **专利搜索** | Google 专利搜索 | `/patents` |
| **自动补全** | Google 搜索建议 | `/autocomplete` |

### 🔧 解决的问题

| 问题 | 解决方案 |
|------|---------|
| ❌ 需要实时信息但 AI 知识有截止日期 | ✅ 通过 API 获取最新搜索结果 |
| ❌ 手动搜索效率低 | ✅ 自动化搜索，1-2 秒返回结果 |
| ❌ 搜索结果格式不统一 | ✅ 结构化 JSON 输出 |
| ❌ 多个搜索类型需要多个工具 | ✅ 一个技能覆盖 10 种搜索类型 |
| ❌ 竞品 API 价格昂贵 | ✅ Serper 价格仅为竞品 1/10 |

### 💡 创新性

| 创新点 | 说明 |
|--------|------|
| **10 合 1 设计** | 单个技能集成 10 种搜索类型，业界最多 |
| **生产就绪** | 内置监控告警、缓存、重试机制 |
| **LangChain 集成** | 官方支持 LangChain/CrewAI 框架 |
| **完整知识库** | 15 篇文档 (~128KB)，最详细的技能文档 |
| **监控集成** | Prometheus+Grafana 监控仪表板 |

### ⭐ 亮点

| 亮点 | 说明 |
|------|------|
| **功能最全** | 10 种搜索类型，超过所有竞品 |
| **文档最详细** | 15 篇文档，涵盖 API/部署/监控/竞品分析 |
| **生产就绪** | 包含完整的监控告警和部署指南 |
| **性价比最高** | API 价格仅为 SerpAPI 的 1/10 |
| **响应最快** | 平均 1.76 秒响应时间 |

### ❓ 为什么要自制

| 原因 | 说明 |
|------|------|
| **市场空白** | ClawHub 没有完整的 Google Search API 技能 |
| **成本考虑** | 现有竞品 (SerpAPI) 价格昂贵，Serper 更便宜 |
| **功能需求** | 需要 10 种搜索类型，现有技能功能单一 |
| **生产需求** | 现有技能缺少监控告警和生产部署指南 |
| **学习价值** | 深入研究 API 集成和知识库建设 |

## 2️⃣ clipboard-manager - 剪贴板历史管理

### 📛 名字由来

**名称:** `clipboard-manager` = **Clipboard** (剪贴板) + **Manager** (管理器)

**命名逻辑:**
- 直白描述功能，一看就懂
- 遵循 Unix 工具命名传统 (如 `file-manager`, `password-manager`)
- 便于用户搜索和发现

### 🎯 核心功能

| 功能 | 说明 | 命令 |
|------|------|------|
| **保存剪贴板** | 自动/手动保存剪贴板内容 | `save.py` |
| **查看历史** | 列出所有剪贴板记录 | `list.py` |
| **搜索内容** | 关键词搜索历史记录 | `search.py` |
| **复制内容** | 将历史记录复制到剪贴板 | `copy.py` |
| **智能分类** | 自动检测内容类型 | 自动 |
| **批量导入** | 从文件批量导入 | `save.py --file` |

### 🔧 解决的问题

| 问题 | 解决方案 |
|------|---------|
| ❌ 剪贴板内容被覆盖后无法找回 | ✅ 历史记录永久保存 |
| ❌ 找不到之前复制的内容 | ✅ 关键词搜索功能 |
| ❌ 重复内容无法识别 | ✅ 智能去重 |
| ❌ 内容类型混乱 | ✅ 自动分类 (文本/链接/密码/代码) |
| ❌ 常用片段重复输入 | ✅ 快速复制常用内容 |

### 💡 创新性

| 创新点 | 说明 |
|--------|------|

| **本地优先** | 所有数据本地存储，隐私安全 |
| **快捷键集成** | 支持系统快捷键快速操作 |
| **批量操作** | 支持批量导入导出 |
| **全文搜索** | 支持全文检索历史内容 |

### ⭐ 亮点

| 亮点 | 说明 |
|------|------|
| **隐私安全** | 本地存储，不上传云端 |
| **智能分类** | 自动识别文本/链接/密码/代码 |
| **全文搜索** | 快速找到历史内容 |
| **轻量级** | 单文件数据库，易于备份 |

## 3️⃣ url-shortener - URL 短链接生成

### 📛 名字由来

**名称:** `url-shortener` = **URL** + **Shortener** (缩短器)

**命名逻辑:**
- 行业标准命名 (如 bit.ly, tinyurl.com)
- 清晰表达功能
- 便于国际化理解

### 🎯 核心功能

| 功能 | 说明 | 命令 |
|------|------|------|
| **生成短链接** | 将长 URL 转换为短链接 | `shorten.py` |
| **查看统计** | 查看链接点击统计 | `stats.py` |
| **列出链接** | 管理所有短链接 | `list.py` |
| **删除链接** | 删除不需要的链接 | `delete.py` |
| **自定义别名** | 自定义短链接后缀 | `--alias` |
| **批量生成** | 批量生成短链接 | `--batch` |

### 🔧 解决的问题

| 问题 | 解决方案 |
|------|---------|
| ❌ 长 URL 难以分享 | ✅ 生成简短易记的短链接 |

| ❌ 多个链接难以管理 | ✅ 统一的链接管理界面 |
| ❌ 依赖第三方服务 | ✅ 本地部署，自主控制 |
| ❌ 短链接可能失效 | ✅ 永久有效，自主维护 |
