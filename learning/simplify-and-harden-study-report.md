## 💡 学习要点

### Simplify Pass 关键技术

| 技术 | 说明 | 示例 |
|------|------|------|
| **删除死代码** | 移除未使用的变量/函数 | `const x = 1;` (未使用) |
| **简化条件** | 简化复杂 if 语句 | `if (x === true)` → `if (x)` |
| **提取函数** | 提取重复逻辑 | 重复代码 → 单独函数 |
| **使用内置方法** | 用 API 替代手动实现 | 循环 → map/filter |

### Harden Pass 关键技术

| 技术 | 说明 | 示例 |
|------|------|------|
| **错误处理** | 添加 try-catch | `try { ... } catch (e) { ... }` |
| **输入验证** | 验证参数有效性 | `if (!input) throw Error` |
| **边界检查** | 检查数组/字符串边界 | `if (index < arr.length)` |
| **资源清理** | 确保资源释放 | `finally { close() }` |

### Micro-documentation Pass 关键技术

| 技术 | 说明 | 示例 |
|------|------|------|
| **函数注释** | 说明函数用途 | `/** 计算总和 */` |
| **参数说明** | 说明参数含义 | `@param {number} x` |
| **返回值说明** | 说明返回值 | `@returns {number}` |
| **TODO 标记** | 标记待改进 | `// TODO: 优化性能` |
