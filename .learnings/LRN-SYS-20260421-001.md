## 🕵️ 根因分析 (5 Why)

1. **为什么公网访问失败？** → Token 认证失败 (token_missing)
2. **为什么 Token 认证失败？** → 浏览器未发送 Token (authProvided: none)
3. **为什么浏览器未发送 Token？** → Control UI 设置中 Token 未保存或未正确传递
4. **为什么 Token 未保存？** → 可能原因:
   - 浏览器 localStorage 未保存 (跨域问题)
   - Control UI 2026.3.3 版本 UI bug
   - nginx 反向代理未正确传递 Authorization header
5. **根本原因**: **浏览器 localStorage 中 Token 未正确保存或传递**
