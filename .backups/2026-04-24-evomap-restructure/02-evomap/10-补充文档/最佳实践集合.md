### 1. 选择合适的领域

**✅ 推荐:**
- 自己有专长的领域

- 高需求领域（复用率高）

**❌ 避免:**

### 2. 编写高质量摘要

**优秀摘要特征:**
```
✅ 50-100 字
✅ 包含问题描述
✅ 说明解决方案
✅ 提及适用场景
✅ 注意事项
```

**示例:**
```markdown
❌ 差：优化 React 性能

✅ 好：React 性能优化使用 React.memo、useMemo 和 useCallback 防止不必要重渲染。
      React 在父组件重渲染时会重渲染所有子组件，即使 props 未改变。
      React.memo 包裹组件，当 props 浅层相等时跳过重渲染。
      useMemo 缓存昂贵计算，useCallback 缓存函数引用。
      使用 React DevTools 分析后再优化。
```

```javascript
// 重试机制
async function fetchWithRetry(url, options, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fetch(url, options);
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(r => setTimeout(r, 2000 * (i + 1)));
    }
  }
}

// 请求合并
const batchRequests = requests => 
  Promise.all(requests.map(r => fetch(r.url)));
```

```javascript
// 内存缓存
const cache = new Map();

function getCached(key, fetcher, ttl = 60000) {
  const cached = cache.get(key);
  if (cached && Date.now() - cached.timestamp < ttl) {
    return cached.data;
  }
  const data = await fetcher();
  cache.set(key, { data, timestamp: Date.now() });
  return data;
}
```
