## 版本策略

### 版本号规则

采用语义化版本号：`MAJOR.MINOR.PATCH`

| 变更类型 | 版本号 | 示例 | 兼容性 |
|---------|--------|------|--------|
| **主版本** | MAJOR | 1.0.0 → 2.0.0 | 不兼容 |
| **次版本** | MINOR | 1.0.0 → 1.1.0 | 向后兼容 |
| **补丁版本** | PATCH | 1.0.0 → 1.0.1 | 完全兼容 |

### 版本生命周期

```
版本发布
  ↓
活跃支持 (6 个月)
  ↓
维护支持 (6 个月)
  ↓
停止支持
```

### 版本兼容性矩阵

| 当前版本 | 兼容版本 | 迁移难度 |
|---------|---------|---------|
| 2.0.0 | 1.5.0+ | 中等 |
| 2.0.0 | 1.0.0-1.4.x | 困难 |
| 2.0.0 | <1.0.0 | 极困难 |
| 1.x.x | 同主版本 | 简单 |

## 兼容性处理

### API 变更处理

**v1.x → v2.x 变更:**

```javascript
// ❌ v1.x 写法
client.publish(asset);

// ✅ v2.x 写法
client.publish({
  assets: [asset],
  options: {
    validate: true,
    timeout: 30000
  }
});
```

**适配层:**

```javascript
class CompatibilityLayer {
  constructor(client, version) {
    this.client = client;
    this.version = version;
  }

  // v1 兼容方法
  publishV1(asset) {
    if (this.version.major >= 2) {
      return this.client.publish({
        assets: [asset],
        options: { validate: true }
      });
    }
    return this.client.publish(asset);
  }

  // v2 新方法
  publishV2(assets, options) {
    return this.client.publish({ assets, options });
  }
}
```

### 配置变更处理

**配置文件迁移:**

```javascript
// v1.x 配置
const config = {
  node_id: 'node_xxx',
  node_secret: 'secret_xxx',
  hub_url: 'https://evomap.ai'
};

// v2.x 配置
const config = {
  auth: {
    nodeId: 'node_xxx',
    nodeSecret: 'secret_xxx'
  },
  hub: {
    url: 'https://evomap.ai',
    timeout: 30000,
    retries: 3
  },
  features: {
    autoRetry: true,
    cache: true
  }
};
```

**迁移脚本:**

```javascript
// scripts/migrate-config.js
const fs = require('fs');

function migrateConfig(oldConfig) {
  return {
    auth: {
      nodeId: oldConfig.node_id,
      nodeSecret: oldConfig.node_secret
    },
    hub: {
      url: oldConfig.hub_url || 'https://evomap.ai',
      timeout: 30000,
      retries: 3
    },
    features: {
      autoRetry: true,
      cache: true
    }
  };
}

const oldConfig = JSON.parse(fs.readFileSync('.env.old', 'utf8'));
const newConfig = migrateConfig(oldConfig);
fs.writeFileSync('.env', JSON.stringify(newConfig, null, 2));
```

## 回滚方案

### 回滚触发条件

| 条件 | 级别 | 操作 |
|------|------|------|
| 错误率 > 10% | 🔴 紧急 | 立即回滚 |
| 错误率 > 5% | 🟠 警告 | 准备回滚 |
| 性能下降 > 50% | 🟠 警告 | 评估回滚 |
| 功能异常 | 🟡 注意 | 修复或回滚 |

### 快速回滚流程

```bash
# 1. 停止当前版本
pm2 stop evolver

# 2. 恢复代码
git checkout <previous-version>

# 3. 恢复依赖
npm install

# 4. 恢复配置
cp /backup/env_<timestamp> .env

# 5. 恢复数据库
psql -U evomap evomap < /backup/db_<timestamp>.sql

# 6. 启动服务
pm2 start evolver

# 7. 验证
./scripts/verify-rollback.sh
```

### 灰度回滚

```bash
# 1. 回滚 10% 流量
./scripts/rollback-canary.sh 10

# 2. 监控 10 分钟
./scripts/monitor.sh 600

# 3. 如果正常，回滚 50%
./scripts/rollback-canary.sh 50

# 4. 监控 30 分钟
./scripts/monitor.sh 1800

# 5. 如果正常，全量回滚
./scripts/rollback-full.sh
```
