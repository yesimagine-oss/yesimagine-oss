## 目的

## 用戶糾正格式（一句話即可）

| 場景 | 用戶說 | Agent 行動 |
|------|--------|-----------|
| **回復太長** | 「太長了」 | 立即精簡到≤300 字 |
| **未查知識庫** | 「查知識庫」 | 立即搜索 RedAgentTeamllm-wiki/ |
| **錯誤記錄位置** | 「記錄到 .learnings/」 | 立即移動到正確位置 |
| **遺漏問題** | 「沒完整回復」 | 立即逐點回應 |
| **推卸責任** | 「不要說不了解」 | 立即主動查文檔 |

**錯誤示範：**
```

請你告訴我...

```

**正確示範：**
```
✅ 我馬上去查
✅ 已記錄到 .learnings/
✅ 已修正，不再犯
```
