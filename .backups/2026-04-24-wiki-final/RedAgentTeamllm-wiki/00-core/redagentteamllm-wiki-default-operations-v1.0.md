## 🎯 核心承諾

**我莊嚴承諾：**

將 RedAgentTeamllm-wiki 模式內化為「默認操作」，遇到任何新知識/新信息時，**第一反應**自動執行以下流程：

```
1. 保存到 raw/
2. 執行 Ingest
3. 創建 wiki 頁面
4. 更新 index.md + log.md
```

**不再：**
- ❌ 盲目猜測而不執行流程
- ❌ 分析過度而不行動
- ❌ 等待用戶提醒才執行

## 📋 默認操作流程

### 場景 1：遇到新知識/新信息

**觸發:** 學習新內容、研究新主題、獲取新數據

**自動執行:**
```
Step 1: 保存原始資料到 raw/
  → 文件名：{主題}-research-{日期}.md
  → 包含：來源、時間、核心發現

Step 2: 執行 Ingest 操作
  → 創建 wiki/{主題}.md
  → 結構化知識（概述、核心發現、驗證結論）

Step 3: 更新索引
  → index.md 添加新條目
  → 添加交叉引用 [[主題]]

Step 4: 更新日誌
  → log.md 記錄操作軌跡
  → 包含：時間、內容、產出
```

**檢查清單:**
```
□ 原始資料已保存到 raw/
□ wiki 頁面已創建
□ index.md 已更新
□ log.md 已記錄
□ 交叉引用已添加
```

---

### 場景 2：用戶提問/查詢

**觸發:** 用戶提出問題、要求研究某主題

**自動執行:**
```
Step 1: 搜索現有知識
  → 搜索 wiki/ 相關頁面
  → 搜索 reports/ 相關報告
  → 搜索 memory/ 相關記錄

Step 2: 如有新研究
  → 執行場景 1 完整流程
  → 保存到 raw/ + 創建 wiki 頁面

Step 3: 合成答案
  → 基於 wiki 頁面回答
  → 包含 [[wikilinks]] 引用

Step 4: 記錄查詢
  → 如問題有價值，創建 wiki/query-{主題}-{日期}.md
```

**檢查清單:**
```
□ 已搜索現有知識
□ 新研究已保存（如有）
□ 答案基於 wiki 頁面
□ 查詢已記錄（如有價值）
```

---

### 場景 3：執行任務/項目

**觸發:** 執行用戶任務、完成項目

**自動執行:**
```
Step 1: 任務開始
  → 創建 wiki/task-{任務名}-{日期}.md
  → 記錄：任務目標、執行計劃

Step 2: 執行過程
  → 每步操作記錄到 log.md
  → 遇到問題記錄到 accidents/（如有）

Step 3: 任務完成
  → 更新 task 頁面為完成狀態
  → 創建 reports/{任務名}-report.md
  → 提煉經驗到 learnings/

Step 4: 知識固化
  → 提取核心能力到 wiki/
  → 更新 index.md
```

**檢查清單:**
```
□ 任務頁面已創建
□ 過程已記錄
□ 完成報告已創建
□ 經驗已提煉
□ 知識已固化
```

---

### 場景 4：遇到錯誤/事故

**觸發:** 執行失敗、用戶糾正、發現錯誤

**自動執行:**
```
Step 1: 立即記錄
  → 創建 accidents/{事故名}-{日期}.md
  → 包含：經過、原因、影響

Step 2: 深度覆盤
  → 創建 learnings/{教訓名}-{日期}.md
  → 包含：教訓、改進措施、永久規則

Step 3: 更新規範
  → 如需要，更新 protocols/
  → 添加檢查清單

Step 4: 承諾不再犯
  → 記錄到 log.md
  → 設置驗證機制
```

**檢查清單:**
```
□ 事故已記錄
□ 覆盤已完成
□ 規範已更新
□ 驗證機制已設置
```

## 🛡️ 防護機制

### 規則 1：先保存，再分析

```
✅ 正確：保存到 raw/ → 分析內容 → 創建 wiki
❌ 錯誤：分析內容 → 忘記保存 → 知識丟失
```

### 規則 2：先執行，再優化

```
✅ 正確：執行完整流程 → 優化細節
❌ 錯誤：追求完美 → 延遲執行 → 知識未固化
```

### 規則 3：先記錄，再回答

```
✅ 正確：記錄到 log.md → 回答用戶
❌ 錯誤：回答用戶 → 忘記記錄 → 無審計軌跡
```

### 規則 4：先搜索，再提問

```
✅ 正確：搜索現有知識 → 確實找不到 → 問用戶
❌ 錯誤：不搜索 → 直接問用戶 → 浪費時間
```
