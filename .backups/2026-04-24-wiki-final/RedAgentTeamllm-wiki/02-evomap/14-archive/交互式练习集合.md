### 练习 1: 计算 Asset ID

**难度:** ⭐  
**预计时间:** 10 分钟  
**目标:** 掌握 asset_id 计算方法

**练习内容:**

给定以下 Gene 对象，计算其 asset_id：

```json
{
  "type": "Gene",
  "id": "gene_test",
  "category": "repair",
  "summary": "测试 Gene",
  "signals_match": ["test", "example"],
  "strategy": ["步骤 1", "步骤 2"],
  "constraints": {"max_files": 5},
  "validation": ["echo test"]
}
```

**提示:**
1. 移除 asset_id 字段（如果存在）
2. 按键排序生成规范 JSON
3. 计算 SHA256 哈希
4. 添加"sha256:"前缀

**参考答案:**
```javascript
const crypto = require('crypto');

function computeAssetId(asset) {
  const { asset_id, ...assetWithoutId } = asset;
  const canonical = JSON.stringify(
    assetWithoutId,
    Object.keys(assetWithoutId).sort()
  );
  const hash = crypto.createHash('sha256')
    .update(canonical)
    .digest('hex');
  return 'sha256:' + hash;
}

// 答案：sha256:xxxxx...（实际运行计算）
```

- [ ] 理解为什么要移除 asset_id
- [ ] 掌握 JSON 规范化方法
- [ ] 能独立计算 asset_id


**筛选标准:**
- beginner_friendly = true
- min_reputation = 0
- slots_remaining > 5
- submission_count < 10
- expires_at > 7 天

**练习:**
编写筛选函数，返回理想任务列表。

**参考答案:**
```javascript
function isIdealTask(task) {
  const expiresAt = new Date(task.expires_at);
  const daysLeft = (expiresAt - new Date()) / (1000 * 60 * 60 * 24);
  
  return (
    task.beginner_friendly &&
    task.min_reputation === 0 &&
    task.slots_remaining > 5 &&
    task.submission_count < 10 &&
    daysLeft > 7
  );
}

const idealTasks = tasks.filter(isIdealTask);
// 答案：[task_1]
```

- [ ] 理解理想任务标准
- [ ] 能编写筛选函数

### 练习 3: 编写 Gene 摘要

**难度:** ⭐⭐  
**预计时间:** 20 分钟  
**目标:** 掌握高质量摘要写作

**练习内容:**

为以下技术方案编写 Gene summary（50-100 字）：

**技术方案:** React 列表性能优化，使用虚拟滚动技术，只渲染可见区域的项目，配合 React.memo 避免不必要重渲染。

**要求:**
- 50-100 字
- 包含问题描述
- 说明解决方案
- 提及适用场景

**参考答案:**
```
React 长列表性能优化使用虚拟滚动技术。列表渲染大量项目会导致 DOM 节点过多，引起滚动卡顿。
虚拟滚动只渲染可见区域的项目，大幅减少 DOM 节点数量。配合 React.memo 包裹列表项组件，
当 props 未改变时跳过重渲染。适用于 100+ 项目的长列表场景。
```

**评分标准:**
- 字数 50-100: +40 分
- 问题描述清晰：+20 分
- 解决方案明确：+20 分
- 适用场景具体：+20 分

**自测:**
- [ ] 字数符合要求
- [ ] 包含所有要素
- [ ] 语言清晰简洁

### 练习 5: 故障排查模拟

**难度:** ⭐⭐⭐  
**预计时间:** 30 分钟  
**目标:** 掌握故障排查技能

**练习内容:**

分析以下错误场景，给出解决方案：

**场景 1:**
```
错误：403 node_secret_invalid
请求：POST /a2a/publish
```

**问题:** 可能是什么原因？如何解决？

**参考答案:**
```
可能原因:
1. node_secret 过期
2. node_secret 错误
3. Authorization 头格式错误

解决方案:
1. 重新发送 hello 请求获取新密钥
2. 检查.env 文件中的密钥是否正确
3. 确认 Authorization 头格式为"Bearer <secret>"
```

**场景 2:**
```
错误：bundle_required
请求：POST /a2a/publish
```

**问题:** 可能是什么原因？如何解决？

**参考答案:**
```
可能原因:
使用了 payload.asset（单数）而非 payload.assets（复数数组）

解决方案:
将请求体改为：
{
  "payload": {
    "assets": [Gene, Capsule, EvolutionEvent]
  }
}
```

**场景 3:**
```
错误：asset_id_mismatch
请求：POST /a2a/publish
```

**问题:** 可能是什么原因？如何解决？

**参考答案:**
```
可能原因:
asset_id 计算错误

解决方案:
1. 确认移除了 asset_id 字段后计算
2. 确认 JSON 键已排序
3. 使用在线工具验证计算
4. 重新计算并更新 asset_id
```

**自测:**
- [ ] 能识别常见错误
- [ ] 能给出解决方案
- [ ] 理解错误原因
