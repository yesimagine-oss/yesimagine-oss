## 1️⃣ Web 搜索 (`/search`)

### 基本信息

| 项目 | 说明 |
|------|------|
| **URL** | `https://google.serper.dev/search` |
| **方法** | POST |
| **Content-Type** | `application/json` |
| **认证** | `X-API-KEY` header |

### 请求示例

```bash
curl --request POST \
  --url https://google.serper.dev/search \
  --header 'X-API-KEY: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
  "q": "AI agent platform"
}'
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `q` | string | ✅ | 搜索关键词 | `"q": "AI agent"` |
| `gl` | string | ❌ | 国家代码 | `"gl": "us"` |
| `hl` | string | ❌ | 语言代码 | `"hl": "en"` |
| `page` | number | ❌ | 页码 | `"page": 1` |
| `num` | number | ❌ | 结果数量 | `"num": 10` |
| `autocorrect` | boolean | ❌ | 自动纠正 | `"autocorrect": true` |
| `tbs` | string | ❌ | 时间过滤 | `"tbs": "qdr:y"` |
| `location` | string | ❌ | 地理位置 | `"location": "New York"` |

### 响应示例

```json
{
  "searchParameters": {
    "q": "AI agent platform",
    "type": "search",
    "engine": "google"
  },
  "organic": [
    {
      "title": "EvoMap - AI",
      "link": "https://evomap.ai/",
      "snippet": "EvoMap is the infrastructure for AI self-evolution...",
      "position": 1
    }
  ],
  "peopleAlsoAsk": [...],
  "relatedSearches": [...],
  "credits": 1
}
```

### 响应字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `searchParameters` | object | 搜索参数 |
| `organic` | array | 有机搜索结果 |
| `peopleAlsoAsk` | array | 相关问题 |
| `relatedSearches` | array | 相关搜索 |
| `credits` | number | 消耗的信用点数 |

## ⚠️ 错误处理

### 常见错误代码

| 错误 | 说明 | 解决方案 |
|------|------|---------|
| `401 Unauthorized` | API Key 无效 | 检查 API Key |
| `402 Payment Required` | 信用点数不足 | 充值或等待重置 |
| `400 Bad Request` | 请求参数错误 | 检查参数格式 |
| `429 Too Many Requests` | 请求频率过高 | 降低请求频率 |
| `500 Internal Server Error` | 服务器错误 | 稍后重试 |

### 错误响应示例

```json
{
  "error": "Invalid API key",
  "code": 401
}
```
