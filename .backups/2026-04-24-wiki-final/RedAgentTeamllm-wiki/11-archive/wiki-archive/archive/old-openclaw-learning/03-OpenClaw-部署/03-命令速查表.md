# OpenClaw 命令速查表

**学习时间**: 2026-03-12 10:24
**用途**: 日常操作快速参考

---

## 🚀 安装与更新

```bash
# 一键安装 (macOS/Linux)
curl -fsSL https://openclaw.ai/install.sh | bash

# 一键安装 (Windows PowerShell)
iwr -useb https://openclaw.ai/install.ps1 | iex

# 检查版本
openclaw --version

# 更新 OpenClaw
openclaw update

# 卸载
openclaw uninstall
```

---

## 📊 状态与诊断

```bash
# 查看整体状态
openclaw status

# 查看会话列表
openclaw sessions list

# 查看会话历史
openclaw sessions history <session-key>

# 查看日志
openclaw logs

# 实时日志
openclaw logs --follow

# 查看最近 N 行日志
openclaw logs --tail 100

# 系统健康检查
openclaw healthcheck
```

---

## ⚙️ 配置管理

```bash
# 查看当前配置
openclaw config

# 编辑配置（Web UI）
openclaw dashboard

# 编辑配置（命令行）
openclaw config --edit

# 验证配置
openclaw config --validate

# 重置配置
openclaw config --reset

# 导出配置
openclaw config --export > backup.json

# 导入配置
openclaw config --import backup.json
```

---

## 🤖 模型管理

```bash
# 查看可用模型
openclaw models list

# 设置默认模型
openclaw models default qwen3.5-plus

# 测试模型
openclaw chat "Hello, test"

# 查看模型用量
openclaw models usage
```

---

## 🧩 技能管理

```bash
# 查看已安装技能
openclaw skills list

# 查看技能详情
openclaw skills show <skill-name>

# 启用技能
openclaw skills enable <skill-name>

# 禁用技能
openclaw skills disable <skill-name>

# 安装新技能
openclaw skills install <skill-name>

# 卸载技能
openclaw skills uninstall <skill-name>

# 更新技能
openclaw skills update <skill-name>

# 更新所有技能
openclaw skills update --all

# 搜索 ClawHub 技能
openclaw skills search <keyword>
```

---

## 💬 交互命令

```bash
# 启动对话
openclaw chat

# 发送单条消息
openclaw chat "你好，今天天气怎么样？"

# 语音对话（如有 TTS）
openclaw chat --voice "讲个故事"

# 带文件对话
openclaw chat "分析这个文件" --file ./document.pdf
```

## 🧪 调试命令

```bash
# 详细日志模式
openclaw --verbose

# 清理缓存
openclaw clean --cache

# 重置 workspace
openclaw reset --workspace
```

## 📋 常用组合命令

```bash
# 完整诊断流程
openclaw status && openclaw config --validate && openclaw chat "test"

# 更新全部
openclaw update && openclaw skills update --all && openclaw restart

# 备份配置
openclaw config --export > ~/openclaw-backup-$(date +%Y%m%d).json

# 快速测试模型
openclaw chat "用一句话介绍你自己" --model qwen3.5-plus
```

## 🔐 安全相关

```bash
# 查看 API Key 配置（脱敏）
openclaw config --show-keys

# 轮换 API Key
# 1. 在控制台创建新 Key
# 2. 更新配置
openclaw config --edit

# 清除敏感日志
openclaw clean --logs --days 7
```

---

## 💡 使用技巧

1. **Tab 补全**: 大部分命令支持 Tab 自动补全
2. **--help**: 任何命令加 --help 查看帮助
3. **快捷方式**: `openclaw` 可简写为 `oc`（如配置别名）
4. **环境变量**: 可用 OPENCLAW_* 环境变量覆盖配置

```bash
# 添加别名（~/.bashrc 或 ~/.zshrc）
alias oc='openclaw'
alias oclog='openclaw logs --follow'
```
