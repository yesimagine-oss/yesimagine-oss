## 🎯 产品定位

阿里云百炼是阿里云推出的**大模型服务平台**，提供：
- 模型训练与微调
- 模型推理与部署
- API 调用管理
- 应用开发工具链

---

## 📦 核心服务

### 1. 模型服务
- **通义千问系列**: Qwen3.5-Plus, Qwen3-Max, Qwen-Coder 等
- **第三方模型**: MiniMax, DeepSeek 等
- **专属模型**: Coding Plan（代码开发专用）

### 2. 应用开发
- 可视化应用搭建
- API 快速集成
- 工作流编排

### 3. 资源管理
- API Key 管理
- 用量监控
- 账单查询

## 🔑 Coding Plan 专属服务

Coding Plan 是阿里云面向**代码开发场景**推出的专属模型服务：

| 特性 | 说明 |
|------|------|
|  baseUrl | `https://coding.dashscope.aliyuncs.com/v1` |
| 适用场景 | 代码生成、代码审查、技术问答 |
| 优势 | 针对代码场景优化，性价比高 |
| 计费 | 按 token 计费，具体查看控制台 |
