## 📦 核心技能

### 1. weather - 天气查询
- **功能**: 获取当前天气和预报
- **来源**: wttr.in 或 Open-Meteo
- **无需 API Key**: ✅
- **使用示例**: "北京今天天气怎么样？"

### 2. web_search - 网页搜索
- **功能**: 使用 Brave Search API 搜索
- **需要配置**: BRAVE_API_KEY
- **使用示例**: "搜索最新的 AI 新闻"

### 3. searxng - 隐私搜索
- **功能**: 使用本地 SearXNG 实例搜索
- **无需外部 API**: ✅
- **使用示例**: "搜索 Python 教程"

### 4. browser - 浏览器自动化
- **功能**: 控制浏览器进行页面操作
- **能力**: 导航、点击、输入、截图
- **使用示例**: "打开 GitHub 并搜索 OpenClaw"

### 5. message - 消息发送
- **功能**: 跨平台消息发送
- **支持**: Telegram, Discord, WhatsApp 等
- **使用示例**: "给张三发消息"

### 6. tts - 语音合成
- **功能**: 文本转语音
- **使用示例**: "用语音读这个故事"

### 7. sessions_spawn - 子代理
- **功能**:  spawn 子代理执行任务
- **使用场景**: 长时间任务、并行处理

### 8. healthcheck - 健康检查
- **功能**: 系统安全审计
- **使用场景**: 安全检查、加固建议

## 📋 技能启用命令

```bash
# 查看已安装技能
openclaw skills list

# 启用技能
openclaw skills enable <skill-name>

# 禁用技能
openclaw skills disable <skill-name>

# 安装新技能
openclaw skills install <skill-name>
```
