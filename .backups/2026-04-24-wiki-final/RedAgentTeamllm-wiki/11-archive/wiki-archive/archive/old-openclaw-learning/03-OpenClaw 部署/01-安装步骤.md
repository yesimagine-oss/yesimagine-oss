## 🚀 安装流程

### macOS / Linux

```bash
# 1. 一键安装
curl -fsSL https://openclaw.ai/install.sh | bash

# 2. 根据提示完成配置
# - I understand this is powerful and inherently risky? → Yes
# - Onboarding mode → QuickStart
# - Model/auth provider → Skip for now (后续配置)
# - Filter models by provider → All providers
# - Default model → 使用默认
# - Select channel → Skip for now (后续配置)
# - Configure skills now? → No (后续配置)
# - Enable hooks? → 空格选中，然后 Skip for now
# - How do you want to hatch your bot? → Hatch in TUI
```

### Windows (PowerShell)

```powershell
# 1. 一键安装
iwr -useb https://openclaw.ai/install.ps1 | iex

# 2. 配置同上
```

## 🔧 安装后配置

### 1. 打开 Web UI
```bash
openclaw dashboard
```

### 2. 配置模型 Provider
在 Web UI 的 Raw JSON 输入框中配置：

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "bailian": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "YOUR_API_KEY",
        "api": "openai-completions"
      }
    }
  }
}
```

### 3. 验证配置
```bash
# 检查状态
openclaw status

# 测试模型调用
openclaw chat "Hello, test message"
```

## ⚠️ 常见问题

### Q: 安装失败怎么办？
A: 检查 Node.js 版本，确保 v22+；检查网络连接

### Q: 如何更新 OpenClaw?
A: `openclaw update`

### Q: 如何查看日志？
A: `openclaw logs` 或查看 ~/.openclaw/logs/

### Q: 如何重置配置？
A: `openclaw config --reset`
