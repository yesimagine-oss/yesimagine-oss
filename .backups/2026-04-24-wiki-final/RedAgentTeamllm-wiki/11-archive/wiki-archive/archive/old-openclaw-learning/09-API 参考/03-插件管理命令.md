
## 🔧 插件配置

### 配置文件位置

`~/.openclaw/openclaw.json`

### 插件配置示例

```json
{
  "plugins": {
    "allow": ["dingtalk"],
    "entries": {
      "dingtalk": {
        "enabled": true
      },
      "telegram": {
        "enabled": false
      }
    }
  },
  "channels": {
    "dingtalk": {
      "enabled": true,
      "clientId": "YOUR_DINGTALK_APPKEY",
      "clientSecret": "YOUR_DINGTALK_APPSECRET",
      "robotCode": "YOUR_DINGTALK_APPKEY",
      "dmPolicy": "open",
      "groupPolicy": "open",
      "messageType": "markdown"
    }
  }
}
```

### 配置说明

| 字段 | 说明 |
|------|------|
| `plugins.allow` | 允许使用的插件列表 |
| `plugins.entries` | 各插件的详细配置 |
| `channels` | 通道配置（与插件配合使用） |

## 🚀 钉钉插件完整配置流程

### 步骤 1: 安装插件

```bash
openclaw plugins install @soimy/dingtalk
```

### 步骤 2: 配置插件

编辑 `~/.openclaw/openclaw.json`:

```json
{
  "plugins": {
    "allow": ["dingtalk"],
    "entries": {
      "dingtalk": {
        "enabled": true
      }
    }
  },
  "channels": {
    "dingtalk": {
      "enabled": true,
      "clientId": "YOUR_DINGTALK_APPKEY",
      "clientSecret": "YOUR_DINGTALK_APPSECRET",
      "robotCode": "YOUR_DINGTALK_APPKEY",
      "dmPolicy": "open",
      "groupPolicy": "open",
      "messageType": "markdown"
    }
  }
}
```

### 步骤 3: 重启网关

```bash
openclaw gateway restart
```

### 步骤 4: 验证状态

```bash
openclaw status

# 输出中 Channels 部分应显示:
# DingTalk: ON - OK - configured
```

## ⚙️ 插件配置参数详解

### 钉钉插件参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `clientId` | 钉钉应用 Client ID | 从钉钉开放平台获取 |
| `clientSecret` | 钉钉应用 Client Secret | 从钉钉开放平台获取 |
| `robotCode` | 机器人代码 | 通常与 clientId 相同 |
| `dmPolicy` | 私聊策略 | `open`/`allowlist` |
| `groupPolicy` | 群聊策略 | `open`/`allowlist` |
| `messageType` | 消息类型 | `markdown`/`text` |

### 安全建议

| 场景 | dmPolicy | groupPolicy |
|------|----------|-------------|
| 个人测试 | `open` | `open` |
| 小团队使用 | `allowlist` | `allowlist` |
| 企业生产 | `allowlist` | `allowlist` |

## ⚠️ 常见问题

### Q1: 插件安装失败

**检查**:
```bash
# 检查 npm 是否可用
npm -v

# 检查网络连接
npm view @soimy/dingtalk
```

**解决**:
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
openclaw plugins install @soimy/dingtalk
```

---

### Q2: 插件加载失败

**检查**:
```bash
# 查看插件状态
openclaw plugins list

# 查看日志
openclaw logs --grep plugin
```

**解决**:
```bash
# 重新安装
openclaw plugins uninstall <插件>
openclaw plugins install <插件>

# 重启网关
openclaw gateway restart
```

---

### Q3: 插件配置不生效

**检查**:
```bash
# 验证配置语法
openclaw config --validate

# 查看配置
openclaw config | grep -A 10 plugins
```

**解决**:
- 确认配置格式正确
- 重启网关使配置生效
- 检查插件名称拼写
