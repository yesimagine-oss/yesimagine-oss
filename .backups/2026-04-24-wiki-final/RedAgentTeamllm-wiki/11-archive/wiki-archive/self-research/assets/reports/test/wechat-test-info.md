# 微信采集测试说明

## 测试需求

微信文章采集需要一个**真实有效的微信文章 URL**。

## 获取微信文章 URL 的方法

### 方法 1: 从微信分享获取

1. 打开手机微信
2. 打开任意公众号文章
3. 点击右上角「...」→「复制链接」
4. 粘贴到 goEX 测试

### 方法 2: 从公众号历史文章获取

1. 访问公众号主页
2. 选择任意文章
3. 复制链接地址

### 方法 3: 使用测试 URL 格式

微信文章 URL 格式：
```
https://mp.weixin.qq.com/s/[文章 ID]
```

## 测试命令

```bash
cd /home/admin/.openclaw/workspace/goEX/build
./goEX --wechat "https://mp.weixin.qq.com/s/[文章 ID]"
```

## 预期行为

1. **无需登录**: 直接抓取文章内容
2. **需要登录**: 等待用户登录（最多 5 分钟）
3. **抓取成功**: 保存到 `RedAgentTeamllm-wiki/raw/wechat/`

## 输出文件

```markdown

**作者**: [公众号名称]

[文章正文内容]

```

## 注意事项

1. **链接时效性**: 部分微信文章链接可能有过期时间
2. **反爬机制**: 微信可能限制频繁访问
3. **登录要求**: 部分文章需要微信登录才能查看
4. **代理建议**: 建议使用代理访问（如有）
