# goToken 设计基因

**项目**: goToken Token 缓存优化器  
**版本**: 运行中  
**提取时间**: 2026-04-22  
**基因类型**: 设计思想

---

## 🎯 核心设计理念

### 1. 75% Token 节省原则

**设计思路**:
```
相同问题 → 缓存命中 → 返回答案 (~5ms)
         ↓
    未命中 → API 调用 → 缓存 → 返回
```

**目标**: 重复问题不重复调用 API

**基因编码**: `goToken_design_001`

---

### 2. 精确匹配缓存策略

**缓存键**: 问题原文（精确匹配）

**优点**:
- ✅ 简单可靠
- ✅ 无歧义
- ✅ 易于调试

**缺点**:
- ❌ 相似问题无法命中
- ❌ 需要语义匹配扩展

**基因编码**: `goToken_design_002`

---

### 3. 2 小时缓存 TTL

**设计思路**:
- 太短 → 命中率低
- 太长 → 答案可能过期

**平衡点**: 2 小时

**基因编码**: `goToken_design_003`

---

### 4. 并发限流保护

**限制**: 最多 2 个并发请求

**目的**:
- 防止 API 额度超限
- 保护后端服务

**基因编码**: `goToken_design_004`

---

### 5. 适用场景边界

| 场景 | 适用性 | 说明 |
|------|--------|------|
| 重复问答 | ✅ 非常适合 | 常见问题、固定回复 |
| 模板化内容 | ✅ 非常适合 | 固定格式报告 |
| 实时数据 | ❌ 不适合 | 天气、股价等 |
| 个性化对话 | ❌ 不适合 | 上下文相关回复 |

**基因编码**: `goToken_design_005`
