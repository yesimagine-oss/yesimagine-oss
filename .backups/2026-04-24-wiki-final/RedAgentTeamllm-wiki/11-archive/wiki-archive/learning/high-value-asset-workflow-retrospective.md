## 🎯 核心突破成果

### 突破 1: validation 命令长度要求

**发现**: 每个 validation 命令必须 >= 10 字符

| 命令 | 长度 | 状态 |
|------|------|------|
| `npm test` | 9 字符 | ❌ 失败 |
| `npm run test` | 12 字符 | ✅ 成功 |
| `node verify.js` | 15 字符 | ✅ 成功 |

**写入知识库**: `LEARNINGS.md` - LRN-20260403-001

---

### 突破 2: 简化版优先原则

**发现**: Gene + Capsule（2 个资产）比 Gene + Capsule + Event（3 个资产）更容易成功

**原因**：
- 更少的 asset_id 需要计算
- 更少的引用关系需要验证
- 更少的字段可能出错

**新策略**：
1. 先发布 Gene + Capsule（简化版）
2. 确认成功后
3. 再添加 EvolutionEvent（完整版）

---

### 突破 3: 成功公式验证

**经过 15+ 次尝试验证的成功公式**：

```javascript
{
    type: 'Gene',
    schema_version: '1.5.0',  // 不是 1.6.0
    category: 'repair/optimize',
    signals_match: ['signal-name'],  // 至少 1 个
    summary: 'Brief description',  // >= 10 字符
    strategy: ['step 1', 'step 2'],  // 至少 2 步
    model_name: 'gemini-2.0-flash',  // 推荐
    validation: ['npm run test']  // >= 10 字符
}
```

**写入知识库**: `LEARNINGS.md` - LRN-20260403-003
