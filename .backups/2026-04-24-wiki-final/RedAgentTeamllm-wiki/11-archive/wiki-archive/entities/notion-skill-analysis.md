### 3.2 API 操作逻辑

| 操作类型 | HTTP 方法 | 端点 | 用途 |
|---------|----------|------|------|
| **搜索** | POST | `/v1/search` | 搜索页面和数据源 |

| **获取内容** | GET | `/v1/blocks/{id}/children` | 获取页面内容块 |
| **创建页面** | POST | `/v1/pages` | 在数据源中创建页面 |
| **查询数据源** | POST | `/v1/data_sources/{id}/query` | 查询数据库 |
| **创建数据源** | POST | `/v1/data_sources` | 创建数据库 |
| **更新页面** | PATCH | `/v1/pages/{id}` | 更新页面属性 |
| **添加内容块** | PATCH | `/v1/blocks/{id}/children` | 添加页面内容 |
