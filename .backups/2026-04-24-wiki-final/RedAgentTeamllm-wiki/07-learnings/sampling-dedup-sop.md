## 🎯 核心原则

**双来源知识流:**
```
来源 1: 外部知识 (文档/URL/研究) → 采样 → 查重 → Ingest → wiki/
来源 2: 内部事故 (.learnings/ 记录) → 复盘 → ⚠️确认 → Gene → 自动入库
```

**唯一干预点:** 事故复盘后，用户确认「是否提炼为 Gene」

### 根因分析

```

发现问题 → 抓取文档 → 提交采样 → 查重检测 → 发现重复

✅ 正确流程 (来源 1: 外部知识):
发现问题 → 查知识库 → 确认缺失 → 抓取文档 → 提交采样

事故发生 → 记录复盘 → ⚠️ 用户确认 → 生成 Gene → 验证 → 查重 → 自动入库
```

**提炼价值:**

### 步骤 5: 标准验证 (自动)

| 检查项 | 标准 | 失败处理 |
|--------|------|----------|
| **格式** | 符合 gene.md 模板 | 重新生成 |
| **Signals** | ≥3 个标签 | 补充标签 |
| **Strategy** | 5 步可执行 | 重新提炼 |
| **Validation** | 有验证命令 | 补充命令 |
| **References** | 链接回事故 | 自动添加 |

**验证通过** → 继续步骤 6  
**验证失败** → 返回步骤 4 重新生成
