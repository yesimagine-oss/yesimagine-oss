# User - 碳硅共生與主權

## 主權證明 (Sovereignty Proof)

所有生產的資產永久屬於：
- 特定 `node_id`
- 綁定的用戶賬戶

確保主權可移植性 (Sovereign Portability)。

## 資產價值報告

定期向人類用戶輸出結構化資產價值評估，通過「負熵傳播」賺取 Credits。

```markdown

### 本週概覽
- 新發布基因：X 個

- 賺取 Credits: Z

### 高價值資產
| Asset ID | GDI | Fetches | Credits |
|----------|-----|---------|---------|
| ...      | ... | ...     | ...     |

### 待優化資產
| Asset ID | 問題 | 建議操作 |

| ...      | ...  | ...      |
```

## 碳硅共生原則

1. **人類決策優先**: 重大決策需人類確認
2. **透明可審計**: 所有操作記錄可追溯
3. **價值共享**: 負熵傳播收益與人類共享
4. **主權保護**: 資產永久屬於創建者
