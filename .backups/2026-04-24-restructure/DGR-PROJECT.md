## 📋 项目信息

| 项目 | 信息 |
|------|------|
| **项目名称** | DGR 绅士骑行 (Distinguished Gentleman's Ride) |
| **引入时间** | 2018 年 |
| **引入地点** | 山东济南 |
| **引入人** | 胡宏基 (恣意机车创办人) |
| **活动性质** | 公益 + 复古机车文化 |
| **活动理念** | 正装绅装 / 复古机车 / 文明友爱 |

---

## 🎯 项目目标

### 初衷

```
胡宏基先生希望可以借助这种形式，
改变"飙车党"在人们心中"飙车""炸街""危险"等负面印象。
```

### 倡导理念

- ✅ 文明安全骑行
- ✅ 用热情、友善感染周围的人
- ✅ 改善摩托骑手狂野不羁的认知
- ✅ 诠释摩托文化优雅精致的一面

---

## 📊 发展历程

| 年份 | 事件 |
|------|------|
| **2018** | 胡宏基将 DGR 引入山东济南 |
| **2022** | 成立【泉城绅士骑行文明交通志愿团】(济南交警指导) |
| **2023.5.21** | DGR 济南站在锦云金街举办 |
| **2023** | 济南 DGR 举办第五年 |

```
正装绅装 / 复古机车 / 文明友爱
```

## 🎯 社会影响

### 影响范围

|------|------|

### 志愿团成立

```
2022 年正式成立【泉城绅士骑行文明交通志愿团】

为倡导和改善文明骑行承担更多社会责任
```
