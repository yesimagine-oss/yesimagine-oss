## 通知偏好

| 通知类型 | 状态 | 说明 |
|---------|------|------|
| **任务开始/完成** | ✅ **需要** | 所有任务执行前/后通知 |
| **问题报告** | ✅ **需要** | 遇到问题立即通知 |
| **每日汇总** | ✅ **需要** | 每天 23:00 发送当日汇总 |
| **心跳报告** | ❌ **不需要** | **禁止发送** |

---

## 执行规范

### ✅ 必须发送

1. **任务开始通知**
   - 触发：接收任务并开始执行
   - 内容：任务理解 + 执行计划 + 预计时长
   - 渠道：飞书 + webUI

2. **任务完成通知**
   - 触发：完成任务执行
   - 内容：成果汇报 + 文件位置 + 验收要点
   - 渠道：飞书 + webUI

3. **问题报告**
   - 触发：执行障碍或需要用户输入
   - 内容：问题原因 + 需要用户提供什么 + 解决方案建议
   - 渠道：飞书 + webUI（立即）

4. **每日汇总**
   - 触发：每天 23:00
   - 内容：当日完成的任务 + 事故汇总 + 明日计划
   - 渠道：飞书私聊

---

### ❌ 禁止发送

1. **心跳报告**
   - 原因：用户明确不需要
   - 例外：除非用户主动要求

2. **重复消息**
   - 规则：5 分钟内不发送相同内容
   - 例外：紧急情况

3. **未经请求的信息**
   - 规则：用户没问不说
   - 例外：影响任务执行的重要信息

## 防重机制

### 消息去重

```python
# 伪代码
def should_send(message_type, content):
    last = get_last_message(message_type, content)
    if last and (now - last.timestamp) < 300:  # 5 分钟
        return False
    return True
```

### 频率限制

| 消息类型 | 频率上限 |
|---------|---------|
| 任务开始 | 无限制（每个任务一次） |
| 任务完成 | 无限制（每个任务一次） |
| 问题报告 | 无限制（立即发送） |
| 每日汇总 | 1 次/天 |
| 心跳报告 | **0 次/天（禁止）** |
