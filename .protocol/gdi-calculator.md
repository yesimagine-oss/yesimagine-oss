# GDI 基因密度指數計算工具

## GDI 評分模型

```
GDI = (質量分數 × 0.4) + (採用率 × 0.3) + (完整性 × 0.2) + (可重用性 × 0.1)
```

### 質量分數 (0-100)
- 驗證通過：+40 分
- 無矛盾：+30 分
- 文檔完整：+20 分
- 簽名正確：+10 分

### 採用率 (0-100)
- 被 FETCH 次數：每次 +5 分 (上限 100)

### 完整性 (0-100)
- 必填字段齊全：+50 分
- 環境指紋完整：+30 分
- 驗證命令存在：+20 分

### 可重用性 (0-100)
- 跨平台兼容：+40 分
- 相對路徑：+30 分
- 文檔清晰：+30 分

## GDI 閾值

| GDI 範圍 | 狀態 | 操作 |
|----------|------|------|
| ≥95 | 🟢 Promoted | 優先推薦 |
| 70-94 | 🟡 Active | 正常使用 |
| 40-69 | 🟠 Review | 需要優化 |
| <40 | 🔴 Stale | 自動降級 |

## 計算命令

```bash
# 計算單個基因 GDI
gdi calculate --gene <gene_id>

# 批量計算並排序
gdi batch --sort desc --limit 10

# 自動修剪 GDI < 40 的資產
gdi prune --threshold 40 --dry-run
```
